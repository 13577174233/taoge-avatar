# 医学通识 · 判断清单

> 打印出来贴冰箱。每条都是「什么情况下不能做 / 必须就医」。

- [ ] **医学的本质是科学手段加仁慈** —— 单靠态度不能替代诊疗；出现呼吸困难、意识改变、剧烈胸痛、大量出血等急症信号，先就医，不是先沟通。
- [ ] **好医生看长远利益与生命质量** —— 这类「少做」的判断必须在术中依实际所见由主刀医生做出并说明理由；患者与家属不可据此自行拒绝已经明确必要的手术。
- [ ] **循证医学三要素是可迁移的解题套路** —— 「患者意愿」不等于可以自选任何治疗；意愿要在医学可行范围内表达，超出范围的诉求需要医生讲清风险，而不是照办。
- [ ] **就诊前把问题写下来，三分钟当六十分钟用** —— 记录不能替代就医判断；出现剧烈胸痛、呼吸困难、意识改变、大量出血、持续高热，直接急诊，不要先整理资料。
- [ ] **医学保的不是物种延续，是个体不被淘汰** —— 这是观念澄清，不涉及处置；但由此推出的「资源该不该花在弱者身上」属于伦理与政策问题，不能拿本条件当结论。
- [ ] **活着是第一层，为此常规可以让路** —— 这是 ICU 内的经验性处置，必须在有监护与抢救条件的医院由医生决策；任何人在家中都不可能、也不可以照做。意识障碍、昏迷一律立即送医。
- [ ] **尊严是第二层：不疼、能听、能走都是治疗目标** —— 镇痛药与精神类药物必须由医生开具与调整，不可自行加量或停药；出现呼吸变慢、意识模糊、跌倒、明显嗜睡，立即就医。
- [ ] **患者的选择优先于医生认为的最优** —— 这类「顺着患者」的方案风险显著更高，必须建立在反复告知、书面记录、随时可转回标准方案的基础上；一旦生命体征恶化，立刻转回救命优先。
- [ ] **感觉正常不等于没病** —— 不明原因消瘦、持续出血、固定部位疼痛超过数周、吞咽困难、便血，即使不难受也要就诊。
- [ ] **健康与疾病是连续谱，没有清晰界线** —— 出现活动后胸闷胸痛、休息可缓解，或静息胸痛持续十几分钟不缓解，立即就医或呼叫急救，不要在家观察。
- [ ] **疾病源自三类进化不完美** —— 代谢类疾病的监测与用药不能因「基因决定」而放弃；已确诊高血压、糖尿病者不可自行停药。
- [ ] **疾病有进化价值，但证据只在感染领域** —— 「别太干净」不等于吃未洗净的食物、不洗手；婴幼儿、老人、免疫抑制者的食品安全与手卫生不能放松。疫苗后发热倦怠是常见反应，但高热不退、精神差、呼吸困难需就医。
- [ ] **治愈靠自我修复，医疗只是支持** —— 这条不能推出「治疗不重要」；该用药、该手术时拒绝，等于拆掉支持系统，自我修复也撑不住。
- [ ] **自我修复被掐断，最强的医疗也无用** —— 任何药物过量都立即急诊，不要等症状出现；药名、剂量、服药时间要如实告知医生，隐瞒会直接改变抢救方案。
- [ ] **ICU 的顶级设备都是「支持」，不是「替代」** —— 上不上机器、何时撤机由医生依病情判断；家属可以参与目标讨论，但不能自行要求上或撤 ECMO 等生命支持。
- [ ] **同样的药，免疫状态不同结局不同** —— 免疫抑制者发热（即使不到高热）就是危险信号，须立即就医并主动说明免疫状态；不可自行观察或自行吃抗生素。
- [ ] **免疫治疗的本质是把自我修复重新打开** —— 免疫治疗可能带来免疫相关不良反应；出现新发气促、持续腹泻、黄疸、皮疹、明显乏力，立即告知医生，不可自行停药或加量。
- [ ] **科学与人文不是此消彼长** —— 不能以「人文」为名降低技术标准，也不能以「科学」为名省略告知与同意。
- [ ] **真科学要算整体，不能只把指标做正常** —— 「考虑整体」不能成为延迟必要处置的理由；急性期先稳定，非急性期再谈体验与流程。
- [ ] **真人文要有科学基础，态度不是唯一标准** —— 不能用「科学会解决」来回避当下的告知、镇痛与心理支持；两者要同时给。
- [ ] **体制层面的安排决定多少人享受到医学** —— 政策覆盖不等于治好保证；纳入医保的药仍须按适应证由医生评估，不可自行购买使用。
- [ ] **医疗不是消费** —— 这一条不改变患者权利：有权知情、有权复印病历、有权投诉与鉴定。「不是消费」不等于「不能追责」。
- [ ] **治疗像过河：只能定方向，不能定结果** —— 预后不确定不等于可以不做准备；该问的风险、替代方案、最坏情况仍要问清。
- [ ] **联盟的三个属性** —— 换医生是权利，但要带走完整病历与影像资料，避免重复检查与治疗中断；急症期不宜中途更换。
- [ ] **患者不是被动接受者，医学进步靠患者贡献** —— 参加试验或接受未成熟技术，必须书面知情同意，明确退出机制与损害救治方案；被劝说「为医学做贡献」时，先问清风险与替代方案。
- [ ] **共同决策：医生给立场，患者给信任** —— 「我相信你」不能替代知情同意；家属必须知道最坏结果与替代方案。患者无法表达时，代理人决定要留书面记录。
- [ ] **进化只做平衡，不做最优** —— 阅读障碍儿童需要专业评估与干预，不是靠「长大就好」；持续腰背痛、视物变形、突发视力下降需就医。
- [ ] **身体按旧环境设计，环境一变优势成风险** —— 不能用「基因决定」解释并放弃干预；血压、血糖已达诊断标准者需规范治疗，不可自行停药。
- [ ] **需求超出能力，压力落在旧硬件上** —— 持续失眠伴情绪低落、兴趣丧失、明显体重变化，需专业评估，不要只靠「调整心态」；胸痛、突发肢体无力立即就医。
- [ ] **学原理而不是背病名** —— 懂原理不等于会看病；出现具体症状仍需就医，不能用原理自行诊断。
- [ ] **病从「外来的鬼」变成「人体内部的事」** —— 出现精神行为异常、抽搐，须精神科/神经科评估，不可用驱邪、排毒替代；延误可能造成不可逆损害。
- [ ] **无所不能的学说，无法积累知识** —— 出现呼吸困难、意识改变、大量失血，必须立即接受现代医学救治；不可用放血、拔罐替代急救。
- [ ] **找病因＝部位＋机制＋致病因子** —— 不明原因发热、消瘦、出血，需系统检查，不要自我归因。
- [ ] **找到病原不等于找到病因，要靠干预验证** —— 疫情期间的防护（戴口罩、洗手、隔离）应在溯源完成前就执行，不能等「确定元凶」。
- [ ] **一切病因都有病理基础（但「病」的标签本身会错）** —— 持续两周以上的情绪低落、兴趣丧失、睡眠与食欲改变，应看精神科或心理科；不可自行按「多巴胺不足」买药。
- [ ] **症状是保护，不是敌人** —— 突发口角歪斜、单侧肢体无力、言语不清，立即呼叫急救；高热伴意识改变、抽搐、呼吸困难，立即就医。
- [ ] **盲目干预症状可能加重病情** —— 贫血必须先查原因；感染期自行服用铁剂可能加重感染；孕妇补铁按产检结果由医生决定，不可自行买来吃。
- [ ] **骨刺不是病，是症状** —— 出现下肢麻木无力、大小便功能障碍、夜间静息痛、进行性跛行，须尽快就诊，不能当「骨刺正常现象」。
- [ ] **原发性高血压更像症状，但仍必须服药** —— 已确诊高血压者不可自行停药、减药或换药，即使血压已正常（那是药物在起作用）；出现血压骤升伴剧烈头痛、胸痛、视物模糊、肢体无力，立即急诊。
- [ ] **只在「过度」时干预症状** —— 3 个月以下婴儿发热、任何年龄发热伴意识改变/抽搐/呼吸困难/皮疹压之不褪色，立即就医。
- [ ] **慢病是突然发现的，不是突然发生的** —— 进行性吞咽困难、便血、不明原因消瘦、持续上腹疼痛，直接就诊检查，不要等常规筛查。
- [ ] **代偿：用没坏的部分顶上去** —— 代偿期的「指标正常」不等于病好了；已确诊慢病者必须按计划复查，不能以「我没感觉」为由停药或停复查。
- [ ] **有代偿的人，首发心梗反而更「安全」** —— 年轻人突发胸痛、胸闷伴出汗、恶心，即使表现不典型也要立即就医；不能因为「我年轻、平时没病」而等待。
- [ ] **主动筛查能降死亡率，「不知道最好」是错的** —— 筛查有假阳性与过度诊断，阳性结果需进一步检查确认，不等于确诊；出现报警症状不能靠筛查替代就诊。
- [ ] **三条打法：源头预防、阻断环节、放大代偿** —— 「放大代偿」的运动必须在医生指导下进行；不稳定心绞痛、未控制的高血压、心衰急性期不可自行加量；运动中出现胸痛、气促、头晕立即停止并就医。
- [ ] **细菌不是敌人，是共生体** —— 免疫抑制者、留置导管者、粒细胞缺乏者出现发热需立即就医，不能套用「细菌是朋友」而忽视感染信号。
- [ ] **细菌反哺人体三条路** —— 情绪持续低落、兴趣丧失超过两周，或出现自伤念头，须立即寻求精神科帮助，不能只靠「调菌群」。
- [ ] **致病的关键是「菌跑错地方」和「屏障破了」** —— 发热、腹泻伴脱水、阴道分泌物异常增多伴瘙痒，需就医明确病原；不要自行用洗液冲洗或自行吃抗生素、抗真菌药。
- [ ] **少用抗生素，别主动攻击常驻菌** —— 医生开具的抗生素必须按疗程足量用完，不可因「怕破坏菌群」自行减量、停药或换药；出现皮疹、腹泻、呼吸困难立即停药就医。
- [ ] **纤维多、糖少、别太干净** —— 增加纤维要渐进并足量饮水，突然大量摄入可致腹胀、便秘加重；肠梗阻、消化道术后患者禁用高纤维饮食。剖腹产有医学指征时（胎位异常、胎儿窘迫等）必须剖，不能为「菌群」冒险。
- [ ] **没有免疫，医学也无能为力** —— 免疫低下者（化疗中、移植后、长期用激素或免疫抑制剂）出现发热、口腔溃疡、持续腹泻、呼吸急促，按急症就医，不要在家观察等待。
- [ ] **免疫致病只有三条路径** —— 不明原因的多器官同时受累（皮疹、关节痛、蛋白尿、血细胞减少并存）应尽快到风湿免疫科就诊，不要当"上火"或"太累"自行调理。
- [ ] **过敏是识别错误，不是免疫力高低** —— 出现呼吸困难、喉头发紧、声音嘶哑、全身大片荨麻疹伴头晕，立即急诊；医生已开的抗过敏药不可自行停药或换药。
- [ ] **提升免疫只有三条路，没有捷径产品** —— 接种后出现呼吸困难、全身荨麻疹、高热持续不退，立即就医；感染后出现持续高热、精神萎靡、呼吸急促、尿量明显减少，不要当作"锻炼免疫"扛过去，须就医。
- [ ] **隔离能保命，但不产生健康** —— 家中若有免疫缺陷患者，任何"多接触环境增强体质"的建议都不适用，须遵医嘱做保护性隔离；患者发热按急症处理。
- [ ] **诊断是假设与验证的循环** —— 循环有截止点。出现意识改变、呼吸困难、大出血、持续胸痛，先抢救再诊断，不要为了"查清楚"而延迟处置。
- [ ] **假设的质量决定走多少弯路** —— 右上腹持续剧痛伴发热、寒战、皮肤或眼白发黄、反复呕吐，按急症就医，不要按"胃病"自行服药观察。
- [ ] **证据不符就换假设，不是丢证据** —— 如果你已经按某个诊断治疗一段时间却不见好转，要求复诊而不是自行加药；症状加重、出现新部位疼痛或发热，须重新就诊评估。
- [ ] **反常疑点就是突破口** —— 反常指标合并意识改变、呼吸循环不稳时，先按急症处理；不要为了解释一个反常值反复复查而延迟处置。
- [ ] **信息不等价，先剔除干扰信息** —— 筛选信息不等于隐瞒信息。正在服用的所有药物（含中药、保健品）、过敏史、既往手术史必须完整告知，这几项属于不可省的证据。
- [ ] **先定目标，再选手段** —— 白斑短期内迅速扩大，或伴乏力、怕冷、心悸、体重变化，须就诊排查；任何外用药（含氢醌类）须医生指导，不可自行长期涂抹，也不可自行停药换成偏方。
- [ ] **患者需求决定目标，没有唯一最优解** —— 封闭只是临时掩盖疼痛，药效过后疼痛加重或出现行走困难、局部红肿发热，须复诊；原文未给封闭的禁忌与并发症，涉及激素注射不可自行重复进行。
- [ ] **用可量化的医学目标逼近主观需求** —— 以"变美""要孩子"为目标的操作同样有适应症与并发症，须在正规机构完成评估；术后出现发热、持续疼痛、植入部位红肿渗液，须及时就诊。
- [ ] **需求与目标的冲突会被技术推移，但仍有边界** —— 子宫移植属重大手术，移植后妊娠属高危妊娠，须在有条件的中心全程管理；出现腹痛、阴道出血、发热须立即就诊。原文未给风险与失败率，不可据此认为该路径普遍可行。
- [ ] **指南是覆盖常见病全流程的标准方案** —— 急危重症不能先查指南再动手。遇到心脏骤停、窒息、大出血，按已训练过的流程立即施救，同时呼叫急救。
- [ ] **指南是地板，不是天花板** —— 按压过程中患者恢复自主呼吸或意识，应停止按压并评估；不规范按压会造成肋骨骨折等损伤，但不应因此不敢压——原文强调"先尽力救命"。任何施救都必须同时呼叫急救。
- [ ] **指南以证据为基础，证据更新它就迭代** —— 如果发现自己在用的是多年前的方案（尤其是急救、抗感染、肿瘤治疗），主动问一句"现在有更新吗"；但不可自行按网上查到的新版指南改药，用药调整须医生执行。
- [ ] **指南留白处，靠临床判断** —— 这是院内场景。目击者遇到有人倒地无反应、无正常呼吸，立即呼叫急救并开始按压，不要等"判断清楚"；不要给无意识者喂水喂药。
- [ ] **药是医学解决方案的物质载体** —— 医生开的药不可自行停药、换药或加量；出现皮疹、呼吸困难、面部肿胀、持续腹泻，立即停药并就医；同时服用多种药物（含中药、保健品）时，主动告知医生和药师。
- [ ] **认知越精细，药的精度越高** —— 靶向药同样需要监测不良反应与疗效，不可因"副作用小"就自行加量；抗肿瘤药不可自行停药或换药，漏服、停药须与主管医生确认。出现发热、皮疹、气促、明显乏力须及时就诊。
- [ ] **认知错了，好药也能杀人** —— 孕期与哺乳期不要自行使用任何药物（含外用药、中成药）；用药后出现皮疹、水肿、呼吸困难、异常出血，立即就医。正在使用沙利度胺等有致畸风险药物者，不可自行停药或换药，须由医生调整并严格避孕。
- [ ] **监管保合格，认知保安全有效** —— 不要因为"国家批准的合格药"就认为可以自行购买服用；处方药须凭处方，用药期间出现任何新症状都应告知医生。长期用药者不可自行停药，尤其是降压、降糖、抗癫痫、抗排异、激素类药物。
- [ ] **疑难病靠网络，不靠单个专家** —— 复杂手术的风险与获益必须由专科团队评估；出现肢体无力加重、呼吸困难、大小便功能障碍，按急症就医，不要等"排到专家号"。
- [ ] **集中比上门高效** —— 不要为了"效率"推迟急症就医；出现胸痛、意识改变、大出血、呼吸困难，直接去急诊或呼叫急救，不要先挂普通门诊排队。
- [ ] **医院让信息流动并留存** —— 就诊时如实提供既往病历与影像资料，不要因为"换了医院"就重做全部检查；对药物过敏史、输血史、手术史必须完整告知。
- [ ] **分级诊疗的本质是分工协作** —— 出现胸痛、意识障碍、大出血、呼吸困难、剧烈腹痛，直接急诊，不要按"基层首诊"的流程排队等转诊。
- [ ] **公共卫生是政府主导的群体预防** —— 公共卫生措施不替代看病。出现发热、疼痛、出血、消瘦等症状仍须就诊，不要因为"已经打了疫苗/注意卫生"就延迟就医。
- [ ] **效益滞后，所以必须靠制度而非自觉** —— 不要把"风险降低 9%"读成"刷牙能防心脏病"；出现胸痛、心悸、活动后气促，按心脏病就诊，不要靠加强刷牙解决。
- [ ] **群体保护有门槛，个体风险要让位** —— 接种后按要求留观，出现呼吸困难、全身荨麻疹、面色苍白、意识不清立即就医；发热超过 38.5℃ 持续不退或注射部位红肿扩大须就诊。已开始的疫苗接种程序不可自行中断。
- [ ] **治病的代价远大于预防** —— 甲状腺功能异常者不要自行停用或改用含碘盐、不要自行补碘或限碘，须由医生结合检查决定；出现颈部肿块、心悸、怕热多汗、体重明显下降，及时就诊。
- [ ] **癌症是六个环节依次失守** —— 出现不明原因体重下降、持续疼痛、异常出血（咳血、便血、绝经后出血）、可触及的肿块、伤口久不愈合，尽早就诊，不要用"我生活方式很健康"来解释掉。
- [ ] **第一环：图纸错了** —— 基因检测报告出现"突变"字样不等于确诊癌症，须由专科医生结合病理判断；不要据一份基因报告自行购药或停药。
- [ ] **第二环：自检失效** —— 确诊肿瘤后是否做基因检测、检测结果如何解读，须由专科团队决定；不可根据一份报告自行选择或放弃治疗。
- [ ] **第三环：自带加油枪** —— 影像报告写"血供丰富/强化明显"不等于恶性，须由医生结合其它特征判断；不要据此自行决定手术或观察。
- [ ] **第四环：骗过警察** —— 确诊肿瘤后是否适合免疫治疗，须做相应检测由医生判断；免疫治疗相关的不良反应（皮疹、腹泻、甲状腺功能异常、肺炎）可能延迟出现，用药期间出现持续腹泻、气促、乏力须及时报告医生。不可自行停药或换药。
- [ ] **六环对应六类治疗** —— 癌症治疗必须在肿瘤专科完成，任何"替代疗法"都不能替代规范治疗；治疗期间出现发热（尤其伴中性粒细胞降低）、持续呕吐腹泻、出血、呼吸困难，须立即就医；不可自行停药、减量或换药。
- [ ] **最大的突变来源是随机错误** —— 不要用"反正是随机的"来解释症状或放弃筛查——出现警示症状仍须就医，筛查仍然有效（见 A4、A5）。
- [ ] **年龄是最强的风险因素** —— 年龄大不等于必然得癌，也不等于不用查；出现不明原因消瘦、持续疼痛、异常出血，按症状就医，不要归因于"年纪大了"。
- [ ] **生命本身就是一种癌前状态** —— 长期被"人人都会得癌"的念头困扰、影响睡眠与体检决策时，应就诊心理科或与主诊医生讨论，不要靠反复自查缓解。
- [ ] **突变只是一环，四成癌症可预防** —— 乙肝、丙肝、幽门螺旋杆菌、HPV 感染的治疗须由专科医生执行，不可自行购药；根除治疗后有复查要求，不可自行停药。
- [ ] **筛查要在癌前阶段切断** —— 出现便血或黑便、排便习惯改变持续两周以上、不明原因消瘦或贫血，直接就诊做诊断性检查，不要等年度筛查。肠镜属侵入性检查，有穿孔、出血风险，须在有条件的机构由医生评估后进行。
- [ ] **与癌共存：控制数量而非清零** —— 不能以"共存"为理由拒绝或中断规范治疗；治疗期间出现新发疼痛、体重快速下降、发热，须复诊评估。任何调整都须由肿瘤专科医生决定，不可自行停药或换药。
- [ ] **冠心病是全身动脉病的一个爆发点** —— 胸痛呈压榨感、持续不缓解，伴大汗、恶心、放射到左肩或下颌，立即呼叫急救，不要自行驾车去医院，也不要等"忍一忍看看"。
- [ ] **冠脉细不是本质问题** —— 有吸烟、高血压、高血脂、糖尿病、肥胖中任意两项者，出现活动后胸闷、气短、胸痛，尽早就诊做心脏评估，不要归因于"年纪大了"。
- [ ] **支架不降低稳定性心绞痛的风险** —— 稳定性心绞痛患者若胸痛发作变频繁、程度加重、静息时也发作、含服硝酸甘油不能缓解，提示转为不稳定，须立即急诊，不要等到预约复诊。任何药物不可自行停药或换药。
- [ ] **根本治疗是生活方式加四类基础药** —— 这四类药都必须由医生处方，不可自行停药、减量或换药。服药期间出现黑便或牙龈异常出血（抗血栓药）、不明原因的肌肉酸痛无力或尿色变深（他汀）、心率过慢或明显乏力头晕（减慢心率药）、干咳或血钾异常（普利类）须及时就诊。
- [ ] **支架救命，但只在危急时** —— 疑似急性心梗时立即呼叫急救，不要自行前往、不要等待家属到齐；术后按医嘱服用抗血小板等药物，不可自行停药或换药，出现穿刺部位血肿、胸痛复发、黑便须及时就诊。
- [ ] **心身疾病要三个环节齐全才算成立** —— 出现持续胃痛、黑便、呕血、血压明显升高伴头痛胸闷，先按器质性疾病就诊排查，不要把症状全部归到"压力大"上而延误诊治。
- [ ] **决定得病的是心理反应强度，不是刺激强度** —— 持续两周以上的情绪低落、失眠、兴趣丧失，或出现自伤念头，须就诊精神科或心理科，不要靠"想开点"硬扛。
- [ ] **心身疾病几乎可以落在任何一个器官** —— 斑秃、哮喘发作、血压骤升、性功能突然改变，都应先完成器质性排查；哮喘急性发作出现说话断续、口唇发紫须立即急诊，不能按"心身"处理。
- [ ] **性格不同，易患的病也不同** —— 被告知"你是 A 型性格"不等于需要服药；但若已出现血压升高、胸闷胸痛，按器质性疾病流程就诊，不要用性格解释掉症状。
- [ ] **治疗原则是心身同治** —— 出现突发性功能改变、体重下降、持续发热、疼痛加重，先做器质性排查；抗焦虑抑郁类药物须由医生处方，不可自行停药或换药。
- [ ] **就诊时主动说出心理因素，否则容易漏诊** —— 如果医生初步判断为心身疾病，仍出现新的躯体症状（消瘦、出血、持续疼痛），须重新排查器质性疾病，不要用"已经诊断过心身病"挡回就诊。
- [ ] **医源性损害只有两类，都不同于犯罪与必然代价** —— 治疗后出现新发剧烈疼痛、发热、出血、意识改变，先按医疗问题急诊处理，不要先争论是不是医源性损害而延误处置。
- [ ] **造成损害的人不限于医疗人员** —— 住院期间出现不明原因发热、切口红肿渗液、腹泻，及时报告医护并按院内感染流程处理，不要自行吃抗生素。
- [ ] **事故靠制度和流程降，不靠个人更小心** —— 拿到药时核对姓名、药名、剂量、用法四项；发现药袋信息与医嘱不一致，先不服用，找护士或药师核对。
- [ ] **更多的损害是医疗局限性的代价** —— 已知有药物性耳聋家族史者，就诊时主动告知医生（见 A5）；使用氨基糖甙类等有耳毒性药物期间出现耳鸣、听力下降，立即报告医生。
- [ ] **有耳聋家族史者，用药前先申报** —— 使用任何抗生素后出现耳鸣、耳闷、听力下降、眩晕，立即停药并就诊，不要等疗程结束；是否停药、换药由医生决定，不可自行停药或换药。
- [ ] **疼痛是主观感受，没有客观测量手段** —— 突发的剧烈胸痛、腹痛、头痛，或疼痛伴大汗、意识改变、肢体无力，立即急诊，不要先吃止痛药顶着；产妇疼痛难忍且被拒绝镇痛时，有权直接要求医生评估。
- [ ] **疼痛有客观的神经传导通路** —— 糖尿病病人泡脚、用暖水袋前先用手肘试温并由家人检查皮肤，出现水疱、破溃立即就诊；出现无痛性胸闷、气短也要当心，不要因为"不疼"就排除心脏问题。
- [ ] **持续超过三个月的疼痛本身就是病** —— 慢性疼痛病人出现新发剧烈疼痛、夜间痛醒、体重下降、发热，须重新排查器质性疾病；出现绝望、自杀念头，立即就诊精神科并告知家属。
- [ ] **止痛之前必须先确诊** —— 突发剧烈腹痛在确诊前不要自行服止痛药；服药后疼痛缓解但出现发热、呕吐、意识改变、腹部板硬，立即急诊；止痛药须按医生处方使用，不可自行加量或换药。
- [ ] **止疼药成瘾的风险被高估** —— 阿片类药物必须由医生处方，不可自行加量、减量或停药；出现呼吸变慢、嗜睡叫不醒、瞳孔缩小，立即呼叫急救；同时注意便秘等常见副作用的管理。
- [ ] **用 0–10 分把疼痛说清楚** —— 分数快速上升（例如短期内从 3 分跳到 8 分）或伴随新发症状，按急症处理；止痛方案调整须由医生决定，不可自行加量。
- [ ] **衰老的本质是自我修复能力下降，不是年龄** —— 高龄者出现发热、气促、精神变差、进食减少，尽早就诊；高龄不等于不能治，不要因年龄自行放弃评估，也不要因"看着不老"而延误就医。
- [ ] **衰老分三个层面，最后一层才是本质** —— 出现记忆力明显下降影响生活、体重不明原因下降、反复骨折，须就医评估，不要一律归为"正常老化"。
- [ ] **人类寿命极限约 120 岁** —— 这条不构成任何"能活到 120 岁"的承诺；出现疾病症状仍按疾病处理，不要用"我基因好"推迟就诊。
- [ ] **晶体智力不掉，流体智力 30 岁后下降** —— 出现迷路、重复提问、算错账、性格改变等影响生活的表现，尽早到记忆门诊或神经内科评估，不要等"严重了再说"。
- [ ] **延缓衰老靠激发修复与代偿** —— 节食以不出现乏力、头晕、体重过快下降为限；运动中出现胸痛、气促、心悸立即停止并就诊；戒酒突然停饮若有震颤、出汗、心慌须就医。任何"抗衰老药物"都不可自行购买服用。
- [ ] **用生小病预防大病** —— 接种后出现高热不退、惊厥、呼吸困难、全身皮疹、面色苍白，立即就医；接种当天不要剧烈运动、保持接种部位清洁。
- [ ] **不生小病，也能预防病** —— 接种后局部红肿、低热、乏力多为短期反应；出现持续高热、呼吸困难、意识改变须就医。
- [ ] **疫苗也能治病** —— HPV 相关病变须按妇科规范随访筛查（细胞学、HPV 检测、阴道镜），不能以"等治疗性疫苗"替代现有筛查与处理。
- [ ] **疫苗安全是三层金字塔** —— 接种后按要求在现场留观（原文未给留观时长，按接种单位规定执行）；出现呼吸困难、全身荨麻疹、意识丧失立即呼叫急救。
- [ ] **合格疫苗不等于零风险** —— 孩子接种后出现发热、肢体无力、持续哭闹、抽搐，立即就医并报告接种单位；接种记录要留好，便于追溯。
- [ ] **群体保护有门槛，别人打也是保护你** —— 无法接种者（免疫缺陷、正在化疗、严重过敏史）在流行期应避开人群密集场所并戴口罩；本人是否属于禁忌人群由医生判断，不要自行决定。
- [ ] **给药途径本质是一套能量投放系统** —— 出现意识模糊、眼眶凹陷、皮肤苍白湿冷、尿量明显减少，属严重脱水信号，须立即急诊，不要在家强行喂水。
- [ ] **静脉输液未必比口服快** —— 孩子出现精神差叫不醒、眼窝明显凹陷、哭时无泪、尿量很少或长时间无尿、皮肤捏起回弹慢，立即急诊静脉补液；腹泻期间不要用含糖饮料或自制盐水替代口服补液盐（配比不可控）。
- [ ] **输液技术按需求分流成三条路** —— 置管侧肢体出现肿胀、疼痛、发热、穿刺点渗液渗血，立即报告医护；输液港与深静脉导管须按规范维护，出现寒战高热要警惕导管相关感染。
- [ ] **任何技术都有适应症，没有通用最优** —— 被建议采用某项新技术（透析、移植、置管）时，主动问清替代方案与不做会怎样；术后出现发热、少尿、切口异常立即就诊。
- [ ] **孩子腹泻，先口服补液盐再谈输液** —— 尿量明显减少、眼窝凹陷、哭无泪、精神萎靡、皮肤回弹慢、四肢凉，立即急诊；不要用运动饮料、果汁、自制糖盐水替代口服补液盐。
- [ ] **疼的问题不解决，外科无法往前走** —— 今天若被建议"手术越快越好、不用麻醉"，应追问麻醉方案；无麻醉下的强刺激操作可能引发血压骤升、心律失常，尤其是有心血管病的人。
- [ ] **不疼之后，复杂精细的手术才成为可能** —— 术前如实告知既往病史、用药（尤其抗凝药）、过敏史、吸烟饮酒情况与打鼾憋气情况；术后出现呼吸费力、嗜睡叫不醒、呕吐误吸、穿刺部位剧痛，立即报告医护。
- [ ] **全麻不只不疼不动，还要"不知"** —— 术后若清晰记得手术过程中的声音、操作或疼痛，务必告知麻醉医生并记录，这类"术中知晓"需要评估与随访；术后出现持续噩梦、闪回、失眠，应就诊。
- [ ] **麻醉衍生出的疼痛治疗，是最后的体面** —— 疼痛治疗方案须由疼痛科或麻醉科医生制定，不可自行加量或停药；出现呼吸变慢、过度嗜睡、便秘加重须就诊。
- [ ] **分娩镇痛可以主动要求** —— 分娩过程中出现持续剧烈头痛、下肢麻木无力加重、穿刺点红肿发热、胎心异常，立即告知医护；镇痛方案与是否继续由医生决定，不可自行要求加药。
- [ ] **有无专业护理，死亡率差一个数量级** —— 住院期间出现发热、切口渗液、痰液变稠咳不出、皮肤发红破溃，及时报告护士；压疮、跌倒、误吸是护理环节最需要盯的三件事。
- [ ] **护理是医疗体验的核心环节** —— 若因沟通不畅而不敢提问、不敢报告症状，务必换一个时间或换一位医护再说一次；对治疗方案有疑问，有权要求医生当面解释。
- [ ] **护士是流程的监督者，因为医生会窄化** —— 家属在病房遇到医护反复尝试同一操作、病人状态变差时，可以直接说"是不是该换方案/叫上级医生"，这句话本身是流程的一部分；病人出现口唇发紫、叫不醒、呼吸停止立即呼叫急救。
- [ ] **没有特效药时，护理就是最好的治疗** —— 出现痰液堵住咳不出、血氧下降、发热、皮肤破溃，立即报告医护；家庭照护者要学会吸痰与翻身拍背，但气道操作须经培训，不可自行尝试。
- [ ] **监督是制度责任，医护同责** —— 发现用药、输血、手术部位与自己的信息不符，立即提出核对，任何一方都应停下来复核；这类核对不是"多事"，是制度设计的一部分。
- [ ] **医学的核心矛盾：获取信息与付出代价** —— 需要影像检查时，告诉医生近期做过的同类检查与是否怀孕，避免不必要的重复照射；检查结果异常须由医生结合症状判断。
- [ ] **没有可见创伤，不等于没有损伤** —— 怀孕或可能怀孕必须提前告知医生；短期内已做过同类检查要主动说明；检查时按要求使用防护用品、避免家属无故留在机房内。
- [ ] **早期"拿生命摄影"，靠规范才收住** —— 在放射区域看到警示标识应离开或按要求穿戴防护；孕妇与儿童非必要不进入检查室陪护。

- [ ] **能量精准投递，就从"看"变成"治"** —— 放疗期间出现皮肤红肿破溃、持续乏力、发热，及时报告主管医生；碎石后出现剧烈腰痛、血尿、发热须急诊。

- [ ] **抗生素是借来的物种竞争武器** —— 使用任何抗生素前必须告知过敏史；用药后出现皮疹、面唇肿胀、呼吸困难，立即停药并急诊。
- [ ] **打细胞壁，所以选择性高但并非无害** —— 青霉素、头孢使用前须告知过敏史，用药后出现皮疹、瘙痒、面唇肿胀、呼吸困难立即停药并急诊；出现严重腹泻（尤其带血或假膜）及时就诊，不要自行吃止泻药。
- [ ] **杀不掉的细菌终将耐药** —— 医生开的抗生素要按疗程足量用完，不因"怕耐药"自行减量或提前停药——剂量不足同样构成选择压力；出现腹泻、皮疹、发热加重及时就诊。
- [ ] **过度使用会打破内共生，招来真菌** —— 使用抗生素期间或之后出现持续腹泻、带血便、发热、口腔白斑、外阴瘙痒加重，及时就诊；不要自行用止泻药或抗真菌药；阴道冲洗出现异常分泌物、疼痛应就诊妇科。
- [ ] **严重感染不能死扛，要早用按疗程** —— 高热持续不退、呼吸急促、意识改变、尿量减少、皮肤花斑，立即急诊，不要在家观察等待；抗生素的品种与疗程由医生决定，不可自行停药、减量或换药。
- [ ] **少备抗生素，别压制自我防御** —— 出现呼吸费力、口唇发紫、痰中带血、持续高热、精神萎靡，立即就诊；儿童不要自行使用镇咳药；家中抗生素过期应及时清理，不可留作"下次再用"。

- [ ] **呼吸机的原理是正压通气，且必须同时解决通气与排痰** —— 带管病人出现血氧下降、心率上升、气道出血、剧烈躁动、发热，都属病情变化信号，须立即报告医护；躁动可能导致脱管，属急症。
- [ ] **热的第一层：器官支持，越接近生理状态越安全** —— 体外循环本身是有创操作，术后出现意识改变、尿量明显减少、出血、发热，须及时报告医护；原文未展开其并发症清单。
- [ ] **热的第二层：用“冷”换修复时间** —— 低温治疗必须在 ICU 内用药物与设备实施，是有创干预；出现寒战、心律失常、出血倾向、感染征象须立即报告医护。原文未给复温方案与并发症处理，不可照此在家操作。
- [ ] **热的第三层：器官替代（ECMO）** —— ECMO 是最高级别支持，也意味着最高的资源消耗与并发症风险（原文未展开）。家属被谈话时须问清：替代的是心还是肺、原发病有无可逆手段、预计支持多久、失败预案是什么。
- [ ] **热修复买的是时间，不是结果** —— 上机期间出现血氧快速下降、心率快速上升、气道出血、躁动，都是病情恶化的即时信号，须立刻呼叫医护，不要等交班。
- [ ] **免疫疗法换的是"内力"，不是外援** —— 免疫疗法不是"没有副作用"的自然疗法，原文未讨论其不良反应；已在使用免疫治疗药物者，出现持续腹泻、皮疹、气促、乏力、甲状腺功能异常等表现须及时报告医生，不可自行停药或换药。
- [ ] **要杀敌，先得认得出敌人** —— 确诊癌症后是否做免疫相关检测、结果如何解读，须由肿瘤专科医生判断；不可据"我的免疫细胞识别能力差"这类说法自行购药。
- [ ] **有个别缓解，不等于疗法成立** —— 听到"某疗法治好过多少人"时，不要据此停掉正在进行的规范治疗；停药、换方案须由主管医生决定。
- [ ] **自我修复能力被系统性低估** —— 把"身体会自己修"当成不吃药、不复查的理由，是这条最危险的一种用法；出现持续发热、不明原因消瘦、疼痛加重、出血，须就医而不是"等等看"。
- [ ] **从机制发现到临床可用，是以十年计的时滞** —— 不要因为"机制已被诺奖证实"就自行寻找未上市的免疫制剂或境外购药；临床用药须在具备条件的医疗机构、由专科医生评估。
- [ ] **搞不清病因，也可以切断链条治病** —— 这类治疗控制的是症状与链条，不是病因，因此多数需要长期维持；出现症状反复、静坐不能、肢体僵硬、手抖、发热伴意识改变，须及时报告精神科医生，**不可自行停药或换药**——骤停可能反跳。
- [ ] **症状背后有物质过程，找不到不等于没有** —— 出现幻觉、妄想、言语紊乱、行为紊乱、拒食、自伤或自杀念头，须尽快到精神专科就诊；家属不要用"想开点""是不是中邪了"来处理，也不要因羞耻感拖延就诊。
- [ ] **意外发现的路径：先看到"人安静了"，再回头找机制** —— 这是发现史，不构成用药建议。抗精神病药须由精神科医生开具与调整，**不可自行停药或换药**；出现高热、肌肉强直、意识改变、严重便秘或吞咽困难须立即就医。
- [ ] **一项治疗的价值，看它能不能恢复功能** —— "能在家吃药"不等于"可以自己调药"；出现症状加重、拒绝服药、攻击行为或自伤风险、生活不能自理，须及时就医，必要时住院。
- [ ] **1949 年的诺奖发错了：希望真空里的破坏性疗法** —— 这是历史教训，不是治疗建议。今天若有人以"毁损某脑区能治精神症状"为名推荐治疗，须要求出示伦理批件、适应证与循证依据，并向正规医院精神科求证。
- [ ] **第二代、第三代药走在同一条思路上** —— 具体用哪一代、哪一种药，须由精神科医生按症状、耐受性与合并用药决定；**不可自行停药或换药**，换药期间出现症状反复或明显副作用须复诊。
- [ ] **生命体征不等于生命** —— 家属若被告知"脑死亡"而病人仍有心跳，容易误以为医院要放弃治疗；此时应要求医生出示判定依据（见 A2），而不是凭"还有心跳"自行拒绝或自行签放弃。
- [ ] **脑死亡的判定：四条标准 + 反复测试** —— 家属可核对的观察信号：病人是否有自主呼吸（脱离呼吸机后有无呼吸动作）、瞳孔对光反射是否存在、有无角膜反射与咳嗽反射。任何一项存在，都不符合"脑干反射全部消失"，应要求重新评估。
- [ ] **为什么用脑死亡：意识在脑、不可逆、不可替代** —— 家属若被要求做"是否继续支持"的决定，须先确认脑死亡判定已完成且规范；对未判脑死亡的重度昏迷病人，仍按危重症救治处理，不存在"救不救"的提前选择。
- [ ] **植物人不是脑死亡，这是生与死的区别** —— 家属可观察的信号：有无自主呼吸（脱机后）、有无睁眼（哪怕无意识）、有无咳嗽与吞咽反射。若这些存在，就不是脑死亡；此时不应放弃救治，也不应被"脑死亡"的说法误导。
- [ ] **脑死亡标准的价值，与器官捐献的时间窗** —— 家属在情绪中做出的决定可能反复；若家庭内部意见不一致，应尽早请医院的器官捐献协调员与伦理委员会介入，而不是拖到感染发生。
- [ ] **循证医学 = 证据 + 经验 + 意愿，证据为王** —— 征求第二意见不等于不信任医生；但如果被告知"必须马上决定"而拿不出指南或对照研究依据，可先要求活检或第二意见（急症除外）。不可自行停药或换药等待"更好的证据"。
- [ ] **个人经验是最低一级证据** —— 听到"我干这行几十年了，听我的"时，可以追问一句"有没有对照研究或指南支持"；但不要在急诊、抢救场景里用这句话拖延处置。
- [ ] **五级证据：从个人经验到荟萃分析** —— 级别高不等于适合你——RCT 与 Meta 分析给出的是群体平均效应，个体是否获益仍要看病情、合并症与意愿（见 A1）；用药调整须由医生决定，**不可自行停药或换药**。
- [ ] **"病人满意"不是疗效指标** —— 症状缓解不等于病好转：疼痛减轻、精神变好可能掩盖病情进展。若正在治疗中出现"感觉好多了"但复查指标恶化，须以复查结果为准，不可自行减药。
- [ ] **会看片子的是经验，赢的是证据集成** —— 无论人工还是算法读片，影像结论都要结合临床与病理；不要因为"AI 准确率 87%"就跳过活检等确诊步骤（原文的达里奥案例正是靠活检排除了癌变）。
- [ ] **药也可以给健康人吃：目的是自主，不是治病** —— 这是观念层的内容，不是用药建议。是否适合口服避孕药须由医生按年龄、吸烟、血压、偏头痛、血栓史评估；**不可自行停药或换药**。
- [ ] **口服避孕药和紧急避孕药是两码事** —— 紧急避孕药不能当常规避孕手段反复使用；服药后出现异常阴道出血、剧烈下腹痛、月经长期紊乱，须就医。口服避孕药须按周期连续服用，漏服会降低避孕效果（原文未给漏服处理方案）。

- [ ] **避孕药不只是避孕** —— 用于非避孕目的时同样是处方药，须由妇科医生评估禁忌症；**不可自行停药或换药**，调经与辅助怀孕的方案由医生制定。

- [ ] **临床没有公式，每个病人都不一样** —— "每个人不一样"不能成为拒绝规范治疗的借口；该做的手术、该吃的药不因"我体质特殊"而省略。
- [ ] **诊断靠挖掘：病人会隐瞒，指标会互相矛盾** —— 就诊时主动说出可能难以启齿的接触史、性史、用药史（含毒品）与心理状况——这不是道德审查，而是诊断必需；隐瞒会直接改变检查方向，抢救时可能致命。
- [ ] **操作类技术：手感和空间感只能从实践来** —— 穿刺属有创操作，须在有抢救条件的机构进行；术中按医生要求屏气、避免咳嗽与活动；术后出现持续胸痛、咯血、呼吸困难、发热，须立即报告医护。
- [ ] **医学禁区探索的三个共性** —— 这条讲的是探索的结构性风险，不能作为"为科学牺牲个体"的辩护；任何人体试验都必须经过伦理审查与知情同意（见 A4）。
- [ ] **自体试验是缺规范时的替代品，今天不提倡** —— 不要模仿任何自体试验：自行注射、自行服药、自行置管都可能致命；出现发热、胸痛、心悸、出血、意识改变须立即就医。想验证某个方法，走临床试验或医生指导的路径。
- [ ] **打破伦理禁区，靠方法不靠勇气** —— 涉及隐私与身体的研究必须经伦理审查与知情同意；被邀请参加此类研究时，有权知道数据如何使用、能否随时退出。
- [ ] **伦理四条底线** —— 参加任何临床试验前，必须拿到并读懂知情同意书；有权随时退出且不影响常规治疗；出现不适先联系研究医生，具体处置听医嘱，不要因为"在试验中"就忍着。
- [ ] **罕见病的现实困境，靠特殊政策解** —— 通过条件批准上市的药品，仍须在医生指导下使用，并配合上市后研究（随访、登记）；出现不良反应须报告，**不可自行停药或换药**。
- [ ] **正确的探索，也可能要几十年才被承认** —— 这条不能被用来鼓励拒绝规范治疗；任何"主流不承认但我相信"的疗法，仍须回到可重复与对照（见 035）。
- [ ] **错误分无知与无能两类，补知识才能治前者** —— 本条是归因框架，不用于临床处置。医疗场景中判断「这属于哪一类错」不能替代对病人的即时处理，病人出现危急情况先救治、后复盘。
- [ ] **体系内的无知之错，体系内的人最难发现** —— 本条是认知框架，不构成对具体诊疗的质疑依据。个人对治疗方案有疑问时，走会诊、第二意见、循证检索三条路，不要自行停治疗。
- [ ] **没有对照就看不见体系之错** —— 本条不是让个人去做对照试验。涉及治疗方案的比较必须由研究机构按伦理审查进行，病人不应自行「停药试一试」来制造对照。
- [ ] **洗手把产褥热病死率从 18.27% 降到 2.19%** —— 洗手是阻断环节，不是治疗。产妇出现寒战、高热、呼吸困难（原文描述的产褥热表现）须立即就医，不能靠加强清洁处理；手部有开放性伤口者不应直接接触产妇与新生儿。
- [ ] **方法正确不等于被采纳，纠错者要付代价** —— 本条讲的是组织行为，不适用于临床决策。个人对治疗方案有异议时，正确路径是找主管医生讨论、申请会诊或第二意见，不是自行改变治疗。
- [ ] **群体防控只有三条：源头、途径、易感人群** —— 这三条是群体措施，不替代个人就医。出现高热、剧烈咳嗽、咳血、呼吸困难，须立即就诊并主动告知接触史与旅行史，不要自行在家「隔离观察」。
- [ ] **病原体不明也要先动，不能等** —— 本条不等于「不用查病原体」。对个体而言，查不清病因时仍须就医做检查；「不能等」指的是群体防控不能停摆，不是个人可以跳过诊断。
- [ ] **传播途径决定防控重心** —— 判断错途径会漏掉真正的暴露。若不确定途径（如接触传播、气溶胶、媒介生物），按最严格的那条途径先防护，同时就医确认。
- [ ] **防护要选人人戴得起、戴得住的那一种** —— 口罩不能替代就医。出现呼吸困难、口唇发紫、咳血、高热不退，立即就医；婴幼儿佩戴口罩有窒息风险，原文未涉及，须由看护人评估。
- [ ] **隔离要分级，群体优先但要兼顾个体** —— 被隔离者出现病情加重（呼吸困难、意识改变、无法进食饮水）须立即转入救治，不能因为「在隔离中」而延迟；隔离期间出现明显焦虑、绝望情绪须寻求专业支持。
- [ ] **女医生变多，实质是患者多了选择权** —— 本条不涉及治疗。任何情况下都不应因为医生性别而延迟急症处置——急诊、产科急症、创伤按就近与能力选择，不按性别挑人。
- [ ] **选医生看问题类型，不看性别优劣** —— 这是选择偏好层面的判断，不构成对任何个体医生的能力评价。急危重症按医院能力与可及性就医，不以医生性别作为筛选条件。
- [ ] **重型新生儿溶血病的关键救治是换血** —— 这是医院内的高风险操作，必须由新生儿科/产科团队在多科协作下完成。家长能做的是识别与转运：新生儿出生后数小时内皮肤迅速变黄、或前几胎有出生后发黄夭折史，立即告知医生并要求转至有换血条件的医院。任何情况下不要在家「观察一天」。
- [ ] **新生儿出生后数小时迅速变黄要立即就医** —— 出现以下任一情形立即就医，不要等满月体检——出生后数小时内出现黄疸、黄疸在一天内明显加重或范围扩大（从脸向躯干四肢蔓延）、前几胎有出生后发黄夭折史、孩子吸吮差或反应差。就医时主动说出家族史。
- [ ] **看起来的个人选择，常是制度约束的结果** —— 本条不涉及医疗。若因工作制度长期牺牲睡眠、体检与就医，属于需要调整的现实风险，不要用「这是我的选择」把它合理化。
- [ ] **复杂和多不带来完美，只带来隐患** —— 本条讲的是「该不该加」，不是「该不该减」。正在服用的处方药不可自行停用或减量；任何调整由医生决定。
- [ ] **多数药只对 30%–50% 的人有效，加药即加损害** —— 不可自行停药或换药。出现黑便、皮下瘀斑、皮疹、明显乏力、尿量减少、意识改变，带上全部药盒（含中成药与保健品）就诊；每次就诊主动出示完整用药清单。
- [ ] **只压指标是症状解，找共同上游才是杠杆解** —— 杠杆解是「加在用药基础上」，不是替代用药。不可自行停药、减药或换药；调整须医生评估后逐步进行。
- [ ] **疗效相同时，选代价最小的那一种做法** —— 截肢范围是外科决策，须由团队结合血供与感染范围判断。肢体出现发黑、恶臭、疼痛突然加剧、高热，立即急诊，不要等复诊；糖尿病足病人尤须早看。
- [ ] **先看这个病的终局，再决定治多深** —— 「动态观察」是有随访方案的医疗决策，不等于不看病。观察期内出现结节迅速增大、声音嘶哑、吞咽困难、颈部淋巴结肿大，立即就诊；按约定复查，不可自行中断随访。是否观察由专科医生判断。
- [ ] **先保命，把紧急事件转成常规事件** —— 这是急救原则，不是家庭自我处置方案。出现意识丧失、无呼吸或仅有濒死喘息、大出血，立即呼叫急救并按调度员指导开始心肺复苏；不要先找病因、不要喂水喂药、不要自行搬运。
- [ ] **一个病能解释所有症状，就别列第二个诊断** —— 这是推理方向，不是诊断结论。出现新症状（尤其体重下降、夜间痛、神经症状、发热）要复诊，不要因为「已经有一个诊断」就全部归因于它。
- [ ] **先想马，最后才想斑马** —— 症状持续不缓解、反复就诊无结论、出现体重下降、夜间痛、出血、神经功能改变等警示信号时，主动提出「会不会是少见病」，不要因为「没有典型表现」而停止就医。
- [ ] **决策不是一次做对，而是从第一版开始校正** —— 校正要有责任人。出院后症状复发或加重须复诊，不要用「出院诊断已经这么写了」解释新症状；也不要因为「诊断可能还会改」就延迟急症处置。
- [ ] **四步都做对，仍然会错** —— 正因为有误诊率，症状不缓解要复诊或寻求第二意见；但急症时不要「多跑几家」耽误时间——先就近处置稳定，再讨论第二意见。
- [ ] **情感越强，越会把眼前的矛盾证据过滤掉** —— 不要因为「我最了解情况」而拒绝会诊或第二意见。出现出血倾向（伤口流血不止、皮下瘀斑、牙龈渗血）、尿量骤减、意识改变，立即就医，并主动说一句「我可能漏了什么，请重新看一遍全部资料」。
- [ ] **不理性会盯着最坏结局，变得激进冒险** —— 激素与免疫抑制剂不可自行加量、减量或停药，须由医生决定。用药期间出现黑便、呕血、剧烈腹痛、发热，立即急诊——这些正是「激进治疗」最典型的代价。
- [ ] **把不符合判断的信息当情报，而不是当敌人** —— 侦察兵思维不等于无限收集信息。急症时先处置再收集，不要为了「更客观」而延迟必要的治疗。
- [ ] **理性决定判断，情感决定温度，要能切换** —— 长期照护与反复失败会累积情绪耗竭。出现持续失眠、兴趣丧失、回避工作超过两周，或出现自伤念头，须主动寻求专业支持，不要用「我要理性」压过去。
- [ ] **决策前先点名干扰源** —— 因为厌烦某个病人或家属而降低照护强度，是可观察的医疗风险。若发现自己不愿去看某床病人，应交班或求助，而不是硬撑。
- [ ] **慢病发病前是可拆的三环链条** —— 三环是预防框架，不能替代诊断。出现不明原因消瘦、出血、持续疼痛、排便习惯改变、长期不愈的溃疡，须就医，不要用「我生活方式很好」解释。
- [ ] **高危因素里只有基因改不了** —— 避免高危因素不能替代治疗与随访。乙肝病毒携带者须按医嘱定期查肝功能、甲胎蛋白与肝脏超声，抗病毒药不可自行停用；已感染者不要因为「我生活很健康」而中断复查。
- [ ] **拿个例反驳健康建议是赌博，不是证据** —— 这条不能用来否定个体就医。自己出现疼痛、出血、消瘦、持续发热，仍须就诊——「大数据说概率低」解释不了具体的症状。
- [ ] **护住修复代偿只靠三件事：少吃、睡够、动起来** —— 用胰岛素或磺脲类的糖尿病患者，节食与运动可能引起低血糖，方案调整须医生决定，不可自行减药或停药；出现心慌、出汗、手抖、意识模糊，立即测血糖并就医。运动中出现胸痛、明显气促、晕厥，立即停止并就医。
- [ ] **四种癌症优先筛查，且有明确年龄切点** —— 筛查阳性不等于确诊，非结肠镜筛查的所有阳性结果都应及时做结肠镜检查。出现便血、不明原因消瘦、持续咳嗽、异常阴道出血，不要等下一次筛查，直接就诊。
- [ ] **指南年龄是底线，高风险者可提前但要商量** —— 提前筛查意味着更多结节被发现、更多随访与焦虑。查出结节后按医生方案随访，不要自行要求手术，也不要因为「结节很小」就断开随访；出现咳嗽加重、咯血、胸痛、消瘦，立即就诊。
- [ ] **全交给医生和全自己决定，都不科学** —— 全权委托不等于放弃知情。手术、麻醉、输血、有创检查前，必须有人把获益与风险说清楚；不清楚就不要签字，先问（见 A2）。急症抢救时的知情可以简化，但事后要补。
- [ ] **知情就是问清五个问题** —— 听不懂就不要签。签字前必须弄清「最坏会发生什么、发生了怎么办、有没有补救方案」；对麻醉方式、输血、植入物、自费项目要单独确认。
- [ ] **家属只谈框架，细节交给专业人员** —— 「只谈框架」不等于隐瞒。获益、风险、替代方案三项必须说；隐瞒诊断与风险会剥夺病人的决定权，也常在事后引发家庭冲突。病人明确要求了解全部细节时，应尊重并请医生来讲。
- [ ] **别用结局反推决策对错** —— 不用结局反推，不等于不复盘。手术并发症、用药不良反应仍要如实上报与记录——那是改进流程的依据，不是追责某一个人的依据。
- [ ] **找支持先找主管医生，不找医生朋友** —— 不要为了等医生朋友的回复而延迟主管医生的处置；急症时以现场团队为准。
- [ ] **善终的第一条，也是最重要的一条是无痛** —— 疼痛不必忍。出现爆发痛、疼痛性质改变、新部位疼痛、静息时也痛，须报告医生调整方案；阿片类药物的加量与更换必须由医生决定，家属不可自行增减。
- [ ] **过度抢救与治疗不足，都在制造痛苦** —— 出现无法缓解的疼痛、呼吸困难、躁动、呕吐，立即联系医疗团队，不要等下一次预约；家属不要自行使用或调整镇静、镇痛药物。
- [ ] **缓和医疗不加速也不延后死亡** —— 缓和医疗不是停止一切医疗。出现可逆的急症（感染、出血、梗阻、剧痛爆发）仍须处理；家属不要把它理解成「什么都不做」，也不要自行拒绝必要的对症治疗。
- [ ] **缓和医疗靠八类具体手段，不靠安慰** —— 吗啡等阿片类药物必须由医生开具与调整，不可自行加量（呼吸抑制风险）；出现呼吸变浅变慢、嗜睡明显加重、意识改变、瞳孔变小，立即报告医护。补液也不是越多越好——过量补液会加重水肿与呼吸困难，原文未讨论这一点，需由医生权衡。
- [ ] **趁清醒写下五个愿望，比让家属事后决定更可靠** —— 生前预嘱不是放弃治疗同意书。写「不要什么」的同时必须写「要什么」——止痛、舒适照护、由谁替我做决定；病情变化要更新。可逆的急症仍须救治，是否可逆由医生判断。
- [ ] **叛逆从继承的尽头长出来** —— 这是历史判断，不涉及医疗处置；不能用它来为任何一种未验证疗法做辩护（「它可能是下一次叛逆」不是证据）。
- [ ] **AI 只回答「怎么做」，所以它属于继承** —— AI 输出不能替代医生诊断。AI 报告与医生当面判断不一致时，以当面诊视为准，并要求医生解释差异；不要依据 AI 建议自行用药。
- [ ] **具体技术不可预测，能押的只有不变项** —— 这条不构成对任何「未来医疗」宣传的背书。遇到宣称几年内能解决某病的技术，仍要看当期证据与适应证。
- [ ] **作者押的三个方向：数据算法、万物互联、基因移植** —— 这是前瞻性猜想，不能作为治疗选择的依据。任何以「基因移植治疗」为名在临床研究之外提供服务的，都应先确认伦理审批与临床注册。
- [ ] **评估新技术，仍要过「为人、科学、希望」三道关** —— 「希望」不能替代疗效证据。遇到以「给病人希望」为由推荐的未经验证疗法，仍应要求适应证、证据等级与风险说明；也不要因为「总会有新办法」而拒绝讨论不可逆病情的安排（与第 49 讲直接相关）。
- [ ] **没有「免疫力高低」的指标，问题多在识别** —— 反复感染（一年多次肺炎、反复带状疱疹、持续腹泻、口腔真菌感染）不是「免疫力低」四个字能带过的，须就医查因；不要用「提高免疫力」的产品替代检查。
- [ ] **小病症状重、大病没症状，差别在有没有认出来** —— 正因为大病早期没症状，才需要按年龄筛查（第 47 讲）。出现不明原因消瘦、持续低热、异常出血、摸到肿块，即使「不疼不痒」也要就医。
- [ ] **免疫要的是见多识广，不是被无限加强** —— 「见多识广」不等于主动去感染。原文对新冠后肿瘤消退的病例明确强调「主动去感染病毒是非常非常危险的」；发热病人不要以「锻炼免疫」为由拒绝就医。疫苗按国家免疫规划与医生建议接种，不因「想让免疫多练练」而自行增加剂次。
