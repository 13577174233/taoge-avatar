# 常见误区对照表

> 越相信左边，右边那条知识就越点不亮。逐条自查。

## 第 000 讲

| 常见错误信念 | 纠正 |
|---|---|
| 医学是医生的事，患者把身体交给医院就行。 | 治疗效果取决于双方；会描述、会合作的人，同样的门诊时间里能拿到的判断质量高得多。 |
| 态度好、说话暖的医生就是好医生。 | 还要技术过硬、把长远利益和生命质量算进方案；只有态度没有技术，帮不到人。 |
| 有了指南和证据，按流程走就行，患者的想法是干扰项。 | 证据、经验、意愿三缺一都不是最佳方案。 |

## 第 001 讲

| 常见错误信念 | 纠正 |
|---|---|
| 医学这么发达，人总该被救回来。 | 自我修复被摧毁时，再强的医疗也无用；医学保的是「别被进化淘汰」，不是不死。 |
| 只要能多活，其他都能忍。 | 剧痛、失能、无法交流本身就是治疗对象，不是活着的附属品。 |
| 患者不懂医，重大决定听医生的就行。 | 医生的「最优」按医学结局算，患者按自己的意义算；冲突时要讲清代价，再由本人决定。 |

## 第 002 讲

| 常见错误信念 | 纠正 |
|---|---|
| 不舒服就是病，舒服就是没病。 | 感觉与病变不同步；癌症可潜伏 20 多年无症状，孕吐这类生理反应也不是病。 |
| 健康就是一点病都没有。 | 斑块、临界指标与正常生活可以共存；界线是人定的处置阈值，不是自然分界。 |
| 病是进化注定的，治不治都一样。 | 进化给的是易感倾向，暴露与行为决定何时发病；原文明确说消除不了不完美，才更要靠医学。 |

## 第 003 讲

| 常见错误信念 | 纠正 |
|---|---|
| 进医院就像进修理厂，交钱换一个好身体。 | 修复动作由身体完成，医疗买的是时间和条件；修复能力缺失时，钱和设备都换不回来。 |
| 用了最好的设备和最好的药，就应该有最好的结果。 | 设备是支持不是替代；结局取决于器官是否还有恢复可能。 |
| 抗生素能杀菌，所以感染都能治好。 | 药物只降低病原负荷，最后一步靠吞噬细胞完成；免疫功能低下者这一步缺失。 |

## 第 004 讲

| 常见错误信念 | 纠正 |
|---|---|
| 医学越科学越冷，想要人情味就得少讲科学。 | 两者不在一个维度上，不存在此消彼长；缺任一边，医学都不成立。 |
| 医生态度好、会共情，就是有人文。 | 态度不是唯一标准；没有科学支撑的关怀改变不了结局。 |
| 生存率上去了，治疗就是进步了。 | 还要看病人为此付出的功能、尊严与生活质量成本。 |

## 第 005 讲

| 常见错误信念 | 纠正 |
|---|---|
| 我花了钱，就该得到想要的治疗结果。 | 医疗的内容、流程、结果都无法事先确定，也不能退款；付费买的是规范诊疗过程。 |
| 医患关系好不好，全看医生水平和态度。 | 患者也是主动的一方，信息提供、依从与共同决策都影响结局。 |
| 重大决定要么听医生的，要么自己说了算。 | 结局不确定时最优解算不出来，要共同决策、共担风险。 |

## 第 006 讲

| 常见错误信念 | 纠正 |
|---|---|
| 人体是大自然精心雕琢的完美艺术品，坏了自己会修好。 | 每个部件都是利益与风险的折中产物，缺陷是设计的一部分，不是意外。 |
| 现代人吃得好动得少是进步，身体应该跟着变好。 | 基因还停在稀缺环境，环境变化跑在进化前面，优势直接转成代谢病风险。 |
| 病了就是身体坏了，跟活法没关系。 | 新需求带来的持续压力会以磨损、突变、失调的形式落到旧硬件上。 |

## 第 007 讲

| 常见错误信念 | 纠正 |
|---|---|
| 查不出病因，说明这病就是心理作用/想出来的。 | 查不出可能是技术不够，也可能是这压根不是病；三种情况必须分开判断。 |
| 从病人身上查出某种病毒/细菌，就说明是它致病。 | 检出只是嫌疑，还需要接种验证与来源追溯，果子狸就是被冤枉的例子。 |
| 老方法用了几千年，总有它的道理。 | 放血用了 2000 年，没有积累下有用的东西，还直接导致死亡。 |

## 第 008 讲

| 常见错误信念 | 纠正 |
|---|---|
| 有症状就是有病，得赶紧把症状压下去。 | 多数症状是保护性反应；压掉症状可能同时压掉了身体的自救。 |
| 骨刺是骨头长刺扎在肉里，所以要把它磨掉。 | 骨刺是关节不稳的代偿性增生，疼的是关节不稳，不是骨刺。 |
| 既然高血压只是个「症状」，就不用一直吃药。 | 概念上算症状，治疗上必须按医嘱持续用药；血压正常是药在起作用。 |

## 第 009 讲

| 常见错误信念 | 纠正 |
|---|---|
| 我平时一点感觉都没有，怎么会有病？ | 代偿把功能顶住了，症状只在代偿失败时出现；没感觉是代偿还在，不是没病。 |
| 病不知道最好，知道了反而死得更快。 | 早期筛查把诊断提前到可治阶段，美国癌症总死亡率 1991 到 2018 下降 27%。 |
| 心梗是老年病，年轻人胸痛不用当回事。 | 年轻人无侧支代偿，首发心梗反而更易猝死。 |

## 第 010 讲

| 常见错误信念 | 纠正 |
|---|---|
| 细菌都是坏的，能杀就杀，越干净越健康。 | 常驻菌提供屏障、合成物质、训练免疫；把它们杀光，耐药菌和真菌反而占位。 |
| 只要身上有菌就是感染了。 | 位置决定性质——在该在的地方是正常菌，移位到不该去的地方才可能致病。 |
| 肠胃不好、情绪差，买点益生菌吃就行。 | 菌群受饮食结构与抗生素暴露主导；持续的情绪问题需要专业评估，不是补菌能替代的。 |

## 第 011 讲

| 常见错误信念 | 纠正 |
|---|---|
| 免疫力低了才生病，所以什么病都要"提高免疫力"；过敏也是免疫力低。 | 疾病与免疫的关系分三层，过敏属第二层"把好人当坏人"的识别错误，不是免疫高低；提高免疫对过敏不解决问题，方向还可能相反。 |
| 有能快速提升免疫力的食品和保健品，多吃点总没坏处。 | 作者明确否认存在这类产品；能做的只有疫苗、内共生、经小感染锻炼，以及避免熬夜、烟酒、压力、偏食。 |
| 把危险全隔开、把孩子养在无菌环境里最健康。 | 隔离能保命但不产生免疫；对免疫正常者，过度隔绝剥夺了免疫成熟的机会。 |

## 第 012 讲

| 常见错误信念 | 纠正 |
|---|---|
| 诊断就是做检查，检查做得越全越保险，查完就有答案。 | 检查只是循环里的"收证据"一环，没有假设的检查是穷举；高手用两个检查确诊胆囊炎，靠的是先有 F4 这个假设。 |
| 认准了一个病，就按这个病治到底，检查结果对不上是检查不准。 | 证据与假设冲突时该换假设，不能丢证据；丢掉不符的证据，循环就退化成自我确认。 |
| 所有指标都正常才是没病，出现一个异常值就是得了重病。 | 反常点要结合预期去读，先分清是干扰信息还是真信号；单一异常既可能是突破口，也可能是误差。 |

## 第 013 讲

| 常见错误信念 | 纠正 |
|---|---|
| 治病的唯一目标就是把病治好，治不好就是治疗失败。 | 目标是问题，治愈只是其中一种答案。白癜风没有确切有效疗法，把目标定成"能演出"，治疗才有可评价的成功。 |
| 有好方案就照最好的做，不用问病人想要什么。 | 需求不同，目标不同，方案就不同；同一个跟腱止点末端病，要比赛和要优先康复选的是两条路。 |
| 病人要什么就给什么，这叫尊重患者。 | 需求是主观的、不可验证的，必须翻译成可量化的医学目标；而且受医学水平、身体条件、经济、社会与伦理法律的限制。 |

## 第 014 讲

| 常见错误信念 | 纠正 |
|---|---|
| 医生当着病人的面查指南，说明他不会看病。 | 查指南是全球医生的常规动作，指南就是用来消除操作者水平差异的；不查才是风险。 |
| 按指南治就是最好的治疗，指南没写的不能做。 | 指南是下限不是上限；它能保证不出错，个体化的部分要靠有经验的医生在留白处判断。 |
| 指南都是几年一改的老东西，不如网上最新的研究靠谱。 | 指南本身就是把最好的证据系统评估后写成的，且有明确更新周期（CPR 每年、AAN 每 3 年、ESC 每 4 年）；单篇研究不足以推翻它。 |

## 第 015 讲

| 常见错误信念 | 纠正 |
|---|---|
| 好药就是没有副作用的药，副作用大说明这药不行。 | 副作用来自作用不够精准；认知越精细，脱靶效应越少。同一种药在不同适应症下，治疗作用与副作用会互换位置。 |
| 这药通过国家审批了，说明安全，可以自己买来吃。 | 审批保证的是"合格"，不保证适合你这个人、这个病；安全有效最终取决于对疾病的认知与个体情况。 |
| 砒霜能治白血病，说明以毒攻毒有道理，偏方也可以用。 | 起作用的是明确的适应症、剂量与监测，不是"毒"本身；缺了这层认知，同一物质就是杀人的东西。 |

## 第 016 讲

| 常见错误信念 | 纠正 |
|---|---|
| 看病就是找专家，专家越有名，病就看得越好。 | 疑难病的解法是多学科协作加平台技术；专家只是网络里的一个节点，离开会诊、设备、ICU，单点技术也用不出来。 |
| 分级诊疗就是把病人挡在小医院，不让我们去大医院。 | 它是按比较优势分工——基层做首诊、慢病与康复，大医院做疑难、复杂、急性；通道是双向的。 |
| 换医院就重新检查一遍更保险，旧病历没什么用。 | 病案与既往资料是医生判断的重要信息来源，重复检查既增加成本也可能带来伤害。 |

## 第 017 讲

| 常见错误信念 | 纠正 |
|---|---|
| 公共卫生就是扫垃圾、消毒、管卫生，跟自己没关系。 | 它管的是疫苗、碘盐、饮用水、食品安全、控烟乃至烟盒颜色，作用在"让人不得病"这一层，比治病更靠前。 |
| 预防做了也看不见效果，不如等病了再治。 | 效益滞后正是它的特点；等到能看见时，代价已经发生在治疗端。刷牙与心血管风险的关系就是这个时间差的例子。 |
| 补碘这些年把甲状腺癌补高发了，赶紧换无碘盐。 | 原文的判断是检测手段变灵敏、发现得多了，补碘与甲状腺癌没有明确相关性；中国 75% 地区缺碘，停碘盐会重蹈印度覆辙。 |

## 第 018 讲

| 常见错误信念 | 纠正 |
|---|---|
| 癌症是突然得的，上个月体检还好好的，这个月就查出来了。 | 癌症是六个环节长期接连失守的结果，体检"正常"只是没查到这里，不等于没有过程。 |
| 得癌症是因为免疫力低，把免疫力提上去就能抗癌。 | 第四环是免疫"认不出"（被伪造身份骗过），不是简单的免疫力低；提高免疫力不解决识别问题，规范治疗才针对这一环。 |
| 把肿瘤切掉、把最明显的病灶处理掉，问题就解决了。 | 手术端掉的是加工厂，图纸错、能源供应、免疫逃逸、转移能力这些环节还在；这也是为什么治疗常要联合。 |

## 第 019 讲

| 常见错误信念 | 纠正 |
|---|---|
| 癌症越来越多，都是环境污染、食品不安全、压力大造成的。 | 突变的主要来源是复制随机错误（66%），环境加遗传只占 34%；癌症高发的主因是寿命延长、分裂次数变多。 |
| 我不抽烟不喝酒、生活规律，就不会得癌。 | 骨癌、甲状腺癌等癌种的突变 95% 以上来自随机错误；生活方式健康降低的是"能否走到癌"的概率，不是归零。 |
| 癌症要么治好，要么等死，中间没有别的路。 | 治疗用生存率评价；把肿瘤控制在安全数量下可以长期正常生活，但"共存"不等于放弃规范治疗。 |

## 第 020 讲

| 常见错误信念 | 纠正 |
|---|---|
| 冠心病就是心脏的血管堵了，放个支架通开就好了。 | 支架只解决一个点，年龄、吸烟、高血压、高血脂、糖尿病、肥胖这些病因还在，其它部位照样会窄。 |
| 冠状动脉天生就细，得冠心病是没办法的事。 | 冠脉不易收缩、内皮自净能力强，弥补了细的劣势；真正的危险因素是吸烟、三高、肥胖与年龄。 |
| 放了支架、做了搭桥就不能运动了，得静养。 | 经医生评估、病情稳定、症状控制后要逐步增加运动量；戒烟和运动是治疗里权重最高的两条。 |

## 第 021 讲

| 常见错误信念 | 纠正 |
|---|---|
| 心病就是心病，开导开导、想通了，身体的不舒服自然就好了。 | 应激加上剧烈心理变化造成的躯体损害是真病（胃溃疡就是标本），需要心身同治，不是靠开导自愈。 |
| 疼、麻、肚子不舒服但检查都正常，就是"矫情"或"装病"。 | 心身疾病有真实的器官落点，检查正常只说明没查到器质性病因，不说明没有病。 |
| 心身疾病只要治器官就行，心理那部分不重要。 | 只治器官效果不好，原文的阳痿病例正是靠打开心理症结才好转；原则是心身同治。 |

## 第 022 讲

| 常见错误信念 | 纠正 |
|---|---|
| 只要在医院里受了伤，就是医源性损害，就该赔。 | 手术必然创伤、药物已知副作用、疾病自然进程都不算；医源性损害只分事故与医疗局限性的代价两类。 |
| 医源性损害就是医生失误，跟清洁工、护工、陪护没关系。 | 院内与医疗过程有关的任何人都是潜在来源，消毒不到位引发的感染就是典型。 |
| 只要医生再细心一点，医疗事故就能避免。 | 个人警觉不能把差错概率归零，靠的是 HIS、PIVAS 这类流程与制度拦截。 |

## 第 023 讲

| 常见错误信念 | 纠正 |
|---|---|
| 忍痛是美德，关公刮骨疗伤都能忍，你怎么就不行。 | 忍痛既不科学也不人道；确诊之后所有的疼都不需要忍，免除疼痛是基本权利。 |
| 止痛药会上瘾，能不吃就不吃。 | 疾病严重时阿片上瘾概率极低，癌症病人吗啡成瘾比例低于 1％；该用不用反而让病人多受苦。 |
| 疼就是某个病的信号，病好了自然就不疼了。 | 超过三个月的慢性疼痛常常找不到原发病，它本身就是病，需要单独治疗。 |

## 第 024 讲

| 常见错误信念 | 纠正 |
|---|---|
| 岁数大了病就找上来，恢复也慢，这就是衰老，没办法。 | 老不等于衰；103 岁仍有不衰的人，14 岁也有已衰的人，差别在自我修复能力。 |
| 抗衰老就是抗氧化、清除自由基，买点补剂就行。 | 自由基只是第一层基因损伤的一种来源；本质那层是修复能力，靠睡眠、运动、戒烟限酒，不靠补剂。 |
| 记不住东西是老了，正常现象，不用管。 | 流体智力确有生理性下降，但记忆下降到影响生活（迷路、算错账、重复提问）须做专业评估，不能一律归为正常衰老。 |

## 第 025 讲

| 常见错误信念 | 纠正 |
|---|---|
| 疫苗就是把病毒打进身体，等于让人得一场小病，能不打就不打。 | 现代疫苗多数已不需要真病原体，人工合成抗原即可激发免疫；"小病"的代价换来的是对大病的长久记忆。 |
| 合格的疫苗就是绝对安全的。 | 合格只是过了设计与监管这一层；减毒活疫苗仍有极小概率致害（全程口服脊灰约 1/25 万），所以安全还要靠设计与覆盖一起兜。 |
| 别人都打了，我就不用打了。 | 群体屏障需要接种率过线（麻疹为 90%），掉队的人一多，屏障就失效，包括那些无法接种的人也会被暴露。 |

## 第 026 讲

| 常见错误信念 | 纠正 |

| 知情就是把病情完全搞懂，久病成医。 | 知情的目的不是把病人培养成医生；家属只需沟通治疗框架与原则性选择，专业细节交给信任的医生。 |
| 结果不好，说明当初的选择错了。 | 结局含大量随机性，同一决策在不同运气下结果不同；评价决策要看当时的信息与概率，不看单次结局。 |
| 找熟人医生问比找主管医生靠谱，毕竟在大医院见得多。 | 只有主管医生看得到用药后的反应、能把症状和数据对上；外部朋友缺反馈回路，只能给原则性建议。 |

## 第 049 讲

| 常见错误信念 | 纠正 |
|---|---|
| 不惜一切代价抢救，才是对亲人最大的爱。 | 过度抢救让死亡过程技术化，延长了生命也延长了痛苦；与治疗不足一样，都是没把痛苦当成要处理的目标。 |
| 缓和医疗就是放弃治疗，跟安乐死差不多。 | 缓和医疗不加速也不延后死亡，它用积极手段解除痛苦；安乐死是加速死亡，两者目标相反。 |
| 临终的痛苦只能忍着，忍过去就好了。 | 疼痛、恶心呕吐、水肿、呼吸困难、躁动谵妄都有对应的处理手段；忍耐不是美德，是没被处理的症状。 |
| 到时候家人自然会替我做主，不用提前写什么。 | 家人意见可能相悖、公开对质甚至闹到法院；清醒时写下的五个愿望，才是减少冲突的依据。 |

## 第 050 讲

| 常见错误信念 | 纠正 |
|---|---|
| AI 都通过执业医师考试了，医生迟早被替代。 | AI 只回答怎么做，不回答为什么；考试考的是既有知识，不考提出新假设，所以它属于继承而非叛逆。 |
| 新技术、新设备比旧方法好，越新越先进。 | 多数新技术只是把既有范式执行得更高效（继承），范式改变才叫叛逆；判断依据是它有没有改变「为什么」的答案。 |
| 照着趋势报告就能看清十年后的医学。 | 没人能精确预测具体技术，连作者自己的 2069 畅想都说「可能全错」；能做的是押不变的需求与判据。 |
| 医学总会有办法，先把眼下的事拖一拖。 | 「希望永存」是价值陈述，不是疗效证据；对不可逆的病情，仍要按第 49 讲提前安排，而不是等下一个疗法。 |

## 第 052 讲

| 常见错误信念 | 纠正 |
|---|---|
| 我总感冒，肯定是免疫力低，得补一补。 | 医院没有衡量免疫力高低的通用指标（艾滋病淋巴细胞下降除外），问题多在识别；先查反复感染的原因，再谈维护。 |
| 没症状就是没病，症状重就是病重。 | 症状是免疫反应的副产品；癌症早期无症状正因为免疫没认出来（免疫逃逸），所以「没感觉」更需要筛查。 |
| 免疫力越强越好，想办法往上提。 | 健全的免疫是识别谱宽，不是反应强度高；反应过强会走向过敏与自身免疫，「见多识广」才是方向。 |
| 抗生素吃了两天见好就可以停，免得伤身体。 | 自行减停会留下最耐受的菌，反而筛选耐药；抗生素要足量足疗程，且必须由医生处方。 |
| 每天喝酸奶就是在补益生菌。 | 普通酸奶里是发酵菌（双歧杆菌、保加利亚乳杆菌等），与益生菌是两个概念；添加了益生菌的产品要看包装标注。 |
| 越干净越健康，家里最好无菌。 | 过度卫生可能与过敏增加相关（卫生假说，尚未全面认可）；但霉菌环境明确有害，清洁与消毒要分开。 |
