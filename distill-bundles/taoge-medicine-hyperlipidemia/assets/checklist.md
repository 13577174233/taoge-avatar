# 血脂异常行动红线清单

> 打印出来贴冰箱。每条都是「什么情况下不能做 / 必须就医」。

- [ ] **危害 = 数值 × 时间** —— 本讲未给症状红线。若出现持续胸痛、胸闷伴出汗且不缓解，按急症立即呼叫急救，不要等血脂报告或下次体检。
- [ ] **隐形：听不见的滴答声** —— 出现活动后胸闷、胸痛、气短，或休息时胸痛持续不缓解，必须立即就医；这类症状不属于「高血脂无症状」的范畴，是斑块已经出事的信号。
- [ ] **40.4% 与「50 人里只有 2 人达标」** —— 这是人群统计，不用于个体判断——不要因为「大多数人都没达标」就认为自己也无需处理；也不要据此判断某家医院的达标率。
- [ ] **不能按胖瘦和年龄猜** —— 本条只解决「要不要查」，不解决「要不要吃药」。查出升高须由医生按风险分层决定治疗；医生已开药者不可自行停药或减量，出现肌肉酸痛、乏力、尿色变深立即就医。
- [ ] **及时干预可以逆转，但不是治愈** —— 逆转不等于可以自行停药。医生已开降脂药者，减量或停药必须由医生决定；出现肌肉酸痛、乏力、尿色变深立即就医。
- [ ] **症不是病：治不治看全局风险** —— 本条的「不必治疗」只能由医生在完成全局风险评估后作出。自行认定「我只是症」而拒绝复查、拒绝用药，是误用本条最常见的方式；医生已开药者不可自行停药、减量或换药，出现肌肉酸痛、乏力、尿色变深立即就医。
- [ ] **「高」字不准确：是血脂异常** —— 看到 HDL-C 偏低不能当成「血脂正常」，也不能自行买产品去升高它；须由医生综合判断。
- [ ] **脂质的四项功能** —— 本条是生理功能，不构成任何「补脂」建议；已有高血脂者不能据「脂质很重要」自行增加脂肪摄入。
- [ ] **没有好坏，只有过度** —— 不能因为「脂质不能太低」自行减药或停药。目标值是否调整必须由医生按危险分层决定；已经出现反复感染、体重下降、乏力应就医查因。
- [ ] **凝血与抗凝互相制衡** —— 本条不支持用鱼油或深海鱼替代抗凝药；已在用抗凝药者增加任何补充剂前必须先问医生。
- [ ] **吃进去的脂肪不直接进血** —— 本条不支持「所以吃油无所谓」——输入过量仍会通过原料变多推高血脂（004 A1、A2）。已有高血脂者不要用它作为放弃饮食管理的理由；医生已开降脂药者不可自行停药或减量。
- [ ] **血脂 = 船 + 货** —— 本条为机制，无直接动作；不构成任何「补充载脂蛋白」的建议。
- [ ] **外源性血脂危害极小** —— 本条不支持「餐后血脂不用管」；原文只说空腹测不到乳糜微粒，没说餐后高峰没有风险。
- [ ] **危害来自内源性，HDL 是克星** —— 本条为机制，不能据此自行购买「升高 HDL」的产品；HDL-C 偏低须由医生评估。
- [ ] **三条去路都很窄** —— 本条不是「所以不用运动」——运动提高消耗正落在第三条去路上（004 A6）；原文否定的只是「靠排」这一思路。
- [ ] **本质是流通中的脂质过多** —— 瘦子不能因为「我不胖」而不查血脂；也不能把这条当成「只需要减重」。
- [ ] **三层盘算：诊断看十年全局风险** —— 诊断未完成前不要自行购药；医生已开药者不可自行停药、减量或换药，出现肌肉酸痛、乏力、尿色变深立即就医。
- [ ] **关键变量是 LDL-C** —— 本条只说明看哪个指标，不构成用药依据；是否用药仍由医生按 A3、A4 判断。
- [ ] **两个端点：4.9 与 1.8** —— 达到 4.9mmol/L 以上必须尽快由医生开启治疗，不要等下一次年度体检；医生已处方者不可自行停药、减量或换药。出现肌肉酸痛、乏力、尿色变深立即就医。
- [ ] **目标随危险分层走** —— 3.4 与 2.6 是目标不是许可——达到目标后仍须按医生安排复查；不可自行停药或减量；出现肌肉酸痛、乏力、尿色变深立即就医。
- [ ] **检查时点：20 岁起，39 岁后每年** —— 本条是筛查时点，不是治疗阈值；查出异常后是否用药由医生按 A3、A4 判断。已用药者的复查频次由医生安排，不能因为「今年查过了」自行停药。
- [ ] **胆固醇每天 500mg 以下** —— 本条是上限不是目标，不必追求零胆固醇；已在服降脂药者不能因为「吃得少」自行停药或减量，出现肌肉酸痛、乏力、尿色变深立即就医。
- [ ] **主食超过总能量 60% 会转成甘油三酯** —— 本条不是「主食越少越好」——原文未给下限。用降糖药、胰岛素者改变主食量前必须问医生。
- [ ] **不饱和脂肪不低于总能量 17%** —— 坚果与植物油同样计入总能量，加它们的同时必须减别处，否则触发能量过剩；本条不构成「多吃油」的许可。
- [ ] **年龄与性别：不可改变的时间表** —— 绝经期女性不能把血脂升高当成「年纪大了正常」而跳过化验；也不能自行用激素替代来「保护血管」——原文未讨论激素治疗，须由医生决定。
- [ ] **吸烟 9.1% 与反式脂肪** —— 本条不能用来计算「少抽几支能降多少」，也不能用来给饮酒设「安全量」；已确诊脂肪肝、高甘油三酯者应就医评估。
- [ ] **一切都指向脂肪分布异常** —— 肚子大同时伴血压高、血糖高者应尽早就医评估代谢问题，不要只做「减肚子」的局部动作；出现胸痛、活动后气短立即就医；医生已开降脂药者不可自行停药或减量。
- [ ] **只有三步，不是遥远的事** —— 本讲未给症状清单。出现持续胸痛、胸闷、出汗不缓解或突发一侧肢体无力、说话不清，立即呼叫急救，不要等门诊。
- [ ] **第一步：血脂变形 + 血管壁损伤** —— 本条为机制，无直接动作；出现活动后胸闷、胸痛应就医查因，不要当成「氧化应激」自行调理。
- [ ] **第二步：斑块戴上帽子，问题被掩盖** —— 体检报告写「未见明显狭窄」不等于没有斑块风险；已被告知有斑块者，出现活动后胸闷、胸痛、气短加重，须立即就医，不能因为「上次说不严重」而拖延。用药者不可自行停药或减量。
- [ ] **第三步：破裂引爆，狭窄只是结疤** —— 突发持续胸痛不缓解、伴大汗、恶心，或突发一侧肢体无力、口角歪斜、说话不清，立即呼叫急救，不要自行前往门诊；不要因为平时「只是有点闷」而延误。已被告知有斑块并已用药者，不可自行停药或减量。
- [ ] **伤人的是自己的免疫系统** —— 本条不能用来否定疫苗、抗感染治疗或抗炎治疗；「免疫系统会伤自己」不等于「应该压制免疫力」。相关用药须由医生决定。
- [ ] **两个可以按下去的地方** —— 本条不是「生活方式可以代替药物」。已被医生判定需要用药（LDL-C 4.9mmol/L 以上、极高危）者，必须同时用药，不可自行停药或减量；出现胸痛、活动后气短加重立即就医。
- [ ] **三步变焦：先风险，后目标，再方案** —— 本条是顺序原则，不能用来推迟已在指征内的治疗——LDL-C 4.9mmol/L 以上属绝对危险，须立即治疗（003 A3）；医生已开药者不可自行停药、减量或换药。
- [ ] **四成冠心病患者血脂「不高」** —— 本条最容易被误用成「数值不高就不用管」。已确诊冠心病者即使血脂「正常」也须按极高危治疗；不可自行停药或减量。
- [ ] **用 China-PAR 评估，按时点刷新** —— 评估结果只用于决定干预强度，不等于诊断；评估显示高危或极高危者须尽快就诊，不可自行购药。评估网页与量表原文未附在本卡，须用原课程文稿区的链接。
- [ ] **三档目标：1.8 / 2.6 / 3.4** —— 目标值是医生与患者共同的决策依据，不是自行加量减量的理由；用药者不可自行停药、换药或减量，调整须复查后由医生决定。出现肌肉酸痛、乏力、尿色变深立即就医。
- [ ] **按档走流程：极高危立即用药** —— 不可自行停药、换药或减量——极高危人群原则上不会停药，停药等于把风险还回去；出现肌肉酸痛、乏力、尿色变深、食欲明显下降或皮肤发黄，立即就医查肝肾功能与肌酶。任何「保健品替代他汀」的做法都不在原文支持范围内。
- [ ] **钙化积分大于 100 就该用药** —— 本条不能自行决定做增强 CT 或造影，须由医生评估指征（两者都有损伤风险）；已被告知需要用药者不可自行停药或减量；检查后出现胸痛、气短加重立即就医。
- [ ] **口号不是处方，处方要具体到克与分钟** —— 本条不能用来替代或推迟医生已开的药物；已在服药者不可自行停药、换药或减量。
- [ ] **先定比例，别先砍脂肪** —— 本条反对的是"极端低脂"，不是鼓励高脂；脂肪供能超过 30% 不在本条支持范围内。执行期间若出现明显乏力、体重下降过快或化验提示白蛋白偏低，应就诊评估，不要继续自行压脂肪。
- [ ] **饱和脂肪压到 7% 以下，不饱和给到 15%-20%** —— 本条是食物结构，不涉及药物；但正在服他汀者不可因为"吃得对了"自行停药或减量，是否调整由医生复查后决定。若吃鱼后出现皮疹、口唇肿等过敏表现，停用并就医。
- [ ] **膳食纤维每天 20-30g，LDL-C 降 5%-10%** —— 增加纤维要同时保证饮水，否则可能腹胀、便秘加重（原文未列具体阈值）；出现持续腹胀、腹痛、排便习惯明显改变应就诊。纤维补充剂不能替代降脂药，不可自行停药改用纤维。
- [ ] **腰臀比比体重更重要：腰细、臀肥、腿粗** —— 运动中出现胸痛、胸闷、头晕、异常气短立即停止并就医；已有心血管病者不可直接照搬"每天 40-60 分钟"的强度，须由医生开运动处方。减重速度原文未给上限，不要用极低热量方式追求 5%-10%。
- [ ] **负面清单三条：反式脂肪、烟、大量饮酒** —— 本条不涉及停药；但戒烟过程中若出现明显焦虑、失眠，可寻求戒烟门诊帮助，不要用"电子烟替代"自行处理（原文未提电子烟）。长期大量饮酒者突然完全停酒可能出现戒断反应，应在医生指导下减量。
- [ ] **植物甾醇：每天 2g，LDL-C 降 10%** —— 植物甾醇是补充剂，不是治疗药物；已在服他汀者不可用它替代他汀，也不可因此自行停药或减量。原文未列出该补充剂的不良反应，服用期间出现任何不适应停用并就诊。
- [ ] **红曲米是"天然他汀"，按药物管，不能自己吃** —— 不可自行购买服用，更不可自行用它替代医生开的他汀、或自行停用他汀换它——不可自行停药、换药、减量，任何调整由医生复查后决定。出现肌肉酸痛或压痛、无力、尿色变深、食欲明显下降、皮肤或眼白发黄，立即就医查肌酸激酶与肝功能。
- [ ] **膳食纤维：25-40g，其中可溶性 7-13g** —— 原文未列出纤维补充剂的不良反应与上限；从食物获取优先。服补充剂期间若出现持续腹胀、腹痛、排便习惯明显改变，停用并就诊。纤维不能替代降脂药，不可自行停药改用纤维。
- [ ] **鱼油只降甘油三酯，还可能升 LDL-C** —— 鱼油是补充剂，不能替代医生开的降脂药，也不可因为吃鱼油自行停用他汀或贝特类。甘油三酯明显升高（尤其伴腹痛）须就医——原文提到家族性高甘油三酯血症可随时引起急性胰腺炎（010）。
- [ ] **运动最值钱的地方是升 HDL-C** —— 运动中出现胸痛、胸闷、头晕、异常气短，立即停止并就医。不可因为开始运动就自行减少或停用降脂药，是否调整由医生复查后决定。
- [ ] **睡眠只能辅助，不能单靠它降血脂** —— 原文未给睡眠方面的具体就医阈值。012 讲把"早醒（原来睡到 8 点现在 5 点自然醒、躺一小时睡不着）"和"不到中午就累得做不下去"列为平衡已被打破的信号，出现时应就诊评估，不要只靠调整作息。
- [ ] **时间是选药最可靠的标准** —— 本条不改变任何用药决定：不可自行停药、换药或减量；想换成"更新"的药，必须由医生评估后决定。
- [ ] **能降血脂不等于好药，要看终局** —— 不可自行服用大剂量烟酸类（维生素 B3）来降血脂；绝对风险较低的人不推荐用他汀做保健——原文说医学研究在他汀用于心脑血管绝对风险比较低的人群时，没有看到很好的预防作用。已在服药者不可自行停药、换药或减量。
- [ ] **他汀怎么降：减合成 + 加速分解** —— 不可自行停药、换药或减量；不同他汀不能自行互换（强度不同）。出现肌肉酸痛或压痛、无力、尿色变深、食欲明显下降、皮肤或眼白发黄，立即就医（详见 A4）。
- [ ] **副作用盯两块：肌肉和肝脏** —— 出现下列任一信号立即就医查肌酸激酶与肝功能——肌肉酸痛或压痛、无力、尿色变深（酱油色）、发热、食欲明显下降、皮肤或眼白发黄。就医前不要自行停药、换药或减量：突然停药会把风险还回去（006 A5），怎么调由医生决定。不可自行停药、换药、减量。
- [ ] **6% 效应：不达标要联合，不要翻倍** —— 不可自行把药片掰成两片、不可自行加用依折麦布、不可自行停药或换药——所有剂量与联合方案由医生在复查后决定。出现肌肉酸痛、无力、尿色变深、食欲明显下降或皮肤发黄，立即就医。
- [ ] **PCSK9 更强，但仍排在他汀之后** —— PCSK9 是处方药，不可自行购买使用，也不可自行停用他汀改用它——不可自行停药、换药或减量，顺序调整由医生决定。原文说 7 年随访未发现特别严重的不良反应，不等于长期风险已排除（原文自己说"我们还有很多不确定，很多的未知"）。
- [ ] **换血是成熟技术，但只给家族性患者救急** —— 这是有创的体外循环操作，必须在有资质的医疗机构、由医生判断指征后进行，不可作为保健项目购买。原文未列出该操作的不良反应；治疗中或治疗后出现头晕、心慌、出血、过敏样反应，立即由医护人员处理。
- [ ] **不改变源头，三个月血脂就回来** —— 不可因为一次化验单正常就自行停用降脂药；停药后血脂回升往往没有症状（000 A2），只能靠复查发现。
- [ ] **药物是单点力量，治不了全局** —— 这条最容易被误用成"反正药物只是单点，不如不吃"。该用药时仍须用药，不可自行停药、换药或减量——单点力量不等于无效，它解决的是最要害的那个环节。
- [ ] **药物是增长体系，身体是平衡系统** —— 这是对未来的推测，不能用来否定当下的规范用药。该吃的药要按时吃、按医嘱复查，不可自行停药、换药或减量；任何"减少药物种类"的想法都要先和医生讨论。
- [ ] **终极解法在源头，但要先做到可量化** —— 这套方法目前尚未落地，不能替代血脂化验与医生判断；也不可因为"我在管理生活方式"就推迟该做的药物治疗。
- [ ] **可穿戴数据要能医用，还需一代人** —— 现阶段可穿戴设备的数据不能作为诊断或调整用药的依据；不可根据手表数据自行加减药。
- [ ] **四高是同一批人的不同阶段** —— 这是流行病学描述，不能用来给自己"算命"，也不能因为"概率高"就放弃干预；已有任一高者须按对应规范治疗，不可自行停药、换药或减量。
- [ ] **RASS 是尿酸与血压之间那座桥** —— 不可因为"两条通路相连"就自行停用降压药或降尿酸药——不可自行停药、换药或减量；出现血压明显升高伴头痛、视物模糊、胸痛，或尿量明显减少、下肢水肿，立即就医。

- [ ] **第二阶段：先修总量，再修结构** —— 已有高尿酸者不能照搬"高蛋白"这一档（A1）；出现痛风急性发作、血糖明显升高或明显水肿，应就医调整方案。饮食调整不改变用药：不可自行停药、换药或减量。
- [ ] **压力的映射：睡眠和精力** —— 出现持续早醒、日间精力明显下降、情绪低落，或自评量表提示风险，应就诊（精神心理科/身心科），不要只靠运动和呼吸训练硬扛。原文给出的自评量表未附在本卡，需用课程文稿区的版本。

- [ ] **第三阶段：必须用药，目标更严** —— 不可自行停药、换药或减量，也不可因为"是药三分毒"自行减少种类或掰半片——目标收紧意味着需要更强的方案，减药等于放弃已达成的控制。出现胸痛、胸闷、活动后气短、尿量明显减少、下肢水肿、皮肤或眼白发黄、肌肉酸痛无力，立即就医。
