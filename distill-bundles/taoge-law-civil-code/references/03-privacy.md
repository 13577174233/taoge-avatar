# 隐私权与个人信息

> 什么时候读这一章：被偷拍偷录、宾馆摄像头、App 过度索权、人脸识别滥用时。

## 第 003 讲模型 · 隐私—个人信息双层保护模型

**核心主张**：隐私按四类客体、六类行为逐项设防，取"明确同意"的强保护；个人信息以"可识别性"为界、以处理三原则设槛，在防御与流动之间求平衡——两套规则相邻但保护强度不同，必须分开判断。

### 1. 隐私分四类：安宁、私密空间、私密活动、私密信息

- **命题**：民法典把隐私细分为安宁、私密空间、私密活动、私密信息四类。
- **展开**：《民法典》人格权编专章规定"隐私权和个人信息保护"，把"隐私"细分为四类：私人生活的安宁、不愿为他人知晓的私密空间、私密活动和私密信息。私密空间不限于住宅——办公室、宾馆房间都在内；私密活动如夫妻生活、私密谈话；私密信息包括医疗信息、财务信息、健康信息、基因信息等。《未成年人保护法》明确未成年犯罪案件中的姓名、家庭住址、肖像属绝对不能公开的隐私；残疾人保护法律也规定残疾儿童、少年的评估报告属隐私。立法同时把侵害隐私权的行为分成六种类型：前五类对应上述客体，第六类是兜底条款。判断一个行为是否侵害隐私，先把被侵害的对象归入四类客体，再对照六类行为。
- **机制**：立法者把"隐"（不愿让人知）与"私"（与公共无关）拆成可诉的客体清单，法院可以对号入座，摆脱"隐私就是阴私、必然牵连名誉"的旧观念，使保护不再依附于名誉权。
- **量化**：原文未给具体期限/数额；本条依据为条文客体的列举式界定——四类隐私客体、六种侵害行为类型（第六类为兜底）。
- **主体**：自然人享有隐私权，法人、非法人组织没有隐私。任何组织或者个人都不得侵害他人隐私；公安机关、国家安全机关在《刑事诉讼法》《反恐怖主义法》《反间谍法》授权并依法定程序时可进入搜查住宅、检查信件、监听窃听。
- **风险**：误以为"只有住宅是私密空间"，就会在办公室、宾馆、家门口摄像头等场景不设防或误判对方行为的违法性——在自己家门口装摄像头拍邻居每日进出，即可能构成侵害邻居隐私权。
- **条件**：四类划分用于判断民事侵权；法律另有规定（侦查、国家安全等）或者权利人明确同意时，相应行为不构成侵害。
- **反例**：把"我不愿意让别人知道的事"都当隐私主张——如披露他人不道德行为可能要衡量公共利益，并非一律构成侵害隐私。
- **动作**：对照四类客体给自己列一张"私密清单"（住址、病史、行程、家庭谈话），标注哪些信息在哪些场合暴露过。
- **自测**：宾馆房间、办公室属于四类隐私客体中的哪一类？
- **难度** 2｜**证据** A

### 2. 私人生活安宁：电话短信邮件传单侵扰即违法（第1033条）

- **命题**：未经明确同意，任何组织或个人不得以电话短信等方式侵扰生活安宁。
- **展开**：《民法典》第1033条禁止的侵扰方式包括电话、短信、即时通讯工具、电子邮件、传单等——骚扰短信、垃圾邮件、广告推送、伪基站半夜来电，都落在禁止范围内。此条有两个例外：法律另有规定（如《刑事诉讼法》授权的侦查监听、依《反恐怖主义法》《反间谍法》采取的技术侦查手段），或者权利人明确同意。两个例外之外，任何人组织营销、推送、催告都不得越过这道线。
- **机制**：回到私人空间后的"不被打扰"是人格尊严的一部分；立法把安宁从事实状态升为受法律保护的客体，防止商业机构用极低的触达成本消耗个人生活。
- **量化**：原文未给具体期限/数额；本条依据为第1033条列举的五种侵扰方式（电话、短信、即时通讯工具、电子邮件、传单）。
- **主体**：义务人是任何组织或者个人（含企业营销、催收机构）；权利人是自然人；公安机关、国家安全机关依法定程序侦查为例外。
- **风险**：企业若无明确同意群发营销短信、深夜电话推销，面临侵害私人生活安宁之诉；个人收到骚扰不保全记录（号码、时间、截图），日后主张难以举证。
- **条件**：以"法律另有规定或者权利人明确同意"为两个例外；仅一般性同意商业推广而未针对特定方式同意的边界，原文未展开。
- **反例**：以为"不上门、只发短信就没事"——短信、传单明确列在第1033条禁止方式之内。
- **动作**：收到骚扰信息时截图保全号码与时间戳，先书面要求停止，持续侵扰再起诉。
- **自测**：第1033条的两个例外是什么？
- **难度** 2｜**证据** A

### 3. 宾馆房间是私密空间，宾馆负安全保障义务（赫某案）

- **命题**：宾馆房间属私密空间，宾馆对房内偷拍设备负安全保障义务。
- **展开**：私密空间不止住宅——自己的办公室、出差住的宾馆房间都算，你在里面可以很放松。《民法典》明确把"宾馆房间"写进私密空间，针对的正是司法实践中出现过的宾馆安装微型摄像头案件。赫某与大酒店隐私权纠纷案：空姐赫某住店后第二天发现空调出冷气处藏着摄像头，宾馆称不知道谁放的、什么时候放的；法院仍判宾馆承担责任，理由是宾馆有安全保障义务，不能要求住客入住后像做地下谍报工作一样先扫描搜查一遍。
- **机制**：经营场所的控制力在宾馆而不在住客，由宾馆承担查防义务成本最低——法律在防"住宿者进门先搜查"的荒诞常态。
- **量化**：原文未给具体期限/数额（赫某案未公布赔偿数额）。
- **主体**：住客可以主张；宾馆受安全保障义务约束；实际安装偷拍设备者另构成侵权乃至刑事犯罪。
- **风险**：入住不检查即更衣、洗浴，影像一旦流出无法追回；发现摄像头只拔掉不留证据，事后无法证明宾馆未尽义务。
- **条件**：宾馆责任以未尽安全保障义务为前提；若设备系第三人安装且宾馆已尽合理查防，责任分担会不同，原文未展开该细节。
- **反例**：以为"摄像头是谁装谁负责，与宾馆无关"——赫某案法院判的是宾馆担责。
- **动作**：入住宾馆先查空调出风口、烟感器及正对床位的可疑物件，发现即拍照留证并要求宾馆处理、报警。
- **自测**：赫某案法院判宾馆担责，依据的是宾馆的什么义务？
- **难度** 2｜**证据** C

### 4. 侵害他人重大权益取得的证据，法院不予采用（李某诉陈某案）

- **命题**：以侵害他人重大民事权益方式取得的证据，法院不会采用。
- **展开**：夫妻离婚时常为证明对方出轨请私家侦探跟拍。李某（女）诉陈某（男）案中，陈某派侦探跟拍妻子，却拍下了李某与其姐姐洗澡的照片。民事诉讼中，以侵害别人重大民事权益的方式取得的证据、或者严重违背公序良俗的证据，法院不予采用——取证手段违法，拍到的"实锤"也是废纸，偷拍者自己反而构成侵害隐私权，被拍到的第三人（如李某的姐姐）也可以另行主张权利。
- **机制**：证据制度在"查明事实"与"手段正当"之间划线：若违法取证也能赢，等于鼓励全社会互相窥探，故程序正义优先于个案的实体真相。
- **量化**：原文未给具体期限/数额；本条依据为民事诉讼证据规则的两类排除情形（侵害重大民事权益、严重违背公序良俗）。
- **主体**：离婚取证方（如丈夫陈某）最易踩线；私家侦探同样可成侵权被告；被拍到的配偶之外的第三人也可独立主张隐私权。
- **风险**：违法取证=举证不能，可能直接败诉；同时偷拍者自己构成侵害隐私权，可能被反诉。
- **条件**：排除的是"侵害他人重大民事权益"或"严重违背公序良俗"取得的证据；在自己家中正常拍摄、公共场所合理拍摄不受此限。
- **反例**：以为"只要拍到了就是证据"。
- **动作**：取证前自问"这个手段本身是否侵害他人隐私"，跟拍、窃听、侵入私密空间这类拿不准的方式不用，改走申请法院调查等合法途径。
- **自测**：李某诉陈某案中偷拍的照片为什么没被法院采用？
- **难度** 2｜**证据** A

### 5. 个人信息的识别性与处理三原则（第1034条）

- **命题**：能识别特定自然人的信息即个人信息，处理须合法正当必要并经同意。
- **展开**：《民法典》第1034条第2款界定个人信息包括自然人的姓名、出生日期、身份证件号码、生物识别信息、住址、电话号码、电子邮箱、健康信息、行踪信息等；判断关键是"能识别特定的人"——个人信息最重要的作用就是让你找到特定的人，防疫流调、刑事侦查、精准广告投放都以识别为前提。处理个人信息须合法、正当、必要，不必要的不多收；须经自然人或其监护人同意，除非法律、行政法规另有规定；还要告知收集内容与用途。信息泄露的后果可极严重：徐玉玉被骗走上大学学费后心脏病发去世。保护个人信息不是目的本身，还要给合理使用留空间，否则数字经济受损。
- **机制**：个人信息之所以受保护，是因为它被滥用时直接威胁人身财产安全与人格尊严（被算法差别定价、"处于监控之中"之感）；但信息完全锁死又会让交往与数字经济停摆，所以立法取向是"防御性保护+合理使用"的平衡。
- **量化**：原文未给具体期限/数额；本条依据为第1034条第2款列举的八类以上信息范围与处理三原则。
- **主体**：仅自然人有个人信息，法人和非法人组织不在此列（企业信息还可能依《企业信息公示条例》公示）；处理者涵盖国家机关、企事业单位、商业机构；未成年人的同意由监护人作出。
- **风险**：信息一旦泄露可导致电信网络诈骗（徐玉玉案）、被犯罪分子追踪；泄露后往往查不出是谁泄露的——信息源太多，这也是明确处理原则对锁定责任主体的意义。
- **条件**：属防御性保护，不排斥合理使用——基于公共利益的信息披露、舆论监督、疫情防控（《突发事件应对法》《传染病防治法》授权的应急处置）可合理处理；自行公开或依法公开的信息可利用，除非权利人明确反对或利用会侵害其重大权益。
- **反例**：把企业工商登记信息当"个人信息"主张保护——法人与非法人组织无个人信息。
- **动作**：APP索权时逐项看是否告知用途，通讯录、行踪等非必要授权直接拒绝。
- **自测**：为什么《民法典》用"个人信息保护"而不用"个人信息权"？
- **难度** 3｜**证据** A

### 6. 隐私权与个人信息的四个关键差别

- **命题**：隐私权保护强于个人信息：须明确同意、不可许可，个人信息可概括授权。
- **展开**：两者联系在于都只有自然人才有；差别有四。其一，权利性质不同：隐私权是人格权，个人信息只是受保护的人格利益——人格权受侵害时即便对方无过错也可要求停止侵害、排除妨碍（家门口装摄像头拍邻居，装摄像头本身谈不上过错，邻居仍可要求停止），个人信息无过错时能否请求停止侵害则要斟酌（仅《民法典》第1167条兜底）。其二，行为界定不同：侵害隐私可发生在生活各领域，非法处理个人信息主要发生在用信息技术大量收集、存储、加工的机关与企事业。其三，能否许可不同：隐私权不可许可（私密部位、私密活动公开可能涉传播淫秽物品罪、违背公序良俗），个人信息可授权他人使用（APP读取通讯录、行踪须经授权）。其四，处理规则严格度不同：个人信息处理的法律、行政法规都可规定，隐私的获取须有法律特别规定或明确同意。
- **机制**：文义解释是法律解释的起点与边界——立法者用"明确同意"还是"同意"，措辞差异即保护强度差异；隐私取强保护，个人信息则在安全与信息流动自由之间平衡。
- **量化**：原文未给具体期限/数额；本条依据为文义对照——《民法典》中"明确同意"仅出现两处（隐私权、患者手术及特殊检查治疗的知情同意）。
- **主体**：自然人是两类规则的共同受益者；APP运营者依赖个人信息的概括授权开展业务；医务人员手术、特殊检查、特殊治疗须患者本人明确同意（昏迷或不适宜告知时为其近亲属的明确同意）。
- **风险**：把个人信息场景"点一下同意就算数"的习惯套用到隐私上，误以为概括授权即可使用他人私密信息，会直接构成侵害隐私权。
- **条件**：本条是两套规则的对照框架；私人之间、家庭生活中的个人信息处理，比较法上（如欧盟《通用数据保护条例》）明确排除适用，我国具体边界待《个人信息保护法》细化。
- **反例**：主张"我同意收集=同意公开我的私密部位照片"——混淆了可概括授权的个人信息与不可许可的隐私。
- **动作**：签含个人信息条款的文件时，先区分所涉内容是"隐私"还是"个人信息"，前者要求逐项明确同意，后者才可接受概括授权。
- **自测**：《民法典》里"明确同意"用在哪两类情形？
- **难度** 4｜**证据** C
