# 常见误区对照表

> 越相信左边，右边那条知识就越点不亮。逐条自查。

## 第 000 讲

| 常见错误信念 | 纠正 |
|---|---|
| 民法就是管婆媳不和、邻里纠纷、遛狗拴绳的"民的法律"，学它没用。 | 民法是社会主义市场经济的基本法，通过主体、物权、债权制度为市场提供基础规则，对法治国家建设的重要性仅次于宪法。 |
| 民法典就是把原来的单行法订在一起，没有新意。 | 编纂有大量增改废，并做了逻辑整理与价值塑造（内部体系与外部体系），分则按权利本位排成"五权+保障编"。 |
| 意思自治就是想怎么约定就怎么约定，签了也随时能反悔。 | 自治以行为能力为前提、以强制性规定和公序良俗为边界；依法成立的合同在当事人之间有相当于法律的效力。 |

## 第 001 讲

| 常见错误信念 | 纠正 |
|---|---|
| 民法典就是把物权法、婚姻法、继承法整合起来，没有什么新意。 | 立法机关梳理回应了公众最关心的问题（夫妻共同债务、隐私与个人信息），并对基因编辑等实验作出伦理表态，多有创新与探索。 |
| 法条里没写的（如网约车平台责任）就是立法者的低级疏漏。 | 不写可能是反复研究后的平衡取舍，是"留白"；解释者应先检索既有规则，不把留白当免责。 |
| 第1259条、第1260条的顿号用错了，说明立法粗糙。 | 2009年法工委立法技术规范明确可加顿号，2011年版国标只是推荐性标准，标点用法没有问题。 |

## 第 002 讲

| 常见错误信念 | 纠正 |
|---|---|
| 离婚冷静期让所有离婚都变难，家暴受害者也离不成婚。 | 冷静期只适用于双方合意的登记离婚；家暴主要出现在一方想离一方不想离的诉讼场景，走法院轨道，不受冷静期约束。 |
| 第一次判不离，隔6个月再起诉法院就必然判离。 | "6个月判离"是现象不是规则，有的法官起诉十几次仍判不离；民法典给出的是"判不准离婚后又分居满一年再诉应当判离"的确定规则。 |
| 只要是婚内一方借的钱，配偶都算夫妻共同债务要一起还。 | 第1064条改采共债共签；超出家庭日常生活需要的个人名义债务原则上不属共同债务，除非债权人证明用于共同生活、共同经营或有共同意思表示。 |

## 第 003 讲

| 常见错误信念 | 纠正 |
|---|---|
| 只有偷看信件、偷进住宅才侵害隐私，发短信、装摄像头不算。 | 六类侵害行为包括以电话、短信、即时通讯工具、电子邮件、传单侵扰生活安宁；家门口摄像头拍邻居、宾馆装微型摄像头都被点名。 |
| 拍到的就是好证据，出轨跟拍理直气壮。 | 以侵害他人重大民事权益方式取得的证据法院不采用，取证手段本身构成侵权，还可能被第三人反诉。 |
| 隐私和个人信息是一回事，点了"同意"就什么都能用。 | 隐私须明确同意且不可许可；个人信息才能概括授权，两套规则强度不同。 |

## 第 004 讲

| 常见错误信念 | 纠正 |
|---|---|
| 住宅70年到期后房子就不是自己的了，要重新买地。 | 第359条规定自动续期；未定的是续期费用怎么收，不是会不会失去房子。 |
| 抵押的房子必须先经银行同意才能卖。 | 第406条改为转让自由＋抵押权追及，无须同意，只需在可能损害抵押权时提前清偿或提存。 |
| 登记了超级优先权就天下无敌。 | 留置权永远排它前面；且十日不登记权利根本不成立。 |

## 第 005 讲

| 常见错误信念 | 纠正 |
|---|---|
| 网签了就万无一失，不会被一房二卖。 | 网签在现行法没有明确法律地位，真正挡处分的是预告登记，且其自能够登记之日起三个月内不申请正式登记即失效。 |
| 房子质量有问题就可以拒收甚至退房。 | 只有质量致合同目的不能实现（严重影响正常居住使用）才能拒收，否则自己构成违约。 |
| 夫妻一方擅自卖房，合同无效，买方只能认栽。 | 无处分权不影响合同效力（第597条），可要求继续履行或主张期待利益损害赔偿。 |
