# 民法典 · 行动与期限清单

> 遇到纠纷照着核对。每条都是「什么期限内做什么 / 做错会失去什么」。

- [ ] **民法典与商品经济互为条件，酝酿了六十六年** —— 把民法当"解决婆媳不和、邻里纠纷的小法"，签合同、买房、婚姻财产安排时不去查民法规则，纠纷发生才发现这些事全由民法典管；这是可核对的认知落差——民法是社会主义市场经济的基本法，通过主体制度、物权制度、债权制度为市场经济提供基础规则。
- [ ] **三大制度回答三个问题：准入、归属利用、交易规则** —— 误以为任何人都可随便签约——行为能力不足者、无权利能力的组织不具备市场准入资格，其交易效力会出问题；这是可核对的资格事实，不是道德劝诫。
- [ ] **以人为本：民法典的关怀从胎儿延伸到死后** —— 以为人一死权利即"全没了"或胎儿完全无资格——第16条明确胎儿在继承、赠与场景有权利能力；处理遗腹子继承时若忽略这一点，会侵害胎儿份额，属可核对的法律后果。
- [ ] **权利本位：分则是五个权利加一个保障编** —— 不知道自己受损的是哪种权利，就会找错编、提错请求——比如把身份权纠纷按财产权思路去主张，请求权基础落空，这是可核对的诉讼技术事实。
- [ ] **意思自治：民法区别于其他法律的核心** —— 以为"没看懂条款也可以反悔"——依法成立的合同在当事人之间有相当于法律的效力，签字前不谈条件、不看条款，事后难以推翻，这是可核对的合同拘束力事实。
- [ ] **意思自治有边界：行为能力分级与强制底线** —— 让8周岁以下孩子自行"签约"（网购大额商品、处置房产），该民事法律行为依法不能由其独立实施，须经监护人法定代理，否则效力不保；与限制行为能力人交易大额事项而未经其监护人同意，同样存在效力风险——这些是条文号可核对的法律后果。
- [ ] **民事案件占九成以上，民法是司法实践的主战场** —— 只关注刑法式"大案"而轻视民法，日常签合同、借款、网上注册时不做权利安排，纠纷发生时才发现自己天天活在民事法律关系里、却毫无事先准备——这是可核对的案件结构事实（九成以上民事）对应的认知错位。
- [ ] **民法典最后一段立法：高强度审议与压倒性通过** —— 把民法典误当成"部门起草、走个过场"的文本，会低估其中每条的审议背景与妥协含义，解释条文时不看立法过程材料，容易读偏——立法史是可核对的公开事实。
- [ ] **民法典的创新：回应公众关切与伦理表态** —— 不知道夫妻共同债务规则已改，被前配偶或其债权人主张连带清偿时不知抗辩路径，只能被动应诉；这是有明确条文对应的权利事实（详见第 3 讲 A6 的展开），不知规则者可能为本不属于自己"共同意思表示"的债务买单。
- [ ] **人格权编不居分则之首：先解决生存权的编排逻辑** —— 把"人格权编排在后"误读成"人格权不重要"，在人格权受侵害时不主张权利——人格权独立成编本身就是本部民法典的标志性安排，误读会导致放弃可主张的救济。
- [ ] **立法是遗憾与留白的艺术：没写不等于没研究** —— 把"法条没写"当成"可以做"——网约车平台、自动驾驶事故的责任问题不是没有责任，只是没有在民法典里专门写明，仍要按既有侵权规则与特别法处理；把留白当免责是可被裁判推翻的误读。
- [ ] **离婚冷静期只管协议离婚，不适用诉讼离婚** —— 30日内任何一方撤回，这次离婚登记即告吹，须重新走程序；误信"冷静期让家暴受害者也离不成婚"而延误采取诉讼、人身安全保护等法律行动，才是真正的风险——冷静期并不适用于诉讼离婚。
- [ ] **判决不准离婚后分居满一年再诉的，应当判离** —— 第一次判不离后若不真实分居、不留分居证据，再次起诉时拿不出"又分居满一年"的证明，法院仍可能不判离；把"第二次起诉必然判离"当规则而拖延准备证据，是可核对的经验误区（有起诉十几次仍不判离的实例）。
- [ ] **不规定同居制度，是立法的有意选择** —— 误以为同居多年就构成"事实婚姻"、自动享受夫妻共同财产制——1994年后只有登记婚才有效，分手时财产按各自所有处理，为对方付出较多的一方若没有书面约定，可能拿不出共有或补偿依据，这是可核对的财产后果。
- [ ] **离婚经济补偿不再以约定分别财产制为前提** —— 离婚时未提出补偿请求或拿不出负担较多义务的证据（照料记录、协助工作的事实），补偿主张可能落空——权利写在条文里，兑现靠举证，这是可核对的诉讼事实。
- [ ] **离婚经济帮助仍以"生活困难"为限，不保生活水平不降** —— 误以为离婚可保住原有生活水平而草率放弃财产协商与补偿主张，事后生活水平下降又达不到"绝对困难"门槛，无法获得帮助——"优越生活但未达低保线"是可核对的落差事实。
- [ ] **夫妻共同债务以共债共签为原则，债权人须自担安排** —— 债权人不对已婚自然人做事先安排，对方离婚后配偶可分走不带负债的一半财产，责任财产法定缩水；反过来，未举债一方只要共同签了字或事后追认，即使离婚也要承担无限连带责任——两个方向都是条文可核对的法律后果。
- [ ] **隐私分四类：安宁、私密空间、私密活动、私密信息** —— 误以为"只有住宅是私密空间"，就会在办公室、宾馆、家门口摄像头等场景不设防或误判对方行为的违法性——在自己家门口装摄像头拍邻居每日进出，即可能构成侵害邻居隐私权。
- [ ] **私人生活安宁：电话短信邮件传单侵扰即违法（第1033条）** —— 企业若无明确同意群发营销短信、深夜电话推销，面临侵害私人生活安宁之诉；个人收到骚扰不保全记录（号码、时间、截图），日后主张难以举证。
- [ ] **宾馆房间是私密空间，宾馆负安全保障义务（赫某案）** —— 入住不检查即更衣、洗浴，影像一旦流出无法追回；发现摄像头只拔掉不留证据，事后无法证明宾馆未尽义务。
- [ ] **侵害他人重大权益取得的证据，法院不予采用（李某诉陈某案）** —— 违法取证=举证不能，可能直接败诉；同时偷拍者自己构成侵害隐私权，可能被反诉。
- [ ] **个人信息的识别性与处理三原则（第1034条）** —— 信息一旦泄露可导致电信网络诈骗（徐玉玉案）、被犯罪分子追踪；泄露后往往查不出是谁泄露的——信息源太多，这也是明确处理原则对锁定责任主体的意义。
- [ ] **隐私权与个人信息的四个关键差别** —— 把个人信息场景"点一下同意就算数"的习惯套用到隐私上，误以为概括授权即可使用他人私密信息，会直接构成侵害隐私权。
- [ ] **添附规则（第322条）：约定→法律规定→发挥效能→保护无过错** —— 装修添建前不写约定，退租时只能依司法解释主张偿付，且偿付范围、利率标准（前些年是人民银行统一贷款利率，现在没有）都不确定，主张不及时即落空。
- [ ] **农地三权分置：耕地流转无须登记，四荒地必须先登记（第339–342条）** —— 四荒地未先登记就流转，处分不生效力；受让方不核查登记状态，付了钱权利落空。
- [ ] **住宅建设用地使用权期满自动续期，费用依法律行政法规办理（第359条）** —— 不能默认"自动续期=永远免费"，续期费用怎么收尚无定论；因公共利益收回恰逢期满时可能一分钱不补，剩余年限长才能获出让金补偿。
- [ ] **居住权是人役权：不得转让，原则上不得出租（第366–371条）** —— 买二手房不查登记簿，可能买到带居住权的房子而居住权人合法居留；以居住权名义经营获利超出权能范围。
- [ ] **抵押物转让自由＋抵押权追及效力（第406条）** —— 受让人不查抵押登记就受让，物上随时可能被主张抵押权、被执行；卖方收钱后，买方可能"钱房两空"还要面对抵押权人。
- [ ] **超级优先权：十日内登记才成立，且压不过留置权（第416条）** —— 超过十天未登记，超级优先权不成立，卖方沦为普通债权人；货交出去之后才想起登记，可能已来不及。
- [ ] **合同成立低门槛：没书面形式可补救，认购书也捆人（第490、495条）** —— 随手签认购书=可能承担与本约一模一样的违约责任；忽视户籍条款，前任卖方的户籍都可能是隐患，"这是法律上不太好处理的一个风险"。
- [ ] **查五证再付款：无预售许可证的合同起诉前补证仍有效，欺诈可罚一倍** —— 不查五证就付款，遇到无证楼盘网签登记全卡住；欺诈情形不主动起诉主张，惩罚性赔偿不会自动到来。
- [ ] **贷款批不下来：先归责，新政情形解约可拿回本金利息（司法解释第23条）** —— 误以为"贷不下来自然没事"——归责于买方时对方有解除权并可索赔；不主动行使解除权，钱已付出而房未得。
- [ ] **网签不是保险箱：真防一房二卖要办预告登记（三个月内申请登记）** —— 只网签不办预告登记，卖方仍可能一房二卖或抵押（网签在执行中的对抗效力只是司法实践发展，法律未明确）；预告登记后拖着不办正式登记，满三个月即失效，保护归零。
- [ ] **验收是权利也是期限：检验期过短只算外观瑕疵异议期（第620、621、622条）** —— 收房当天高兴签字，隐蔽瑕疵异议期过后只剩外观瑕疵可提；无约定时二年不通知，权利彻底消灭——除斥期间，不延长。
- [ ] **登记才取得所有权：交房未登记遇查封的四条救济与借名买房** —— 交房后拖延不过户，期间被查封，四条件缺一即救不回；借名买房若出名人转卖，第三人善意恶意都能取得所有权，借名人只剩债权请求。

## 期限与数额速查

- **民法典与商品经济互为条件，酝酿了六十六年**：首次起草1908年；起草历经三年、1911年完成；《大清民律草案》1569条；《中华民国民法》1225条；《民法通则》156条（1986年）；《德国民法典》2385条（1896年）；《法国民法典》2181条（1804年）；从1954年第一次起草到现在已经66年。
- **三大制度回答三个问题：准入、归属利用、交易规则**：原文未给具体期限/数额（三大制度为结构描述，无量化门槛）。
- **以人为本：民法典的关怀从胎儿延伸到死后**：18周岁取得完全行为能力；第13条（出生取得、死亡消灭权利能力）、第16条（胎儿）、第185条（英烈保护）。
- **权利本位：分则是五个权利加一个保障编**：七编（总则+分则六编）；分则"1+6""5+1"；财产权两项、人身权两项、以人身为前提的财产权一项。
- **意思自治：民法区别于其他法律的核心**：原文未给具体期限/数额；《民法典》第5条（自愿原则）、《法国民法典》第1103条。
- **意思自治有边界：行为能力分级与强制底线**：8岁以下无行为能力（第144条）；8—18周岁限制行为能力；满18周岁完全行为能力；电梯吸烟案一审判决赔偿1.5万元（《侵权责任法》第24条）；《民法典》第1186条。
- **民事案件占九成以上，民法是司法实践的主战场**：每年3000多万件案件；90%以上是民事案件；刑事案件和行政案件不到10%；每天约发生20个左右的民事行为（讲者估算）。
- **民法典最后一段立法：高强度审议与压倒性通过**：2015年启动，到通过历时五年；5月24日下午35个代表团、1100多名代表发言、1800多条意见；5月25日上午与5月26日晚连续两次会议；5月28日通过；2886名代表、2票反对。
- **民法典的创新：回应公众关切与伦理表态**：2017年底、2018年初收到500封左右群众来信；涉案债务有的甚至高达几千万。
- **人格权编不居分则之首：先解决生存权的编排逻辑**：原文未给具体期限/数额（本条为编排序位安排，无量化门槛）。
- **立法是遗憾与留白的艺术：没写不等于没研究**：2015年启动立法至今五年；涉及第1259条、第1260条的顿号争议；2009年法工委立法技术规范；2011年版国家标准《标点符号用法》为推荐性标准。
- **离婚冷静期只管协议离婚，不适用诉讼离婚**：30日（自婚姻登记机关收到离婚登记申请之日起）；2021年1月1日起施行；第二次申请发证的期限原文未给具体期限。
- **判决不准离婚后分居满一年再诉的，应当判离**：分居满一年（新增规则）；现行实践中两次起诉间隔6个月；法定离婚事由中的"因感情不和分居满两年"。
- **不规定同居制度，是立法的有意选择**：1994年（我国基本废除事实婚）；原文未给其他具体期限/数额。
- **离婚经济补偿不再以约定分别财产制为前提**：原文未给具体数额（补偿数额标准原文未给，"一年挣一亿"为讲者举例）；补偿在已分割共同财产的基础上进行再调整。
- **离婚经济帮助仍以"生活困难"为限，不保生活水平不降**：原文未给具体数额（"适当的帮助"数额未定）；司法实践以城市低保作为绝对困难的判断参照；日本比较法例子"有的甚至拿10%都不到的财产"。
- **夫妻共同债务以共债共签为原则，债权人须自担安排**：2004年《婚姻法司法解释（二）》；2017年补充规定；2018年最高法《关于审理涉及夫妻债务纠纷案件适用法律有关问题的解释》共四个条文、三项实体规则；"分得五千万""一块钱变五毛"均为讲者举例。
- **隐私分四类：安宁、私密空间、私密活动、私密信息**：原文未给具体期限/数额；本条依据为条文客体的列举式界定——四类隐私客体、六种侵害行为类型（第六类为兜底）。
- **私人生活安宁：电话短信邮件传单侵扰即违法（第1033条）**：原文未给具体期限/数额；本条依据为第1033条列举的五种侵扰方式（电话、短信、即时通讯工具、电子邮件、传单）。
- **宾馆房间是私密空间，宾馆负安全保障义务（赫某案）**：原文未给具体期限/数额（赫某案未公布赔偿数额）。
- **侵害他人重大权益取得的证据，法院不予采用（李某诉陈某案）**：原文未给具体期限/数额；本条依据为民事诉讼证据规则的两类排除情形（侵害重大民事权益、严重违背公序良俗）。
- **个人信息的识别性与处理三原则（第1034条）**：原文未给具体期限/数额；本条依据为第1034条第2款列举的八类以上信息范围与处理三原则。
- **隐私权与个人信息的四个关键差别**：原文未给具体期限/数额；本条依据为文义对照——《民法典》中"明确同意"仅出现两处（隐私权、患者手术及特殊检查治疗的知情同意）。
- **添附规则（第322条）：约定→法律规定→发挥效能→保护无过错**：原文未给具体期限/数额；举例为租期十年、第三年退租；四项法律效果的顺位（约定、法律规定、发挥物的效能、保护无过错当事人）。
- **农地三权分置：耕地流转无须登记，四荒地必须先登记（第339–342条）**：三分之二（原《物权法》社员代表大会同意门槛，耕地流转现已不要求）；"四荒"指荒山、荒沟、荒丘、荒滩四类。
- **住宅建设用地使用权期满自动续期，费用依法律行政法规办理（第359条）**：标准期限70年；原文提及存在50年甚至30年的住宅年限案例；续期时长与费用标准原文未定。
- **居住权是人役权：不得转让，原则上不得出租（第366–371条）**：原文未给具体期限/数额（居住权期限由约定，本讲未展开）。
