# 常见误区对照表

> 越相信左边，右边那条知识就越点不亮。逐条自查。

## 第 000 讲

| 常见错误信念 | 纠正 |
|---|---|
| 「三高」管好就够了，尿酸高一点没感觉，不用管。 | 高尿酸是系统性的代谢问题，会加速三高、直接增加心脑肾损伤，且在无症状期体内已有晶体沉积。 |
| 尿酸高都是吃出来的，管住嘴就行。 | 食物只占尿酸来源的 20%，升高的核心在排泄；只忌口等于只对两成因素做功。 |
| 高尿酸一旦得上就得终身吃药，治不好。 | 只要没走到痛风性肾病、肾功能不全就都有挽救余地，且大多数高尿酸用不到吃药。 |

## 第 001 讲

| 常见错误信念 | 纠正 |
|---|---|
| 尿酸是废物，越低越好，能排多干净就排多干净。 | 正常水平的尿酸是抗氧化剂，过低（低于 120μmol/L）大多提示肾脏疾病；目标是让尿酸不高，不是把它清空。 |
| 尿酸高只伤关节，跟血压、血糖、心脏没关系。 | 高尿酸是代谢紊乱，会经炎症通路加速三高，并直接增加冠心病、脑中风、肾结石与肾功能衰竭的风险。 |
| 人进化出尿酸说明尿酸高是好事，不用管。 | 保留尿酸是进化选择，但那些优势在今天已不明显甚至相反，现代人的高尿酸主要是代价那一面。 |
| 查了尿常规，尿酸正常，所以没问题。 | 尿尿酸对健康影响不大，要判读的是血尿酸。 |

## 第 002 讲

| 常见错误信念 | 纠正 |
|---|---|
| 尿酸高就是没管住嘴，火锅、啤酒、海鲜吃多了。 | 食物只占尿酸来源的 20%，大部分人是排泄出了问题；只忌口是只对两成因素做功。 |
| 尿酸越低越好，最好排干净。 | 尿酸是范围指标，低于 120μmol/L 大多由肾脏疾病导致，需要查肾功能。 |
| 尿酸高是基因决定的，我命由天不由我，做什么都没用。 | 基因只决定转运蛋白的底子，肥胖、甜食、酒精、高血脂高血糖都会影响这些蛋白的功能，生活方式可以改。 |

## 第 003 讲

| 常见错误信念 | 纠正 |
|---|---|
| 痛风不痛了就是好了，不用再管尿酸。 | 间歇期只是没有症状，晶体仍在，尿酸达标才能让晶体重新溶解；不痛恰是治疗的关键窗口。 |
| 尿酸高但没感觉，说明身体没事，等痛风发作再说。 | 无症状期体内已有微小尿酸钠晶体，与痛风之间没有明确界限，干预要从这个时期开始。 |
| 痛风就是关节痛，忍几天就过去了，不会伤别的器官。 | 痛风石会破坏关节骨头与肾功能，痛风肾病往往在出现水肿、少尿时已是终末期。 |

## 第 004 讲

| 常见错误信念 | 纠正 |
|---|---|
| 预防高尿酸就是忌口，海鲜啤酒不碰就行。 | 食物只占来源 20%，只忌口是只对两成因素做功；减重才是预防里的决定性手段。 |
| 减肥太麻烦，先把海鲜啤酒戒了更省事。 | 减重同时减少嘌呤合成、促进尿酸排泄、切断代谢紊乱，是全面改善，杠杆比忌口长得多。 |
| 已经痛风了，吃点维生素 C、鱼油就能降尿酸。 | 这三类补充剂只在预防阶段有用，已高尿酸时起不到降尿酸作用，也不能减少发作。 |
| 红酒对心脏好，可以放开喝。 | 所有含酒精的酒都升尿酸，预防阶段的底线是每天酒精不超过 10ml，红酒一杯就到线。 |

## 第 005 讲

| 常见错误信念 | 纠正 |
|---|---|
| 尿酸高先自己忌口，药能不吃就不吃，等痛风了再说。 | 无症状期已有明确用药门槛（超过 540μmol/L，或超过 480μmol/L 且有合并症），达标越晚、晶体沉积越多。 |
| 尿酸降下来就说明治好了，可以停药。 | 目标是长期达标；是否减药、停药必须由医生判断，自行停药会让晶体重新沉积。 |
| 降尿酸主要靠吃药，生活方式只是辅助。 | 基因只解释 8% 的变化，十年增长 200% 说明主因在生活方式；单点战术打不赢。 |
| 尿液 pH 不用管，结石是运气问题。 | pH 小于 6 是尿酸性肾结石的重要原因，指南建议把尿 pH 保持在 6.2-6.9。 |

## 第 006 讲

| 常见错误信念 | 纠正 |
|---|---|
| 痛风就是海鲜啤酒吃出来的，只要忌口就能降尿酸。 | 饮食作用分人群——健康人影响很小，已高尿酸者才成为「最后一根稻草」；单靠忌口也长期控不住。 |
| 严格低嘌呤饮食是降尿酸的唯一正道，只吃青菜主食最保险。 | 低嘌呤饮食本质是低蛋白，会带来碳水与脂肪的补偿性摄入，长期反而推高血糖血脂、加重高尿酸。 |
| 喝茶养生，多喝茶能降尿酸。 | 没有证据证明茶能降尿酸，反而有研究认为喝茶量与尿酸风险增加正相关；要喝就喝黑咖啡。 |
| 果汁是健康的，可以替代白水。 | 含糖饮料（含果糖、玉米糖浆）会阻止尿酸排泄，高尿酸者每天饮水应在 2L 以上，饮料要避开。 |

## 第 007 讲

| 常见错误信念 | 纠正 |
|---|---|
| 运动会诱发痛风，所以尿酸高的人最好别运动。 | 运动诱发发作只在强度越界、脱水、受寒时才发生；长期规律运动的人尿酸更低，无症状高尿酸者适度运动还延长预期寿命。 |
| 既然运动降尿酸，那就练得越猛、越久越好，跑个马拉松最有效。 | 超过最大心率 70%、单次超过 1.5 小时、强度越高的长时间运动，血尿酸反而越高；力量训练过量同样经乳酸通道抑制尿酸排泄。 |
| 痛风发作时多活动活动，把关节「活动开」就好了。 | 急性期运动增加关节损伤，不适合任何运动；要等疼痛基本消失，再从非常低的强度起步。 |

## 第 008 讲

| 常见错误信念 | 纠正 |
|---|---|
| 尿酸高是胖出来的结果，先把尿酸降下来，体重自然会回落。 | 两头证据（减肥使尿酸接近正常、脂肪组织增加合成并造成胰岛素抵抗）指向肥胖为因、高尿酸为果，因此要减重，不是等尿酸降了再减。 |
| 生酮、低碳水瘦得最快，正好用来快速降尿酸。 | 主食极少、肉很多的模式必然带来大量嘌呤，直接升高尿酸；低蛋白高脂肪同样会搅乱代谢。 |
| 减肥就得狠练，晚上出去跑一场出透汗最有效。 | 寒冷、剧烈运动、脱水三样叠加会让血尿酸直线升高；体重降了、尿酸升了，痛风就来了。 |
| 只要瘦得快，尿酸早晚会跟着降。 | 饥饿产生的酮体与尿酸争同一条排泄通道，瘦太快尿酸必然升高，速度应控制在每月 0.5～1kg。 |

## 第 009 讲

| 常见错误信念 | 纠正 |
|---|---|
| 非布司他比别嘌醇新、副作用小，所以应该自己换成非布司他。 | 非布司他靶点更精准、40mg 抵 300mg 别嘌醇，但可能带来更多心血管风险，指南仍把它排在别嘌醇之后；换药须由医生决定。 |
| 尿酸降到正常就说明治好了，可以把药停掉。 | 滴定原则里的「立即停止」是停止加量，不是停药；达标后需按医嘱维持，停药会让尿酸回到原点。 |
| 秋水仙碱吃到拉肚子，说明药劲上来了，效果最好。 | 恶心、呕吐、腹泻是中毒剂量低的典型表现，往往在效果刚出现时就开始；止疼效果与小剂量无关，出现这些症状要停药就医。 |
| 刚吃降尿酸药反而发作更频繁，说明这药不适合我，赶紧停。 | 这是溶晶引起的反跳，可能性高达 64% 左右，指南因此要求起始降尿酸时联合小剂量止疼药至少 3-6 个月；发作要找医生调整，不是停药。 |

## 第 010 讲

| 常见错误信念 | 纠正 |
|---|---|
| 痛风是疼过才算，没疼过就不是痛风，尿酸高一点没关系。 | 指南的定义是体内有尿酸晶体即算痛风，晶体一出现损伤就已开始，发作只是时间问题。 |
| 尿酸数值越高，越容易痛风；看这一个数就能知道自己会不会发作。 | 饱和点随温度、酸碱度、炎症状态在不同人和不同日子间变动，单看浓度没法判断谁会转成痛风。 |
| 既然代谢组学能预测痛风、能定制食谱，现在就可以花钱去做一套。 | 模型尚未外部验证，标志物的个体定量也不成熟；原文自己用的是「未来，如果更多人可以验证」，现在只能当研究方向。 |
| 只要每天凑够一次运动量，白天坐多久都无所谓。 | 连续监测显示全天经常站立、走动的人，尿酸与胰岛素敏感性都优于久坐加偶尔大运动量的人；活动总量与单次剂量是两件事。 |

## 第 011 讲

| 常见错误信念 | 纠正 |
|---|---|
| 尿酸高就是会痛风，跟血压、心脏、肾脏没关系。 | 尿酸既是 RASS 处理的信号，又通过排泄损伤肾脏这个 RASS 中枢，还与血压形成双向加重的回路；四高的结局都落在心、脑、肾。 |
| 四高是四个独立的病，血压高吃降压药、血糖高吃降糖药，各治各的。 | 糖、脂肪、蛋白质三条通路共用一套转运与供能系统，坏一条会拖累另外两条；要在一高出现时就同时查其余三项。 |
| 血脂正常，血管就不会长斑块。 | 普通血脂不堆斑块，氧化后的才堆；高尿酸会加速脂质氧化，把斑块时间从五到十年缩到三五年。 |
| 糖尿病是吃糖吃出来的，不吃甜食就不会得。 | 高尿酸先让细胞对胰岛素不敏感，形成胰岛素抵抗，再推向 II 型糖尿病；能量过剩与尿酸升高在同一条路上。 |

## 第 012 讲

| 常见错误信念 | 纠正 |
|---|---|
| 既然四高的方案相通，那把四门课的建议加在一起执行最全面。 | 四高的建议会互相冲突（高血糖要高蛋白、高尿酸忌高蛋白；高血压推力量训练、高尿酸限力量训练；高血脂说喝茶降脂、高尿酸说茶可能升尿酸），只能取交集。 |
| 身体没病就该练到极限，强度越高越好。 | 心肺极限不是越高越好，而是用 220-年龄算出区间，中等 40%-59%、高强 60%-89%，每周 75 分钟高强度或 150 分钟中等即可。 |
| 只要吃得清淡、把碳水压到最低，四高都能好。 | 三大能量物质缺一不可，碳水应占 55%～75%、脂肪 20%～30%、蛋白质 1g～1.5g/kg；极端压低碳水会拖垮代谢。 |
| 医生开的药太多，症状没了就自己减一半，少吃点总没坏处。 | 多高并存时互为因果，指南要求的目标更严（尿酸 360μmol/L，合并糖尿病 300μmol/L 以下）；减量或停药必须由医生决定，自行减药是慢病防治失败的主因之一。 |
