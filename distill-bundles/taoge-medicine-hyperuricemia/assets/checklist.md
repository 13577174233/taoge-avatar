# 高尿酸行动红线清单

> 打印出来贴冰箱。每条都是「什么情况下不能做 / 必须就医」。

- [ ] **高尿酸是「第四高」，不是痛风的附属品** —— 本条是认知框架，不构成自我诊断依据。出现关节红肿热痛、夜间突发剧痛，或体检尿酸升高，应就医评估，不要按「第四高」自行买药。
- [ ] **尿酸升高的主因在排泄，不在吃喝** —— 本条用于纠正「管住嘴就够了」的误判，不是「可以随便吃」的许可。已确诊高尿酸或痛风者仍须按第 5、6 讲的方案控制饮食。
- [ ] **30 岁是患病高峰，50 岁前男性风险是女性 8 倍** —— 年轻男性一次尿酸偏高不等于确诊，须按第 3 讲复测；出现关节红肿热痛应就医，不要按「年轻扛得住」处理。
- [ ] **可防可逆，但有一条不可越的线** —— 必须定期查肾功能，不能只盯尿酸。出现夜尿增多、尿量减少、下肢水肿应立即就医——这三条是第 3 讲给出的肾损害可观察信号。
- [ ] **不必苦行僧，找得到「美食与尿酸的平衡」** —— 放宽不等于放开。出现关节红肿热痛立即回到严格限制并就医，急性期不是「腾挪」的时候。
- [ ] **尿酸是嘌呤代谢的终产物，嘌呤只是「邮差」** —— 本条是机制认知，无直接操作风险。但「终产物」不等于「废物」，不可据此追求把尿酸降到极低——第 2 讲明确低于 120μmol/L 大多由肾脏疾病导致。
- [ ] **要盯的是血尿酸，不是尿尿酸** —— 尿尿酸正常不能排除高尿酸；拿到报告先确认那栏是血尿酸（血清/血浆），再判读。
- [ ] **尿酸是双刃剑：正常抗氧化，过高促氧化** —— 本条不能反推「所以尿酸低一点更好」——原文明确低于 120μmol/L 大多由肾脏疾病导致，需要关注。
- [ ] **人类保留尿酸是自然选择，换来四重功能** —— 本条不产生任何治疗动作；「尿酸有好处」不能用于拒绝降尿酸治疗。
- [ ] **高尿酸经炎症因子加速「三高」** —— 本条不替代血压血糖检测。尿酸高的人应同步测血压、空腹血糖、血脂；一旦确诊三高，按相应疾病规范就医，不能只降尿酸。
- [ ] **高尿酸直接损伤心、脑、肾三条线** —— 出现关节红肿热痛（尤其夜间突发、第一跖趾）应按痛风急性发作就医，不要自行按摩、热敷或硬扛；出现胸痛、言语不清、单侧肢体无力立即急诊。
- [ ] **尿酸有性别与绝经状态不同的正常区间** —— 尿酸低于 120μmol/L 应查肾功能，不要当成「身体好」；区间是人群参考值，个体需结合症状与肾功能判断。
- [ ] **高尿酸的界值：420 与 360** —— 单次超标不等于确诊，第 3 讲要求复测；确诊后按第 5 讲的分层设目标值，不要拿界值当治疗线。
- [ ] **嘌呤 80% 自己合成，20% 来自食物** —— 本条不能作为「可以放心吃」的依据——原文同时指出，正因为内源相对恒定，不同人尿酸水平的差异还是「吃」主导得更多一点。
- [ ] **尿酸升高主要出在排泄，不在合成** —— 排泄通道受损可能来自肾脏疾病或药物。出现尿量变化、水肿应查肾功能，不要只在饮食上找原因。
- [ ] **肾脏四步重吸收，最终只排出 6%-10%** —— 本条是机制认知，不构成用药依据；影响肾小管转运的药物须由医生评估。
- [ ] **降尿酸真正的靶点是重吸收转运蛋白** —— 苯溴马隆、丙磺舒、氯沙坦均为处方药，用不用、用多少必须由医生决定，不可自行购买服用，不可自行停药或换药；用药期间按医嘱复查尿酸、肝功能、肾功能。
- [ ] **无症状期只能靠体检发现：两次超 420** —— 单次超标不等于确诊，但也不等于可以不管；应在同一实验室复测，并结合肾功能评估。
- [ ] **无症状期并不无害：晶体已经在沉积** —— 此期唯一可靠的动作是复查与生活方式干预；出现关节红肿热痛即进入痛风初期，应就医而不是继续观察。
- [ ] **急性发作画像：夜间、第一大脚趾、一周内结束** —— 急性发作期需就医用药，不要自行按摩、热敷或硬扛；出现发热、关节破溃、疼痛超过一周不缓解，需排除感染等其他病因，不能一律当成痛风。
- [ ] **结晶挑地方：末梢循环差的部位先沉积** —— 脚趾、足背出现无痛性硬结节（疑似痛风石）应就医评估，不要自行挑破或挤压。
- [ ] **间歇期是逆转窗口：降下来晶体能溶回去** —— 不痛不等于不用治；停药、停复查都会让这个窗口关闭。是否停药必须由医生根据尿酸是否长期达标决定，不可自行停药或换药。
- [ ] **痛风石与痛风肾：最后两阶段难以回头** —— 出现夜尿增多、尿量减少、下肢水肿、关节处硬结节，必须立即就医查肾功能——这些是可观察信号，不能等到疼痛才去。
- [ ] **只调饮食预防高尿酸，事倍功半** —— 本条不是「饮食无用」。痛风急性期与已高尿酸者仍须严格控饮食，否则会直接诱发发作。
- [ ] **减肥是预防的决定性手段，且不挑方法** —— 减重速度过快、极端节食可能诱发痛风发作（原文未讨论，但属常见风险）；出现明显乏力、心悸、脱水应停止并就医。
- [ ] **酒只看酒精总量：每天不超过 10ml** —— 出现痛风发作、肝功能异常应停酒并就医；服用影响尿酸代谢的药物期间饮酒的风险原文未讨论，须问医生。
- [ ] **果糖是唯一能直接升尿酸的碳水** —— 本条属饮食选择，无急性风险；用代糖饮料替代时，原文只把它列为替代品，未评估长期影响。
- [ ] **奶制品吃得越多，尿酸越低** —— 选低脂或脱脂而非全脂，原文未说明全脂奶的危害机制，本卡不做额外推断；肾病患者蛋白质摄入量须由医生定量。
- [ ] **补充剂只在「还没高尿酸」时有用** —— 补充剂不能替代药物，也不可自行加量；服用抗凝药者补充鱼油、孕期补充剂量，须咨询医生。出现不适立即停用并就医。
- [ ] **高尿酸是生活方式病，基因只解释 8%** —— 生活方式为主线不等于可以不吃药；未达标前不可自行停药、减药，用药调整须由医生决定。
- [ ] **目标只有一个：尿酸长期达标，按风险定值** —— 目标不是越低越好——原文明确不建议将血尿酸长期控制在 180μmol/L 以下。达标后是否减药、停药由医生决定，不可自行停药或换药。
- [ ] **无症状期什么时候开始吃药：540 与 480** —— 是否用药必须由医生结合三方面评估决定。不可自行购买降尿酸药服用，不可自行停药或换药；用药后按医嘱复查尿酸、肝功能、肾功能。
- [ ] **痛风期门槛更低，目标更狠** —— 用药与停药都必须由医生决定，不可自行停药或换药；「300 到 180 之间」是医生判断的区间，不是自行加量的理由。
- [ ] **碱化尿液：把晨尿 pH 提到 6.2-6.9** —— 碳酸氢钠的使用与剂量必须由医生根据尿 pH 决定，不可自行长期服用；出现水肿、血压升高、腹胀应停药并就医；出现腰痛、血尿等结石症状立即就医。
- [ ] **心理一增一减** —— 减压方法不能替代降尿酸治疗与药物；出现持续失眠、情绪明显低落、无法工作应就医，不要只靠冥想硬扛。
- [ ] **健康人不必忌口，患者那 20% 是最后一根稻草** —— 已高尿酸者出现关节红肿热痛即按急性发作处理并就医；急性期饮食要求更严（A2、A4）。
- [ ] **嘌呤三档与「低嘌呤饮食长期无效」** —— 痛风急性发作期仍须避开高嘌呤食物（A4）；长期执行低嘌呤饮食者应监测血糖、血脂与体重。
- [ ] **用 DASH 综合结构替代单一食物禁忌** —— 慢性肾病患者按 DASH 吃可能钾、磷负荷过高，须由医生或营养师调整；出现水肿、尿量减少应就医。
- [ ] **酒：上限、酒种排序与发作期滴酒不沾** —— 饮酒后出现关节红肿热痛应立即停酒并就医；正在服用降尿酸药或止痛药期间饮酒的风险原文未讨论，须问医生。
- [ ] **每天饮水 2L 以上，含糖饮料不喝** —— 限水人群饮水过量可致水肿、心衰加重；出现水肿、气短、尿量明显减少应停止加量并就医。
- [ ] **茶不推荐，黑咖啡可以** —— 本条不含治疗作用，不能替代降尿酸药物；出现心悸、失眠、胃痛应减量或停用。
- [ ] **短期升尿酸，只在强度越界时发生** —— 运动后夜间或次日出现关节红肿热痛（多见于大脚趾、踝、膝），按急性发作处理并就医，不要热敷、不要继续练；出现胸闷、心悸、头晕立即停止运动并就医。
- [ ] **长期看，规律运动降尿酸** —— 长期收益以年计，不能用「我今天练了」来替代复查；尿酸持续偏高或已发作过痛风者，运动不能替代药物，是否用药由医生决定。
- [ ] **强度上限：最大心率的 70%** —— 运动中或运动后出现胸痛、胸闷、明显心悸、头晕、眼前发黑，立即停止并就医；正在服 β 受体阻滞剂者心率会被压低，公式算出的区间不可靠，须问医生。
- [ ] **剂量：每周 150-300 分钟，单次别超 1.5 小时** —— 运动中或运动后关节出现红肿热痛，停止训练并就医；有心脏病史者运动总量与强度须经医生评估，不要自行拉到 300 分钟。
- [ ] **急性期不动，间歇期补水保暖** —— 急性发作的关节红肿热痛、活动受限，休息并就医，不要靠运动「活动开」；出现发热、关节多处同时发作，尽快就诊；运动前后尿色明显加深、尿量减少，说明脱水，立即补液并停止运动。
- [ ] **关节炎期：照样要动，但要换方式** —— 活动中关节出现锐痛、肿胀加重、皮温升高，立即停止并就医；不要以「练到疼才有效」为标准，关节炎期的目标是活动度与肌力，不是负荷。
- [ ] **肥胖是原因，不是结果** —— 减重期间出现关节红肿热痛、明显乏力、心悸，先停下并就医；已在服降尿酸或降糖、降压药者，不可自行停药或换药，减重带来的剂量变化要由医生调整。
- [ ] **减肥期不能低碳水、不能生酮** —— 减重期间痛风发作，按急性发作处理并就医；不要为了「压尿酸」自行加用降尿酸药或保健品，用药须由医生决定，不可自行停药或换药。
- [ ] **减肥期不能剧烈运动，尤其在天冷时** —— 夜间或运动后突发单关节剧痛、红肿发热，按急性发作处理并就医；出现胸闷、胸痛、头晕立即停止运动并就诊。
- [ ] **减肥速度：每月 0.5～1kg** —— 减重期间出现明显乏力、头晕、心悸、痛风发作，停止节食并就医；不要用代餐、泻药、利尿剂换速度，也不要自行服用降尿酸药，用药须遵医嘱，不可自行停药或换药。
- [ ] **方案：500～700 大卡缺口 + 均衡饮食** —— 减重过程中出现持续乏力、脱发、月经紊乱、痛风发作，暂停并就医；不要同时自行加用减肥药与降尿酸药，任何用药调整须经医生，不可自行停药或换药。
- [ ] **先减腰围：每增 1 公分，风险 +9%** —— 腰腹痛、腹部包块、体重短期明显下降伴腰围变化，先就医排查，不要当成减脂成果；运动中出现腰痛加重应停止并就诊。
- [ ] **少合成：别嘌醇一线，非布司他第二** —— **不可自行停药或换药，也不可自行加减剂量。** 服别嘌醇或非布司他期间出现皮疹、发热、口腔或眼部黏膜糜烂、皮肤大片剥脱，立即停药并急诊（此类反应起病快）；出现胸闷、胸痛、心悸、活动后气短，尽快心内科就诊；出现尿量明显减少、下肢浮肿，及时复诊查肾功能。
- [ ] **多排出：苯溴马隆有肝毒性，酶类只能注射** —— **不可自行停药或换药。** 服苯溴马隆期间出现乏力、食欲明显下降、皮肤或眼白发黄、尿色加深如浓茶，立即停药并查肝功能；注射酶类药后出现皮疹、面唇肿胀、呼吸困难、血压下降，属急性过敏，立即急诊；服药期间出现尿量减少、腰痛、血尿，尽快就诊。
- [ ] **滴定到达标：达标就停加量，不是停药** —— **不可自行停药或换药，不可自行加减剂量。** 尿酸复查已达标也不等于可以停药，须由医生决定维持方案；加量期间出现皮疹、发热、明显乏力、尿量减少、关节红肿热痛加重，及时就诊；连续漏服后不要自行补双倍剂量，联系医生。
- [ ] **治标：秋水仙碱一线，小剂量即足量** —— **不可自行停药或换药，不可自行加量。** 服秋水仙碱期间出现恶心、呕吐、腹泻，是中毒的早期信号，立即停药并就医；出现尿量明显减少、下肢浮肿，急诊查肾功能；服非甾体抗炎药后出现黑便、呕血、上腹剧痛，立即急诊；用激素期间出现发热、伤口不愈、血糖明显升高，尽快复诊；任何一类止疼药都不要与酒同服。
- [ ] **起始降尿酸，就要合用止疼药 3-6 个月** —— **不可自行停药或换药，尤其不可自行提前停掉联合的止疼药。** 起始降尿酸的几个月内出现新的关节红肿热痛，是反跳而非药物无效，及时联系医生调整而不停药；出现恶心呕吐腹泻、黑便、皮疹、尿量减少，尽快就诊。
- [ ] **捎带手：降压降脂降糖药里有能降尿酸的** —— **不可自行停药或换药，不可为了「顺便降尿酸」自行加药。** 已在服降压、降脂、降糖药者，换药必须由医生决定，自行停用会带来血压、血糖失控；服药期间出现头晕、乏力、肌肉酸痛、尿量减少、皮疹，及时复诊。
- [ ] **判定痛风看晶体，不看有没有发作过** —— 关节红肿热痛反复发作、出现痛风石或关节变形，应就诊风湿免疫科或内分泌科，不要靠「忍过去」；不要为了「查有没有结晶」自行要求做有创检查，方案由医生定。
- [ ] **尿酸浓度本身预测不了痛风** —— 尿酸值高低都不能替代就诊判断，单次正常不代表安全，单次偏高也不代表马上发作；关节红肿热痛仍要就医，不要靠「我的尿酸不算太高」自我排除。
- [ ] **七种代谢物的模型，能区分痛风与无症状高尿酸** —— 这类模型是研究工具，不是诊断工具。不能拿它替代尿酸检测，更不能据此自行开始或停止降尿酸药——用药必须由医生决定，不可自行停药或换药。
- [ ] **精准营养靠代谢组学，不是靠一份菜谱** —— 不要购买宣称「代谢组学定制食谱」的商业服务来替代正规营养门诊；有肾功能不全、糖尿病者调整饮食须由营养师或医生给出方案。
- [ ] **精准运动：全天零散活动胜过偶尔狠练** —— 增加日常活动量时若出现关节疼痛加重、心悸、头晕，减少活动并就诊；不要用「反正要动」把急性发作期也填满。
- [ ] **精确记录：拍照与可穿戴设备替代量表** —— 记录工具不产生治疗方案，不要根据 App 给出的数字自行调整降尿酸或降糖、降压药，不可自行停药或换药；若记录行为引起明显焦虑或暴食-节食循环，停用并寻求专业帮助。
- [ ] **高尿酸是四高里交互最多的那根线** —— 这些是群体统计，不是个人风险值。查出任意一高，要同时查其余三项；已在用药者不可自行停药或换药。
