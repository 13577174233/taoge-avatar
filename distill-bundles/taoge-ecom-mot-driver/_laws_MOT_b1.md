# MOT 分律表 第1批（MOT001–MOT010）

**来源课程**：汪志谦·MOT体验设计课（16讲）
**批次**：b1（MOT001–MOT010，覆盖发刊词＋01–09讲）
**日期**：2026-11-07
**领域**：营销/体验设计

| 编号 | 短名 | 一句话 | 来源 |
|---|---|---|---|
| MOT001 | 关键时刻律 | MOT不是把服务整体拉高，而是找到那不到1分钟的决策瞬间，用洞察解码人心、用落地编码植入，在那一点打出峰值 | 发刊词／MOT001 |
| MOT002 | 三时刻律 | 消费者只记得最高、最低、最终三个时刻，正确姿势是灭低谷、在不到10个真正影响决策的时刻造峰值，其余投入皆为无效功 | 01讲／MOT002 |
| MOT003 | 短板维度律 | 进店、转化、复购、推荐四维先看数据找当下最差的一维，聚焦打透，不做四维平均提升 | 02讲／MOT003 |
| MOT004 | 三问三答律 | MOT须写成"是谁、在什么状况下、感受到什么"的40字内场景句，只从爱你的人、不爱你的人、喜欢你的人三类口中挖 | 03讲／MOT004 |
| MOT005 | 五感切口律 | 进店MOT只能从"爱你的人"的五感记忆里挖；有效进店必须留下印记并撑到转化，否则进店率再高也是无效功 | 04讲／MOT005 |
| MOT006 | 三句式律 | 一见就进靠三句：就是这样（五感唤醒既有认知）、那是怎样（好奇与从众）、怎么会这样（反差冲撞），落点须是可拍照可转述的一物 | 05讲／MOT006 |
| MOT007 | 五障碍律 | 转化率问题八成出在"你讲的他接收不到"，逐条拆五大障碍：说人话、对准需求、让美可见、给信任状、指向买哪一个 | 06讲／MOT007 |
| MOT008 | 试看买律 | 转化落地三句：试这个（把探寻者变使用者）、看这个（五感把美可视化）、买这个（明确指向＋信任状＋抹平换购损失） | 07讲／MOT008 |
| MOT009 | 六值时刻律 | 复购靠六种"值了"的时刻（最初开箱/最真符合/最高峰值/最有面子/最低逆转/最没想过）造峰值并把低谷清零，值一次不够，要次次都值 | 08讲／MOT009 |
| MOT010 | 习惯三句律 | 复购落地三句：平凡变极致、低谷变峰值、梦想变真实；峰值必须标准化才叫习惯，否则一次不达标即跌成差评 | 09讲／MOT010 |

**校验**：10 行，编号连续 MOT001–MOT010，无缺口。
