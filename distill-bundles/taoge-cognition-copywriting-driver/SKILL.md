# 文案创意驱动包（Dongdongqiang Copywriting Driver）

> **一句话定位**：一套把"写一句打动人的话"从灵感变成流程的操作手册——先想清楚对谁说话、改变什么认知，再把参数翻译成人能感知的体验，最后用对的调性在对的平台说对的话。
> **来源**：东东枪·创意文案30讲（得到，前奥美广告创意人，2026-10-27 S级归档DD01-DD31共31篇）。

---

## 一、总图（一句话记住）

**广告=对谁说话（对象）→改变什么（策略）→拿什么打动（体验×洞察）→怎么说（说法×调性×语境）→让人动（行动）→说得对（评判）**

烂文案的病根不是文字差，是策略没想清楚就动笔。

## 二、核心律速查（31律）

### 第一模块：触动人心的深层原理（策略层）

| 编号 | 短名律 | 一句话 | 用法 |
|---|---|---|---|
| DD02 | 改变行为律 | 广告=改变看法感受→改变行为 | 写文案先问：我要改变他什么看法？不是为了好看 |
| DD03 | 制造改变律 | 怎样让外星人吃辣椒（反常识切入） | 好创意从改变一个"理所当然"开始 |
| DD04 | 策略先行律 | 职业求爱者第一步：想清楚再开口 | 每次写文案前先写三行：目标人群/商业目标/传播目标，没想清楚不开工 |
| DD05 | 认准对象律 | 如何同时追求30个姑娘（谁会买不是所有人） | 详情页按人群拆模块——送礼讲体面、自吃讲风味、长辈讲好消化 |
| DD06 | 核心体验律 | 功能×场景×情感，参数翻译成人话 | 顾客买的不是钻头是墙上那个洞；"精选宣威火腿"→"咬一口就是云南老家的味道" |
| DD07 | 品牌价值三层 | 功能/情感/社会价值，持续锚定 | 同一锚点反复积累，别今天打功能明天打情感 |
| DD08 | 何为洞察律 | 说出顾客没说出口的那句话 | 别写"这本书真好"，写读者心里有但没说出口的那句 |
| DD09 | 发现洞察律 | 李宗盛（人性）vs王尔德（文字巧） | 洞察从人性来，不是从文字游戏来 |
| DD10 | 细分洞察律 | 为什么叫好不叫座 | 洞察要落到具体人群，不是泛泛人性 |

| DD13 | 说法三换律 | 换角度/换场景/换人称 | 同一句卖点换三种说法，找最打人的 |

| DD19 | 语境变革律 | 到什么山唱什么歌（平台差异） | 小红书发真实试吃笔记、抖音发15秒冲突短视频、直播间用热闹实惠话术 |
| DD20 | 互动源头律 | 没人理你怎么办（留接话口） | 每段文案留钩子——"你最近读完的一本书是哪本" |
| DD21 | 制造动机律 | 好标题=悬念/反差/跟我有关 | "怕甜又想吃月饼？这款连吃3块不齁"；钩子要利饵要香，内容必须接得住 |
| DD22 | 唤起行动律 | 表白当天就领证（低门槛路径） | 别让人看完不知道干嘛，给一条最低门槛的下一步 |

| DD24 | 头脑沙漏律 | 别傻了还要头脑风暴（发散-收敛） | 先大量发散再狠收敛，不是围着桌子喊 |
| DD25 | 思考路径律 | 不靠脑洞靠路径 | 文案有方法论，不是靠天才 |

### 第三模块：创作原则（评判层）

| 编号 | 短名律 | 一句话 | 用法 |
|---|---|---|---|
| DD27 | 辞达而已律 | 文案标准是"达"不是"美" | 先把话说清楚，再谈文采；眼前一亮但说不清=废品 |
| DD28 | 评判对错律 | 先看对错再看好坏，好而不对=犯罪 | 每条文案先过对错关：服务于哪个商业目标？方向对了再磨文字；ROI=相关性/原创性/冲击性 |

## 三、文案五步写作 SOP

1. **策略先行（DD04+DD05）**：写三行——对谁说话（具体人群）、改变什么看法、商业目标是什么。没想清楚不动笔。
2. **挖洞察找体验（DD08+DD06）**：顾客没说出口的那句话是什么？功能×场景×情感翻译成"他最想告诉朋友的那句体验"。
3. **孵化说法（DD11+DD12+DD13+DD21）**：发散3版以上说法，用点石成金（特征→场景→感受）和三换（角度/场景/人称）优化；标题用悬念/反差/跟我有关制造动机。
4. **定调性通语境（DD17+DD19+DD20）**：品牌人格关键词是什么？这个平台（小红书/抖音/直播间）该用什么语境？留互动钩子。
5. **评判落行动（DD28+DD15+DD22+DD27）**：先过对错关（服务哪个商业目标），再给低门槛行动路径，最后自查"达"了没有。

输出格式：结论先行（对谁/改变什么/一句话文案）→ 每步证据 → 落点（冠生园文案/读书IP笔记/唐翌轩作文 行动项）。

## 四、应用场景映射

| 项目 | 应用 |
|---|---|
| 昆明冠生园电商文案 | 策略先行：每条文案先写三行目标人群/商业目标/传播目标（DD04）；人群细分：详情页按送礼/自吃/长辈拆模块（DD05）；体验翻译："精选宣威火腿"→"咬一口云南老家味道"（DD06）；说法优化：每个卖点写3版挑最优（DD12/DD13）；低门槛行动：9.9元试吃装拉力代替推力（DD15）；调性统一：定"实在亲切云南老伙计"关键词（DD17）；平台语境：小红书真实试吃/抖音15秒冲突/直播间热闹实惠（DD19）；标题动机："怕甜又想吃月饼？这款连吃3块不齁"（DD21）；评判对错：先过商业目标关再磨文字（DD28） |
| 个人IP「读书的饕哥」 | 洞察写作：别写"这本书真好"，写读者没说出口的那句（DD08）；标题三手法：悬念"藏了30年的读书方法"/反差"读了100本才明白"/跟我有关"读书读不进去的看这篇"（DD21）；互动钩子：每段留"你最近读完的一本书是哪本"（DD20）；两段式结构：第一段戳痛点（读不进记不住）第二段给解法（我的读书法）；调性像朋友推荐不像专家说教（DD17） |
| 唐翌轩写作表达 | 立意先行：先定中心思想（塔尖）再组织段落（DD16/DD29）；共情非自嗨：用细节描写打动读者不堆论据（DD06）；观察生活：洞察从人间烟火来（DD09）；先对错后好坏：立意正确再谈文采，方向错文采越好越跑偏（DD28）；四幕说服：问题→拆解→方案→理由（DD29） |
| 其他包接线 | 营销实战YX（taoge-ecom-marketing-driver）：DD是YX在4P推广环节的文案功夫补给——YX讲推广组合，DD讲推广里具体怎么写；品牌BR（taoge-brand-marketing-driver）：DD07品牌价值三层+DD17调性=品牌人格，与BR品牌资产积累互证；传播DC（taoge-cognition-communication-driver）：DD21标题党接DC23平台算法，DD08洞察接DC15意义符号 |
| 读书系统 | 东东枪课蒸馏内容回挂：文案创意知识块 |

## 五、边界

- 本包是**文案写作流程**，不替代投放渠道选择与预算分配（那是YX营销组合的活）。
- 好文案是"对"在前"好"在后——文字漂亮但方向错（对错人/说错题）等于犯罪，别陶醉于辞藻。
- 标题党三手法是钩子不是欺骗：内容必须接得住，货不对板下次就不信你。
- 模型置信度：DD02-DD31 均为 S级归档蒸馏（东东枪创意文案30讲，2026-10-27）；DD01发刊词/DD31结语关键词为总纲。
- 与YX分工：YX管"怎么卖"（渠道/预算/推广组合），DD管"怎么写"（文案/创意/表达）；两者是推广环节的上下游。
- 更新规则：认知革命项目每新增文案/创意/表达类模型，同步追加本包。
