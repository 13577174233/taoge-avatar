# 内容视觉提示词工程

## 何时用

- 要出封面、图文卡、配图、首尾帧，需要一段能直接粘贴进即梦/Sedream 的提示词。
- 看到一个视频或爆款图，想知道它的画面是怎么构成的，并复刻成自己的版本。
- 已有系列图，需要延展一张但不想风格跑偏。

## 一、先定载体（决定一切）

| 用途 | 画幅 | 关键约束 |
|---|---|---|
| 小红书封面 | 3:4 | 顶部与底部各留 8% 安全区，主标题在上三分之一 |
| 小红书图文卡 | 3:4 | 一张一个观点，字少、留白多，文字占比≤30% |
| 朋友圈配图 | 1:1 或 4:3 | 非商业化、素人抓拍感，不做海报 |
| 公众号头图 | 2.35:1 | 左文右图或上文下图，留出标题位 |
| 短视频首尾帧 | 与视频同比例 | 首尾帧同景别同机位，便于双锚定 |

定完载体再写提示词。画幅不写进 prompt，作为工具参数单独传。

## 二、四层结构法

按顺序想清楚，最后合并成一段连续中文，不保留小标题。

### 第 1 层 载体骨架

画面类型（摄影/平面/拼贴/插画）、物理分区（上中下、左中右）、阅读顺序、主体位置、信息层级（主标/副标/落款）。

### 第 2 层 场景语义

谁在看、在哪看（通勤/睡前/办公室）、要什么情绪（信任/好奇/被戳中/松弛）、这页承担什么任务（封面抓点击 / 内页给观点 / 收尾给金句）。

### 第 3 层 九维实例填充

每个可见元素都要覆盖：

1. **绝对位置**：不得用"旁边""附近"，用"画面右上角、距上边缘约 1/5 处"。
2. **元素类型**：书、茶杯、纸卡、钢笔、干茶叶、木纹桌面、投影光斑。
3. **形态细节**：材质、轮廓、姿态、角度、磨损、反光。
4. **内容描述**：物体处于什么状态（茶杯冒热气、书翻开在第 37 页）。
5. **文字视觉样式**：字体气质（衬线/手写/无衬线）、字号层级、字色、字重、是否描边。
6. **状态信息**：光影方向、时间感（午后/夜里）、温度感。
7. **关联关系**：谁压着谁、谁被谁挡住、主次比例（主体占画面多少）。
8. **风格特征**：纪实、胶片、杂志编辑感、极简、暖调怀旧——选一个具体词，不用"高级""好看"。
9. **工艺处理**：光线（侧逆光/暖盏灯）、颗粒、纸张压痕、景深、轻微过曝。

### 第 4 层 文字与事实纪律

- 中文待渲染文字用中文双引号“”逐字框定；英文用英文双引号。
- 每张图独立完整，不写"同上""其余一致"。
- 禁 XX、某某、标题文案、待补充文字、占位符。
- 价格、日期、销量、评分只能来自用户提供或已核实来源。

## 三、系列图锚点（防跑偏）

系列图不是每张都重新生成，而是：

1. **首图锁锚**：材质（深胡桃木桌/牛皮纸/粗陶）、光源（暖侧光，来自左上）、色调（深棕+米黄+一点暖红）、道具（书、茶杯、老花镜、钢笔，选 2-3 个固定）。
2. **后续用图生图延展**，把首图作为参考图传进去，明确"保留：材质/光位/色调/道具位置；修改：卡片文字与局部道具"。
3. 只换文字和一两件道具，不动构图骨架。
4. 参考图顺序固定，多图时用 [img0][img1] 标明各自作用。

## 四、逆向拆解五步（看视频/爆款图时用）

用户要求拆解学习视频时，除了技法，必须产出可复现的图片提示词。

1. **定载体**：画幅、横竖、是封面还是内页、是摄影还是平面。
2. **拆分区**：从上到下、从左到右，把画面切成 3-5 个区，逐区记录有什么。
3. **逐元素九维**：对每个关键元素套第 3 层的九维，能写多细写多细。
4. **提不可变资产**：找出这套画面的"视觉 DNA"——材质、光位、色调、字体气质、构图比例。这是复刻的关键，不是道具本身。
5. **出双版本**：
   - 完整版 600-1000 字，可直接粘贴即梦，含全部文字与位置。
   - 精简版 150-250 字，只留 DNA 与主体，供快速试。

拆视频时：先抽 3-5 帧看清画面，再拆；不凭印象描述。

## 五、文字渲染的三条硬规矩

1. 一段 prompt 里最多两处文字块（主标 + 副标，或主标 + 落款），多了必出错字。
2. 中文长句拆成两行写，行与行用"换行"明确。
3. 生成后必查：错字、杂散文字（书封、纸角、杯身最易出事）、文字是否被切边、是否出现第二语言。

## 六、交付格式

每张图交三行：

```
【图 N｜角色】封面 / 观点卡 / 收尾
【提示词】完整版（600-1000 字）
【参数】3:4｜参考图：xxx（若有）
```

系列图再加一行：`【锚点】与本系列一致：材质/光位/色调/道具`

## 七、自检（交付前逐条）

1. 载体与画幅先定，未把比例写进 prompt
2. 每个元素有绝对位置，无"旁边/附近"
3. 每张独立完整，无"同上"
4. 所有可见文字逐字写出并加引号
5. 系列图有明确锚点与保留/修改清单
6. 单图文字块不超过 2 处
7. 无平台名、无运营词、无模型名、无 HEX、无文件路径
8. 没有第三方在世艺术家姓名或受保护 IP 作风格锚点
