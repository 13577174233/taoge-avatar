# 学业规划与学科提分

## 定位

把"2029年高考目标分"倒推成每学期、每月、每周可执行的动作。核心原则：**先诊断再开方，先提性价比最高的分。**

## 三年总框架（物化生组合）

| 阶段 | 时间 | 核心任务 | 阶段目标 |
|------|------|---------|---------|
| 高一适应期 | 2026.09-2027.01 | 适应高中节奏；语数英打底；物化生建立框架 | 站稳年级中上；确定优势/短板科目 |
| 高一下-高二上 | 2027.02-2027.12 | 选科终稿；弱科专项突破；合格考全过 | 选科确认（物化生或调整）；弱科不再拖后腿 |
| 高二下 | 2028.02-2028.06 | 一轮复习启动；强基/综评素材积累；竞赛评估 | 位次锁定（目标院校区间明确） |
| 高三上 | 2028.09-2029.01 | 一轮复习完成；一模定位 | 一模位次达标 |
| 高三下 | 2029.02-2029.05 | 二三轮；二模三模；强基报名 | 位次稳中有升 |
| 高考 | 2029.06 | 冲刺+考试 | 正常发挥 |

## 提分策略：优先级排序方法

1. 拉出最近3次大考各科成绩，计算"离目标分的差距 × 提分难度 × 提升空间"。
2. 优先处理：差距大 + 提分快 + 分值高的科目（通常是数学、物理的中档题失分）。
3. 次优先：语数英主科的稳定项（作文、阅读、计算准确率）。
4. 最后：赋分科目的位次竞争（生物/化学要进年级前30%才有赋分优势）。

## 各科要点（物化生方向）

### 语文
- 基础：文言文实词虚词、默写零失分（送分题必拿）
- 阅读：限时训练+答题模板化（小说/散文/实用类各一套）
- 作文：素材库建设（每周2个人物/事件素材），结构稳定（议论文五段式）
- 高频动作：每周1篇限时作文，每月复盘失分类型

### 数学
- 高一：函数、三角、数列打地基，错题本当日清
- 高二：立体几何、解析几何、概率统计专题突破
- 高三：中档题限时训练（选择填空45分钟目标），压轴题量力取舍
- 高频动作：每日1套选填限时，每周1次整卷模拟

### 英语
- 词汇：每日30-50词滚动记忆，真题语境背诵
- 阅读/完形：限时训练，错因归类（词汇/逻辑/细节）
- 写作：应用文模板+续写套路，练字工整
- 高频动作：每日1篇阅读+每周1篇作文批改

### 物理（首选）
- 核心：受力分析、运动学、能量/动量守恒、电磁学框架
- 模型化学习：把题目归入物理模型（滑块、传送带、双杆等）
- 高频动作：错题归模型，同类题连做3道直到熟练

### 化学
- 元素化学：性质记忆表格化
- 反应原理：速率平衡、电化学、水溶液离子平衡是高分区分点
- 高频动作：方程式书写每日5条，有机推断每周3套

### 生物
- 背诵量大：教材回归（黑体字、图示、课后题）
- 遗传题：概率计算专项；实验设计题：套路化训练
- 赋分提醒：目标卷面分冲高段，才有赋分优势
- 高频动作：教材精读每周2章，错题按"概念/计算/实验"分类

## 考试目标管理

1. 每科设定"保底分/目标分/冲刺分"三档。
2. 每次大考后复盘：达成的科目（保持）、未达成的（进下月计划）。
3. 用位次而非分数评估进步（年级排名/物理类位次）。

## 寒暑假计划模板

```
【暑假（每年7-8月）】
- 阶段1（前2周）：休整+期末复盘+薄弱科目诊断
- 阶段2（中间4周）：主科每日2小时 + 弱科每日1.5小时专项
- 阶段3（最后2周）：收心+新学期预习（数学/物理提前一章）
- 每周安排：学习5天休息2天，每日8小时上限
```

```
【寒假（每年1-2月）】
- 前3天：复盘上学期期末卷
- 中段：弱科集中突破（每天3小时单科）
- 后段：开学摸底准备
```

## 学习习惯建设（家长可监督项）

- 错题本：当日错当日改，周末重做本周错题
- 限时训练：每科每周至少1次限时（严格计时）
- 手机管理：学习时段物理隔离（住校由学校管控，走读家庭设规则）
- 睡眠：高中生保证7小时+，睡眠不足直接砍学习效果
- 每周复盘：周日30分钟回顾本周计划完成度，调整下周

## 输出物

1. 学期目标分解表（sheet）
2. 月度提分行动计划（含每周动作）
3. 寒暑假计划表
4. 考试成绩追踪表（位次）
