# 商业洞察驱动认知包（Business Insight Driver）

> **一句话定位**：一套把"商业现象"从拍脑袋翻译成系统动力学诊断书的判断工具——看穿要素间连接关系、找增强回路飞轮、识别调节回路天花板、预判滞后效应与基模陷阱，不在症状上使劲而在模型上下刀。
> **来源**：刘润·商业洞察力30讲（BI01-BI36共35篇S级归档，2026-10-25全量收官；登记不归档5项：放榜合辑1+直播视频4）。结构：导论2+建立模型8+训练场一5+训练场二5+训练场三6+训练场四14。

## 一、总图（一句话记住）

**洞察力 = 看透系统要素间的连接关系；普通人改结果、优秀人改原因、顶级高手改模型。**

- 系统 = 一组相互连接的要素。改要素没用，改连接关系才有用（海鲜馆单次博弈改多次博弈；麦当劳高速店直营；和尚分粥制度）。
- 五结构模块搭一切复杂系统：**变量 → 因果链 → 增强回路 → 调节回路 → 滞后效应**。
- 解决难题用5把刀：还原大前提 / 突围边界墙 / 安装缓冲器 / 跨越临界点 / 找到根本解。
- 看透人心用4件套：上下同欲 / 群体压力 / 结构性张力 / 创业之心。
- 预测未来用9基模+4模型组：受阻（公地悲剧/成长上限/成长与投资不足）、失控（舍本逐末/饮鸩止渴/意外之敌）、通吃（富者愈富）、锁死（恶性竞争/目标侵蚀）。
- 终身练习三思维：公式思维 / 层次思维 / 演化思维；三剑法：储备模型 / 不断追问 / 多打比方。
- 敬畏万物三边界：复杂度灾难（算不清）、概率性因果（对了也不一定赢）、认知力极限（你的模型只是当下有用）。

### 模块一：建立模型——5个结构模块（BI03-BI10，8讲）

| 编号 | 模型名 | 一句话 |
|---|---|---|

### 模块五：终身练习——三思维三剑法+敬畏（BI27-BI31+加餐，9讲）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| BI27 | 公式思维律 | 销售=流量×转化率×客单价×复购率；CO2=P×S×E×C；定倍率；用户忠诚度=（我提供价值-他提供价值）+转移成本；公式是高手从上帝手中偷的地图 |
| BI28 | 层次思维律 | 时代>战略>治理>管理；整体大于局部之和；药神三层次追问：患者→共同体→治理 |
| BI29 | 演化思维律 | 给所有事加时间轴；学2000年的谷歌不学今天的；熊彼特三刻度：创新→熊彼特租金→模仿；外企高管到民企把成熟期方法搬成毒药 |
| BI30 | 三剑法律 | 储备模型（站高手肩膀）/不断追问（莱维特钻孔机→孔→挂照片→留住美好瞬间）/多打比方（小米生态链=烤红薯生意5个字讲透流量溢出） |
| BI31 | 敬畏万物三边界律 | 复杂度灾难（生物圈2号2亿美元氧气崩到14.5%）/概率性因果（正确模型也输给概率）/认知力极限（亚当·斯密→纳什迭代；"你的模型和我不一样"） |
| BI32 | 沟通一致性律 | 你同时传递的其他信息会削弱主信息；"欢迎您"牌子挡在关着的门上=矛盾信号；个别用户问题是用户问题，众多用户问题是产品问题 |
| BI34 | 边角料创新律 | 一切创新本质是把成本降低30%以上；小米8H颈枕用床垫边角料/18650尾货拼充电宝69元腰斩市场；隔行不隔理，收益>成本公式通用 |
| BI35 | Costco会员制律 | 商品毛利压到14%以下靠会员费赚钱（占利润86%）；续费率96%；SKU 4000 vs 沃尔玛13万；周转12次；库存周期29.5天；命门=物流+地产+人口 |
| BI36 | 需求翻译品牌律 | 未来品牌不是有生产线的厂牌，是把消费需求翻译成供应链语言的翻译者（薇娅2018双11单场2.67亿）；AI取代便宜司机慢取代医生快；传统企业看清后发力拦不住（李宁18亿渠道复兴/大润发淘鲜达486店日均700单） |

## 三、商业问题全链路诊断 SOP（6步）

遇到"这个生意/这个增长/这个决策/这个对手为什么会这样"类问题时按序走：

1. **画因果链（BI05/BI09）**：先别下结论，把现象拆成变量→因果链。漏中间项（咖啡→精力中间有咖啡因代谢）、迷信相关（星座违章=低纬生育高峰）、颠倒因果（价格定成本）三个误区逐个排。
2. **找回路（BI06/BI07）**：这条因果链是增强回路（越转越快的飞轮）还是调节回路（往回归的天花板）？增长卡住=增强回路被调节回路压住；越做越累=增强回路被负向激活。
3. **验滞后（BI08）**：原因在结果附近吗？150天供应链啤酒游戏证明反馈滞后会放大波动。如果干预后没立刻见效，先等滞后效应走完再判断对错。
4. **定基模（BI22-BI25）**：套9基模看踩了哪个——受阻（公地悲剧/成长上限/投资不足）/失控（舍本逐末/饮鸩止渴/意外之敌）/通吃（富者愈富）/锁死（恶性竞争/目标侵蚀）。同时套上3个以上基模的业务就是高危线。
5. **选干预点（BI11-BI15）**：5把刀选哪把？大前提变了用还原大前提；撞刚性约束用突围边界墙；波动太大用安装缓冲器；不连续变化用跨越临界点；症状反复用找到根本解。不要在症状解上使劲。
6. **敬畏三边界（BI31）**：承认复杂度算不清（小步快跑试错）、承认概率（10次对6次就不错）、承认模型只是当下有用（和团队讨论说"我的观察角度是这样的"不说"你错了"）。

输出格式：结论先行 → 因果链草图（文字版）→ 回路判定 → 基模匹配 → 干预点（BI编号）→ 落点行动项。

## 四、应用场景映射

| 场景 | 应用 |
|---|---|
| 电商（冠生园） | 销售漏斗四变量（流量×转化率×客单价×复购率）逐个拆找最弱变量（BI27）；盘飞轮——冠生园有没有"用户越多→品牌越强→复购越高→用户越多"的正向增强回路（BI06）；受阻基模体检——公地悲剧（节令公共流量大家抢完都不赚）/成长上限（云南月饼TAM到高原）/成长与投资不足（销量涨但内容/新品/研发没跟上）（BI22）；失控基模预警——直播低价=舍本逐末+饮鸩止渴（BI23）；富者愈富判断——云南本地已被嘉华潘祥记通吃就别恋战，资源转投低糖日常化新战场（BI24）；目标侵蚀检查——今年GMV目标不许往下调，完不成复盘原因不改数字（BI25）；边角料创新——月饼季后馅料/产线/人力能不能做新品（BI34）；Costco会员制可行性——付费会员把利润从商品差价转到会员费（BI35）；沟通一致性——对外说高端但直播间9.9包邮就是"欢迎您"牌子矛盾（BI32） |
| 投资（18只持仓） | 每只持仓写一个利润公式（销量×单价×海外占比等），季报对变量（BI27）；层次思维定位——公司出问题是时代层（不可改）还是管理/治理层（可改），时代层问题不补仓（BI28）；演化思维——判断公司处于创新期/熊彼特租金期/模仿期，模仿期利润会被摊薄（BI29）；基模体检——周期股（潍柴/云天化）看是不是公地悲剧+恶性竞争（全行业抢公共需求最后一起死）；诺德铜箔价格战=饮鸩止渴，行业出清前不加仓（BI23）；富者愈富——持仓股是行业头部（富者）还是尾部（穷者），尾部不加仓（BI24）；目标侵蚀——持仓公司年初定的利润目标半年后往下调一次就离破产近一步（BI25）；敬畏概率=分散持仓+留安全边际，不重仓押单一"看懂的"（BI31） |
| 教育（唐翌轩） | 学习飞轮——他在哪科已经进入"学好→被表扬→更想学"的富者愈富，先把那科推到年级前列建立信心（BI24）；滞后效应——刷题提分短期有效但到高二新题型就崩，因为反馈滞后没看见根本问题（BI08）；舍本逐末——靠刷题背答案应付考试=症状解，真正理解学科逻辑=根本解，高一还有时间改高二再改来不及（BI23）；目标侵蚀——考砸后不许自动降目标，和他约定具体数字贴书桌（BI25）；层次思维——成绩不好先往上跳两层看是选科/方向错了还是只是习惯差，别在第四层拼命（BI28）；演化思维——高一方法每年暑假迭代，不要拿高三学霸时间表硬套（BI29）；沟通一致性——嘴上说尊重他选择但选科时不断暗示物化生，孩子对矛盾信号极其敏感（BI32）；不断追问——从"选什么科"追到"将来想过什么生活"（BI30） |

## 五、边界

- 不替代行业研究、不替代财务三表分析、不替代竞争情报——它是"看透结构"的透镜，具体数字和事实要靠FN系列（财务）/H系列（周期）/YX系列（营销）补。
- 不预测股价、不做精确商业预测——它给"看到影响未来的力量"的尺子，不是水晶球。
- 模型置信度有限——刘润自己在BI31就警告：生物圈2号2亿美元都算不清，人脑搭的模型只是"当下有用"，不是永恒正确。
- 跨行业迁移要过演化思维关——学2000年的谷歌不学今天的；把成熟期打法搬到成长期就是毒药。
- 敬畏概率——正确模型不代表一定赢，还要战胜概率；10次决策对6次就合格。
- 模型置信度：BI01-BI36 均为S级归档蒸馏（刘润商业洞察力30讲，2026-10-25全量收官35篇归档+5项登记不归档）。
