# 抑郁症医学课驱动认知包（Depression Medicine Driver）

> **一句话定位**：抑郁症不是「想不开」，而是一组有诊断标准的脑与心理疾病；治疗建立在理解之上——从症状、本质到治疗方案逐层拆，才知道哪一步在起作用、哪一步还只是粗糙近似。
> **来源**：王立铭·抑郁症医学课（WLM001–WLM014 共 14 篇 S 级归档，2026-11-07 全量收官；页头 13/13＝发刊词1＋正课12，筛选器「共14讲」＝13＋加餐1）。

## 一、总图（一句话记住）

**认病（WLM001–WLM002）→ 解本质（WLM003–WLM007）→ 上治疗（WLM008–WLM012）→ 看未来（WLM013–WLM014）**

四层递进：**症状层（诊断标准）→ 本质层（心理学、神经科学、进化论）→ 治疗层（谈话、两代药物、大脑刺激、正念）→ 公共层（三痛点三希望与情绪管理普及）**。

关键结构：**理解与治疗相伴相生**——对本质的理解越深，方案才越具体；方案的应用又反过来推动理解。

## 三、理解与应对 SOP（6 步）

1. **先分清是情绪还是病**（WLM002）：对照临床诊断标准看持续时间、严重程度、功能受损；不把一段时间的低落直接等同于抑郁症。
2. **三层解释各过一遍**（WLM003–WLM007）：心理学层看认知模式与社会关系是否扭曲；神经科学层看结构改变与信号模型；进化层看这段情绪在原始环境里原本解决什么问题。
3. **判断「错配」在哪**（WLM007）：是现代环境变了（社交稀疏、睡眠剥夺、比较压力），还是个人生活节奏剧变；这决定干预方向。
4. **选治疗路径**（WLM008–WLM011）：一线从心理治疗与规范药物治疗入手；药物选择区分血清素与谷氨酸两条机制；顽固病例才讨论大脑刺激，且区分 ECT／TMS／DBS 的强度与风险。
5. **补充低成本工具**（WLM012）：把正念冥想去神秘化，做成每天可执行的短练习，而不是灵修口号。
6. **把问题提到公共层**（WLM013–WLM014）：科普与去污名、患者指导、资源与成本三条同时推进；定期体检把基础项查全。

## 四、应用场景映射

| 场景 | 适用律 | 落地 |
|---|---|---|
| 家人朋友说自己「抑郁了」 | WLM002 WLM001 WLM008 | 先按标准判断是否需要就医，不急着劝「想开点」；有条件即陪同就诊，谈话治疗是一线选项 |
| 自己长期低落 | WLM006 WLM007 WLM012 | 先查睡眠、社交、比较压力三条错配源；用正念短练习与规律作息，必要时就医 |
| 讨论抗抑郁药 | WLM009 WLM010 WLM011 | 区分两代机制与起效时间，不自行停药；顽固病例再谈 ECT／TMS／DBS |
| 孩子或学生情绪问题 | WLM007 WLM013 | 先改环境（睡眠、屏幕、比较压力），再谈干预；把情绪管理当技能教，不当品质问题批 |
| 做科普与内容表达 | WLM001 WLM013 | 用「疾病＋可治疗」定调，去污名化；不渲染、不猎奇、不给个案下诊断 |
| 企业健康管理／体检设计 | WLM014 WLM013 | 基础项查全，情绪筛查纳入常规；把情绪管理纳入员工支持而非公关话术 |

## 五、边界

- **绝对不替代诊疗**：本包不诊断、不建议用药剂量、不判断是否停药；任何自伤、自杀意念须立即转介精神科与危机干预（WLM002／WLM008）。
- **机制解释仍是近似**：血清素与谷氨酸模型都「正确但粗糙」，不能理解为「抑郁症就是血清素低」（WLM005／WLM009／WLM010）。
- **疗效数据要看条件**：药物与刺激疗法的有效率来自特定试验人群，个体差异大，顽固性抑郁的比例约 10% 是课程口径而非普适数字（WLM011）。
- **进化解释是假说**：负面情绪作为生存工具的解释属进化心理学框架，存在争议，引用须标注（WLM006）。
- **文化与性别差异**：表达方式、就诊率、病耻感在不同地区与性别间差异明显，干预设计须本地化（WLM007／WLM013）。
- **加餐内容时效性**：体检报告解读类内容依赖当期指南，具体指标阈值须查最新标准（WLM014）。
- **免 AI 化输出**：简体中文、零 emoji、结论先行、表格化；涉及疾病表述不用「矫情／玻璃心」类词，不写「赋能／抓手」类空话。
