# 批判性思维 · 自查清单

> 在具体处境里照着核对。每条都是「什么信号说明方法已失效应停 / 什么情况该找专业人士」。

- [ ] **批判性思维是对思考的再思考** —— 把「批判思考过程」误用成否定说话者本人，沦为抬杠或人身攻击；像王富贵案例那样追问若不顾关系与场合，会变成咄咄逼人。
- [ ] **三步评判思考质量** —— 跳过第一步的自洽检查直接谈格局与公允，审视会悬空；把三步当机械流程套到每段闲聊上，白白消耗思考成本。
- [ ] **「重要但不紧急」本身是待审视的观点** —— 把「既重要又紧急」当新教条，为一切学习焦虑开绿灯，反而挤占真正紧急的事务。
- [ ] **博克：大学思维的三阶段** —— 把三阶段当成线性晋升表，用「你还在第一阶段」贬低他人；博克的划分针对大学教育场景，未必覆盖成人经验学习。
- [ ] **思考自由度受双重局限** —— 只把局限归因于知识不够而无限囤课，忽略思维方式本身的定势；用「你不懂X」否定他人发言资格。
- [ ] **海绵式思维割让知识体系构建权** —— 矫枉过正变成什么都不吸收、事事先质疑，丧失快速积累期；知识体系弱的人借「我有批判性思维」拒绝一切输入。
- [ ] **淘金式思考者：边吸收边甄别** —— 把「不断提问」做成逢信息必杠，学习与社交效率双降；只挑金子导致接触面收窄，错过意外信息。
- [ ] **做自己的旁观者** —— 自我分裂演变成过度自我监控与自我批判，焦虑加重；把冥想的不评判与批判性思维的评判混用，两头落空。
- [ ] **批判性思维不依赖学科、不直接给答案** —— 把批判性思维当万能工具，指望它给出正确答案；因它「不给答案」而认定它无用。
- [ ] **批判的是思考过程，不是人** —— 借「我只是批判思考过程」之名行否定他人之实；督导式追问被对方理解为挑衅时，对话即告失效。
- [ ] **感觉、猜想、推断：只有推断值得批判** —— 用「这不过是你的感觉」贬低对方正当的情绪表达；把尚未论证的猜想当成推断去严审，错置火力。
- [ ] **个人感觉变成公共证据时要追问根据** —— 把「你有什么根据」用成压制他人发言的口头禅，让讨论变成举证竞赛；对无关紧要的闲聊也如此追问，招人厌烦。
- [ ] **完整的思考＝论题＋论证＋结论** —— 为凑齐三要素把别人的即兴发言强行拆成三段，检查沦为形式；只查结构不查内容，漏掉「材质不对」的前提。
- [ ] **论题分事实类与价值类** —— 把价值论题当事实论题去「摆证据」，或把事实论题扯成立场之争；用事实题的回答方式答价值题，答非所问。
- [ ] **由结论倒推隐藏论题** —— 倒推出的论题可能与立论者真实意图不符，需向对方确认而非武断代答；拿倒推结果给别人「定罪」容易曲解。
- [ ] **检查论题是为了训练不走题** —— 把「不走题」执行成僵守提纲，拒绝正当的话题演进；对发言者反复纠偏会压制讨论活力。
- [ ] **论证是把论题和结论衔接起来的理由** —— 把「我有理由」当护身符，堆砌借口冒充论证；因Argument有争吵义而回避正当的论证检查。
- [ ] **有论证支撑的观点才配称为结论** —— 逢观点必问「有什么根据」，把对话变成审讯；误把结论先行堆出的理由当真支撑。
- [ ] **偷换结论多源于二选一预设** —— 把「你是不是偷换结论」当万能反驳词，打断其实成立的推理；自己为图省事也用二选一预设速判。
- [ ] **结论先行：先决定再找理由** —— 用「你结论先行」否决一切直觉决策——直觉在某些领域（如资深从业者）本有信息含量，关键在事后补检验；指控他人结论先行易引发对抗。
- [ ] **论证＝前提＋推理，结论归入论证** —— 以为推理有效论证就合格，忽视前提造假；把前提与结论捆绑评判，失去分别检验的机会。
- [ ] **用「因为放置法」找出前提** —— 把「加上因为很顺」误判为逻辑真——顺畅只说明前提归属，不代表前提成立；多义句套不同位置都通顺时需人工分辨。
- [ ] **前提成立与否的三条粗查原则** —— 以「跟我的经验不冲突」轻信超出个人经验范围的前提；个人经验本身有偏差，会错杀正确前提。
- [ ] **推理手法要与结论确定度匹配** —— 把归纳结论当确定结论传播（如「试过三次都灵，所以此法必然有效」）；把演绎用错前提，形式有效掩盖前提造假。
- [ ] **别把「解释」当成论证** —— 把伪装成解释的断言当已证事实接受；反过来把正当解释错判为「逃避论证」，制造无谓冲突。
- [ ] **概念前后不一致就是偷换概念** —— 拿「你偷换概念」当万能反驳词压制对方；对方定义虽异但已明示新定义（如「我说的X是指…」）时不属偷换，误判会显得不宽容。
- [ ] **关键概念要准确、无歧义** —— 为准确而堆砌限定词，表达变得笨重；过度纠正他人用词显得傲慢，破坏对话。
- [ ] **概念的精确程度反映审慎与郑重** —— 为精确而精确，让对方淹没在限定条件里抓不住重点；用「精确」包装不耐烦（事无巨细列条款搪塞）。
- [ ] **在论证中直接给出定义** —— 用自定义概念包装立场（如把「好人」定义成对自己有利的），定义本身又成了需要被审视的对象；定义过窄让结论变得平庸。
- [ ] **隐藏假定：没说出来的前提，分两类** —— 把所有未言明之事都当可疑假定追问，交流成本剧增；只查事实型假定漏掉价值型，争论永远不在一个层面。
- [ ] **找隐藏假定：反对者与第三方两个视角** —— 找出的「假定」可能只是抬杠式曲解，需验证它确实是结论成立的必要条件；对每句话都找假定会陷入无限怀疑。
- [ ] **假定找出来后按前提标准评判** —— 事实型假定与价值型假定混用标准——用「来源不可靠」否定价值偏好，或用「我不认同」否定事实陈述；单假定可疑就全盘否定结论，未考虑多重论证。
- [ ] **排查假定就是洞察自己的世界观** —— 自我洞察变成自我审判，对每个念头都上纲上线；把「识破假定」当智力优越感去戳穿别人。
- [ ] **思考质量优先于决策速度** —— 把「重质量」当拖延长考量的借口，小事也开大庭；在需要即时反应的场景（驾驶、急救）仍坚持慢思考，危险。
- [ ] **速度偏好的代价：粗糙决策与放弃思考** —— 把「慢就是好」极端化，错过确实稍纵即逝的机会；以「三和大神」案例嘲笑经济困境者，忽视结构性因素。
- [ ] **思考框架的三要素** —— 执着于搭「完美框架」而不敢下判断；把三要素当成清单式真理，忽略它们因人而异（「每个人都有自己的思考框架，可能各不相同」）。
- [ ] **用批判性思维审视倾向与知识带来的偏差** —— 意识到倾向存在后反而过度自我怀疑，事事不敢下判断；用「你有立场」否定一切异见。
- [ ] **信念是最坚固又最隐秘的隐藏假定** —— 把一切观点都拔高成「信念」来分析，草木皆兵；将「信念坚不可摧」浪漫化，放弃检视。
- [ ] **信念的四种形成方式** —— 用「我这是本能／共识」为信念豁免检视——形成方式不正等于正确；把信念来源分析变成对父母或社会的单向清算。
- [ ] **抵触情绪排查法：三问识别信念** —— 把愤怒误当信念的唯一信号——情绪激动也可能只是立场或利益受损；用三问「鉴定」他人信念后贴标签。
- [ ] **把信念当普通观点无情审视** —— 「无情审视」变成自我否定风暴，动摇自我价值感；以「审视信念」为由贬低他人信仰，侵犯边界。
- [ ] **认同推导过程而非信念内容** —— 被误读为「可以随便改信念」——认同推导过程恰恰要求更严格的论证；对深嵌身份的信念（信仰、性取向相关）强行剥离可能造成创伤。
- [ ] **立场是判断背后的身份与态度** —— 拿「你有立场」否定一切发言——人人有立场不等于人人都不公正；身份影响力小的人误以为自己的观点无边界。
- [ ] **问「对手立场」评估利益绑架** —— 用「你被利益绑架」一票否决利益相关方的合理主张——利益相关者往往最有发言权，需审其论证而非取消资格；对手立场的推理误伤无辜第三方。
- [ ] **调转立场，你接受现在的结论吗** —— 换位流于表面想象，自以为替对方想了实则仍用自己的价值观代言；用「你换位想想」要求受害者理解加害方。
- [ ] **立场一致性代表价值观稳定** —— 把一致性当僵硬教条，拒绝在新信息下修正立场——修正若公开说明理由，不算不一致；用「你以前不是这么说的」打压正当的观点更新。
- [ ] **情绪欲望影响的是价值判断而非事实判断** —— 以「你被情绪影响」否定对方的正当价值主张；把情绪稳定化当成目标，压抑情绪反而更深影响判断。
- [ ] **审视情绪的三问加一** —— 三问变成自我指责（「我又嫉妒了」），情绪被压抑而非被看见；用「一年后不后悔」合理化冲动决定。
- [ ] **审视欲望的两问：想要什么＋平行宇宙验算** —— 欲望被识破后自我厌恶（「我果然功利」）——欲望本身中性，问题在是否透明；验算问句忽略合理自利：想要钱不构成主张无效。
- [ ] **识别情绪欲望能澄清人生目标** —— 把「澄清目标」变成新的执念，用目标一刀切掉所有「主线外」体验；以「为了人生目标」正当化对他人 commitments 的逃避。
- [ ] **时代局限：信念带着时代烙印** —— 时代相对主义——认为「一切信念都只是时代的产物」而放弃是非判断；用「代沟」之名拒绝倾听老人或年轻人的具体理由。
- [ ] **用长线视角问题破时代局限** —— 「长线必然更好」变成信仰，为未来牺牲当下过重（老年人今天的实际困难是真实的）；3年30年是修辞尺度，不同决策需要不同时间窗。
- [ ] **格局局限：没法知道我们不知道什么** —— 以「格局局限没法破」为惰性开脱；用「你格局不够」压人，却拿不出对方缺失维度的内容。
- [ ] **格局局限无直接解法，只能保持开放** —— 把「意识到局限」变成口头禅式的谦虚表演，实际决策毫无变化；「没有直接解法」被解读为「不必作为」。
- [ ] **批判性思维不能替你汲取信息** —— 把此局限当作拒绝学习批判性思维的理由——它不替代汲取，但汲取没有它同样低效；反之，只修炼拣选而停止摄入。
- [ ] **系统不完备：哥德尔定理的一般化** —— 把哥德尔定理泛化成「一切都不可知」的相对主义——定理有严格的数学适用条件，类比只作启发；用「系统内无解」拒绝一切改进努力。
- [ ] **语言的边界就是思想的边界** —— 语言决定论的极端化——以为语言 lacking 就完全无法思考对应内容；用「词都造不出来」否定新现象的真实存在。
- [ ] **批判性思维不负责构建：裁判不下场** —— 以「批判性思维不负责构建」为由只练评判、放弃学习创造；评审者越俎代庖替创作者产出，两头受损。
- [ ] **成长性思维：把问题当作成长的工具** —— 成长叙事被滥用成「感谢苦难」，回避对不公或错误方法本身的纠正；「在能力范围之外做事」被读成盲目冒进。
- [ ] **创造性思维：为改变世界探索新解法** —— 把「为改变世界」浪漫化，忽视破坏性后果（作者自己也只借反派说明魅力，非认可其行为）；以「创新」之名拒绝一切既有规程。
- [ ] **珍惜思考成本，设计你的「不折腾费」** —— 把「不折腾」当懒的挡箭牌，漏掉复利型的小优化；金钱指标对非货币事务（关系、健康）失真。
- [ ] **被反复验证的常识不必重造轮子** —— 「常识」被滥用为拒绝思考的挡箭牌——许多旧常识后来被证伪（如「坐月子不能洗头」）；专家共识也可能利益污染，照单全收有盲区。
- [ ] **十个主问题的通用提问清单** —— 机械过一遍10问而不理解其背后的检查意图，流于形式；把「重要吗」的刹车误判，漏审或滥用审视。
- [ ] **20天×15分钟的新闻审视训练** —— 「20天明显提升」是作者的预期承诺而非测量结果，期望过高易失望；练习变成挑新闻毛病的心态训练，滋生优越感。
- [ ] **信奉形成逻辑而非观念内容** —— 「可以被说服」被误读为没原则——作者的前提是信奉形成逻辑，逻辑本身仍要过硬；用「我信逻辑」贬低他人重情重义的选择。
- [ ] **新闻反转是信息供应方式进化的产物** —— 把「反转是进步」读成「初报都不可信」，滑向对一切信息的不信任；用「肯定会反转」预设立场，放弃跟进事实。
- [ ] **相信某个渠道＝让渡定义事实的权力** —— 把「确认它值得」简化成看粉丝量或权威头衔——头衔与可靠性并非等价；信任单一渠道久了丧失校验习惯。
- [ ] **用止损线调和理性与行动力** —— 止损线形同虚设（设了不执行）；把「允许鲁莽」扩大到他人身上，替别人定可承受的损失。
- [ ] **批判性思维帮你定义真问题** —— 停在「找出不对」的阶段反复挑剔，团队士气与进度双损；把「定义真问题」当成不推进决策的借口。
- [ ] **批判性思维不要求抛弃立场，只求自洽公正** —— 把「保持自洽」简化为言行一致的形式要求，忽视前提本身错的情况——自洽的种族主义者依旧不公正，还需公正检验；借「立场分析」对他人动机诛心。
