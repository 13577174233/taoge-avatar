# 论题与结论：走题与偷换

> 什么时候读这一章：发现讨论跑题、对方或自己偷换结论时。

## 第 003 讲模型 · 思考三要素—论题检查模型（kp.thinking.c15l003m）

**核心主张**：完整思考＝论题＋论证＋结论（A1）；论题分事实类与价值类（A2）；隐藏论题由结论倒推（A3）；检查论题的价值在训练首尾对齐（A4）。

### 1. 完整的思考＝论题＋论证＋结论

- **命题**：一段完整的思考必含论题、论证、结论三个核心信息要素。
- **展开**：面对一段带判断的话，检察官视角的第一个问题是：你的论题、结论和论证部分分别是什么？论题是引起立论者思考的问题或分歧，有了论题后面的思考才会发生；结论是立论者希望证明、也希望你接受的观点；论证是从论题到结论的证明过程。三者构成公式：完整的思考＝论题＋论证＋结论。蔡钰把一次思考比作一根抻直的三节棍，论题、论证、结论各是一节小棍，检查任务是：三根小棍分别都有没有、齐不齐；有没有摆成一条直线、首尾有没有跑偏；是不是真的小棍、有没有哪根材质不对是麻绳。初始设定：结论是已经存在的，因为启用批判性思维的前提就是已面对一个观点。（出处：第3讲）
- **机制**：给思考建立最小结构单元，使后续检查有明确的三处落点而非整体印象。
- **量化**：三个要素／三节棍／三件事（原文逐字）；检查工作用接下来的5讲完成（原文逐字）。
- **主体**：适用于书面论证与口头表达的自我检查；三岁小孩式的只言片语无从拆解，不适用。
- **风险**：为凑齐三要素把别人的即兴发言强行拆成三段，检查沦为形式；只查结构不查内容，漏掉「材质不对」的前提。
- **条件**：此为作者的教学框架，非实证结论；失效场景：对方输出的是叙事或抒情而非论证时，找不到论题属正常，不必硬拆。
- **反例**：面对一句玩笑话问「你的论证呢」。
- **动作**：遇到要评判的观点，先动手写下它的论题、结论、论证各是什么，再开始评判。
- **自测**：思考的三个核心信息要素是什么？三节棍的比喻要检查哪三件事？
- **难度** 2｜**证据** C

### 2. 论题分事实类与价值类

- **命题**：论题分讨论事实与讨论价值主张两大类，对应不同结论类型。
- **展开**：最常见的论题有两种。一种在讨论事实，关心世界万物在过去、现在或未来是什么样的，如「为什么中国10年来的人口出生率在下降」「人工智能是不是真的在蚕食世界」「黑洞是不是真的存在」「狮子更凶猛还是老虎更凶猛」，这类论题对应的结论都应该是事实判断。另一种在讨论价值主张，关心世界应该是什么样的，包括行为的对错、好坏和情理责任，如「为什么应该反对吸烟」「应该生二胎吗」「互联网公司推行996合理吗」（其实是「公司应不应该推行996」），这类论题讨论的结论都是价值判断。（出处：第3讲）
- **机制**：先给论题定性，才知道该用事实证据还是价值理由去检验其结论，避免两类标准的错配。
- **量化**：两种论题（原文逐字）；「10年来的人口出生率」（原文逐字）。
- **主体**：适用于分析公共争论与日常分歧；纯审美、口味类表达不适用。
- **风险**：把价值论题当事实论题去「摆证据」，或把事实论题扯成立场之争；用事实题的回答方式答价值题，答非所问。
- **条件**：此为作者的分类框架，非实证结论；失效场景：混合论题（如「该不该加薪」含事实前提与价值判断）需要拆开处理，简单二分不够用。
- **反例**：争论「香菜好不好吃」时搬出营养成分表。
- **动作**：下次争论先问一句：我们在讨论「是什么」，还是在讨论「该不该」？
- **自测**：两类论题分别对应什么结论类型？996问题实际讨论的论题是什么？
- **难度** 2｜**证据** C

### 3. 由结论倒推隐藏论题

- **命题**：思考者通常不直说论题，可根据结论倒推将其找出。
- **展开**：如果观点本身在回答某个问题，问题就是论题；但更多时候思考者直接给出结论和论证，论题需要翻出来——方法是根据结论来倒推。例：2019年4月马云谈996的文章，开头说「关于996，现在这是国内一个很热门的话题」，并未明说论题；第二句「我个人认为，能做996是一种巨大的福气」即是全文结论，据此可倒推论题是：中国公司和年轻人应该支持还是反对「996」。只要能明确结论，就能倒推出论题，因为这两者一定应该是对齐的。另一场景：抛出论题和给出结论的人不是同一个人时，若不好好审题就容易答非所问——问王富贵「你为什么想训练批判性思维」，他答「我刷得到看见了就买了」，给的是事实解释，而问的是他对这事的价值判断。（出处：第3讲）（此为作者立场，非指南结论）
- **机制**：利用「论题与结论天然对齐」的结构关系，从可见的结论端反推不可见的起点。
- **量化**：原文未给具体数值（本条为方法阐述）。
- **主体**：适用于分析文章、演讲与回应他人提问；对方结论本身模糊时，倒推也失效。
- **风险**：倒推出的论题可能与立论者真实意图不符，需向对方确认而非武断代答；拿倒推结果给别人「定罪」容易曲解。
- **条件**：此为作者观点，非实证结论；失效场景：结论本身含糊或前后多个结论时，倒推无单一答案，需先澄清结论。
- **反例**：领导问「这个方案为什么延期」，下属答「我们上周开了三次会」——答了经过，没答原因判断。
- **动作**：读一篇观点文时，先划出结论句，再写下它对应的论题，检查两者是否对齐。
- **自测**：如何从马云的文章找出论题？王富贵的回答错在哪？
- **难度** 2｜**证据** E

### 4. 检查论题是为了训练不走题

- **命题**：找论题的最大价值是训练思考首尾对齐的不走题意识。
- **展开**：有人会问：结论加个问号不就是论题吗，有什么好讲的？蔡钰的回答：寻找和检查论题这个动作，最大的意义不是检查它存不存在，而是检查它是不是跟结论做到了匹配和对齐，训练「不走题的意识」——让思考的起点和终点始终对标。她解释即兴发言大脑空白的原因：发言之前没有在心里明确起点和终点、锚定论题和结论；口头讨论时要边说边想，大脑里一边规划当下说什么、一边规划下一步说什么，关键路标没锚定就容易跑偏或聊飞。明确论题和结论就明确了思考的起点和终点，能帮我们评估接下来的思考和论证在不在主线上。她建议养成习惯：面对一段思考判断，把论题、结论和论证分别找到、拎出来——这是在训练审题意识和正面回答问题的习惯。（出处：第3讲）（此为作者立场，非指南结论）
- **机制**：论题充当思考的路标，路标清晰时每次输出都可对照起点，跑偏可被即时发现。
- **量化**：原文未给具体数值（本条为方法论阐述）。
- **主体**：适用于即兴发言、项目沟通与写作构思；高度程序化的对答（如报数）无需此训练。
- **风险**：把「不走题」执行成僵守提纲，拒绝正当的话题演进；对发言者反复纠偏会压制讨论活力。
- **条件**：此为作者观点，非实证结论；失效场景：头脑风暴类讨论本就需要发散，「跑题」可能是探索的一部分，不宜强拉回主线。
- **反例**：协作中同事问方案何时能给，答「我做完手上的事马上写」，没回答时间点。
- **动作**：即兴发言前花10秒在心里默念「我要回答的问题是X，我的结论是Y」，再开口。
- **自测**：检查论题的最大意义是什么？发言大脑空白的症结是什么？
- **难度** 2｜**证据** E

## 第 004 讲模型 · 结论三问检查模型（kp.thinking.c15l004m）

**核心主张**：论证是衔接论题与结论的理由（A1）；有论证支撑才配称结论（A2）；偷换结论源于二选一预设（A3）；结论先行使论证沦为维护（A4）。

### 1. 论证是把论题和结论衔接起来的理由

- **命题**：论证是支持一个判断的推理思路或推导过程。
- **展开**：英文里「论证」对应的单词Argument同时有交流意见甚至争吵的意思，认为批判性思维是抬杠的人，误解常从这里来。但在批判性思维语境里，论证不是争吵和交流意见，它指支持一个判断的推理思路或推导过程。如果说论题是「你在讨论什么」，结论是「你的观点是什么」，那么论证就是「你的理由是什么」，论证这根小棍子负责把论题和结论衔接起来。论题、论证和结论三根小棍子要首尾对齐，所以讲结论之前必须先引出论证这个概念。（出处：第4讲）
- **机制**：把含混的「理由」明确为「推理思路」，使论证可以被逐段检验而非笼统接受或拒绝。
- **量化**：原文未给具体数值（本条为定义阐述）。
- **主体**：适用于分析与表达观点的所有人；不适用于纯情绪宣泄场景。
- **风险**：把「我有理由」当护身符，堆砌借口冒充论证；因Argument有争吵义而回避正当的论证检查。
- **条件**：此为作者的定义框架，非实证结论；失效场景：叙事、说明类文本不含判断，谈不上论证。
- **反例**：「我不喜欢他，因为他那个人吧……」——只有态度没有推理思路。
- **动作**：表达重要观点前，先自问「我的理由是什么」，把推理思路写成一句话。
- **自测**：Argument的歧义从哪来？论证在思考结构中负责什么？
- **难度** 2｜**证据** C

### 2. 有论证支撑的观点才配称为结论

- **命题**：没有论证支撑的孤立观点，不能算结论。
- **展开**：日常口语里观点、结论、看法、判断常被混用，但从逻辑学和批判性思维的视角看，「结论」的结含有总结、结尾的意思，是一种总结性的判断，要经过推导和论证才能得出；而观点和判断不一定带有论证支撑。只提出观点、没有提供论证和分析推理过程的，只是一个孤立存在的纯观点，不能算结论。所以看到一个观点，应马上问：你这个看法有什么根据？这一问能规避很多无效争论——有论证支撑就可以往下评判其它环节，答不上来就没必要深入审视了。非要评判没经过论证的观点，局面就像小朋友吵架：「我比你厉害」「我才比你厉害」「反弹」「再反弹」，拼的不是事实和逻辑，是耐力和音量——互联网梗「人类的本质是复读机」说的就是这个。而如果有人说「我比你厉害，是因为我投篮的命中率是70%，而你只有30%」，论证过程摆出来，就可以审视了。（出处：第4讲）
- **机制**：用「有没有论证支撑」作为观点与结论的分界，让讨论从观点对轰转入可检验的推理。
- **量化**：投篮命中率70%对30%（原文逐字）。
- **主体**：适用于讨论、辩论与决策复盘；寒暄、闲聊不必追问根据。
- **风险**：逢观点必问「有什么根据」，把对话变成审讯；误把结论先行堆出的理由当真支撑。
- **条件**：此为作者的规范性定义，非实证结论；失效场景：明确的价值表态（如「我就喜欢」）无需论证支撑，不适用此标准。
- **反例**：朋友说「今晚这家店真好吃」，你回「请出示论据」。
- **动作**：听到或说出重要观点时，先问一句「根据是什么」，再决定是否继续深入讨论。
- **自测**：观点和结论的区别是什么？追问根据能规避什么？
- **难度** 2｜**证据** C

### 3. 偷换结论多源于二选一预设

- **命题**：偷换结论是用相关性强的结论替换正面回答的结论。
- **展开**：偷换结论，就是用一个相关性很强的结论来偷换掉正面回答问题的结论，这其实是在审视「结论和论证是不是匹配」，而且发生得神不知鬼不觉。例：鱼和熊掌难以兼得，我拿不到鱼，所以我会拿到熊掌——把「没有鱼」偷换成了「有熊掌」。夫妻吵架里妻子说「我对家庭付出太多了，又做家务又管娃，你惭愧吗」——列再多辛苦事实也只能证明妻子自己付出得多，并没有证明丈夫付出得少，家庭付出未必非黑即白，双方付出可能只是不在一个维度。偷换结论的发生机制：立论者心里作了一个默认预设，认为结论只能二选一——「外表的魅力是短暂的，所以姑娘应该关注内涵」预设了改善容貌与投身事业只能二选一且没有第三个选项；「年轻人不愿意生孩子，所以养猫的人会越来越多」预设了不生孩子就会去养猫；「西医科学说明中医不科学」「奶茶受欢迎说明咖啡市场要没落」「中国经济在走强说明美国经济要放缓」同理。结论是思考的终点，大雷音寺被换成小雷音寺、康师傅被换成康帅博，前面的评判之路就白费了。（出处：第4讲）
- **机制**：未被言明的二选一预设悄悄收窄了可能性空间，让「否定A」直接滑向「肯定B」。
- **量化**：原文未给具体数值（本条为机制阐述）。
- **主体**：适用于审视媒体观点、争论与自己的推断；对方向你倾诉而非立论时不适用。
- **风险**：把「你是不是偷换结论」当万能反驳词，打断其实成立的推理；自己为图省事也用二选一预设速判。
- **条件**：此为作者的方法论观点，非实证结论；失效场景：问题本身确实是二选一（如投票二选一议题）时，「二选一预设」并非偷换。
- **反例**：妻子列举付出事实后直接得出「你不爱这个家」，两个结论并不等价。
- **动作**：听到「A不成立所以B成立」句式时，追问：除了B还有没有C？这个二选一是谁规定的？
- **自测**：什么是偷换结论？它常由什么心理机制导致？
- **难度** 3｜**证据** C

### 4. 结论先行：先决定再找理由

- **命题**：结论先行时，论证不再是推导而是对决定的维护。
- **展开**：第三个提醒与前两个相反：不是把结论拎出来、找准它，而是问——你有没有结论先行，再想办法论证它是合理的？这个问题在评估：面前的结论是不是被过分放大、被当作了前置的真理；若是，后面找出来的论证完全是为服务结论而存在，可能超出批判性思维可以评判的语境，让人无法反驳。结论先行易发生在人作选择时：情绪、偏好、立场等因素已让我们有了结论，再在理性上把它合理化。例一：2019年4月郭台铭宣布竞选台湾地区领导人，解释参选原因是「妈祖前几天托梦给他，叫他要出来为台湾做事」——如果相信他先有了参选决定，这个理由简直无敌，因为它没法证伪，甚至让信仰妈祖的对手被动。例二：网络梗「天凉王破」——霸道总裁已经决定让王氏集团破产，随口找理由「天凉了」；前提是真的，推理却是无效的，天凉与破产之间没有能成立的逻辑关系。人一旦先作了决定，接下来给出的理由就不是用来推导决定，而是想办法维护决定；这也提醒自己作决定时，搞明白影响决策的到底是理性判断还是别的什么。（出处：第4讲）
- **机制**：决策顺序倒置后，认知资源从「检验结论」转向「捍卫结论」，理由沦为修辞。
- **量化**：原文未给具体数值（本条为机制阐述）。
- **主体**：适用于审视公共人物表态与自己重大决策；日常即兴偏好表达不适用。
- **风险**：用「你结论先行」否决一切直觉决策——直觉在某些领域（如资深从业者）本有信息含量，关键在事后补检验；指控他人结论先行易引发对抗。
- **条件**：此为作者观点，非实证结论；失效场景：紧急情况下先拍板后补论证是常见且必要的决策方式，不宜苛责。
- **反例**：先决定不换工作，再搜集「现在行情不好」的新闻佐证。
- **动作**：做出重要决定后，自问：如果理由被推翻，我还维持这个决定吗？
- **自测**：结论先行时论证变成了什么？郭台铭和「天凉王破」的例子各说明什么？
- **难度** 3｜**证据** C
