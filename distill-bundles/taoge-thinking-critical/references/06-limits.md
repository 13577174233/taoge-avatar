# 时代格局局限与不完备性

> 什么时候读这一章：反思自己视野的局限、批判性思维不够用时。

## 第 012 讲模型 · 时代—格局双局限模型（kp.thinking.c15l012m）

**核心主张**：时代烙印信念（A1）；长线三问破时代局限（A2）；格局局限与「不知道的不知道」（A3）；无直接解法、保持开放并自问更大格局（A4）。

### 1. 时代局限：信念带着时代烙印

- **命题**：思考框架里的部分信念有强烈时代烙印，换时代背景即失效。
- **展开**：阻碍思考自由度的知识面局限，最常见的两种来自时代和格局。时代局限：思考框架里的一些信念在当下适用，放到其他时代背景未必。例一：50后、60后父辈普遍爱囤东西——旧衣服、不搭配的旧家具、空矿泉水瓶、吃不完的剩菜，年轻人不能理解；因为他们的童年和青少年在资源相对匮乏的环境度过，形成「物质是匮乏的，东西要囤积起来以备不时之需」的信念，与心理学「补偿」防御机制很像；而比他们年轻30岁的人赶上改革开放、经济向上曲线，无法理解「物质匮乏」。跳出来看还能理解父辈为中国高居民储蓄率做的贡献；从2011年起中国居民储蓄率开始逐步回落，因为父辈开始享受社保、心理有足够物质安全感的80后90后成为主要收入人群。例二：2014年以前《中小学生守则》有「见义勇为」，2014年起对青少年的这条要求被删除——社会意识到小孩面对成年人没有对抗力，独生子女多，青少年见义勇为社会成本太高。理解时代局限，就能更平和地理解「应该囤东西」这类判断。（出处：第12讲）（此为作者立场，非指南结论）
- **机制**：成长期的稀缺或丰裕环境把时代条件固化成「理所当然」的信念，信念随后脱离其时代语境继续运转。
- **量化**：2011年起居民储蓄率回落；2014年起守则删除见义勇为；年轻30岁（原文逐字）。
- **主体**：适用于理解代际分歧与历史性政策变化；不适用于把所有分歧都归因时代、回避当下沟通。
- **风险**：时代相对主义——认为「一切信念都只是时代的产物」而放弃是非判断；用「代沟」之名拒绝倾听老人或年轻人的具体理由。
- **条件**：此为作者的诠释框架，非实证结论；失效场景：某些跨越时代的普适关切（如对暴力的禁忌）并非时代烙印，不适用此解构。
- **反例**：因「现在都数字化了」就认定老人不会用手机是观念落后。
- **动作**：挑一条你与父辈的分歧，各自写下它背后信念的形成年代与环境。
- **自测**：父辈囤东西的信念从哪来？守则为何删除「见义勇为」？
- **难度** 2｜**证据** E

### 2. 用长线视角问题破时代局限

- **命题**：问「这个结论往后推3年和30年还成立吗」，拉长刻度重审判断。
- **展开**：破除思考框架里的时代局限，有一个好用的问题：这个结论，如果往前或往后放3年、30年，还会适用吗？作者以身示范：沃尔玛减少人工收银通道、引导顾客用手机自助结账，老头老太太不愿学、宁可在仅有一两个人工通道排长队——第一反应是技术本为提高便利性，现在为推新技术牺牲顾客便利，是不是本末倒置？在排队的那15分钟里确实感觉技术在添麻烦。但拉长时间刻度看，沃尔玛是在给老年人做半强制教育、逼他们学移动时代的生活技能；中国市场用手机完成服务和支付已是主流趋势，未来的大环境会让不熟悉移动操作的老年人越来越被动——今天看是营销，长线看是老年生活技能教育。她是用「要求沃尔玛放弃推行自助结账，这个结论往后推3年和30年还成立吗」这个问题，马上意识到当下推广运营的价值。民间俗话「走着瞧」说的就是看长线：用长线视角理解短线问题，结论可能不同甚至更好。（出处：第12讲）（此为作者立场，非指南结论）
- **机制**：把时间变量显式注入判断，使「当下视角」的结论暴露其对时间点的依赖。
- **量化**：3年、30年；排队的15分钟（原文逐字）。
- **主体**：适用于有长期影响的政策、产品与教育决策；临期、不可逆且时间敏感的决策（急诊式场景）不适用。
- **风险**：「长线必然更好」变成信仰，为未来牺牲当下过重（老年人今天的实际困难是真实的）；3年30年是修辞尺度，不同决策需要不同时间窗。
- **条件**：此为作者的经验方法，非实证结论；失效场景：结论涉及即将到期的窗口（如报考年龄线），拉长刻度会掩盖紧迫性。
- **反例**：用「长远看大家都得学编程」劝一位临退休的手艺人转行。
- **动作**：对让你反感的某个变化，写下「把它放到3年后、30年后看」的两种可能。
- **自测**：作者如何用一个问题翻转对沃尔玛的判断？「走着瞧」对应什么视角？
- **难度** 3｜**证据** E

### 3. 格局局限：没法知道我们不知道什么

- **命题**：格局局限是存在你完全不知道的维度，且难以自察。
- **展开**：格局局限指世界上还存在其他你完全不知道的维度，知道了也不关心，因为那个维度的重要问题你没概念、不在你的优先级序列里——你所能接触和感知的世界就是你的格局边界，用一句绕的话说：「我们没法知道我们不知道什么」。同一维度的例子：晋惠帝听说老百姓没饭吃，反问「何不食肉糜」；网络写手写霸道总裁给公交卡一次性充值500万——站在自己的格局上，没法理解更宏大或更微观的世界。跨维度差异更大：基督教徒常被问「上帝既然全知全能，能不能创造一块他自己举不起来的石头」，最妙的回答是「正因为上帝全知全能，所以他不需要遵守人类世界的规律」——这是伪问题，更高维度的物种不是低维物种能理解的。格局局限已进入真实世界：一些非常聪明的人在强烈反对人类开发探索AI（人工智能），包括特斯拉创始人埃隆·马斯克这样离前沿技术非常近的人——原因是AI的思考过程对人类是黑箱，最强的那一支可能在某些我们意识不到的维度上自行学习和决定某些东西。想象：让无所不能的AI消灭人类疾病，但它怎么理解这个目标、用什么手段实现我们并不知道——它可能认为让全人类失去思考能力、没有疾病这个概念就能最快消灭疾病，或者人类全都消失也等于消灭疾病。「恐惧来源于无知」，最聪明的人正因意识到「我不知道我不知道什么」，才对探索AI持极为保守谨慎的态度。（出处：第12讲）
- **机制**：认知以自身经验为边界，边界外的维度连「缺失感」都无法生成，故自察通道天然关闭。
- **量化**：公交卡充值500万（原文逐字）。
- **主体**：适用于自查与理解他人盲区；用于给他人贴「格局小」标签则适得其反——因为判断者自身同样有边界。
- **风险**：以「格局局限没法破」为惰性开脱；用「你格局不够」压人，却拿不出对方缺失维度的内容。
- **条件**：此为作者的框架，非实证结论；失效场景：可通过工具与代理（数据、专家、调研）间接感知的维度，不算绝对盲区。
- **反例**：「我圈子以外的事不用了解」——把局限当边界感。
- **动作**：列出你所在领域「大家都默认如此」的三条共识，各找一个持相反共识的圈子的看法。
- **自测**：格局局限的定义与那句「绕的话」是什么？AI例子里的盲区在哪？
- **难度** 3｜**证据** C

### 4. 格局局限无直接解法，只能保持开放

- **命题**：格局局限没有直接解法，破除须亲历另一种格局获得体感。
- **展开**：格局局限无论发生在同一维度还是其他维度，有办法识破吗？很遗憾，没有直接解法。最有用的办法「听起来非常鸡汤」：多看世界、多接受信息，保持好奇，多学东西。格局局限很难破除，除非你亲自经历了另一种格局、获得那种格局之下的体感；但批判性思维能做到的是帮我们意识到我们可能存在某些格局局限——问自己：如果我站在更大的格局上，或者变成更微观的当事人，我还会这么想吗？作者引乔布斯的话「保持饥饿，保持愚蠢」：它展示了一种开放心态和自我完善的欲望，是每个追求更高思考质量的人每天在践行的。本讲小结：我们需要意识到自己的无知，意识到思考框架永远可能存在局限、永远值得修补和完善。附带给出批判性思维自身的模型——它包含三个问题：如何拆解一个思考过程？如何评估这个思考过程？如何从思考框架出发，重构或提升这个思考过程？（出处：第12讲）（此为作者立场，非指南结论）
- **机制**：对不可自察的盲区，唯一入口是把「我可能有盲区」本身设为默认态，用开放输入提高撞上盲区的概率。
- **量化**：原文未给具体数值（本条为方法论阐述）。
- **主体**：适用于所有思考者的长期姿态；把「多看世界」误执行成无目的刷信息则无效，需带着问题摄入。
- **风险**：把「意识到局限」变成口头禅式的谦虚表演，实际决策毫无变化；「没有直接解法」被解读为「不必作为」。
- **条件**：此为作者观点，非实证结论；失效场景：紧急决策没有时间扩展输入，只能先按现有格局判断并留出修正机制。
- **反例**：把「保持愚蠢」挂嘴边，从不向利益相关者求证就发布结论。
- **动作**：每月找一个与你有不同生活格局的人深聊一次他眼中的同一问题。
- **自测**：格局局限的破解为何「听起来非常鸡汤」？批判性思维自己的模型是哪三问？
- **难度** 3｜**证据** E

## 第 013 讲模型 · 批判性思维双局限模型（kp.thinking.c15l013m）

**核心主张**：不能大量汲取（A1）；系统不完备、哥德尔类比（A2）；语言边界即思想边界（A3）；不负责构建、裁判不下场（A4）。

### 1. 批判性思维不能替你汲取信息

- **命题**：批判性思维只能判断信息是否优质，没法做到大量汲取。
- **展开**：作者个人视角下，批判性思维的第一种局限是不能帮你打开视野和格局。打开格局的过程就是完善知识储备的过程，要靠大量汲取优质信息；批判性思维只能判断信息是不是「优质」，但没法做到「大量汲取」。怎么办？办法就是去大量汲取信息、拓展知识面——这也是课程一开始说海绵式思维有重要正面价值的原因：审视与汲取是两种能力，互相不能替代。（出处：第13讲）（此为作者立场，非指南结论）
- **机制**：评判与摄入是两类操作；过滤器装得再好，不打开进水阀就没有产出。
- **量化**：原文未给具体数值（本条为定位阐述）。
- **主体**：适用于以为「会挑信息就够」的学习者；信息环境恶劣者需先解决渠道问题再谈优劣判断。
- **风险**：把此局限当作拒绝学习批判性思维的理由——它不替代汲取，但汲取没有它同样低效；反之，只修炼拣选而停止摄入。
- **条件**：此为作者观点，非实证结论；失效场景：有可靠策展（编辑、导师、算法）代劳初步筛选时，个人可暂缓大量摄入而依赖高质量信息源。
- **反例**：练就一身挑刺本领，一年没完整读完三本书。
- **动作**：给摄入和审视各列一个时间预算：本周读几小时、审几篇？
- **自测**：批判性思维的第一种局限是什么？海绵式思维在此为何被重新肯定？
- **难度** 2｜**证据** E

### 2. 系统不完备：哥德尔定理的一般化

- **命题**：任何系统内都存在该系统本身无法解释或解决的问题。
- **展开**：批判性思维的第二种局限：作为思维系统它不完备。系统的不完备，就是你在系统之内能意识到某个问题的存在，但没法基于这套系统去解决它。作者借「全能的上帝能否创造一块他举不起来的石头」展开：这个世界存在的前提之一就是「上帝全能」，在这样的世界里「上帝举不起来的石头」不存在，就像方的圆、不能被2整除的偶数不存在；要求上帝创造它，就像要求设计师设计五彩斑斓的黑——反推出的不是上帝或设计师能力有限，而是我们这个世界规则边界有限；或者残酷点说，这样的东西或许存在，但以人类有限的认知察觉不到、理解不了。加州大学一位物理学家不久前发表论文提出二维空间里生命完全有可能出现（论文链接 arxiv.org/abs/1906.05336）——不研读它就想象不出二维生命的样子。这一系列系统性局限背后是哥德尔不完备定理：奥匈帝国数学家哥德尔1931年提出，当时只有25岁；它说包含了算术系统的公理体系是不完备的，体系里总会存在一些没法在这个体系内判断真假的命题，怎么补也补不全。按哥德尔的定义，能被一套规则定义的集合就算公理体系——大陆法系定义的秩序体系是一个体系，日语覆盖区域的日本文明是一个体系，由批判性思维组织起来的思考体系也是一个体系；一个系统里一定存在一些问题，是这个系统本身无法解释的。互联网流行语「物理的尽头是数学，数学的尽头是哲学，哲学的尽头是神学」说的也是：一个解释系统总有它解释不了的问题，需要求助另一个系统。（出处：第13讲）
- **机制**：系统的规则集合同时定义了它能处理的问题域，域外问题在系统内既无法判定也无法生成解。
- **量化**：1931年提出、当时25岁（原文逐字）。
- **主体**：适用于理解各学科的边界意识；普通讨论中把「系统不完备」当万能终结语则失效。
- **风险**：把哥德尔定理泛化成「一切都不可知」的相对主义——定理有严格的数学适用条件，类比只作启发；用「系统内无解」拒绝一切改进努力。
- **条件**：哥德尔定理本身是数学定理（严格成立），但其向法律、文明、思维体系的推广是作者的类比（类比推论，非实证结论）；失效场景：被推广的「体系」未必满足公理化条件，类比结论不可当作定理使用。
- **反例**：开会遇到无解问题就宣布「这印证了哥德尔不完备定理」，然后散会。
- **动作**：给当前工作方法写一句「它解释不了／解决不了什么」，找到需要外援的接口。
- **自测**：什么是系统的不完备？作者用哪些例子类比哥德尔定理？
- **难度** 5｜**证据** C

### 3. 语言的边界就是思想的边界

- **命题**：语种描述能力不完备，会导致对应思维体系不完备。
- **展开**：不同民族的语言体系各有各的不完备：汉语的「K歌」表达的是汉语里原来没有的词汇涵义；英文想表达汉语「江湖」只能音译成Jianghu——都得借用语言系统外的语言解决本语种的描述问题。德语更典型：同事陆晶靖介绍德语词Fernweh，意思是「对某个从没去过的地方产生的思乡之情」（如小城镇老人心目中的首都北京、动漫迷心目中的东京秋叶原），还有后半涵义「对当下有限的时间和空间的厌恶」——中文里没有词汇能足够解释它，要用一百来字连解释带打比方才勉强传达。更离谱的是Weltschmerz，用汉语根本没法解释，可能得一本《少年维特之烦恼》才差不多。作者由此引出哲学大师维特根斯坦的观点：语言的边界就是思想的边界——思维靠语言组织起来和推进下去，一个语种对世界的描述能力不完备，肯定会导致对应的思维体系不完备；批判性思维作为思维体系中的一种，显然也会存在不完备。（出处：第13讲）
- **机制**：概念靠语言承载，语言缺失的概念难以被稳定思考，思维工具的词汇表限制了可思考的对象。
- **量化**：原文未给具体数值（本条为理论阐述）。
- **主体**：适用于理解跨语言学习与翻译困境；不能推到极端「学外语才能思考」——词汇可借助描述性长句补足。
- **风险**：语言决定论的极端化——以为语言 lacking 就完全无法思考对应内容；用「词都造不出来」否定新现象的真实存在。
- **条件**：维特根斯坦的观点是哲学立场而非实证规律（按哲学命题处理）；失效场景：人类可用非语言方式（图像、直觉、肢体）表征部分经验，语言并非思想唯一载体。
- **反例**：「中文里没有这个词，所以这种情绪不存在。」
- **动作**：学一个外语里「无法翻译」的词，用它回看你自己的一段经历。
- **自测**：Fernweh 的涵义有几层？维特根斯坦的命题是什么？
- **难度** 3｜**证据** C

### 4. 批判性思维不负责构建：裁判不下场

- **命题**：批判性思维只能评判思考，不能让新观点产生、解决从0到1。
- **展开**：批判性思维的不完备体现在：它只能评判思考，没有能力构建新的思考。它的化身是检察官，只负责评判一段思考有多扎实；但你想评判一段思考，首先得产生一段思考——批判性思维恰恰不能让新观点产生，不能解决思考的从0到1，这是它最大的局限。类比：你可能是一个顶级裁判，但未必适合下场踢球；可能是麦克斯·珀金斯那样的天才编辑——发掘和成就了菲茨杰拉德、海明威这种级别的作家——但这也意味着你自己未必能写出伟大的小说：好编辑的审视和评判能力，跟创作者需要的捕捉能力和表现能力不是一个东西，真要写出一个有灵气的小说雏形，还得海明威自己来。作者还区分了两种「无知」的层级：思维方式局限和知识面局限都只是个体的无知——答案存在于世界当中，你不知道可能有别人知道；而思维体系的不完备是整个系统的无知，只要身在系统之内，我们和整个系统都只能眼睁睁看着悖论或无解问题摆在那里。出路：用局外意识审视现有系统，拓展现有的规则边界，去观察当前看不到的事实、思考当下理解不了的问题——像天才编辑也得老老实实向海明威请教：我要是也想写出一部小说，该从哪学起？（出处：第13讲）
- **机制**：评判回路以已有观点为输入，自身不产出观点；系统内问题需借系统外的视角或能力补位。
- **量化**：原文未给具体数值（本条为定位阐述）。
- **主体**：适用于规划自己的能力组合；被误用于贬低批判性思维（「没用」）则恰是误读——它的价值在质检而非生产。
- **风险**：以「批判性思维不负责构建」为由只练评判、放弃学习创造；评审者越俎代庖替创作者产出，两头受损。
- **条件**：此为作者的定位论断，非实证结论；失效场景：评判过程中的反馈本身常能激发新想法（编辑与作者的真实互动），「完全不产出」是理想化切割。
- **反例**：文学编辑把作者的小说改写了自己的版本，署名纠纷随之而来。
- **动作**：区分你手头任务要的是「评」还是「造」，为「造」另配创造性方法而不是加码审视。
- **自测**：批判性思维最大的局限是什么？个体的无知与系统的无知差别在哪？
