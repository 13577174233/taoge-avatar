# 家庭财富管理驱动认知包（Family Wealth Driver）

> **一句话定位**：家庭财富管理不是「怎么把钱赚更多」，而是「怎么用 30–45 岁这 15 年挣的钱，撑住横跨三代的一系列事件」——先排事件顺序，再配工具，最后才谈收益。
> **来源**：李璞·家庭财富管理（LFP001–LFP023 共 23 篇 S 级归档，2026-11-07 全量收官；发刊词1＋正课01–11＋加餐答疑5＋私享直播6＝23）。

---

## 一、总图（一句话记住）

**观念（LFP001–004）× 工具（LFP005–006）× 事件落地（LFP007–012）× 答疑补漏（LFP013–017）× 直播实战（LFP018–023）**

四层递进：**先正观念（不急着赚钱，先排事件）→ 再配工具（负债与理财各归其位）→ 逐事件落地（配置/健康/买房/生育/养老/传承）→ 最后用实战问答补上不确定环境下的现金流与组合问题**。

核心算式：**家庭财富＝可预期现金流 × 事件覆盖度**，不是账面数字的大小。

| 编号 | 模型名 | 一句话 |
|---|---|---|
| LFP005 | 负债中性律 | 负债是中性的财务杠杆：刚性支出适合负债，享受消费不适合，负债投资很不可取 |
| LFP006 | 事件先行律 | 配工具先问「为哪个事件买」，不是先选产品；三步：事件时间点、风险系数、可投资余额 |

### 事件管理（LFP007–LFP012）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| LFP007 | 三桶配置律 | 先记账算年度结余，再盘点防守型／稳定型／进攻型资产，最后按家庭情况定比例 |
| LFP008 | 保险对应律 | 疾病不确定但工具确定：按日常小病—中症—重症，依次匹配社保、普惠型保险、医疗险、重疾险 |
| LFP009 | 自住投资分律 | 买房先定自住还是投资：自住要舒服，投资看价值；对外看政策，对内盘现金 |
| LFP010 | 抚养底线律 | 法定抚养义务止于 18 岁基础供给；额外投入重点在健康与教育，谨慎扩张 |
| LFP011 | 账户养老律 | 养老不是攒一笔巨款，而是日常／紧急／休闲三账户分别配置；日常账户要等长、抗通胀的现金流 |
| LFP012 | 传承标准律 | 传承是每个家庭的标准动作而非富豪专利；防「传非所愿」靠正式遗嘱与专业律师协议 |

| 编号 | 模型名 | 一句话 |
|---|---|---|
| LFP013 | 安全感律 | 安全感来自可预期的现金流与备用金，不来自账面数字的大小 |
| LFP014 | 抗通胀律 | 抗通胀靠与生活成本挂钩的长期现金流与实物资产，短期博弈不解决购买力问题 |
| LFP015 | 保险三层律 | 家庭保险按社保—普惠—商业三层补齐，先覆盖大额低频风险，再补小额高频 |
| LFP016 | 工资安排律 | 工资先分三份：必要支出、备用金、可投资；比例固定下来，再谈收益 |
| LFP017 | 养老三柱律 | 养老财务资源来自社保、企业、个人三根支柱；缴费基数、地点、年限是最关键三项 |

| 编号 | 模型名 | 一句话 |
|---|---|---|
| LFP018 | 组合无门槛律 | 组合与资金量无关：两三个产品搭配（储蓄＋基金/股票＋保险）并每年动态平衡，就能拿到市场平均回报 |

## 三、家庭财富规划 SOP（6 步）

1. **定单位与边界**（LFP001–LFP002）：把配偶、父母、子女的收支与负债并成一张家庭表；先做资质与合规排查，把「不爆雷」写在目标第一条。
2. **排事件清单**（LFP003–LFP004）：列出未来 20 年刚性事件（医疗、买房、养老、教育）与柔性事件，标注时间点与金额区间；先补 3–6 个月备用金。
3. **选工具**（LFP005–LFP006）：对每个事件问「时间点、风险系数、可投余额」，再决定用负债、储蓄、保险还是权益；不先选产品。
4. **按事件落地**（LFP007–LFP012）：资产分防守／稳定／进攻三桶并定比例；保险按三层补齐；买房先定自住或投资；生育只保底线；养老建三账户；传承立遗嘱。
5. **固定工资流水**（LFP016＋LFP011＋LFP017）：工资三份比例写死；查清社保缴费基数、地点、年限，测算三支柱缺口。
6. **不确定环境下的守与攻**（LFP018–LFP023）：先稳现金流结构，再用 2–3 个产品搭组合并年度再平衡；杠杆只上在确定现金流处。

## 四、应用场景映射

| 场景 | 适用律 | 落地 |
|---|---|---|
| 家庭年度财务复盘 | LFP001 LFP004 LFP016 | 用家庭表算年度结余，按刚性事件顺序重排预算，工资三份比例固定 |
| 要不要买房／换房 | LFP009 LFP005 LFP004 | 先定自住或投资；自住看舒适与现金压力，投资看政策与租售比；杠杆只承受刚性需求 |
| 保险配置问「买什么」 | LFP008 LFP015 | 按社保—普惠—商业三层、按小病—中症—重症对应，先大额低频 |
| 养老规划 | LFP011 LFP017 LFP019 | 三账户分设＋三支柱测算缺口，先算缺口再选工具 |
| 手中有一笔钱想投资 | LFP006 LFP018 LFP022 | 先问为哪个事件、多久要用；2–3 个产品＋年度再平衡即可，避开四类误区 |
| 经济下行期理财 | LFP020 LFP021 LFP023 | 先守现金流与安全资产，改结构而非猜方向；杠杆暂停 |
| 子女教育与传承 | LFP010 LFP012 | 教育只保底线＋重点投健康与教育；传承早立遗嘱，别等临终 |

## 五、边界

- **不构成投资建议**：本包只给规划框架与排序方法，不预测收益、不推荐具体产品；任何具体标的须自行核验资质与合同条款（LFP002）。
- **收益假设必须标注**：组合平均回报的表述依赖长期市场假设，实际结果受费率、税负、期限影响，不能当成承诺（LFP018）。
- **政策变量强相关**：社保缴费规则、房地产政策、普惠型保险条款随地区与年份变化，测算前须查当期口径（LFP009／LFP017）。
- **家庭结构决定结论**：单身、丁克、多子女、赡养四位老人的现金流结构差异极大，同一比例不可照抄（LFP001／LFP010）。
- **杠杆的适用边界**：仅限能提升确定现金流的场景且留缓冲；自住房贷以外的消费贷、投资加杠杆一律不建议（LFP005／LFP023）。
- **讲师为个人经验**：李璞的方法以中国城镇中产家庭为主要样本，农村资产、跨境资产、家族企业股权等场景需另配专业意见（LFP012）。
- **免 AI 化输出**：简体中文、零 emoji、结论先行、表格化，不写「赋能／抓手」类空话。

## 运行检查点与失败处置（2026-11-13，统一纪律）

四个 STOP 与三条失败分支见调度层 `taoge-cognitive-os/references/06-run-checkpoints.md`：数据缺失写「数据缺口」不补零｜口径冲突两口径并列不二选一｜真实下单与对外发布只给方案、执行由本人确认｜超边界明说并指向对应包。

失败分支：数据接口失败 → 用最近一次可用数据并标注日期，不虚构当期数值｜模型算不出 → 输出「模型不可用 + 缺哪些输入」｜被要求超能力 → 退回边界声明并指向对应包。
