# 领导力驱动认知包（Leadership Driver）

> **一句话定位**：一套把"领导力"从职位头衔翻译成动员动作的修炼工具——谁扛难题、怎么提问、怎么讲故事、怎么带人、怎么从失败学习、怎么成为自己，一切难题与人群互证。
> **来源**：刘澜·领导力30讲（LD01-LD36共36篇S级归档，2026-10-25全量收官），十模块：导论2+我来3+我不知道3+你觉得呢4+我讲个故事3+我教你5+失败了恭喜你3+我要改变什么4+为什么4+我是谁5。

---

## 一、总图（一句话记住）

**领导力 = 动员群众解决难题 × 十句口诀修炼链**

领导力不是职位是责任（德鲁克：领导力是责任不是头衔特权金钱）；不是魅力是结果（魅力往往是负担）；不是一呼百应是少数人响应多数人观望。十句口诀是反本能的行动提醒器：我来→我不知道→你觉得呢→我讲个故事→我教你→失败了恭喜你→我要改变什么→为什么→我是谁→我该是谁。每一句都对应一项修炼，从扛责到动员到讲故事到带人到从失败学习到反思到深思到认识自己到成为自己。

## 二、核心律速查表（LD系列36条，按模块分组）

### 模块0：导论（LD02-LD03，2讲）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| LD02 | 领袖力律 | 领导力=承担解决问题的责任，不是职位；领导力是领导职位的责任，领导职位是领导力的资源 |
| LD03 | 口诀修炼律 | 领导力像高考考十门科目；十句口诀是关键时刻的反本能行动提醒器；听一个人说话判断他领导力成色 |

### 模块1：我来！（LD04-LD06，3讲）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| LD04 | 推拉两分律 | 推力=职位权力（报酬/强制/合法）；拉力=个人权力（专家/参照/信息）；高手主要用拉力 |
| LD05 | 魅力结果律 | 魅力不是发挥领导力的前提，而是发挥领导力的结果；魅力被神化后是领导者的负担 |
| LD06 | 我来口诀 | 面对集体难题挺身而出；对上级平级说"让我来"，对下级说"跟我来"；旁观者效应=人越多越没人站出来 |

### 模块2：我不知道。（LD07-LD09，3讲）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| LD07 | 领导管理两分律 | 领导解决挑战性难题（靠群众），管理解决技术性问题（靠权威）；每个经理人两种责任都要扛 |
| LD08 | 希特勒问题律 | 动员群众解决难题=领导力；光动员不解题不是领导力；实现目标≠解决难题（目标本身可能是假药） |
| LD09 | 我不知道口诀 | 四种时候说"我不知道"：技术性问题你不是权威时/挑战性难题前放下过去锤子时/已有答案想听更好答案时/确信答案最好但要让下属自己组装时 |

### 模块3：你觉得呢？（LD10-LD12+LD32加餐，4讲）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| LD10 | 两种关系律 | 交易型关系（交换完谁都没变）vs变革型关系（双方升华）；先从柴米油盐入手再谈更高任务 |
| LD11 | 唱反调律 | 新分类法=独立思考×积极参与；明星员工因提反对被当态度差；设"唱反调奖"建文化 |
| LD12 | 你觉得呢口诀 | 沙因第三种谦虚=依赖他人而生的谦虚；提问四标准=思想启发/情感激励/关系促进/行动推动 |
| LD32 | 追随力律 | 追随力=动员领导解决难题；三要点=委婉唱反调（私下/为难式/借力）/积极唱反调（建设性/决策前）/向上建立关系 |

### 模块4：我讲个故事...（LD13-LD15，3讲）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| LD13 | 故事两要素律 | 形象（越形象越打动人）+距离（离听众越近越打动人）；动物寓言距离远不是好故事 |
| LD14 | 故事镜子律 | 四种正确故事=我是谁/我们是谁/我们向何处去/我们为什么要变革；每种都带一面镜子让听众照到自己 |
| LD15 | 三种讲故事律 | 用嘴讲（倾听-感受-改变）/用道具讲（目睹-感受-改变）/用仪式或行动讲（体验-感受-改变）；砸冰箱=用行动讲故事 |

### 模块5：我教你。（LD16-LD19+LD33加餐，5讲）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| LD16 | 老师三动作律 | 设计（目的/流程/学习流程）/教导/服务；领导者首先是设计师不是船长（彼得·圣吉） |
| LD17 | 学校危害律 | 学校教育三危害=只鼓励个人成功/给答案不提问题/补人之短不用人之长 |

| LD19 | 五层次律 | 管教/说教/身教/请教/传教；前三层是管理，后两层才是领导；新主管上任要定期反馈别等年底算账 |
| LD33 | 问题心智律 | 三法则=重要问题看情况/许多问题问错了/有些问题有标准参考答案；最重要的领导力是提问 |

### 模块6：失败了？恭喜你！（LD20-LD22，3讲）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| LD20 | 失败分水岭律 | 没犯过大错=平庸（德鲁克）；三类障碍=心理（损失规避）/社会（学校组织不鼓励失败）/能力（热炉效应） |
| LD21 | 组织失败四态度律 | 及早发现（走动式管理）/鼓励报告（甚至奖励失败）/深入分析（问发生了什么不问谁干的）/主动实验（聪明的失败=精心计划小规模试点） |
| LD22 | 失败七分类律 | 坏的失败（无视规章/粗心大意/能力不足/流程缺陷）/正常失败（已知风险/难料风险）/好的失败（探索创新）；四重定义=善意提醒/成功过程/有益发现/学习机会 |

### 模块7：我要改变什么？（LD23-LD25+LD34加餐，4讲）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| LD23 | 反思本质律 | 反思=对思之再思；不是回头看，不是总结，是对已有思考方式本身再思考；可事前/事中/事后反思 |
| LD24 | 反思四要素律 | 抽身而出/放下情感/转换角度/指导实践；预演失败=事前尸检（假设项目已失败找原因） |
| LD25 | 反思三层次律 | 小反思改行动/中反思改目标/大反思改心智模式；关键升级常常是放下情感而非换角度（英特尔标本） |
| LD34 | 真善美难律 | 领导力四大特征=求真（斯托克代尔悖论：信心+直面残酷现实）/求善（为社会创造价值）/求美（创造力）/求难（美好的东西往往很难） |

### 模块8：为什么？（LD26-LD29，4讲）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| LD26 | 决策决定律 | 决策=普遍问题一般解（一次解决一批）；决定=个别问题个别解（一次解决一个还常解决不了）；连问五个为什么找根因 |
| LD27 | 系统思考律 | 整体大于部分之和/在整体中理解部分/部分最优化对整体不一定有利；第二个为什么=找系统目标 |
| LD28 | 整合思考律 | 鱼和熊掌我要兼得；转变冲突观（建设性）+资源观（充足）；第三种为什么=问"为什么不" |
| LD29 | 根隐喻律 | 商场是战场/人力是资源/组织是机器；领导者要主动发现自己在用什么根隐喻，避免副作用 |

| 编号 | 模型名 | 一句话 |

| LD31 | 成为自己律 | 三个两难=自我对别人/结果对原则/原则对原则；每一次选择都是一次自我塑造 |

## 三、领导力问题诊断 SOP（5步）

遇到"这事怎么带团队/怎么解决/怎么带人/怎么自我修炼"类问题时按序走：

1. **判难题（LD07/LD08）**：先区分是技术性问题（靠权威/流程/考核）还是挑战性难题（靠群众动员）。技术性问题上流程上SOP，挑战性问题进入下一步。
2. **判关系（LD10/LD11）**：看你和对方的关系是交易型还是变革型。交易型先解决柴米油盐再谈更高任务；变革型要双方都升华。如果是上下级关系还要查：有没有唱反调的人？团队敢不敢当面反对你？
3. **选口诀（LD06/LD09/LD12/LD15/LD19/LD22/LD25）**：根据当前卡点选对应口诀——没人站出来说"我来"；你不知道答案说"我不知道"；要动员团队说"你觉得呢"；要传递愿景说"我讲个故事"；要培养下属说"我教你"；失败了说"失败了恭喜你"；要复盘说"我要改变什么"。
4. **深思四层（LD26/LD27/LD28/LD29）**：口诀用完还不够，问题复杂就深思——先问第一种为什么找根因（决策），再问第二种为什么找系统目标（系统），再问"为什么不"找整合解（整合），最后检查根隐喻（我们是不是把组织当机器了）。
5. **练身份（LD30/LD31）**：最后回到自己——这件事里我是谁？我热爱吗？我擅长吗？机会对吗？遇到两难时我该选哪个原则？每一次选择都在塑造我是谁。

输出格式：结论先行 → 每步证据（LD编号）→ 落点行动项。

## 四、应用场景映射

| 场景 | 应用 |
|---|---|
| 电商（冠生园） | 跨部门出事第一个说"我来"不等派活（LD06）；开会至少一半时候回"你觉得呢"先听下属方案（LD12）；做季度目标先问"我们该不该继续做这件事"不只问"怎么做更好"（LD25）；重复问题连问五个为什么挖到系统根因再动手（LD26）；团队考核加"是否对齐整体目标"不只看个人KPI（LD27）；遇到二选一问"为什么不"找整合解（LD28）；检查团队语言——"人力成本"换"人力投资"（LD29）；失败复盘先分类（好/正常/坏）再谈怎么改（LD22）；新主管定期反馈别等年底（LD19）；用"走顾客日"行动讲故事（LD15） |
| 投资（18只持仓） | 管理层出事后看措辞——躲责还是担责，措辞躲责降级（LD03）；持仓股出利空先判断是事件还是模式，别一跌就卖（LD26）；套牢时问"当初买入逻辑还在吗"不只问"怎么操作"（LD25）；看公司是奖励成功还是容忍失败——有失败奖的组织创新强（LD21）；管理层只讲结果不讲原则的警惕爆雷（LD31）；公司是把人当成本还是当资产看财报措辞（LD29）；魅力型创始人神化后听不进反对——董事会有无反对派（LD05）；学投资找一个大师学通别碎片化（LD36） |
| 教育（唐翌轩） | 跟孩子讲领导力=遇到难题站出来解决不是当官（LD02）；孩子考砸先问"你当时怎么想的"不只看对错（LD23）；选科选志愿帮他画三环——热爱什么擅长什么机会在哪（LD30）；孩子提意见注意方式——不是不能提是怎么提（LD32）；学习别追求学了多少门课追求学通几门（LD36）；家里做"责任到此为止"的榜样（LD03）；孩子成绩问题往根因挖不只骂不努力（LD26）；教育孩子少用奖惩推拉多用身教和讲理（LD04） |

## 五、边界

- 不教组织架构设计、不教HR制度条文——它是领导者的修炼视角，不是管理操作手册。
- 不预测组织成败、不做精确人才测评——它给"动员群众"的尺子，具体人事决策靠行业体感补。
- 领导力口诀不是话术——它要求改变本性，装着装着成真，但前提是真信真做。
- 跨行业应用天然失真——军队/企业/家庭场景不同，口诀相同但动作要调。
- 模型置信度：LD01-LD36 均为S级归档蒸馏（刘澜领导力30讲，2026-10-25全量收官36篇+1篇登记不归档）。
