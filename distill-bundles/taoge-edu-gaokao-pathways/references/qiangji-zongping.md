# 强基计划与综合评价报考细则（2029届参考框架）

> 每年3-5月教育部发布当年简章；以下为方法论框架，报名时以当年官方简章为准。

## 一、强基计划

### 基本规则
- 招生院校：39所双一流高校（清华、北大、复旦、上交、浙大等）
- 招生专业：数学、物理、化学、生物、力学、基础医学、历史、哲学、古文字等基础学科
- 录取公式：综合成绩 = 高考成绩×85% + 校测成绩×15%（各校比例略有差异，以简章为准）
- 录取批次：提前批之前单独录取，不影响普通批志愿

### 孩子适配评估（物化生）
| 条件 | 建议 |
|------|------|
| 数理化生有竞赛省一以上 | 强基价值高，可冲 |
| 数理化成绩稳定年级前5%-10%，无竞赛 | 可尝试，重点在校测 |
| 成绩中段（目标一本线附近） | 强基性价比低，专注普通高考 |
| 对基础学科（非热门应用型）无兴趣 | 慎报——强基专业不能转热门专业（部分学校受限） |

### 关键时间节点（2029届预测）
- 2029.03-04：各校发布简章、网上报名
- 2029.05：确认志愿
- 2029.06高考后-07：入围名单公布、校测（笔试/面试/体测）
- 2029.07：录取

## 二、综合评价

- 招生方式：高考成绩+校测+学业水平/综合素质档案，按比例合成
- 云南适用院校：以当年在滇招生简章为准（部分省外高校在滇试点）
- 材料：高中成绩单、获奖情况、社会实践、自荐信
- 动作：高二开始积累"综合素质档案"素材（研学、科创、志愿活动、获奖证书），有据可查

## 三、专项计划（务必高一核查资格）

| 类型 | 基本条件（以当年文件为准） | 备注 |
|------|--------------------------|------|
| 国家专项 | 户籍+学籍在贫困地区县，连续3年 | 昆明主城区通常不符合 |
| 地方专项 | 户籍+学籍在本省贫困县 | 同上 |
| 高校专项 | 农村学生，户籍学籍在农村区域 | 需核查 |

> 若孩子户籍在昆明主城区，通常不符国家/地方专项；但需每年复核政策，避免遗漏。

## 四、竞赛路线（五大学科竞赛）

- 数学/物理/化学/生物/信息学
- 省一：强基校测优势、部分综评认可
- 省队/国奖：强基破格入围、保送（仅集训队）
- 建议：高一试探性参与（校内选拔/初赛），高二根据成绩决定投入深度；**绝不以牺牲高考主科为代价**

## 五、港澳升学（备选）

- 香港：港大/港中文/港科等独立招生，看高考成绩+面试，学费10-20万+/年
- 澳门：澳大/澳科等，门槛低于港校
- 动作：高三上学期决定是否申请，与内地志愿并行不冲突
