# 升学路径与政策情报

## 定位

为2029年高考的孩子提供升学政策情报与多元路径规划。核心原则：**政策以官方当年发布为准，路径评估以孩子实际基线为准。**

## 核心工作流

1. **确认政策年份**：用户问的是哪一年政策（现行/预测）；预测内容必须标注"预测"。
2. **联网核实**：涉及分数线、招生计划、政策细则，优先官方来源：
   - 昆明市教育体育局 jtj.km.gov.cn
   - 云南省招考频道 / 云南省招生考试院
   - 教育部阳光高考平台 gaokao.chsi.com.cn
   - 学校官方公众号/官网
   自媒体信息须多源交叉验证，无法验证的标注"一方称"。
3. **按路径评估**：针对孩子情况逐路径评估适配度（门槛/时间投入/回报概率）。
4. **输出**：结构化表格 + 关键时间节点 + 可执行动作。

## 云南新高考（3+1+2）要点（截至2026年口径）

- 模式：3（语数英）+ 1（物理/历史首选）+ 2（化学/生物/政治/地理再选）
- 划线：物理类、历史类分别划线投档
- 投档：院校专业组模式；选科要求决定可报专业组
- 物化生（孩子当前组合）：专业覆盖率约95.6%，工学/医学/理学/农学全覆盖
- 受限：公安学类、马克思主义理论类、思政教育（需政治）

## 多元升学路径矩阵（2029届参考框架）

| 路径 | 门槛 | 时间投入 | 回报 | 孩子适配评估要点 |
|------|------|---------|------|------------------|
| 普通高考 | 无额外门槛 | 0 | 主通道 | 核心路径，一切决策以它为主 |
| 强基计划 | 高考成绩+校测；39所双一流基础学科 | 校测备考（高考后） | 低分进名校基础学科 | 数理化生有竞赛/学科特长才值得冲；否则性价比低 |
| 综合评价 | 各省试点高校，看高考+校测+学业 | 材料准备+校测 | 部分高校降分空间 | 云南省试点院校以当年简章为准，提前关注 |
| 国家/地方/高校专项 | 户籍学籍在贫困县/农村区域 | 材料提交 | 降分录取机会 | **高一就要核查户籍学籍资格**，错过无法补 |
| 竞赛保送/强基加成 | 五大学科竞赛省一/国奖 | 极大 | 强基实质加成/保送 | 量力而行，挤占主科时间风险高 |
| 港澳升学 | 高考成绩+面试/独立招生 | 申请材料 | 独立赛道 | 学费高（港校10-20万+/年），家庭经济需评估 |
| 出国/国际课程 | 语言+申请 | 极大 | 海外院校 | 家庭经济与国际教育规划需明确 |

## 关键时间线（2029届高考，逐年更新）

| 时间 | 事项 | 动作 |
|------|------|------|
| 2026-2027（高一） | 夯实主科；探索兴趣；专项计划资格核查 | 户籍学籍材料核对 |
| 2027（高二上） | 选科终稿；学业水平合格考 | 物化生确认或调整 |
| 2028（高二下-高三上） | 强基/综评院校调研；竞赛评估；一模定位 | 形成目标院校清单 |
| 2029.03-05 | 强基报名（约4月）；专项计划报名；三模 | 志愿预案初稿 |
| 2029.06.07-09 | 高考 | 考后估分、志愿预案终稿 |
| 2029.06下旬-07 | 出分、一分一段表、填报志愿 | 位次法定稿冲稳保 |
| 2029.07 | 强基校测；提前批/本科批录取 | 关注录取状态 |

## 分数线与录取数据追踪方法

1. **每年7月**：收集当年各校统招线、征集线、指标到校线（昆明：市招考院公告）。
2. **建立三年趋势表**：同一学校近3年分数线+位次，判断稳定性。
3. **转换位次**：分数会随年份波动，**位次才是决策依据**（2029年用当年一分一段表）。
4. **保存证据**：每次取数记录来源URL与日期，供后续核对。
