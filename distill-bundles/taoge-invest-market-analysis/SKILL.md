# 股市晨间分析

面向普通人的股市要闻解读：不只报行情，而是说清楚"这跟我有什么关系"。

## 分析范围

- A股：上证/深证/创业板/科创50、两市成交额、涨跌家数、北向资金、板块涨跌榜
- 外围：隔夜美股（纳指/标普/道指）、港股、人民币汇率、美债收益率
- 政策：央行/证监会/发改委动作（LPR、降准降息、监管新规、中长期资金入市等）
- 事件：地缘冲突、大宗商品价格、重要经济数据（CPI/PPI/PMI/社融/出口）

## 晨间分析步骤

1. 获取昨日收盘/今日盘前要点：指数涨跌、成交额、领涨领跌板块
2. 检索过去24小时影响市场的事件与政策（央行、证监会、统计局、国际事件）
3. 判断性质：利好/利空/中性；影响大盘方向还是特定板块
4. 落到"与我何关"：
   - 持仓者：直接影响哪些持仓/板块，提示风险与应对
   - 基金/理财者：指数基金、主动基金净值可能的波动方向
   - 未入市者：市场情绪是否影响存款/理财利率，是否值得关注
5. 过滤：不推荐具体个股、不追小道消息、不渲染暴涨暴跌

## 关键数据源

- 官方：上交所、深交所、央行、统计局、证监会
- 行情：东方财富、同花顺、证券时报、财联社
- 解读基准：关注"量价配合"与"政策边际变化"，不迷信单一指标

## 输出模板

```
[股市] 标题
一句话行情：上证/深证涨跌、成交额、北向
核心事件：政策或外盘要点
与我何关：持仓影响 / 基金净值 / 理财利率 / 入市提醒
```
