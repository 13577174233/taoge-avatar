# 创意思维驱动包（Hao Guangcai Creativity Driver）

> **一句话定位**：一套把"灵感"变成"流水线"的创意工程学——不等灵光一现，用八扇门找思路、八术批量量产、六法则检验传播，任何问题都能套出不同解法。
> **来源**：郝广才·创意思维课（得到，台湾资深创意人/出版人，2026-10-27 S级归档HC01-HC27共26篇，HC02学习攻略登记不归档）。

---

## 一、总图（一句话记住）

**创意=和人看一样的东西有不一样的看法；它不是天赋是工程学——八扇门找思路，八术批量出点子，六法则筛出能传得开的那个**

| 模块 | 核心动作 | 核心问题 |
|---|---|---|
| 生成原理（HC01/03/04/05） | 破三陷阱、问题即机会、先独立再整合 | 先把脑子里"标准答案"那道墙拆了 |
| 八扇门（HC06-HC13） | 组合/转换/联想/反向/问题/错误/感情/模仿 | 从哪个角度切这个问题 |
| 量产八术（HC14-HC21） | 联想术/最渴望联结/空隙/再定义/软化/附身/配角/刻意 | 怎么一次出90个点子选大创意 |
| 传播六法则（HC22-HC27） | 简单/第一/聚焦/故事/游戏/安全 | 这个点子能不能自己长腿传出去 |

## 二、核心律速查（26律）

### 生成原理（破墙）

| 编号 | 短名律 | 一句话 | 用法 |
|---|---|---|---|
| HC01 | 工程学律 | 创意不是灵光一现的天赋，是可拆解可复制的套路组合 | 不等灵感，先拿套路库去套业务问题（别人卖甜我们打低糖）；判断公司有没有创意基因看它是否被逼着持续生新创意 |
| HC03 | 不一样看法律 | 和人看一样的东西有不一样的看法，问题即创意机会，从收租者变探索者 | 把业务抱怨翻译成问题清单，区分个人问题vs集体问题（集体问题解决后收获最大）；设计"M&M巧克力条款"式简单检查点暴露复杂环节马虎 |
| HC04 | 三陷阱律 | 标准答案对方也知道、固有习惯筑透明墙、直线思维一套方法用到底 | 每个营销brief写完强制写三个"反着来"版本；警惕拿去年增长直线外推今年；教孩子"第一个答案摆着找下一个" |
| HC05 | 脑暴反常识律 | 团体脑暴比个人作业少30-40%创意，会议擅长凝聚共识不擅长发想 | 创意会改用德尔菲法：每人先独立写3个方案传下家补充五轮，最后才开会；个人研究股票先独立写判断再看别人观点 |

### 八扇门（找思路）

| 编号 | 短名律 | 一句话 | 用法 |
|---|---|---|---|
| HC06 | 组合拆开门 | 不相干事物拼起来差别越大力道越大，复杂东西按场景拆开 | 老字号x网红ins风组合；大礼盒拆成伴手礼装/中秋送礼装/下午茶装三个小规格；产品规划列10个"差别大"组合方向 |
| HC07 | 转换借用门 | 物转用途/人转才/地转利；世界是无息银行，旧东西照搬借形赚感情 | 盘点历史配方库挑3个老产品复古重做（Moleskine式）；老厂房转体验店；孩子"缺点"换角度看可能是才华 |
| HC08 | 联想门 | 时刻运用、去掉"不"、以万物为师（动物/植物/人/小孩），跨界越远越新 | 每月一次跨界联想会，从动物储食/植物保鲜/孩子盲盒游戏各借一个方法到产品；防歪门——联想要合基本逻辑 |
| HC09 | 反向门 | 大家往东你往西，钥匙是"不可能"和"不合理"，没人反对=不够创新 | 每个新品方向配一个反向版（别人收费我开放IP共创、别人塞满我空盒自选）；全网唱多的票减仓、有争议但逻辑硬的加仓 |
| HC10 | 问题门 | 消费者不知道自己要什么，层层发问追本质，答案常在问题旁边 | 客服差评区分群体问题配解法；不卖不动别改配方先追问哪个环节流失；读财报把"业绩好不好"换成5层追问 |
| HC11 | 错误门 | 错误是美好意外，跌倒别急着爬先看能捡什么，别人跌倒别嘲笑那是金矿 | 建"错误机会台账"，发错货/写错文案记录错误本身+可能的新品方向；投资每笔亏损复盘"这里面能捡什么"；孩子错题引导他说藏着什么金矿 |
| HC12 | 感情门 | 打感情牌比讲功能管用，感情三载体=图像/音乐/故事，别跟情感作对 | 文案从"用什么料"改成"送给谁唤起什么感情"；短视频固定用打动人的画面+怀旧BGM+品牌故事；消费股把品牌情感绑定度当打分项 |
| HC13 | 模仿门 | 模仿关键在创造不在模仿，最好跨界，五步=盘点/找师父/画蓝图/修正/砍后路 | 跨行业找师父学底层逻辑（广州酒家单一品类聚焦的骨），不抄本地同行；投资等赛道被验证再加创造性差异化；选科学别人的规划方法不照搬别人选什么 |

### 量产八术（出点子）

| 编号 | 短名律 | 一句话 | 用法 |
|---|---|---|---|
| HC14 | 联想术 | 相关联想列词圈元素联结，随机联想拉最不相关的词写特性利益点，发想与评判分开 | 礼盒文案走流程逼出90个点子选3个大创意；上午发想下午评估；选能延伸颜色/口味/包装的大创意不选小创意 |
| HC15 | 最渴望联结术 | 爱情比音乐重要，别谈产品谈用户更在乎的事；目标用户越窄越好 | 窄定"给长辈送中秋礼的30-45岁昆明人"，列20个渴望事物删掉相关的，挑"不踩雷有面子"联结低糖云腿；短视频前3秒先讲用户渴望 |
| HC16 | 空隙填补术 | 人和物之间找未满足需求，物和物之间填空隙，还能主动分层创造空隙 | 列"空隙地图"：大礼包和网红零食中间填低糖+小包装+云南特色；像通用斯隆按送礼对象/预算分层推系列产品；警惕供给方想象的低频伪需求 |
| HC17 | 再定义术 | 不发明新东西，换眼光重新定义行业；重要是角度不是尺度，时时换角度 | 逼出3个跳出食品框架的新定义（不是卖月饼的是"送礼不踩雷解决方案"）；投资选能持续重新定义赛道的公司；选科重新定义成"选未来看世界的工具" |
| HC18 | 软化术 | 正面硬拼和反面放弃都走不通时，找第三条有趣面 | 低糖云腿广告不讲健康讲"减肥的人终于敢吃第二块"的幽默场景；遇抄袭不告法院学明和电机把山寨品反向包装成绝版复刻；困局先问第三条路在哪 |
| HC19 | 附身术 | 借别的领域高手的行事作风想自己的问题，自我消失才跳出框架，不能找周边熟人 | 礼盒方案附身无印良品（极简克制卖生活方式）而非同行；投资学棒球手威廉斯严格选球——大部分时间观察，慢直球落中心格才全力打；选科附身农业教授/校长/孩子自己多角度看 |
| HC20 | 配角术 | 不盯主角改，把注意力放到不起眼的配角上，围绕大卖主角找配角 | 列产品配角清单（提手/内托/贺卡/开箱仪式感）逐个找改进空间；投资找热门赛道卖铲人（设备/材料/包装/物流）；教育别只盯分数主角，改睡眠/运动/笔记配角 |
| HC21 | 刻意术 | 人为夸张/荒谬/没有/反常/限定，打破常规吸引眼球；限制条件反生无限创意 | 列礼盒常识（传统包装/全糖/中秋限定）逐个改反常识；用刻意限定找差异化（限定对象/限定人数/限定情况）；短视频前3秒夸张钩子 |

### 传播六法则（筛传播）

| 编号 | 短名律 | 一句话 | 用法 |
|---|---|---|---|
| HC22 | 简单法则 | 人脑是反应不是思考，传播利用用户固有联想而非改变用户；一次只给一个关键信息、连续传递不超三次 | 低糖云腿只讲"低糖不齁"一个卖点，其余删掉；短视频信息点不超过3个；每家公司用一句话说清靠什么赚钱；给孩子讲题一次只讲一个点 |
| HC23 | 第一法则 | 人只记得第一不记得第二，错过大领域第一就切细分分类做第一，和世界纪录绑定 | 切"云南低糖云腿第一品牌/昆明送礼不踩雷礼盒第一"打透；投资只投细分品类第一名；帮孩子找他自己的细分第一 |
| HC24 | 聚焦法则 | 一个点长期打形成固定心智反应；三心法=找对立面/找焦点活动/长期坚持 | 锁定"低糖云腿"一个词未来3年所有素材围绕它，对立面是传统高糖月饼；每年中秋做一个标志性焦点活动；选品牌聚焦清晰、心智占一个明确词的公司 |
| HC25 | 故事法则 | 美感让人信（曲线+留白）、独特让人记（系统力量不是单一元素）、故事让人深（熟悉故事+跟产品关联+给产品取名） | 给主打产品取故事感名字，包装用曲线留白不堆传统图案；用云南老字号/送礼习俗这些用户熟悉的元素联结产品；投资把品牌故事力当消费股打分项 |
| HC26 | 游戏法则 | 把要传播的事变游戏，进阶感+变化感让人持续投入 | 设计会员进阶体系（普通/银卡/金卡/黑卡），每季推限定口味制造变化；开箱拍得像拆盲盒；学习搞错题从青铜到王者的进阶 |
| HC27 | 安全法则 | 不要天马行空，前进半步给人确定性=安全感；找熟悉框架套用、绑基本需求、绑万无一失主题 | 套"云南老字号/中秋送礼"熟悉框架不搞陌生概念；做日清凹槽式小改进——礼盒里加一张"送礼不踩雷指南卡片"；投资选给用户确定感的老字号品牌 |

## 三、创意五步生产 SOP

1. **定义问题（HC03+HC10+HC11）**：把抱怨翻译成创意机会，区分个人问题vs群体问题，层层发问追本质；先别急着否定问题里的错误，那可能是入口。
2. **选门（HC06-HC13）**：从八扇门挑最合适的思路方向——要反差用组合门，要省力用转换借用门，要破局用反向门，要挖机会用问题门/配角门，要打动人用感情门，要站前人肩膀用模仿门。
3. **量产（HC14-HC21）**：用联想术/最渴望联结术/空隙填补术走流程批量出90个点子，发想与评判分开，选大创意不选小创意；僵局时上软化术/附身术，要吸眼球上刻意术。
4. **过传播筛（HC22-HC27）**：这个点子能不能自己长腿？——一次只传一个信息吗？切进了某个第一的细分吗？聚焦一个词长期打吗？有故事有美感吗？能游戏化吗？给用户确定性了吗？六道筛子过一遍。
5. **落地与复盘（HC11+HC05）**：先独立写完方案再跨人整合，别一上来围坐脑暴；发出去后把错误当金矿台账复盘，反哺下一轮。

输出格式：结论先行（这个问题切哪扇门、出哪几个大创意、过了哪几道传播筛）→ 每步证据 → 落点（冠生园礼盒/短视频文案、A股叙事识别、唐翌轩表达训练 行动项）。

## 五、边界

- 本包是**创意发想框架**，不替代战略判断与运营执行——八扇门八术能量产点子，但点子对不对、投不投、怎么落地靠BR品牌透镜+SW商业实战+数据验证。
- 创意方法不保证成功：反向门/刻意术走极端有翻车风险，HC27安全法则提醒传播要给用户确定性，不是所有创意都该极端化。
- HC02课程学习攻略为元方法登记，不产核心律；HC01发刊词定调"创意是工程学"入律但不展开操作。
- 模型置信度：HC01、HC03-HC27共26律均为S级归档蒸馏（郝广才创意思维课，2026-10-27）；案例（Walkman/珍珠奶茶/黑猫宅急便/Swatch等）为课程原例，落地时需结合冠生园实际数据二次验证。
- 更新规则：认知革命项目每新增创意/发想/文案类模型，同步追加本包。
