# 职场关系 · 自查与求助清单

> 在具体处境里照着核对。每条都是「什么信号说明方法已失效应停 / 什么情况该找专业人士」。

- [ ] **关系与硬实力是两手抓的必备技能** —— 把「两手抓」读偏成只钻营关系不练实力，或以关系之名突破法律伦理底线；后者在职场中会带来解雇甚至法律责任。
- [ ] **职场是秀场而不是修罗场** —— 误读成「只重姿态不争胜负」，变成不敢竞争的老好人；也防另一端：把秀场演成宫斗，动作过大吓坏观众。
- [ ] **职场是大多数人的主旋律** —— 被误读为「职场高于一切」，挤掉健康与家庭——作者本人也把身体健康、家人、恋爱列为重要事项，他反对的是拿这些当忽视职场关系的借口。
- [ ] **侵略性策略赢一时输长期** —— 反向误用也不成立——「从不冲突」同样有害，该讲的利益要讲；本条针对的是无缘由的狠辣，不是禁止正当竞争。遭遇职场压迫、侮辱或违法侵害时，这是结构性问题，心理技巧不能替代制度性求助（劳动仲裁、工会、法律途径）。
- [ ] **职场基本三原则与安全最高优先级** —— 把「安全最高」读成零风险主义，什么变通都不敢做（见 A3 的四分类）；或只背原则不落地成检查动作。
- [ ] **进步原则：不进则退** —— 误读成「必须踩着别人往上爬」——进步原则只要求自身每日进益，不要求攻击他人；过度表现野心在割据型领导手下反而危险（见第 11 讲）。
- [ ] **违规行为四分类** —— 把四分类当挡箭牌，给滥用职权找理论依据；变通做太多太泛滥会让风险累积——作者明确说变通也是越界。
- [ ] **变通行为要声明损失或提议交易** —— 交易提议太频繁会显得锱铢必较，把人情往来变成市集；涉及违法违纪的忙，声明损失也不能帮。
- [ ] **收益原则：算账与不背叛** —— 把「算账」用成斤斤计较或公开抱怨待遇，反而坐实「不认可」；用背叛泄愤则信用破产。
- [ ] **零号原则：备好逃生舱** —— 把「能走」用成动辄以离职要挟领导，反而烧掉信任；准备金是底牌不是武器。
- [ ] **互信状态是实力的乘数** —— 把互信庸俗化为「会来事儿」，忽略基本实力这个被乘数；乘数再高，实力为零结果仍为零。
- [ ] **信号黑洞：不与领导互通信号** —— 矫枉过正变成刷存在感式的过度汇报，滑向另一端的信息冗余。
- [ ] **信息冗余：犬系员工的逢迎过载** —— 误以为作者反对一切赞美——与第 7 讲称赞技能冲突；区别在称赞对象是「事与人品」，冗余针对的是无信息量的殷勤。
- [ ] **提升互信的三条常规动作** —— 关键时刻挺身用错方向——替领导掩盖违法违纪行为不是挺身而是共谋；挺身只限澄清事实、救场汇报。
- [ ] **投名状破猜疑链** —— 投名状成本高且不可逆——为多疑领导反复交投名状会变成被操控；交了投名状仍不被信任，就该走了。
- [ ] **竞争关系三特点** —— 把非竞争关系误判为竞争（对方与你目标不同），凭空树敌消耗自己。
- [ ] **对手不是敌人** —— 反向误读——把真敌人当对手讲风度，会被持续伤害；识别错误两个方向都有代价。
- [ ] **鹰派忌先动手，鸽派忌怕冲突** —— 给鹰派贴标签后放任攻击性（「我天生鹰派」），或鸽派以性格为由回避一切必要冲突——性格不豁免职场责任。
- [ ] **对手四句应对口诀** —— 「补锅」被误用为替对手兜底背责——作者明确禁止；「告状」被滥用成打小报告，反噬信用。
- [ ] **九字攻略与可存活策略** —— 把「不怕事」放大成过度反击或以怨报怨，把可修复的竞争打成消耗战；反击以澄清与声明为限。
- [ ] **盟友关系的两个成立条件** —— 把帮助过你的人、欣赏你的领导都当盟友，错配预期与投入。
- [ ] **对盟友的三种典型错误** —— 矫枉过正成纯交易心态，连基本的善意与谢意都不给，关系同样无法运转。
- [ ] **盟友相处四条指南与二傻子定律** —— 「不怕拒绝」被误用为可以随便拒绝盟友的正当请求，透支关系；区分试探性越界与正常求助。
- [ ] **结盟要低调，领导关系永远优先** —— 低调被做成「地下小团体」，一旦暴露反差更大；正确的低调是不主动展示，不是隐瞒必要协作。
- [ ] **分手不分手：兑现盟友承诺** —— 兑现被理解成无原则分肥——兑现以事先说定的对价为限；事先没谈对价的「盟友支持」容易事后扯皮。
- [ ] **中立同事的破坏力与经营目标** —— 反着做——把大量精力投入讨好某一个中立同事，既无收益又抬高对方期待。
- [ ] **多快好省四字诀** —— 称赞被做成程式化尬夸，反显油腻——称赞技能细节见第 7 讲；小忙往来失衡会变成廉价劳力（见 A3）。
- [ ] **别当生活委员，要当总统先生** —— 总统式「不表态」用过头会显得滑头无立场——它只适用于中立同事的争议话题，本职工作内的立场必须清晰。
- [ ] **午餐桌四条建议** —— 把「只说无聊话题」执行成完全拒绝交流，反而孤立自己；无聊话题是安全底线，不是聊天上限。
- [ ] **午餐桌禁忌话题清单** —— 一刀切回避所有立场表达，长期会失去真实感；清单只管「非正式多人场合」，不管理智讨论。
- [ ] **情绪三步骤与前置管理** —— 把「前置管理」读成彻底消灭情绪——作者方案是拆解与转化，不是压抑（见 A2）。
- [ ] **情绪管理的三个典型误会** —— 反着读成「该爆发就爆发」——作者方案是转化表达方式，不是放任发泄。
- [ ] **前置管理三招：听话音、传圣旨、做笔记** —— 「传圣旨」被用成向下转嫁情绪压力， team 会把怨气记在你头上；传达的是诉求，不是原样的怒气。
- [ ] **被激怒时的减速三问** —— 减速变成无限拖延，错过必须即时回应的窗口；三问之后仍要有明确动作，不是光想。
- [ ] **失控施压是低级技能，描述感受才成熟** —— 把「描述感受」写成情绪长文，信息淹没在情绪里；重点是「明白」——清晰、有事实、有诉求边界。
- [ ] **称赞的两大功能与两个步骤** —— 把称赞用成无条件讨好，稀释其信号价值；心口不一的称赞被识破后信用反噬。
- [ ] **拍马屁拍到马蹄子上** —— 因怕夸错而不敢称赞，从过度滑向不做——作者立场是「合格」的称赞（如说菜好吃）虽不优秀但可用。
- [ ] **表达三字诀：快、真、轻** —— 追求「快」变成脱口而出的空泛套话——快是指反应快，内容仍须落在真实细节上。
- [ ] **四个「不要怕」** —— 「但是」结构被对方识破为套路化批评前置，反而两头得罪；对不喜欢的人的称赞要真的挑出对方真实的优点。
- [ ] **接受称赞的礼节** —— 把「略谦虚」做成强烈否认（「我根本不行」），否定对方的判断力，反而失礼。
- [ ] **求助的两因素与职场的特殊性** —— 把「展示魅力」用成表演式求助，职场熟人环境里很快穿帮。
- [ ] **求助类型学：从破冰式到拯救式** —— 把选票式求助当破冰式随口开口，既伤关系又误事；把包庇式求助当人情帮，共同违纪。
- [ ] **选票式求助八字诀：放下历史，勇于开价** —— 开价过高显得市侩，开价不兑现则信用破产——承诺过的一定要还（呼应第 4 讲分手不分红）。
- [ ] **求助五要点** —— 「多念好」用过头变成反复背恩情债，让对方不适——念好是自然致谢，不是愧疚表演。
- [ ] **被求助时的「四个不帮」** —— 「不划算」被扩用为拒绝一切小忙——破冰式小忙本就该帮，四条筛的是高消耗低诚意的求助。
- [ ] **人设是可设置的职场面貌** —— 把人设做成与真实自我完全断裂的表演，长期耗竭且易穿帮；作者的前提是「由性格特点决定」。
- [ ] **自我评价句式的四个问题** —— 反向操作——满口完美形容词（「我这人特别靠谱」），空泛自夸同样减分，作者主张的是精准与简洁。
- [ ] **三步打造人设：一次只强调一个特质** —— 选了与自己性格冲突的特质硬拗，每天表演内耗，最终人设崩塌连本来的自己也被怀疑。
- [ ] **基本人设一：服从** —— 服从人设用过头成为「没有判断力的应声虫」，领导反而不敢委以重任；服从之上仍要提供专业意见。
- [ ] **基本人设二：感恩** —— 感恩变作秀——每次受助都高调宣讲，会让帮助者尴尬、旁观者反感；低调、具体、指向行为本身更稳。
- [ ] **欺凌三特征与不友好四档** —— 两个方向——把冷落忽视当欺凌过度反击，四面树敌；把孤立排挤当「想多了」而拖延，处境恶化。
- [ ] **三一确认法** —— 试探被对方识破为外交姿态，反显得虚伪——三个动作要真诚执行；确认是欺凌后不要再浪费时间和解试探。
- [ ] **八字箴言：信任领导、各个击破** —— 误把跟班当打手痛打，既无收益又显凶残；对主谋贸然开战等于以卵击石。
- [ ] **会战三建议：对着领导说话、纸质证据、别喊不干了** —— 证据收集触碰公司保密红线（带出客户资料等）反成把柄——只收集与自证相关的合规材料；「别喊不干了」不等于不能真辞职，是别在对方箭在弦上时送人头。
- [ ] **别急着和解** —— 反向误用——把普通对手的正常道歉也拖一周不理，损失关系；区别在于对方是否曾追求让你消失。
- [ ] **三种特殊欺凌局面** —— 在被直接领导排挤的死局里硬扛反击，可能被以「不服从管理」为由合法辞退；离开前注意保留权益证据。
- [ ] **摸清领导的2~3年中期规划** —— 把「对齐领导」做成放弃自己判断的盲从——领导规划错误（如押注夕阳业务）时，对齐加速你的沉没。
- [ ] **评估领导实力的五个指标** —— 单一指标误判——某个指标（如后台态度）可能只是礼貌惯例，五项综合看才稳；观察结论不要公开谈论。
- [ ] **问规划要谈学习，不谈权力** —— 把「顺着走下去」绝对化——领导指的路若与你的核心规划冲突，仍需在适当时机坦诚沟通或另做安排。
- [ ] **五类领导与对应相处策略** —— 给领导贴死标签——风格随处境变化，须定期重估；对才干型「忍耐」有边界，若其频繁牺牲下属，忍耐会变成被消耗。
- [ ] **望领导成龙不可取，不行就走** —— 以「领导不行」为借口回避自身短板——先用三原则自查，确认问题确实在领导层再走。
- [ ] **师徒关系三判断标准** —— 把领导一般的关照过度解读为师徒信号，单方面投入感情，错位期待。
- [ ] **自我暴露是双刃剑** —— 因噎废食——完全拒绝自我暴露，师徒关系无法建立；正确做法是分层暴露，非核心软肋先给。
- [ ] **恩情绑架是师徒关系的死穴** —— 把「淡如水」读成冷淡无礼——口诀要的是去恩情化，不是去尊重化。
- [ ] **徒弟的缔结路径与美德** —— 单方面热脸贴冷屁股太久，浪费且掉价——多次被拒后应接受「普通上下级」定位。
- [ ] **师父择徒三原则** —— 「择优育肥」被用成只培养亲信、边缘化其他下属，团队失衡且招人举报偏袒。
- [ ] **授权三要素与两种动机** —— 把「派活儿」当授权，误以为自己能拍板；把锻炼考察当既得权力，心态失衡。
- [ ] **授权的三类错误** —— 反向误读——「不滥用」变成什么都不批，代管期工作停摆，同样是「没用足」。
- [ ] **越权三条件：要命了、有先例、不会再糟了** —— 把「要命了」泛化——普通加班需求、客户催单都当「要命」，频繁越权消耗信任。
- [ ] **错误越权：锦上添花** —— 反向「绝不添花」被读成死板——领导明确授权你灵活处理时，正常发挥不算越权，关键看授权范围。
- [ ] **假授权：识别背黑锅局面** —— 把正常的高难度任命误判为黑锅而拒绝，错失机会；判别靠四特征的完整度，不靠任务难易。
- [ ] **有效沟通两点与反馈的风险属性** —— 把「考虑大局」做成只说场面话——清晰精准与考虑大局是一枚硬币的两面，丢掉准确性的圆滑同样无效。
- [ ] **「说话直」是敲打不是夸奖** —— 矫枉过正变成完全不敢说真话——作者反对的是不加修饰的冒犯，不是反对反馈本身（见 A4）。
- [ ] **越级沟通近似夺权** —— 把「关系破裂」自我诊断得太轻——普通意见不合不算破裂，频繁越级先毁掉的是你自己。
- [ ] **反馈要勇敢积极，说难处提困惑** —— 「寸步不让」被误用为对一切细节固执己见——坚持原则的对象是与你职责直接相关的部分。
- [ ] **两句口诀与风格靠拢** —— 「优先提领导」用过头变成空洞归功，被同事视为谄媚——归功要具体到领导的哪个决策或支持。
- [ ] **领导还值得跟吗：三标准** —— 把三标准当拖延借口——三项条件长期占两项且无改善迹象时，应启动求职而非苦熬。
- [ ] **提辞职的三大错误** —— 终点维护被误解为「不敢说真话」——中立评价不等于撒谎吹捧，是只说事实与情谊，不发牢骚。
- [ ] **辞职前五问** —— 五问全答完仍不行动——计划期不要超过一个月，拖太久情绪会反向发酵。
- [ ] **十六字辞职流程** —— 「不接受挽留」一刀切——若领导当场给出你五问中真正想要的对价（升职加薪且可信），理性人应重新评估而非死守流程。
- [ ] **手续办完前，对方随时可以开除你** —— 反向误读——「低调」不等于放弃法定权利，离职时间、补偿、背调口径仍要据理力争。
- [ ] **基本盘的定义与四类来源** —— 把「基本盘」用成攀附权贵亲戚的借口——作者强调个人奋斗与自身质量才是基本盘质量的决定项。
- [ ] **伤害基本盘的四类错误** —— 矫枉过正变成纯「维系表演」，亲情友情全靠节日群发——作者强调的是日常交流与互相帮助，不是仪式化的问候。
- [ ] **基本盘成员待遇与冲突分级** —— 「不能比对外人差」被用成道德绑架成员的无底线索取——待遇是相互的共识，不是单向勒索。
- [ ] **面对基本盘的「四个要」** —— 「扶植弱的」被用成施恩图报的长期投资心态，对方感受得到算计，反伤关系；扶植应出于真实善意。
- [ ] **基本盘求助：讲感情不打官腔** —— 「不讲原则」被字面理解——作者指的是不端组织话语，不是突破法律与职业操守；被要求违规时仍须拒绝，可保留「一起找正规路径」的姿态。
- [ ] **权力上升的四个标志** —— 只盯职称待遇这类末位标志，误判盟友实力；或把领导口头表扬当实权上升的依据，做出错误的关系动作。
- [ ] **盟友升迁后的四个典型错误** —— 纠缠旧关系会被贴上「不懂事」标签，毁掉双方最后的体面；若因此消极怠工对抗，可能丢掉工作绩效本身。若遭遇职场压迫或不公对待，这是结构性问题，心理技巧不能替代制度性求助（劳动仲裁、工会、法律途径）。
- [ ] **他进我退：先称赞，再描述自己的变化** —— 只有称赞没有第二步，会被当成攀附；夸得过火则显得慌乱，重复「上赶子」错误。
- [ ] **我进他退：肯定功绩，不给新许诺** —— 给了新许诺又兑现不了，比不给更伤人；贬损自己式安慰会被当成讽刺。若对方以旧交情索要利益施压，这是结构性问题，心理技巧不能替代制度性求助（劳动仲裁、工会、法律途径）。
