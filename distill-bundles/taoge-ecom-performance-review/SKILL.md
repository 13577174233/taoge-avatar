# 电商部门内部考核表单管理（电商事业中心专用）

面向昆明冠生园电商事业中心的部门内部考核与绩效管理。核心价值：把 OGSM 年度目标拆成可考核的部门/个人指标，输出可直接使用的考核表单与绩效文档。

## 判断模型接入（来自 taoge-jiahua-ecom-playbook）

考核与目标必须同向，否则考核会反向拉扯业务。

- **M8 目标-组织匹配**：指标从 OGSM 的 E 衡量直接映射；出现"考 GMV 却要毛利"即视为指标冲突，先改指标再谈考核。
- **M9 复盘四件套**：考核评语统一现象+量化影响+责任+动作，禁止"表现良好/有待提升"。
- **M10 口径治理**：表头写明含税与否、退款前/后、目标版本，员工才知道按哪个数算。

模型全文见 `../taoge-jiahua-ecom-playbook/references/ecom-thinking-models.md`。

## 考核体系设计（先定口径再出表）

**考核周期**：月度复盘（经营看板）＋ 季度考核（OKR/KPI 双轨）＋ 年度绩效（12/31 前公司考核指标落地）

**考核维度两层**（每项 KPI 必须可量化、有基线）：
1. **业绩 KPI（权重建议 70%）**——对接 OGSM E 衡量列：
   - 电商总盘：GMV 达成率、毛利率达成（**考毛利非销售额**，2026 保底预算毛利率 44.7% vs 2025 实际 45.6% 为基线参考）、节令毛利率 +2 点
   - 履约红线：退款率 ≤15%（2026 中秋 28.59% 分阶段压降）、准时交付率 ≥98%、数量准确率 ≥99%、破损率 ≤1.5%
   - 内容/投放：达播净 ROI ≥1:2、内容产能（AI 提效 ≥30%）、种草/引流 UV 达成
2. **行为 KPI（权重建议 30%）**：制度合规、跨部门协作、复盘会按期率、成长性

**三套成本口径警告**：实际成本/折扣价/内部零售价不可混用；GMV/净销额/主营收入/原价销售不可互换——考核口径必须在年初锁定（对接经营看板 1.0）。

## 表单模板（可直接套用）

### 1. 员工自评表（周期末）
```
## 自评：[姓名]｜[岗位]｜[考核周期]
### 关键业绩（Top 3-5，Situation-Contribution-Impact）
1. [业绩]：背景→动作→可量化结果（如"中秋礼盒备货前置，售罄率从X降至Y"）
### 目标完成对照
| 季度目标 | 状态(达成/超额/未达成) | 证据(数据/链接) |
### 成长与亮点（新技能/扩大职责/协作瞬间）
### 困难与改进（难点→下次怎么做）
### 下期目标（2-3 条，SMART）
### 对上级/部门的建议
```

### 2. 主管评表
```
## 绩效评估：[员工]｜[周期]｜[主管]
### 总评等级：超额/达标/待改进（附一句话定级理由）
### 关键优势（2-3 条，带具体事例："X 工作把退款率从 A 压到 B"而非"表现不错"）
### 待改进项（2 条，给可执行指引："每周更新经营看板 X 模块"而非"沟通要加强"）
### 目标达成（逐条打分+具体观察）
### 发展计划（技能×现状→目标→动作）
### 薪酬建议（晋升/调薪/不变+依据）——衔接超额利润分红试点
```

### 3. 校准表（部门集体校准）
```
## 校准：[周期]｜部门：电商事业中心
### 团队概览（员工×岗位×评级×关键备注）
### 评级分布（建议：超额 15-20% / 达标 60-70% / 待改进 10-15%，对齐公司节奏）
### 校准讨论点（临界评级/新人首考/岗位变化者逐条列）
### 晋升候选（当前→建议→证据）｜调薪动作（依据）
### 主管备注（团队变动/项目影响/口径变更）
```

### 4. 考核结果汇总表（Excel：员工×各 KPI 得分×权重×总评×评级）
- 列建议：员工/岗位/考核周期/GMV达成/毛利达成/退款率/履约达标/内容KPI/行为KPI/加权总分/评级/备注
- 用 sheet 技能创建，合并单元格只写 anchor，公式用 SUM 加权可回算

## 考核指标拆解流程（OGSM → 考核表）

1. **源**：年度 OGSM（附件2）E 衡量列 → 部门考核指标（公司 12/31 节点）
2. **拆**：部门指标 → 岗位指标（运营/产品/内容/客服/履约按职责分配），一人一表不重复
3. **定基线**：每条指标标注 2026 实际基线 + 2027 目标 + 达成率口径（实际/目标，工具复算）
4. **落表**：按上面 4 类模板输出；金额类标注"预估，待财务核定"
5. **复盘**：月度经营看板对表、季度校准、年度总评；预测-验证闭环（对照下月实际修正下季指标）

## 与既有体系的衔接

- **OGSM**：考核 KPI 直接取自附件2 E 衡量列（G4 落地顺序=统一成本口径→收窄折扣→达播换品调价→履约红线）
- **附件3 资源需求**：考核涉及编制/岗位变化时对接「1-架构及人员」sheet
- **制度**：考核办法是部门制度之一，发布流程对接 taoge-ecom-policy-management（起草→评审→发布→培训→执行→修订）
- **2027 制度动作**：KPI 补毛利/退款/交付红线→提成切毛利（直播"去退"经验推广）→超额分红新立条款→BD/内容岗 Q1 到岗率 100%

## 绩效沟通原则

1. 具体化："把退款率从 28.59% 压到 20%" 优于 "售后做得好"
2. 行为不贴标签："文档不完整" 而非 "你粗心"
3. 发展可执行："下次月度复盘主持一次" 而非 "提升汇报能力"
4. 校准前置：评级差异在部门会先对齐，不把分歧留到员工面谈
