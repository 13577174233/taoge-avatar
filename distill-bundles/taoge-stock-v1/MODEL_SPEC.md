## 1. 结论先行

### 1.1 核心数字表（V1.0，24 个月滚动样本外）

| 指标 | 数值 |
|---|---|
| 样本外交易笔数 | 196 笔（与 v3 逐笔完全一致） |
| 胜率 | **37.76%**（95% 置信区间 31.3% ~ 44.7%） |
| 盈亏比 | 3.58 |
| Profit Factor | 2.17 |
| 单笔期望 | **+3.874%**（t=3.16，bootstrap 95% [1.584%, 6.53%]） |
| 24 个月累计收益 | **+75.88%** |
| 最大回撤 | **−9.52%** |
| 单位风险收益（收益/回撤） | **7.97** |
| 逐窗超额 | +2.16 / +7.28 / +29.40 / −0.33pp，t=1.42（不显著） |

### 1.2 三句话结论

1. **V1.0 是风控增强版，不是收益增强版**：相对 v3 只加了「组合级回撤熔断」，196 笔交易逐笔完全相同；收益从 +75.53% 微升到 +75.88%，最大回撤从 −12.20% 降到 **−9.52%**，单位风险收益 6.19→7.97。
2. **评测指出的两个缺口已补，并修正了一个判断**：v3 在**期望维度显著跑赢随机**（z=3.29，第 98.8 百分位），但胜率只在第 1.2 百分位；此前「无 alpha」只对「同档位被动等权」基准成立，不能说选股毫无信息。W3 的 +30.67pp 超额确实靠少数大牛（Top10 贡献 66.3% 毛利）。
3. **四项结构改进里三项被数据否掉**：波动率目标仓位、illiq 辅助排序、延长持有到 30 日全部不纳入；只有回撤熔断通过。且熔断若参与重新选参会引发参数漂移，反而更差——V1.0 因此明确沿用 v3 逐窗参数。

### 1.3 最关键的两条警示

- **超额仍不显著且集中于 W3**：剔除 W3 后三窗超额均值只有约 +2.68pp；真正的超额可能只有一个 6 个月窗口那么宽。
- **研究污染**：熔断阈值 0.08/0.04 与「沿用 v3 参数」的选择都看过消融结果。真正干净的验证必须等 2026-12 之后的新数据，对 V1.0 只跑一次、不回改。

## 3. V1.0 完整策略规格

### 3.1 六层结构（L0–L4 沿用 v3，L5 为本次新增）

```
L0 环境层（仓位档位）  沪深300>MA60 且 宽度>40% → 半仓；再叠加 宽度>50% 且 指数20日动量>0 → 满仓；否则空仓
L1 趋势层              收盘 > MA_fast 且 MA_fast > MA_slow(60)
L2 触发层              收盘创 brk 日新高（不含当日）且 量比 > 1.5
L3 确认层              DIF>DEA 且 DIF>0；RSI14∈[50,80]；当日涨幅∈[0.5%,7.5%]；RS20<0.35（拥挤度过滤）
L4 风控层              3×ATR 止损 / 跌破 MA20 / 满 20 交易日出场
L5 组合级回撤熔断（新） 权益回撤>8% → 新仓预算×0.5；回到 −4% 内解除
排序分                 0.55×z(RS60/ATR%) + 0.25×z(RS20/ATR%) + 0.20×z(量比)
```

`宽度 = 池内收盘价 > MA20 的股票占比`，逐日横截面计算，不含未来数据。

### 3.2 L5 组合级回撤熔断（V1.0 唯一增量）

```
peak_eq = max(peak_eq, 每日收盘权益)
dd_now  = 当日权益 / peak_eq − 1

若 dd_now < −0.08                 → risk_off = True（触发）
若 risk_off 且 dd_now > −0.04     → risk_off = False（滞回解除，避免频繁切换）

买入预算 = min(权益 × 档位 × (0.5 if risk_off else 1.0) / 10, 现金 × 0.995)
```

- **只削减新开仓预算**，已有持仓按 L4 正常退出，不强制平仓；
- T 日收盘判定，影响 T+1 开盘新仓（无未来函数）；
- 与 L0 **相乘**而非替代：L0 管「市场能不能做」，L5 管「组合亏多了先收手」；
- 阈值 8%/4% 是研究设定，**未做阈值网格优化**，不应视为已验证最优值。

熔断实际触发情况：W1 有 **62.8%** 交易日处于 risk_off（正好是最大回撤来源），W3 为 5.8%，W2/W4 为 0%。

### 3.4 逐日执行伪代码

```
for 每个交易日 t（按时间正序）:
    # 1) 执行昨日挂单（T+1 开盘）
    for s in 昨日卖出挂单: 以 open[t] 卖出，扣 0.125%，记录一笔（含 hold_days 交易日数）
    for s in 昨日买入挂单（按 score 降序）:
        若 持仓数>=10 或 停牌 或 已持有: 跳过
        若 open[t]/前收−1 > 6%: 跳过
        lvl = 档位[t] × (0.5 if risk_off else 1.0)
        budget = min(权益 × lvl / 10, 现金 × 0.995)
        若 可买股数 < 100: 跳过

    # 2) 收盘后评估持仓出场
    if close < 入场价 − 2.0×ATR14:  「ATR止损」
    elif close < MA20:              「跌破MA20」
    elif 持有交易日数 >= 20:        「时间止盈」

    # 3) 收盘后生成入场候选
    if 档位[t] > 0 且 持仓数 < 10:
        for s in 股票池: if L1且L2且L3: 加入候选
        按 score 降序取前 10 → 明日买单

    # 4) 盯市 + 更新熔断状态
    权益 = 现金 + Σ 持仓市值
    peak_eq = max(peak_eq, 权益)
    dd = 权益/peak_eq − 1
    if dd < −0.08: risk_off = True
    elif risk_off 且 dd > −0.04: risk_off = False
```

## 5. 评测反馈带来的两项新发现

### 5.1 v3 随机基准（500 次）：选股层跑赢随机，但胜率极低

保持入场日、出场日、笔数不变，只把股票随机替换为同池当日有行情的另一只，重复 500 次：

| 指标 | 实际（V1.0 = v3） | 随机均值 ± SD | 所处百分位 |
|---|---|---|---|
| 单笔期望 | +3.874% | +1.005% ± 0.871% | **第 98.8 百分位**（z=3.29） |
| 胜率 | 37.76% | 45.64% | **第 1.2 百分位** |

**结论**：突破信号确实含有选股信息（期望显著跑赢随机）；此前「无 alpha」只对「同档位被动等权」成立（t=1.35）。两个基准不能混为一谈。

### 5.2 W3 超额归因：靠少数大牛

- Top1 一笔 +107.27%，占总毛利 18.8%；Top10 占 **66.3%**；
- ≥20% 的大牛 14 笔，贡献 **81.4%** 毛利；
- 剔除 Top10 后，W3 期望从 +9.10% 掉到 **+1.734%**；
- 出场结构：时间止盈 19 笔平均 +25.71%（几乎全部利润），跌破 MA20 26 笔平均 −0.17%，ATR 止损 4 笔平均 −9.58%。

**结论**：W3 超额高度依赖少数大牛，不是稳定的横截面选股能力。

### 参数路径依赖陷阱（重要）

把熔断做成正式模型并**重新选参**后，W2 的 `brk` 从 60 漂移到 120，测试收益从 +36.40% 掉到 +20.99%，24 个月只剩 +56.01%。原因是熔断改变了训练期收益排序。

**方法论结论**：风控规则必须做双轨验证——固定参数消融（隔离结构效应）+ 重新选参滚动（检验路径依赖）。只做前者会高估改进，只做后者会把参数漂移误判成结构无效。V1.0 因此明确沿用 v3 逐窗参数。

## 7. V1.0 的边界（必须与结论一起读）

1. **没有新的选股 alpha**：196 笔交易与 v3 逐笔完全相同，价值只在风险控制。
2. **收益提升几乎可忽略**（+0.35pp），真正改善的是回撤（2.68pp）。
3. **超额仍不显著**：逐窗超额 t=1.42（4 窗），依旧集中在 W3。
4. **研究污染**：熔断阈值与「沿用 v3 参数」都看过消融结果；真验证要等 2026-12 后新数据。
5. **未解决问题**：幸存者偏差、行业暴露未中性化、W3 尾部依赖、涨跌停/连板/分红再投资/冲击成本未建模。
6. **不可实盘**：历史模拟研究，不构成投资建议。

A：**只强在风险控制**。加了组合级回撤熔断后，最大回撤从 −12.20% 降到 −9.52%，单位风险收益 6.19→7.97；196 笔交易逐笔完全相同，收益仅从 +75.53% 微升到 +75.88%。

**Q：胜率多少？**
A：24 个月滚动样本外 **37.76%**（196 笔，CI 31.3–44.7%）。v5 重选参版 38.97% 是**被否决**的版本，不是 V1.0；6 个月单窗（v2 旧模型）是 21.95%。口径不能混用。

**Q：V1.0 能实盘吗？**
A：不能。第 7 节列了 6 条边界，最要命的是逐窗超额不显著（t=1.42）且集中在 W3，以及阈值设定存在研究污染。

**Q：V1.0 选股能力比 v3 提升了吗？**
A：没有，也不应该这样表述。V1.0 的 196 笔交易与 v3 完全一致，它只是"同样的交易在弱市少押仓位"。

**Q：为什么V1.0 不重新选参？**
A：因为熔断会改变训练期收益排序。重新选参后 W2 的 `brk` 从 60 漂到 120，收益少了 15pp，24 个月只剩 +56.01%。详见第 6 节「参数路径依赖陷阱」。

**Q：评测指出的其它改进为什么没采纳？**
A：波动率目标仓位、illiq 辅助排序、延长持有到 30 日三项都做了 4 窗消融，数据均不支持：前两项少赚约 18pp，第三项虽多赚但尾部依赖加剧、剔除 Top10 后期望转负。

**Q：最重要的风险是什么？**
A：W3 一个窗口贡献 +29.40pp 超额，Top10 个股贡献 66.3% 毛利，剔除后期望只剩 +1.734%；且真样本外验证尚未做。

**Q：下一步？**
A：① 等 2026-12 后数据做真样本外（只跑一次）；② 补行业分类，做行业中性化与 W3 行业归因；③ 熔断阈值敏感性（0.05/0.08/0.12）只在训练期选；④ 换池检验。

## 9. 术语表

| 术语 | 含义 |
|---|---|
| 组合级回撤熔断 | 组合权益从峰值回撤超阈值后，削减新开仓仓位；不强制平仓，已有持仓按个股风控退出 |
| 滞回 | 触发阈值与解除阈值分开（8% / 4%），避免状态在阈值附近频繁切换 |
| 参数路径依赖 | 新增规则改变了训练期收益排序，导致重新选参时参数漂移，净效果与固定参数消融不同 |
| 前复权 | 按分红送股调整后的历史价格序列，用于连续计算收益率 |
| T+1 开盘成交 | T 日收盘产生信号，下一交易日开盘价成交，避免未来函数 |
| Rank IC | 横截面上因子排名与未来 N 日收益排名的相关系数 |
| 盈亏比 | 平均盈利 / 平均亏损；不含胜率信息 |
| 单笔期望 | 所有交易收益率的算术平均；为正才可能长期赚钱 |
| bootstrap 95% 区间 | 对交易收益重采样的期望置信区间；不含 0 才算统计显著 |
| 同档位被动等权 | 用完全相同的大盘开关与仓位档位，但不选股、直接等权持有全池，用于剥离择时贡献 |
| 尾部依赖 | 正收益高度依赖少数大牛股；用 Top10 毛利占比与「剔除 Top10 后期望」衡量 |
| 幸存者偏差 | 只用「今天仍存在」的股票构建历史池，天然剔除退市与长期衰落标的 |
