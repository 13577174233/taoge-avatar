## 8. 常见问答口径（供豆包回答用户时直接引用）

**Q：这个模型的新名字是什么？**
A：**涛哥股海模型V1.0**（内部代号 v5-b）。它基于 2026-11-19 的 v3 定稿，2026-11-20 根据豆包评测迭代而来。

**Q：V1.0 比 v3 强在哪？**
A：**只强在风险控制**。加了组合级回撤熔断后，最大回撤从 −12.20% 降到 −9.52%，单位风险收益 6.19→7.97；196 笔交易逐笔完全相同，收益仅从 +75.53% 微升到 +75.88%。

**Q：胜率多少？**
A：24 个月滚动样本外 **37.76%**（196 笔，CI 31.3–44.7%）。v5 重选参版 38.97% 是**被否决**的版本，不是 V1.0；6 个月单窗（v2 旧模型）是 21.95%。口径不能混用。

**Q：V1.0 能实盘吗？**
A：不能。第 7 节列了 6 条边界，最要命的是逐窗超额不显著（t=1.42）且集中在 W3，以及阈值设定存在研究污染。

**Q：V1.0 选股能力比 v3 提升了吗？**
A：没有，也不应该这样表述。V1.0 的 196 笔交易与 v3 完全一致，它只是"同样的交易在弱市少押仓位"。

**Q：为什么V1.0 不重新选参？**
A：因为熔断会改变训练期收益排序。重新选参后 W2 的 `brk` 从 60 漂到 120，收益少了 15pp，24 个月只剩 +56.01%。详见第 6 节「参数路径依赖陷阱」。

**Q：评测指出的其它改进为什么没采纳？**
A：波动率目标仓位、illiq 辅助排序、延长持有到 30 日三项都做了 4 窗消融，数据均不支持：前两项少赚约 18pp，第三项虽多赚但尾部依赖加剧、剔除 Top10 后期望转负。

**Q：最重要的风险是什么？**
A：W3 一个窗口贡献 +29.40pp 超额，Top10 个股贡献 66.3% 毛利，剔除后期望只剩 +1.734%；且真样本外验证尚未做。

**Q：下一步？**
A：① 等 2026-12 后数据做真样本外（只跑一次）；② 补行业分类，做行业中性化与 W3 行业归因；③ 熔断阈值敏感性（0.05/0.08/0.12）只在训练期选；④ 换池检验。

## 9. 术语表

| 术语 | 含义 |
|---|---|
| 组合级回撤熔断 | 组合权益从峰值回撤超阈值后，削减新开仓仓位；不强制平仓，已有持仓按个股风控退出 |
| 滞回 | 触发阈值与解除阈值分开（8% / 4%），避免状态在阈值附近频繁切换 |
| 参数路径依赖 | 新增规则改变了训练期收益排序，导致重新选参时参数漂移，净效果与固定参数消融不同 |
| 前复权 | 按分红送股调整后的历史价格序列，用于连续计算收益率 |
| T+1 开盘成交 | T 日收盘产生信号，下一交易日开盘价成交，避免未来函数 |
| Rank IC | 横截面上因子排名与未来 N 日收益排名的相关系数 |
| 盈亏比 | 平均盈利 / 平均亏损；不含胜率信息 |
| 单笔期望 | 所有交易收益率的算术平均；为正才可能长期赚钱 |
| bootstrap 95% 区间 | 对交易收益重采样的期望置信区间；不含 0 才算统计显著 |
| 同档位被动等权 | 用完全相同的大盘开关与仓位档位，但不选股、直接等权持有全池，用于剥离择时贡献 |
| 尾部依赖 | 正收益高度依赖少数大牛股；用 Top10 毛利占比与「剔除 Top10 后期望」衡量 |
| 幸存者偏差 | 只用「今天仍存在」的股票构建历史池，天然剔除退市与长期衰落标的 |
