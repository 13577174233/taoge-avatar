## 3. V1.0 完整策略规格

### 3.1 六层结构（L0–L4 沿用 v3，L5 为本次新增）

```
L0 环境层（仓位档位）  沪深300>MA60 且 宽度>40% → 半仓；再叠加 宽度>50% 且 指数20日动量>0 → 满仓；否则空仓
L1 趋势层              收盘 > MA_fast 且 MA_fast > MA_slow(60)
L2 触发层              收盘创 brk 日新高（不含当日）且 量比 > 1.5
L3 确认层              DIF>DEA 且 DIF>0；RSI14∈[50,80]；当日涨幅∈[0.5%,7.5%]；RS20<0.35（拥挤度过滤）
L4 风控层              3×ATR 止损 / 跌破 MA20 / 满 20 交易日出场
L5 组合级回撤熔断（新） 权益回撤>8% → 新仓预算×0.5；回到 −4% 内解除
排序分                 0.55×z(RS60/ATR%) + 0.25×z(RS20/ATR%) + 0.20×z(量比)
```

`宽度 = 池内收盘价 > MA20 的股票占比`，逐日横截面计算，不含未来数据。

### 3.2 L5 组合级回撤熔断（V1.0 唯一增量）

```
peak_eq = max(peak_eq, 每日收盘权益)
dd_now  = 当日权益 / peak_eq − 1

若 dd_now < −0.08                 → risk_off = True（触发）
若 risk_off 且 dd_now > −0.04     → risk_off = False（滞回解除，避免频繁切换）

买入预算 = min(权益 × 档位 × (0.5 if risk_off else 1.0) / 10, 现金 × 0.995)
```

- **只削减新开仓预算**，已有持仓按 L4 正常退出，不强制平仓；
- T 日收盘判定，影响 T+1 开盘新仓（无未来函数）；
- 与 L0 **相乘**而非替代：L0 管「市场能不能做」，L5 管「组合亏多了先收手」；
- 阈值 8%/4% 是研究设定，**未做阈值网格优化**，不应视为已验证最优值。

熔断实际触发情况：W1 有 **62.8%** 交易日处于 risk_off（正好是最大回撤来源），W3 为 5.8%，W2/W4 为 0%。

### 3.4 逐日执行伪代码

```
for 每个交易日 t（按时间正序）:
    # 1) 执行昨日挂单（T+1 开盘）
    for s in 昨日卖出挂单: 以 open[t] 卖出，扣 0.125%，记录一笔（含 hold_days 交易日数）
    for s in 昨日买入挂单（按 score 降序）:
        若 持仓数>=10 或 停牌 或 已持有: 跳过
        若 open[t]/前收−1 > 6%: 跳过
        lvl = 档位[t] × (0.5 if risk_off else 1.0)
        budget = min(权益 × lvl / 10, 现金 × 0.995)
        若 可买股数 < 100: 跳过

    # 2) 收盘后评估持仓出场
    if close < 入场价 − 2.0×ATR14:  「ATR止损」
    elif close < MA20:              「跌破MA20」
    elif 持有交易日数 >= 20:        「时间止盈」

    # 3) 收盘后生成入场候选
    if 档位[t] > 0 且 持仓数 < 10:
        for s in 股票池: if L1且L2且L3: 加入候选
        按 score 降序取前 10 → 明日买单

    # 4) 盯市 + 更新熔断状态
    权益 = 现金 + Σ 持仓市值
    peak_eq = max(peak_eq, 权益)
    dd = 权益/peak_eq − 1
    if dd < −0.08: risk_off = True
    elif risk_off 且 dd > −0.04: risk_off = False
```
