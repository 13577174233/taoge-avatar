# 新品市场分析（电商事业中心专用）

面向昆明冠生园食品有限公司·电商事业中心。核心价值：把「新品情报 + 内部数据 + 行业证据」转化为可拍板的新品进入/放弃/暂缓建议，为产品规划师立项提供依据。

## 判断模型接入（来自 taoge-jiahua-ecom-playbook）

立项结论不是"能不能卖"，而是"放在哪个角色位、让利后还剩多少、有没有复购"。

| 模型 | 落点 | 不合格表现 |
|---|---|---|
| M3 产品角色 | 五维评分前先答"它是引流/利润/形象/节庆专款" | 只看销量预测，不定义角色 |
| M7 让利治理 | 定价模块给"让利后毛利"，含达人佣金与折扣 | 用标价算毛利 |
| M5 用户资产 | 加复购与延展评分项，标首购后 90 天复购信号 | 只评估首销爆发 |
| M2 目标可信度 | 爆品目标（如 300 万）附产能/流量承接与折算 | 目标直接写进规划，不问承接 |

模型全文见 `../taoge-jiahua-ecom-playbook/references/ecom-thinking-models.md`。

## 分析前置（证据纪律）

- **输入**：新品情报卡（taoge-ecom-product-intelligence 输出）、内部销售与供应链数据（用户提供）、行业与竞品公开证据；
- **证据分级**：一级=官方数据/后台实拍/权威机构报告；二级=主流媒体报道/可复核二手；三级=仅线索。一二级可展示，三级仅作线索提示；
- **数字句末标源**：每个数字附来源；无来源标「待补充」，不凭记忆填数；
- **区分事实与判断**：先过事实门，再做战略推导；结论必含取舍（优先项/放弃项/重审条件）。

## 分析框架（六模块）

1. **市场需求与规模**：品类大盘（如云腿月饼、低糖烘焙）、增速、线上占比、季节窗口；判断「需求是否真实、是否够大、是否当下」；
2. **竞争格局与竞品对标**：直接竞品 TOP（价格/规格/卖点/销量信号）、空白机会（价格带缺口、规格缺口、口味缺口）；对标表格列示；
3. **消费者需求与痛点**：目标人群、购买场景（自食/送礼）、搜索热词、差评集中点（太甜/太油/包装破损/份量）；来源=舆情/评价/客服记录；
4. **定价与利润空间**：建议价格带 vs 竞品、成本与毛利测算（含佣金/运费/包材）、定价依据；成本数据缺时标「待补充」并给出毛利敏感区间；
5. **货源与供应链可行性**：原料可得性、产能与起订量、包材合规（≤3层/≤3公斤包装新规）、上新周期；
6. **五维评分与决策**：市场需求 × 竞争度 × 利润空间 × 季节性 × 复购率（每维 1-5 分，依据逐条列示），输出进入/放弃/暂缓建议 + 重审条件。

## 输出物

- **新品市场分析报告**（编号 `GSY-DS-YYYY-XP-NNN`，密级视是否含成本/佣金定「仅限管理层」）；
- 结构：三句话看懂 → 六模块分析 → 五维评分表 → 决策建议（进入/放弃/暂缓 + 理由 + 重审条件）；
- **产品定义方向**（供产品规划师）：结构/口味/价格带/包装/设计五维初步定义；
- **验证信号与证伪条件**：每条建议附「上线后什么信号证明对、什么信号证伪」。

## 执行 SOP（六步）

1. **立项**：确认新品对象与决策问题（值不值得做/怎么定位/对标谁）；
2. **证据收集**：情报库调取 + 行业/竞品检索（general_search 并行、doubao-industry-analysis 行业盘、doubao-announcement-analysis 竞品上市公司）；
3. **对标分析**：竞品价格/规格/卖点/销量对标表，找空白机会；
4. **内部核验**：与数据分析师核对内部销售/成本/供应链数据（口径同源）；
5. **评分决策**：五维评分 + 进入/放弃/暂缓建议；
6. **成稿质询**：报告成稿 → 战略报告顾问质询 → 归档 `12-产品项目管理/03-新品市场分析/` → 交产品规划师立项。

## 与团队其他技能衔接

- 输入 ← 新品情报（taoge-ecom-product-intelligence）；输出 → 产品规划师（doubao-product-manager）立项/Roadmap；
- 定价与货盘 → 销售策略官（doubao-product-selection、sales-decision-analysis）落地；
- 事件/政策影响（包装新规、健康化监管）→ doubao-market-hotspot 传导分析补充。

## 认知革命接线（2026-10-30）

新品立项的合规边界与健康化证据接线：

接线来源与能力定位：
- taoge-law-thinking：刘晗法律思维模型（33模型），食品标签/广告宣称/包装新规/经销商合同的合规定性
- taoge-law-civil-code：民法典模型（6模型），合同编（供货/经销/格式条款）条文依据
- taoge-health-family：家庭健康总览模型（105模型），新品目标人群的健康需求画像
- taoge-medicine-nutrition：临床营养模型（21模型），低糖/减油/控卡新品的营养证据

业务调用入口：
- 新品合规边界核查（食品标签宣称、广告法、包装≤3层≤3公斤新规）→ taoge-law-thinking 定性 + taoge-law-civil-code 条文
- 供货/经销合同与供应链条款风险 → taoge-law-civil-code 核对违约责任与格式条款
- 低糖健康新品五维评分 → taoge-health-family（目标人群健康需求是否真实）+ taoge-medicine-nutrition（营养证据支撑度）给"市场需求/复购率"两维加专业权重
