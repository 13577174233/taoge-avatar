# 冠生园电商工作台（内部档案 · 模板 · 路由）

## 这是什么

一套"拿得出证据、落得下动作"的工作台，给昆明冠生园电商事业中心的日常经营任务用：

1. **档案地图**：30,901 份历史文件放在哪、哪份能回答哪类问题（`references/归档地图.md`）；
2. **交付骨架**：年度总结、年中复盘、请示公文、招标文件、岗位说明书、制度手册、门店 SOP、品牌提案承接、考察报告——每类的章节与必备要素（`references/交付模板骨架.md`）；
3. **口径与列名**：体系×渠道对账、单品销售、包裹成本、目标分解、OEM 成本、单店测算的表格列结构（`references/口径与对账模板.md`）；
4. **节令链路**：中秋/年货/鲜花饼节/端午六步作战与每步产物（`references/节令作战链路.md`）；
5. **组织与制度**：岗位/编制/绩效/360/制度版本/合同类型（`references/组织与制度.md`）；
6. **检索速查**：常见问题 → 目录与文件名（`references/检索速查.md`）。

## 不是什么

- 不是"把历史数字照抄成冠生园口径"：嘉华 1.75 亿、德和报价、旧绩效档位都**有时效**，只作举证与对标，先换当期口径再算。
- 不是新技能重复造：具体业务方法在既有技能里已有沉淀，本技能只做**取证据 + 给骨架 + 指路**。
- 不是档案重排：原件一律不动，只维护索引。

## 触发场景

- "以前那份中秋规划/年货策略/利润表/门店测算在哪？"
- "有没有现成的年度总结骨架/请示模板/招标书/岗位说明书？"
- "当年这个节令是怎么排的、复盘看哪些指标？"
- "把这件事按冠生园的打法拆一下"——需要口径、骨架、责任人、时点。
- 需要跨技能调度：写规划、写总结、做情报、做判断，但缺内部证据。

## 五条硬纪律

1. **先查索引再开口**。任何"历史怎么做的"结论，必须能落到 `归档总索引.csv` 的一行与一个可打开的原件；查不到就说查不到，不凭印象编。
2. **口径先对齐再算**。体系/渠道/包裹/单店四套口径互不通用；同一指标出现两个数，先并列口径定义、时间范围、分母，再决定能不能比。
3. **模板只给骨架，内容用当期数据**。骨架复用（章节、列名、审批链），数字必须来自冠生园当期报表。
4. **时令与制度有时效**。平台规则、快递报价、绩效档位、广告法表述，引用前标注年份并核当期有效版本。
5. **加法不覆盖**。用户手改定稿为权威基准；历史档案只读，不回写、不改名、不移动。

## 使用方法（三步）

### 第一步：定位（1 分钟）

```bash
cd "/Users/tanghaitao/DoubaoWork/项目库/08_职业经验复盘与能力蒸馏/06_归档总索引"
python3 - <<'EOF'
import csv
rows = list(csv.DictReader(open("归档总索引.csv", encoding="utf-8-sig")))
kw = "中秋"                     # 换成任务关键词：定价/招标/岗位/门店/利润/提案/考察…
grp = ""                        # 可填 P08_合作项目 / P09_内部经营 / P10_中秋文档 …
for r in rows:
    if kw in r["相对路径"] and (not grp or r["群组"] == grp):
        print(r["群组"], "|", r["相对路径"], "|", r["大小MB"], "MB")
EOF
```

先看 `references/归档地图.md` 的主题索引确定该去哪一组，再用上面命令把候选文件缩到 3–10 个，最后才打开原件。

### 第三步：交付前自检（五项）

- 每个历史数字都能追到原件路径（写进脚注或备注，不必在正文展开）。
- 口径表已注明：口径名 / 时间范围 / 分母 / 用途 / 不可混用项。
- 骨架里的"审批/责任人/时点"三列没有留空。
- 引用旧规则、旧报价、旧档位时，标注年份并附当期核验结论。
- 多版本产物按"一成果一终稿 + 历史版本折叠"交付，不并列堆版本。

## 边界

- 档案里 2015–2022 多为嘉华、德和、代运营客户语境，迁移到冠生园必须换指标集与口径，不直接沿用基数。
- 图片、压缩包、旧版 `.doc`、mp4 为登记口径，未逐份/逐帧解析；需要时按目录抽读，抽读结论要标注"抽样"。
- 涉及合同、平台规则、广告法表述，本技能只给结构与核查点，最终以法务/当期官方规则为准。
- 不做平台后台操作、不代做投放执行、不生成对外承诺性结论。
