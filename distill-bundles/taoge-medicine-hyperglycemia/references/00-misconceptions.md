# 常见误区对照表

> 越相信左边，右边那条知识就越点不亮。逐条自查。

## 第 000 讲

| 常见错误信念 | 纠正 |
|---|---|
| 血糖还没高，这事跟我没关系。 | 血糖每天在波动，波动本身就在加速衰老；原文称反复升高者的衰老速度是同龄人的数倍。 |
| 每年体检测血糖，就能把高血糖的风险关在门外。 | 常规体检漏掉糖尿病前期这个过渡期，查出来没事不代表可以放心。 |
| 血糖高了吃药控制就行，生活上想怎样就怎样。 | 最好的药也达不到高血压那样的控制能力，管理生活方式才是主力。 |

## 第 001 讲

| 常见错误信念 | 纠正 |
|---|---|
| 血糖高了才有危害，血糖值正常就没事。 | 伤害从波动就开始；高血糖的"高"指的是波动幅度远超普通人，不是 24 小时都高。 |
| 血糖值还在正常范围，波动大一点无所谓。 | 正常人一天波动 2-3mmol/L，波动到 5mmol/L 在医生眼里就已经比较大了。 |
| 痘痘是上火、是皮肤问题，忌口、换护肤品就行。 | 血糖波动大是痤疮最重要的因素之一，这类痘痘忌口和祛痘药都容易失效，该查血糖。 |
| 考试前吃点甜的补脑，孩子一上午更有精神。 | 血糖波动小的孩子一上午的记忆力、注意力、反应速度反而更好；甜食正好制造一次大波动。 |

## 第 002 讲

| 常见错误信念 | 纠正 |
|---|---|
| 抗糖就是不吃甜的、买点抗糖产品。 | 减少 AGEs 只有三个入口——少吃含 AGEs 的食物、限总热量七分饱、压住血糖波动；分解 AGEs 的药只做到动物实验，副作用大，不能用于人。 |
| 血糖高一会儿没关系，反正会降下来。 | 血糖越高，AGEs 生成越快，且产物不可逆累积；冲高的次数与幅度都会记账。 |
| 吃进去的糖化垃圾可以靠"排毒"、多喝水、保健品排掉。 | 吃进去的 AGEs 只有约 1/3 经肾脏排出，2/3 留在体内，身体把它当衰老的自然产物，不会启动免疫清除。 |
| 手脚发麻、视力模糊是年纪大了，跟血糖没关系。 | 髓鞘蛋白、晶状体蛋白正是糖化最爱堆积的地方，这些症状是高血糖损害的同一条通路。 |

## 第 003 讲

| 常见错误信念 | 纠正 |
|---|---|
| 单位体检年年正常，血糖就肯定没问题。 | 常规体检只测空腹血糖，而 2/3 的高血糖人群空腹正常、餐后升高；报告还常常不提示前期。 |
| 空腹血糖没到 7.0，就不是糖尿病前期。 | 空腹达到 5.6mmol/L 就已进入空腹血糖受损区间；餐后 2 小时达到 7.8mmol/L 同样算前期。 |
| 血糖正常期没什么可做的，等高了再说。 | 正常期才是干预黄金期，肥胖占发病因素半壁江山，减 10% 体重就有预防效果。 |
| 到了糖尿病期，关键是找到更好的药。 | 各指南跨越种族与经济得出的同一个答案是"自我管理最重要"，药是处方的一部分，不是全部。 |

## 第 004 讲

| 常见错误信念 | 纠正 |
|---|---|
| 糖尿病前期没症状，不用管，等真得了再说。 | 前期是几乎唯一可逆转的窗口期，跨过去之后摘帽的可能性就微乎其微，并发症会一个个找上来。 |
| 逆转高血糖靠吃药，找个好药就行。 | 大庆、DPP、DPS 三大研究证明核心是生活方式，DPP 里生活方式的效果甚至比服用二甲双胍还好。 |
| 逆转就是拼命减重，减得越多越快越好。 | 目标区间是 1 年内减重 5%-10% 不反弹，"不反弹"是条件之一；减完反弹等于没做。 |
| 低碳水降糖，那就长期不吃主食。 | 40%-50% 是逆转期的短期结构，糖尿病稳定期不必这么低，极端低碳水长期难以坚持且有害。 |

## 第 005 讲

| 常见错误信念 | 纠正 |
|---|---|
| 降血糖就别吃主食，碳水越少越好。 | 低碳水只在 3-6 个月内有效，长期影响不大且带来肾脏功能损伤、高血脂；糖尿病稳定期低碳水没必要。 |
| 买点降糖保健品、维生素，就能代替管住嘴。 | 维生素与矿物质补充剂未见预防作用与并发症改善，中草药剂量不统一、指南未纳入；只有服二甲双胍者可能需补 B12。 |
| 低 GI 的食物可以随便吃，多吃不升糖。 | GI 只反映升糖速度不反映数量，总量仍受每日热量约束；山药粉这类"冲糊"主食 GI 反而到 120 多。 |
| 我不胖，热量不用管。 | 血糖正常、体重稳定者确实不必抠公式，但一旦已是糖尿病前期或糖尿病，总热量就是处方的一部分，需要每天相对严格遵守。 |

## 第 006 讲

| 常见错误信念 | 纠正 |
|---|---|
| 运动降糖，练得越猛越好。 | 强度超过 90% 多可能引起血糖反跳，有效区间是 40%-89%，且要先热身 10 分钟。 |
| 办了健身卡，周末一次练够一周的量就行。 | 要少量多次，每周 3-7 天、每次 30-50 分钟，最差也不能超过间隔 1 天——肌肉对糖的利用只持续一到两天。 |
| 打了胰岛素去运动，不用特意加餐或测血糖。 | 用胰岛素或促泌剂的人运动后易低血糖，须在医生指导下运动前后测血糖、运动前补碳水或调整药量。 |
| 力量训练不降糖，练了没用。 | 有氧与力量同时进行可带来更大程度的血糖下降；力量训练按 1RM 的 50%-80%、8-10 个动作、隔天做。 |

## 第 007 讲

| 常见错误信念 | 纠正 |
|---|---|
| 高血糖就是吃出来的，管住嘴就行，跟心情没什么关系。 | 糖的渴望来自奖赏回路，血糖升高还有应激这条内源路径；不处理心理，能坚持营养、运动处方的可能性降到 10% 以内。 |
| 心理问题靠自己扛，扛过去血糖自然会好，看医生是小题大做。 | 轻度靠自我管理，中重度（医生判定焦虑、抑郁或进食障碍）必须由医生开启药物或心理治疗，自我管理只能叠加不能替代。 |
| 既然要减压，抽根烟、喝点酒放松一下没关系。 | 烟是唯一完全不可取的出口，会加速糖尿病和并发症；酒有明确上限（男每周 7-14 杯、女减半），且每克酒精 7 大卡要计入总能量。 |
| 控制血糖就要狠一点，饿着才降得快。 | 不要饿到 3 分以下，7-8 分饱就停；硬憋的忌口会累积压力，最后以暴食形式反弹。 |

## 第 008 讲

| 常见错误信念 | 纠正 |
|---|---|
| 血糖高就加药把数字压下去，压到正常就算治好了。 | 终点是减少心梗、肾病与死亡；血糖已达标但心肾高风险者仍要加心肾保护药物。 |
| 新药一代比一代强，老药二甲双胍过时了，该换新的。 | 一线首选从没改过，仍是二甲双胍——有效、安全、经受时间考验，且长期试验显示能降低心脑血管并发症。 |
| 某某肽、某某列净都是「新型降糖药」，可以互相替代，还能顺便减肥。 | 两者机制分属不同路（模拟肠促胰素 vs 增加尿糖排出），适应证与获益不同，均须医生处方，不能互换、不能自行购买当减肥药。 |
| 打胰岛素会上瘾、会依赖，能拖就拖，实在不行再打。 | 胰岛素是三步策略的最后一步，是否启用由三种及以上药物仍未达标决定；该用而未用会让血糖持续失控，而是否停用、减量必须由医生判断。 |

## 第 009 讲

| 常见错误信念 | 纠正 |
|---|---|
| 并发症和高血压一样，把指标治好，并发症自然就好了。 | 高血糖波及全身器官，且与损伤之间的因果并不明确，血糖降下来并发症会不会好转也不清楚——所以只能靠早期发现与早期干预。 |
| 心梗了送到医院，放个支架通开就行，现在医疗这么发达。 | 糖尿病对血管的损伤是一整段，等心梗时往往整条血管像线一样细，没有地方放支架。 |
| 神经病变会疼会麻，我自己能感觉到，不疼就是没病。 | 50% 的神经病变没有任何感觉，所以要在确诊糖尿病当年就做针扎、温度、震动觉检查，此后每年一次。 |
| 并发症一旦开始就没救了，反正也治不好，不如不管。 | 大血管早期可用新药与更严格的血压血脂控制，小血管早期把糖化控到 6.5% 左右可大大延迟甚至停在当下；放弃的是晚期，不是全程。 |

## 第 010 讲

| 常见错误信念 | 纠正 |
|---|---|
| 妊娠期高血糖生完孩子就恢复了，是小事，不用当回事。 | 一过性不等于无害——妈妈未来风险 7 倍左右，孩子 8 倍、肥胖 2 倍，风险还会往下一代传。 |
| 怀孕了营养要跟上，血糖标准可以放宽一些。 | 标准正好相反，2010 年 IDF 与中国指南都把界值调得更严：空腹 ≥5.1、1 小时 >10.0、2 小时 ≥8.5，任一超标即异常。 |
| 一人吃两人补，孕期就该多吃，体重涨得多说明孩子长得好。 | 孕期体重必须控制在比较严格的范围内；巨大儿比例是普通妈妈的 10 倍，出生体重每增加 1kg 未来糖尿病风险增加 25%。 |
| 查出妊娠期高血糖就赶紧吃降糖药，跟普通人一样治。 | 孕期除胰岛素外可用药物极其有限，只能最大程度靠生活方式，用药必须由产科与内分泌医生决定。 |

## 第 011 讲

| 常见错误信念 | 纠正 |
|---|---|
| 有了 AI 和连续血糖监测，以后吃饭让手机告诉我怎么吃就行。 | 设备仍有创、代谢组学尚未把食物与代谢物一一对应，个体精准营养还在实验室到产品的路上。 |
| 指南处方是给所有人用的，对我肯定也最合适。 | 现有处方来自人群平均数据，基因组与分子代谢的差异会让同一份方案在不同人身上效果不同。 |
| 数字医疗是未来的事，跟我现在没关系，等成熟了再说。 | 群体层面大部分技术点已突破、离落地更近；而个体层面当下就能做的是把生活方式操练起来并定期筛查。 |
| 我已经是糖尿病前期了，等国家的 AI 管理系统来管我。 | 现有医生力量覆盖不到 0.1% 的糖尿病前期人群，个人必须先自己查、自己改，不能等系统上门。 |

## 第 012 讲

| 常见错误信念 | 纠正 |
|---|---|
| 我只有高尿酸（或只有一高），其他三项跟我没关系。 | 四高通过 RASS 与胰岛素抵抗两条通路互相串，高尿酸时间一长，高血压、高血脂和高血糖也都不远了。 |
| 血脂高就吃降脂药，把血脂降下来，斑块就不会长了。 | 尿酸有氧化性能，会大大增加血脂氧化概率；单纯高血脂形成斑块要五到十年，合并高尿酸或高血糖就用不了三五年。 |
| 四高的炎症就是发炎了，吃点消炎药、抗生素压下去。 | 这里的炎症是免疫系统攻击自己身体的慢性内耗，与细菌感染无关，抗生素无效；要处理的是能量过剩与持续应激。 |
| 既然四高是进化没跟上，那就只能回到原始人的活法。 | 原文明确否定了这条路，指向的是在身体与环境之间找适应平衡点——具体怎么做是第 13 讲的内容。 |

## 第 013 讲

| 常见错误信念 | 纠正 |
|---|---|
| 既然四高相通，把四门课的方案全做一遍最保险。 | 四门课方案会互相冲突（低碳水高蛋白 vs 不宜高蛋白、静力拉伸 vs 力量训练受限、喝茶降脂 vs 喝茶升尿酸），要做的是取交集。 |
| 没病的时候不用管，等查出指标异常再治。 | 健康期正是把平衡点撑大的窗口，一动一静练出来的应激耐受，决定你遇到大病或高压时扛不扛得住。 |
| 多吃菜少吃肉最健康，碳水越少越好。 | 三大能量物质缺一不可，碳水要占 55%-75%、脂肪 20%-30%、蛋白 1g-1.5g/kg 体重，关键是比例稳定而不是砍掉某一类。 |
| 是药三分毒，指标好一点就自己把药减了。 | 多高并存时互为因果、互相增强，10 年后才发生的心梗可能 3 年就到；目标也更严（尿酸 360μmol/L 降至 300μmol/L 以下），减药必须由医生决定。 |
