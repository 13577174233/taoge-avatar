# 产品月度销售分析（电商事业中心专用）

面向昆明冠生园食品有限公司·电商事业中心。核心价值：把「各平台月度销售数据」转化为可拍板的产品月度销售分析报告与下月产品销售策略建议。

## 判断模型接入（来自 taoge-jiahua-ecom-playbook）

月度分析不是数据搬运，三个判断必须落地：

| 模型 | 落点 | 不合格表现 |
|---|---|---|
| M4 渠道贡献毛利 | "渠道"维给贡献毛利（扣点/投流/佣金/退货/履约/分摊后） | 只排 GMV 占比 |
| M9 复盘四件套 | 未达成项写成现象+量化影响+责任+动作 | 归因写"市场竞争激烈" |
| M10 口径治理 | 月度口径与年度目标版本对齐，调过目标要注明 | 用调整后目标算达成率却不声明 |

模型全文见 `../taoge-jiahua-ecom-playbook/references/ecom-thinking-models.md`。

## 数据范围与口径（与报告体系同源）

- **平台范围**：兴趣电商（抖音/快手/视频号/小红书）+ 搜索电商（淘宝/京东/拼多多）；多店需分店列示（如抖音两店、天猫昆冠/云之冠）。
- **数据源**：内部=聚水潭/金蝶/平台后台/客服记录；外部=平台官方报告/行业机构/上市公司公告。无来源数字标「待补充」，不凭记忆填数。
- **口径定义**（每份报告固定声明，置于报告开头）：统计周期（精确起止日）、GMV 口径、达成率分母（目标值）、退款率定义（申请/确认口径）、同比基准（可比周期），避免跨口径误读。
- 与节庆总结/年度规划引用数字逐项一致；不一致时以聚水潭/金蝶最终口径为准并同步修订。

## 七维复盘框架（月度必做）

1. **总盘**：GMV/达成率（vs 目标）/同比环比/客单价变化，结论先行三句话看懂；
2. **分平台**：各平台 GMV/占比/环比，平台迁移信号（如搜索电商下滑、兴趣电商放量）；
3. **分品类/分SKU**：品类结构占比、爆款 TOP（放量信号）、滞销款（砍品候选）、新品表现（上市后 90 天内跟踪）；
4. **异动归因**：任一指标环比变动 >±15% 必须归因（活动/价格/流量/竞品/供应链/季节性），区分「已查证」与「推测」；
5. **退款与履约**：退款率（红线 ≤15%）、48h 发货率（≥95%）、破损率（≤1.5%）、客诉集中点；
6. **库存与供给**：爆款断货风险、滞销库存积压、备货滚动建议；
7. **策略建议（可拍板）**：放量/砍品/调价/补货/上新，每条带「落地后可预见结果 + 验证信号」。

## 报告规范（继承报告体系 V2.0）

- **编号**：`GSY-DS-YYYY-CP-NNN`（CP=产品月报，YYYY=报告年度，NNN 当年序号）；
- **密级**：含内部销售数据一律标注「仅限管理层」；页眉左=公司全称·部门，页眉右=报告编号，页脚=页码+密级；
- **署名链**（报告末页）：编制=数据分析师，审核=战略报告顾问（结论质询），批准=项目统筹负责人，落款=电商事业中心产品项目团队+日期；
- **七项质量门禁**：数据可溯源 / 判断有依据 / 结论可拍板 / 产品五要素（结构/口味/价格带/包装/设计，涉产品建议时）齐全 / 三句话可读 / 去AI味 / 格式合规（中文引号、无 emoji、audit 0 错误）。

## 执行 SOP（月度循环，五步）

1. **取数**：拉取各平台后台/聚水潭/金蝶数据，覆盖统计周期；先声明口径（周期/平台/定义）；
2. **清洗与交叉校验**：sheet/excel-structured-analysis 清洗（去重/口径统一），quantitative-audit-recalculation 复算合计/占比/达成率，出差异表；
3. **七维复盘**：按上方框架逐维分析，异动归因逐条取证；
4. **成稿**：结论先行（三句话看懂 + 核心决策），过 doubao-human-signal 去 AI 味，转 PDF 用 artifact-preview 渲染自检；
5. **质询归档**：战略报告顾问红队质询 → 归档 `12-产品项目管理/01-月度销售分析/` → 交付并更新索引。

月度报告骨架模板见 [references/monthly-report-template.md](references/monthly-report-template.md)。

## 输出物

- 完整版月度销售分析报告（Word，含数据附表 Excel 可选）；
- 精简版（≤5 页）供管理层速读：P1 封面+三句话看懂+核心决策，P2 总盘+分平台，P3 分品类/SKU，P4 异动归因+退款履约，P5 策略建议+署名链；
- 下月产品销售策略建议清单（并入报告第七章，可单独拆出）。

## 与团队其他技能衔接

- 新品表现数据 → 回写新品市场分析（taoge-ecom-product-market-analysis）验证新品判断；
- 策略建议 → 销售策略官（doubao-ecommerce-proposal、taoge-ecom-annual-planning）落地为活动/价格方案；
- 滞销/爆款清单 → 产品规划师（doubao-product-manager）做 SKU 精简与产品线调整。
