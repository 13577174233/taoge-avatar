# 新品情报收集（电商事业中心专用）

面向昆明冠生园食品有限公司·电商事业中心。核心价值：把「分散的市场新品信号」转化为结构化、可检索、可追溯的新品情报库，供新品市场分析与产品规划使用。

## 判断模型接入（来自 taoge-jiahua-ecom-playbook）

情报卡多两栏，情报才可直接进入决策：

- **产品角色（M3）**：每条新品标"引流/利润/形象/节庆专款"，标不出的归为"角色未知"，不进入立项池。
- **复购信号（M5）**：记录是否有复购设计（规格、口味、订阅、组合），不只看上新热度。
- **证据口径（M10）**：价格标含税/到手价/标价，销量标平台口径与抓取日期。

模型全文见 `../taoge-jiahua-ecom-playbook/references/ecom-thinking-models.md`。

## 渠道清单（按优先级）

| 渠道 | 监测对象 | 手段 |
|---|---|---|
| 电商平台上新 | 抖音/淘宝/京东/拼多多/小红书/视频号 同品类新品、竞品店铺上新 | 平台搜索（关键词如「云腿酥」「鲜花饼」「月饼」新品）、店铺上新页、销量排序 |
| 兴趣内容 | 达人与直播间带货新品、爆款种草笔记 | doubao-video-extract、video_search、小红书/抖音内容搜索、doubao-sentiment-tracker |
| 线下渠道 | 商超/烘焙店/伴手礼店新品陈列与价格 | 用户实地信息/图片/清单（用户提供） |
| 行业与机构 | 焙烤食品协会、艾媒、勤策等新品趋势报告、行业媒体 | general_search、web_fetch 精读 |
| 上市公司 | 广州酒家/五芳斋/桃李/元祖等公告中的新品动作 | doubao-announcement-analysis、enterprise_agentic_search |
| 内部线索 | 客服客诉中的需求信号、供应链可承接的新原料/新工艺 | 客服记录、内部讨论 |

> 平台明确点名时（如用户说「看看抖音上个月有什么新出的云腿月饼」）优先用对应平台渠道收集；未点名时按上表全渠道扫描。

## 新品情报卡（每条一条，统一字段）

```
品名 | 品类 | 品牌/店铺 | 规格 | 价格带 | 渠道 | 上市时间 | 卖点摘要 | 销量信号（预估/截图）| 图片/链接 | 信息来源 | 收集日期
```

- 销量信号必须标注「已查证」（后台/页面实拍）或「估算」（依据销量区间/点赞互动）；
- 图片素材用 image_search 获取或取自平台页面，存情报库 assets，链接来源如实记录。

## 执行流程（六步，继承信息收集项目 SOP）

1. **收集**：按渠道清单并行扫描（general_search 拆多关键词并行，单次 ≤3 查询；平台内容用对应平台工具）；
2. **筛选**：与本公司品类相关（烘焙/糕点/礼盒/伴手礼）优先，剔除无关品；保留 3-5 条高信号新品；
3. **交叉验证**：同一新品 ≥2 个独立来源才标记「可信」，单来源标「待验证」；价格/规格以官方店铺页面为准；
4. **入库**：按情报卡字段写入情报库（见下），图片素材入 assets；
5. **简报**：输出新品动态简报（本周/本月 TOP 新品 + 对冠生园的含义一句话）；
6. **索引更新**：更新情报库索引文件，标注重复项与去重。

## 情报库结构（建议落位 `12-产品项目管理/02-新品情报库/`）

```
02-新品情报库/
├── 00-索引.md            ← 按月份+品类登记，可检索
├── YYYY-MM/
│   ├── 新品情报卡-周报.xlsx（或 csv）
│   ├── 新品动态简报.md
│   └── assets/（新品图片素材）
```

## 输出物与频率

- **周度**：新品动态速览（TOP 5 + 一句话含义），供团队例会；
- **月度**：新品情报月报（全量入册新品 + 趋势信号：价格带迁移/品类热点/竞品上新节奏）；
- **触发式**：用户点名某新品/某竞品动态时，专项收集 + 深度卡（含市场分析接口）。

## 与团队其他技能衔接

- 情报库高信号新品 → 新品市场分析（taoge-ecom-product-market-analysis）立项评估；
- 竞品上新节奏 → 销售策略官（doubao-market-hotspot）做事件传导与应对；
- 用户点名某新品做深度分析 → 新品市场分析师（doubao-product-analysis）专项分析。
