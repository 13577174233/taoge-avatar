# AI 短剧企划方法论

> **一句话定位**：从"立项写总纲"到"日产2篇短故事"的完整AI短剧创作流水线方法论。
> **方法论来源**：滇王秘录10集AI短剧企划实战（2026-10-26）+ 入殓师系列番茄短故事日产流水线（2026-09-29）。
> **蒸馏来源**：03_项目方法论蒸馏报告_20261102.md 第五节 S1-S4。

---

## 使用方式

1. **新短剧立项** → 走 S1 九段企划总纲模板，逐段填写，产出完整企划文档。
2. **连载/长篇创作中** → 维护 S2 伏笔账本，每集动笔前查表确认该埋/该收。
3. **AI 生成视频/图片前** → 查 S3 角色一致性锚点表，逐角色对照检查服装/道具/状态。
4. **番茄短故事量产** → 启动 S4 日产流水线，按6角色分工+每日时间线跑。
5. **判断该不该用这个技能** → 先看「应用场景映射」和「边界」节，确认你的需求在射程内。

## S1. AI 短剧企划总纲 9 段模板（立项必走）

> 来源于滇王秘录10集实战。立项时必须按以下9段输出完整企划，缺一不可。
> 核心强调：**人物AI一致性锚点表、伏笔账本、每集生成约束**三条是AI短剧区别于传统编剧的关键。

| 段 | 内容 | 填写要点 |
|---|---|---|
| ① 系列定位表 | 系列名、类型、集数、单集结构、核心卖点、视觉基调、语言风格 | 表格化一行一项；视觉基调写明双主色（如暗青+鎏金）；单集结构标注场数 |
| ② 故事核心 | 一句话故事 + 立场红线 + 主题句 | 一句话≤80字；立场红线必须明确（谁是正义方/谁是反派）；主题句要有情感落点 |
| ③ 人物表（含AI一致性锚点） | 主角团/反派/关键配角，每人标注身份+外貌+服装+道具锚点 | 表格化；**锚点必须具体到可复现**（发型/耳环/眼镜/服装款式），不能写"气质冷峻"这种AI生成不了的词 |
| ④ 视觉与场景设定 | 每个主场景的AI生成要点 + 核心道具清单 | 场景含色彩脚本（如"滇池墓=夯土黄+青铜青"）；道具标注是否跨集复现（PROP） |
| ⑤ 分集总纲表 | 每集标题+一句话推进+集末钩子 | 表格化；集集有反转；钩子必须是悬念/反转/新信息，不能平淡收尾；标题2-4字 |
| ⑥ 人物弧 | 每个主要角色从起点到终点的转变轨迹 | 每人一句话弧光，标注关键转折集；反派也要有弧光（或明确不变） |
| ⑦ 伏笔账本 | 所有伏笔的埋设集/回收集/内容说明 | 详见 S2 节；必须有埋设集和回收集，跨季伏笔单独标注 |
| ⑧ 最终结局 | 最后一集的收束场景+主题句落点 | 必须有画面感；留第二季钩子（如有续季计划） |
| ⑨ AI生成适配说明 | 角色一致性、场景可控性、道具复现、每集生成约束 | **这三条是AI短剧的生命线**：固定色彩脚本、固定造型、单集场数约束、台词密度约束 |

### ⑨ AI生成适配说明的三条硬约束（必须写进企划）

1. **角色一致性约束**：每集对照角色锚点表检查，服装/道具/伤痕状态不能跳。
2. **场景色彩脚本约束**：每个主场景固定色系，场景图生成时保持该色系。
3. **每集生成约束**：单集场数（5-7场）、构图比例（竖屏9:16优先中近景）、台词密度（单场≤8句）、机关场景避免纯黑。

## S2. 伏笔账本（连载必维护）

> 来源于滇王秘录第七节。长篇连载短剧/小说必须维护一张伏笔追踪表，写每一集前先查表确认该集该埋/该收。

### 表格模板

| 伏笔内容 | 埋设集 | 回收集 | 说明 | 跨季标记 |
|---|---|---|---|---|
| 铜钥匙（蛇纹） | E1 | E8/E10 | 守陵人信物链起点：E8演化为耳环内藏机关针（引信），E10移交怒山青铜钥匙 | 第二季 |
| 三面蛇纹铜镜 | E2/E4/E7 | E7/E9 | 集齐开王陵内殿；镜面反光激活机关 | 否 |
| 爷爷手记"守陵人" | E1/E3 | E6 | 林家血脉真相，七十三代守陵传承 | 否 |
| 半张藏宝图 | E1 | E6 | 与老宅暗格拼成完整滇王图 | 否 |
| "三更灯火五更鸡"口诀 | E4 | E9 | 哑婆燃铜灯敲铜铃，湖面内外呼应，王陵封存 | 否 |
| 蛇纹铜耳环 | E1 | E8/E10 | 守陵人传人信物；E8弹出机关针启动自毁引信；E10月光下指向怒山 | 否 |
| 第七个标记 | E1/E6 | E10 | 滇王图之外的第七个坐标——怒山，第二季猎场 | 第二季 |
| 周文礼的"温和" | E3 | E6/E9 | 内鬼双面；E9反水自曝真正目标是第七个标记 | 否 |

### 跨季钩子标注规则

- 第一季不回收的伏笔，在「跨季标记」列标注"第二季"（或具体季数）。
- 跨季钩子必须是**有独立悬念价值的坐标/信物/秘密**，不是随便留一个尾巴。
- 第二季立项时，先回看伏笔账本，确认哪些钩子要兑现、哪些要升级。

### 维护纪律（三条硬规则）

1. **每埋必登记**：写任何一集时，如果埋了新伏笔，当场登记进账本，不许事后补。
2. **回收时勾掉**：伏笔回收那集，在账本里标注实际回收集，验证"埋了就有收"。
3. **避免挖坑忘填**：每5集做一次伏笔审计——账本里所有"埋设集≤当前集但回收集>当前集"的条目，确认它还在剧情线上有存在感。

## S3. 角色一致性锚点表

> 来源于滇王秘录第三/九节。AI生成多集视频/图片时，角色一致性是最大痛点——解决方案=在企划阶段锁定锚点，每集生成时对照检查。

### 锚点结构

每个角色的锚点分三层：
- **关键特征固定描述**（外貌+服装+道具）：跨集不变，是AI生成的"身份锁"。
- **状态变化追踪**（伤痕/湿身/尘土/情绪）：分集单独锁定，标注从哪集开始变化。
- **高复现道具（PROP）固定造型**：跨集反复出现的道具，造型固定不变（如铜钥匙的锈蚀程度、羊皮图的作旧程度）。

### 真实示例1：林晚（主角）

| 维度 | 锚点内容 |
|---|---|
| 身份 | 26岁，省考古院文物修复师；滇王守陵人后裔 |
| 外貌锚点 | 齐肩短发、左耳一枚蛇纹铜耳环（爷爷遗物）；眼神沉静 |
| 服装锚点 | 修复室白大褂（都市线）/ 野外冲锋衣（下墓线） |
| 道具锚点 | 铜耳环（守陵人信物）、爷爷手记 |
| 状态变化 | E7潜水后湿身；E8被捕拘束（手腕红痕）；E9下墓后尘土覆盖 |
| 性格锚点 | 沉静、关键时刻极稳 |

### 真实示例2：老瘸（配角）

| 维度 | 锚点内容 |
|---|---|
| 身份 | 50岁，旧江湖"摸金"出身，后金盆洗手转做守陵人 |
| 外貌锚点 | 花白寸头、右腿微瘸（旧伤） |
| 服装锚点 | 常年皮夹克+工装裤 |
| 道具锚点 | 腰间一串旧铜铃 |
| 状态变化 | E4摆渡人之死后情绪沉重（不体现在外形，但体现在走位/表情描述） |
| 性格锚点 | 话糙理不糙，江湖规矩多 |

### 可复用模板

```
| 维度 | 锚点内容 |
|---|---|
| 身份 | 年龄/职业/身份背景 |
| 外貌锚点 | 发型+标志性面部特征（必须是AI可复现的视觉元素） |
| 服装锚点 | 日常装/场景装（分线标注） |
| 道具锚点 | 随身标志性道具 |
| 状态变化 | 从第X集开始的状态变化（伤痕/湿身/换装等） |
| 性格锚点 | 一句话性格描述（用于台词风格参考） |
```

### 硬规则

- 每集场景统一服装/道具状态，不能跨集遗忘。
- 伤痕/湿身/尘土等状态变化**分集单独锁定**，写进分集总纲的备注。
- 反派锚点保持稳定，不随剧情变化外形（反派的"识别度"是观众的安全锚）。
- 跨集高复现 PROP（铜钥匙/铜镜/藏宝图）单独追踪，造型固定不变。

## S4. 番茄短故事量产工厂（日产2篇流水线）

> 来源于入殓师系列实战（2026-09-29启动）。从选题到发布的完整流水线，主攻番茄免费小说短故事赛道。

### 4.1 项目规格

| 项 | 规格 |
|---|---|
| 主阵地 | 番茄免费小说 · 短故事赛道 |
| 日产量 | 2 篇 / 天 |
| 单篇字数 | 10000–20000 中文字符（完结短篇） |
| 交付格式 | `.docx`（Word），封面 `.png` |
| 归档 | `YYYY-MM-DD/` 日期目录 |

### 4.2 6角色分工表

| 角色 | 职责 | 输入 | 输出 |
|---|---|---|---|
| **选题策划**（热点侦察员） | 每日跑一轮多平台热点侦察，输出选题方向 | 各平台热榜、网文榜单 | 当日热点侦察.md + 6-8个选题 |
| **主笔**（创作Agent ×2，并行） | 按选题写完整短故事正文 | 选题 + 创作模板 | .md正文 + .创作说明.md |
| **封面美术** | 为主笔产出的故事生成3:4竖版封面 | 故事题材 + 主角设定 | .png封面 |
| **编辑/质检** | 校验字数、节奏、红线、排版 | 主笔交付物 | 质检通过 / 打回修改 |
| **发布运营** | 登录番茄作家后台提交作品 | 质检通过的docx + 封面 | 后台已提交 + 作品链接 |
| **规则研究员**（一次性+季度更新） | 沉淀各平台规则手册 | 公开资料 | 平台规则手册.md |

### 4.3 每日时间线

```
09:00  热点侦察员启动
        └─→ 产出《热点侦察-当日.md》，推荐2个差异化选题
10:00  主编（Organizer）拍板2个选题（一男频一女频/一悬疑一情感，强对比）
10:30  主笔A、主笔B并行开写（各自按故事创作模板）
        ├─ 主笔A：故事1.md
        └─ 主笔B：故事2.md
14:00  主笔完成初稿 → 自检字数（必须10000-20000）
14:30  封面美术并行生成两张封面
15:00  编辑/质检：字数、节奏、红线、Word排版
15:30  按发布SOP提交番茄后台
16:00  归档到 YYYY-MM-DD/ 目录
```

### 4.4 五条创作红线（必须贯彻）

1. **反套路优先**：每篇至少1个读者猜不到的反转，结局不能是"做梦/精神病"偷懒。
2. **题材池男频女频拉开**：男频（悬疑/民俗/都市/赛博/末日/系统/修真）、女频（复仇/甜宠/重生/虐渣/穿书/打脸），每日两篇题材拉开。
3. **语言直白有情绪张力**：直白、带批判性或鄙视感；**不要文艺腔、不要堆砌比喻**。
4. **前100字出钩子前500字出事件**：开篇即冲突，不许慢热。
5. **不堆市场分析进正文**：热点分析单独成文，故事正文就是故事。

### 4.5 与AI短剧长篇企划的分工关系

| 维度 | S4 番茄短故事量产 | S1 AI短剧长篇企划 |
|---|---|---|
| 产出形式 | 纯文字短篇小说（1-2万字） | 竖屏视频短剧（10集×3-5分钟） |
| 生产节奏 | 日产2篇，快节奏量产 | 一个企划跑几周/几个月，慢工出细活 |
| 核心能力 | 选题敏感度、开篇钩子、字数控制 | 世界观搭建、人物弧、伏笔账本、角色一致性 |
| 受众平台 | 番茄免费小说（文字阅读） | 红果/抖音短剧（视频观看） |
| 共享资产 | 创作红线（反套路/语言风格/开篇钩子） | 同上 + 角色锚点表 + 伏笔账本 |

**一句话**：短故事量产练的是"开篇抓人+快速完结"的手感，长篇企划练的是"世界观自洽+跨集一致"的功力；两者共享创作红线，但方法论各自独立。

## 边界

### 本技能是什么
- AI辅助的竖屏短剧企划方法论（盗墓/悬疑/护宝/民俗类）
- 番茄短故事量产流水线SOP
- 角色AI一致性锚定方法论

### 本技能不是什么
- **不是纯文字网文长篇连载方法论**：本技能聚焦"短"——单集3-5分钟/单篇1-2万字，不写百万字长篇网文的连载结构（那是 doubao-novel-writing 的事）。
- **不是传统影视编剧方法论**：传统编剧的三幕结构、人物小传、场记表不在本技能射程内；本技能的核心是"AI生成适配"——角色一致性、场景可控性、道具复现这些传统编剧不需要操心的事。
- **不是AI视频生成技术指南**：本技能解决"写什么、怎么规划"的问题，不解决"怎么用Seedance/即梦生成视频"的技术操作（那是 doubao-creative-video / seedance-25 的事）。
- **不做平台运营/投流/数据分析**：发布SOP只到"提交后台"为止，投流ROI、粉丝运营不在本技能范围。

### 特别提醒
- **角色一致性是AI视频/图片生成最大痛点**：传统编剧不需要在企划阶段就写"齐肩短发+左耳铜耳环"这种锚点描述，但AI短剧必须写——因为AI每生成一帧都可能"换脸"，锚点表就是你的"角色锁"。
- **立场红线不可妥协**：盗墓探险类题材必须明确"主角团是守陵护宝人，反派才是盗掘走私集团"，不出现可操作性的盗掘、销赃细节。
- **民俗悬疑有特别边界**：女向悬疑严禁冥婚/结阴亲/怀鬼胎；民俗元素作为虚构悬疑素材可以，宣扬封建迷信不行。
