# 目标下达与逐月分解

**判断要点**（配合 `ecom-thinking-models.md` M2/M10）：目标先过产能、流量、节奏三关，再拆表；拆完必须能回答"谷月靠什么补、峰月靠什么不爆"。四类表是工具，不是答案。

来源：`2020-1 渠道销售目标 1.0/1.2/2.0/3.0/4.0`、`2020-2 节庆营销目标`、`2020-3 产品目标`、`2020-4 月饼&端午/云腿小饼/鲜花饼/海盐曲奇`、`2021销售目标提报 12.18/12.21/12.28`、`2021产品目标提报 12.23`、`7月经营分析`。

## 一、四类目标表（缺一类就无法考核）

| 表 | 维度 | 用途 |
|---|---|---|
| 渠道目标 | A部 / B部 / C部 / 社交 / 400·新渠道 / 经销商 | 分团队考核 |
| 品类目标 | 鲜花饼 / 月饼·汤圆·粽子 / 云腿小饼 / 饼干·其他 | 供应链与产能 |
| 节庆目标 | 年货 / 鲜花饼节 / 端午 / 中秋 / 平台营销（3.8、618、99、双11、双12） | 战役排期 |
| 单品·系列目标 | 招牌经典、现烤、百花、甄选云南、洗沙、滇式中点、外购、曲奇、粽子、汤圆、年货 | 产品运营考核 |

四张表必须能**交叉对平**：渠道合计 = 品类合计 = 节庆 + 日销合计 = 全年目标。

## 二、逐月分解表（标准字段）

每个产品/品类一张，季度小计单列，渠道横向铺开：

```
季度 | 月份 | 前年销售 | 上年销售 | 本年目标 | 本年实际 | 达成率 | 同比增幅
一季度 | 1月 … 3月
一季度小计
二季度 …
合计
```

渠道级再套一层：每个部门重复"前年/上年/目标/实际/达成/同比"六列，右侧接总销售行。
嘉华 2020 鲜花饼表实测：1 月 883 万、2 月 564 万、3 月 732 万……9 月 2771 万（全年峰值），12 月 1060 万。
注意目标有两版：年度规划口径 1.1406 亿，年度总结口径调整为 1.10 亿（年中调整），实际 1.0948 亿、达成 99.53%、基本持平。**引用时必须说明用的是哪版目标**。

**用法**：先看月度形状（峰在哪、谷在哪），再看部门分配是否与形状匹配。谷月要靠平台营销和日销补，峰月要靠产能和仓配兜。

## 三、节庆与日销的结构口径

2020 规划口径：全年 1.8 亿 = 节庆 + 日销，其中

- 年货 1370 万 / 鲜花饼节 330 万 / 端午 123 万 / 中秋 3350 万 / 平台营销约 1776 万
- **日销 8245 万**（占 45.8%）
- O2O：饼屋外卖 3500 万 + 佳禾 75 万 = 3575 万；佳禾网络蛋糕 100 万

2021 口径：节庆合计 1.05 亿（年货 2800 / 鲜花饼节 2000 / 端午 500 / 中秋 5200）+ 平台营销 3200 万 = **占全年 65%**。

**判断规则**：节庆占比 >60% 即单峰依赖，必须在规划里单列"上半年日销补位方案"，否则 Q1/Q2 必崩（2020 Q1 达成 80.77%）。

## 四、目标提报的收敛流程（多轮收敛，不是一次拍）

2021 年真实节奏：

| 轮次 | 日期 | 内容 |
|---|---|---|
| 一轮 | 12.18 | 各部门首版提报（普遍偏高） |
| 二轮 | 12.21 | 按产能/预算压缩，渠道间再平衡 |
| 三轮 | 12.28 | 定稿（含经销商与新品） |
| 产品目标 | 12.23 | 单品/系列目标单独提报，与销售目标对齐 |

规则：每轮留版本号与差异说明（谁上调、谁下调、依据是什么），不要只留最终版；否则次年复盘无法解释"目标为什么这么定"。

## 五、目标合理性检查点（血泪教训）

2021 年 7 月经营分析原文第一条未达成原因就是"**目标制定不合理，缺跟踪**"：

- 7 月自营 560.7 万，达成 72.50%，同比 −19.70%，单月缺口 252 万；1–7 月累计 5192.3 万，达成 93.94%，缺口 525 万
- 全年自营目标 1.365 亿，7 月底只完成 38.04%，而时间进度已 58.08%
- 全品类全年 2.1 亿，累计 5972.2 万，仅 28.44%

**所以下达目标时必须同时给三件东西**：①月度分解 ②时间进度线（每月应到百分比）③偏差预警阈值（连续两月低于进度 5pct 即触发复盘）。
