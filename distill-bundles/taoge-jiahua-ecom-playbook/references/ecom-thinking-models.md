# 电商经营思维模型（嘉华档案反推）

本文件不是模板库，是**判断工具**。写规划/总结时用它决定"这一页要回答什么问题、用什么证据、得出什么结论"，而不是套嘉华的表格和数字。

每条格式：判断问题 → 模型 → 报告里怎么用 → 嘉华证据（只作举证）→ 误用。

---

## M1 增长结构判断：先看形状，再看总量

**判断问题**：这门生意的收入在时间和品类上是什么形状？是节庆脉冲，还是日常流水？

**模型**：画三条线——月度收入曲线、节庆销售占全年比、第一大品类占比。三条线合起来给出结构结论：
- 单峰（一个节庆 > 30% 全年）→ 上半年产能闲置、Q3 挤兑、复购低，增长靠"再压峰值"而非"补谷"；
- 多峰（四个节庆均匀）→ 产能全年可用，但每峰都要独立备货与内容；
- 日常型（节庆 < 40%）→ 靠复购与货盘宽度，增长慢但现金流稳。

**报告怎么用**：年度规划第一页不写总目标，先写"我们的收入形状是 X，因此明年增长只能从 A/B/C 三处来"。总结第一页先给形状有没有变（峰更尖还是更平），再给达成率。

**嘉华证据**：2020 年中秋 4419.9 万、鲜花饼 1.0948 亿占 62.63%，2021 节庆合计占 65%；嘉华自己写"过度依赖中秋单峰，上半年产能闲置、复购低"。

**误用**：只报"同比 +7.23%"不报形状，等于把结构问题藏进总数里。

---

## M2 目标可信度检验：目标 × 产能 × 节奏 三角

**判断问题**：这个目标是被"许"出来的，还是被"算"出来的？

**模型**：目标必须同时通过三关——
1. 产能关：峰值日发货量、仓储、客服人力能否承接（嘉华 2021 中秋包裹预估偏差 26.6%）；
2. 流量关：渠道能带来多少可转化流量，投流预算与 ROI 是否支撑；
3. 节奏关：逐月分解后，谷月靠什么补，峰月靠什么不爆。
三关缺一关，目标就是愿望。

**报告怎么用**：目标页旁边放"承接能力表"（日峰值单量、客服坐席、仓容、投流预算），并写清"若不达，先动哪一项"。复盘时把偏差归到"目标定错"还是"执行没跟上"，不要一律写"市场原因"。

**嘉华证据**：月饼九年目标 600→5200 万，实际达成率 110.7/71.8/91.2/77.0/108.9/78.0/93.3/105.2/87.7%，九年只有三年达成；2021 年 7 月复盘第一条原因写"目标制定不合理、缺跟踪"。

**误用**：把"去年 +15%"直接当年目标，不问产能与流量是否同步 +15%。

## M3 产品角色分工：不按品类平均用力

**判断问题**：每个 SKU 在货盘里演什么角色？引流、利润、形象、节庆专款，还是清库存？

**模型**：四类角色 + 一条纪律——
- 引流款：低毛利、高转化，负责拉新与搜索权重；
- 利润款：主销价格带，负责毛利；
- 形象款：高客单/礼盒，负责品牌与团购；
- 节庆专款：只在大促出现，负责制造"限定感"。
纪律：每个角色都要有独立目标与考核，不能用一个 GMV 目标考核四种角色。

**报告怎么用**：产品页先给"角色盘"（每角色 SKU 数、销售占比、毛利率），再给单品排行。淘汰 SKU 时按角色判断，不按销量一刀切。

**嘉华证据**：鲜花饼 11 个系列分工（招牌经典/百花/甄选云南/现烤/滇式中点等）；2020 鲜花饼节专款只占 4%、常规品 96%，说明"专款"角色没立住。

**误用**：把节庆专款和日常主销放同一张排行榜比销量，结论必然是"专款失败"。

## M4 渠道经济学：看贡献，不看流水

**判断问题**：每个渠道扣掉全部成本后，还赚不赚钱？下一块钱投哪个渠道边际回报最高？

**模型**：全载成本 = 平台扣点/佣金 + 投流 + 达人分佣 + 退货与赔付 + 履约 + 分摊人力。算出三个数：
1. 单渠道贡献毛利（不是 GMV）；
2. 单渠道获客成本与复购（LTV/CAC）；
3. 边际 ROI——再加 10% 预算，回报是升还是降。
判定：加投 / 维持 / 收缩 / 退出。

**报告怎么用**：渠道页给"渠道损益表"（收入、扣点、投流、履约、退货、分摊、贡献毛利、贡献率），结论写"哪个渠道养哪个渠道"。别只放一张 GMV 占比饼图。

**嘉华证据**：2021 年 7 月渠道损益 6.54% / −3.48% / 20.14%，三个渠道贡献率差 23 个百分点；嘉华把 B 端（盒马/华润-OLE）单列核算，不与 C 端混。

**误用**：用"销售额占比"代替"毛利贡献占比"，把亏损渠道当成增长引擎。

## M5 用户资产：复购 × 延展，而不是一次成交

**判断问题**：今年买的人，明年还会不会买？除了买鲜花饼，还会买什么？

**模型**：用户价值 = 客单 × 复购频次 × 延展品类数。三个杠杆分别对应三种动作：
- 客单 → 组合装、礼盒、加购；
- 复购 → 会员权益、节庆提醒、订阅制；
- 延展 → 从主品类扩到关联品类（烘焙→节庆→伴手礼）。

**报告怎么用**：用户页拆"新客数 / 复购率 / 复购客单 / 会员贡献占比"，并给"一个用户一年买几次、买几个品类"。GMV 放最后一页。

**嘉华证据**：五级会员 + 积分 + 7 个个人号，2020 会员方案预算 7.4 万；嘉华复盘把"复购低"列为单峰依赖的后果之一。

**误用**：只报新增会员数，不报会员贡献与复购率——注册数不等于资产。

## M6 节庆战役节奏：倒排 + 峰值管理

**判断问题**：这场战役从哪天开始准备，哪几天是生死线？

**模型**：T-90 定货盘与价格 → T-60 内容与达人锁定 → T-45 备货与仓容 → T-30 预售/加购蓄水 → T-15 投流放量 → T-7 峰值压测（客服/发货/退款）→ T+3 售后与复盘。每个节点有唯一负责人和验收物。

**报告怎么用**：节庆复盘第一页给"节奏表：计划 vs 实际"，标出哪个节点晚了几天、造成多少损失。规划页给"下一场战役的倒排表"，不写"加强准备"。

**嘉华证据**：中秋复盘写"包裹预估偏差 26.6%、平台罚款 37 万、爆款下架"；2021 年把中秋拆成 T-8/T-4/T-2 三阶段。

**误用**：复盘只写"活动圆满结束"，不写节点偏差——明年还会在同一个节点翻车。

## M7 让利治理：让利是投资，不是打折

**判断问题**：这笔折扣/返利/佣金，买回了什么？额度、对象、回收条件是什么？

**模型**：三定一核——
- 定额度：年度让利总额占销售比设上限（嘉华红线 40%）；
- 定对象：给"能带来增量"的渠道/达人/经销商，不给"本来就买"的人；
- 定条件：返利以实收打款为基数，达成才给，不达不给；
- 核回报：每笔让利对应增量销售或复购，算不出回报就停。

**报告怎么用**：折扣页给"让利结构表"（平台活动/达人佣金/经销商返利/优惠券各占多少），再给"让利 ROI"。结论写"明年砍哪一类、加哪一类"。

**嘉华证据**：经销商三层返利（入仓 30%/一件代发 25%，季度 6 档 + 年度超额 9 档），年度折扣总额 ≤40%；2021 销售折扣政策 v1–v5 连改五版，说明让利失控是常态。

**误用**：把"折扣率上升"写成"加大促销力度"，不写它吃掉了几个点毛利。

## M8 组织与目标匹配：目标加多少，编制加多少

**判断问题**：这套目标，现有的人和岗接得住吗？

**模型**：目标—编制—岗位—激励四件对齐——
- 编制：关键岗有没有人，缺口多久补上；
- 岗位：一人多岗时，哪件事会被牺牲；
- 激励：考核指标是否与目标同向（考 GMV 却要毛利，必然走反）；
- 能力：新业务（内容/直播/私域）有没有对应能力，没有就先建能力再定目标。

**报告怎么用**：目标页同页放"编制与在岗表 + 关键岗缺口 + 补齐时间"，并写"缺口未补前，目标按 X% 折算"。组织页给"班底表"（谁负责什么、备份是谁）。

**嘉华证据**：2020 编制 61 人、四中心；2021 编制 61 vs 在岗 57；10 个关键岗 7 个空缺时，规划里同步写了引进计划。

**误用**：目标 +38.9%，编制不动，还在同一批人身上加三个新渠道。

## M9 复盘四件套：现象 + 量化影响 + 责任 + 动作

**判断问题**：这条"问题"能不能被验收？

**模型**：一句话四段——
现象（发生了什么，带数字）→ 量化影响（损失/少赚多少，算到钱）→ 责任归因（哪个环节、哪个岗）→ 动作（谁、几号前、做到什么标准）。
缺任一段就是感受，不是复盘。

**报告怎么用**：问题页统一用四列表格；每个问题必须有"下月验证信号"。次年规划里，上一年的问题要逐条回应"已解决/未解决/为什么"。

**嘉华证据**：2020 年度总结写"上半年受疫情影响缺线下流量、5 月鲜花饼节后调整运营模式与渠道微创新"，有现象有动作；但部分页面只写"有待提升"，次年重复出现。

**误用**：写"加强管理""提升效率"——无法验收的动词。

---

## M10 口径治理：任何数字先定口径

**判断问题**：这个数是谁的口径？能不能和另一个数直接比？

**模型**：三问——
1. 含税还是不含税、GMV 还是净销额、自营还是含经销商；
2. 成本用实际价、折扣价还是内部结算价；
3. 目标是最初版、调整版还是复盘版。
三问不清，数字不进正文，只进备注。

**报告怎么用**：每张表加"口径行"（含税/口径/期间/来源）；同一页出现两个口径时，必须写"不可直接比较"。

**嘉华证据**：同一份 2020 年度总结总销售三个数（1.7516/1.7547/1.7481 亿）；鲜花饼节 +19.6% 与 +41% 并存；自营达成 104.25% 与目标 1.5050 亿对不上（年中调过目标）。

**误用**：把不同口径的数放同一张趋势图，做出"增长"或"下滑"的假结论。

## 写规划时的五问自检

1. 收入形状是什么？明年增长具体从哪三处来（各占多少）？
2. 目标过得了产能、流量、节奏三关吗？过不了，先改哪一项？
3. 每个产品角色、每个渠道的贡献毛利算清楚了吗？
4. 让利总额、对象、回收条件定了吗？
5. 编制与激励跟目标同向吗？缺口什么时候补？

## 写总结时的四问自检

1. 形状变了吗（峰更尖还是更平），为什么？
2. 哪些问题能写成"现象+影响+责任+动作"，哪些还只是感受？
3. 每个结论背后的口径统一吗？
4. 次年要改的三件事，是否都能被下月/下季验证？
