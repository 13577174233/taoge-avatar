**用法**：先过 `ecom-thinking-models.md` M6（倒排与峰值管理）、M9（问题四件套）。九步是检查清单，不是目录；每步落一句结论，结论不合格就回炉。

来源：`2020端午复盘总结.pptx`（66 页）、`2021嘉华中秋总结-电子商务公司-V1.0.pdf`（33 页）、`2020端午香粽总结`。

## 一、复盘九步（固定顺序，不许跳）

1. **市场大盘**：品类搜索人气、同比、人群规模。例：2020 年 5–6 月粽子搜索 486.8 万人次、+33.2%；鲜花饼搜索 2018→2020 由 41 万降到 35.9 万，缓慢下滑。
2. **销售节奏**：周期长度、高峰天数、峰值日、与平台大促重叠。端午实测：整体提前 16 天、共 66 天、高峰 20 天；判断依据=线上活动节奏 + 比价习惯 + 物流效率。
3. **销售分布**：区域与客单分层。端午：云贵川渝占比 >50%，客单 81 / 96 / 62 元三档，区域品牌溢价明显。
4. **增长原因**：逐条列且可核销。端午六条：618 重叠、包装升级、周期前置、直播主推、礼盒直折、多口味组合。
5. **问题**：写成"缺什么 + 影响多少"。端午原文三条：前期缺系统性规划与专项预算、推广力度与常规品无差异、过度依赖打折伤品牌与利润。
6. **市场趋势**：淘系零食类目 5/6 月浏览 4 亿人次；粽子 6 月峰值搜索人气 348,631 ≈ 380 万人、1874 万次。
7. **品牌渗透**：头部（五芳斋）/ 第二梯队（多元）/ 跨界入局三层结构。
8. **竞品 Top10 拆解**（第三节）。
9. **新品成败 + 视觉设计复盘**（第四、五节）。

**读法**：先看自己排名变化，再看追赶者增速——被 +80% 的对手超过，比被头部拉开更危险。

## 四、新品成败判断口径

- 五芳斋艺术粽 / 低热量 / 潮玩：评价差，形式创新未换来口感
- 真真老老高汤锁鲜（15 天短保）+ 自热粽：累计约 350 万，有场景支撑的创新才成立
- 喜茶 / 李子柒 / 日食记：包装 > 口味，复购不成立
- 原文结论（可引用）：**"创新可以，但一定要保证口感；要么就做传统口味，不创新不乱搞。"**

规则：新品立项写清"口感不变的部分是什么、创新在包装还是配方、验证指标是首购还是复购"。

## 五、视觉与人群复盘

- 客群：女性 78%、18–34 岁、江浙粤省会为主、客单 25–60 元
- 风格：现代中式 + 传统纹样 + 手绘/C4D；配色红 / 墨绿 + 玫瑰金
- 风向：花西子文渊团队带起"古典品质"风潮，节庆视觉从"喜庆"转向"质感"
- 设计周期：端午 4.10–6.25（约 2.5 个月），上线前必须锁定

**客诉 273 笔分类**：供货异常 66、标签异常 49、异物（头发）37、内置错漏 36、脱氧剂破损 31、发霉 19、塑料 19；云腿小饼 53 笔占 19.4%。

**失败原因三条（原话）**：主播数量与直播模式不匹配（无法高频直播）；9.12 起大批量催发货/催回复评论，冲刺期断播；MCN 因产能问题放弃合作。

## 七、复盘结论写法

- 一节一句判断、句句带数：`大盘涨 33.2%，我们涨 158%——但专款占比不到 5%，涨的是常规品`。
- 每个问题后挂"下次节庆检查点 + 责任人"。
- 末尾一页"下一节庆倒排表"：T-90 立项 / T-60 视觉 / T-45 备货 / T-30 内容 / T-15 直播 / T-7 仓配 / T+3 售后。
