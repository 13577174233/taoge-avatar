# 月度/季度/半年经营分析

**用法**：先过 `ecom-thinking-models.md` M4（渠道贡献毛利，不看流水）、M9（问题四件套）、M10（口径治理）。七段是骨架，每段的第一句必须是结论，不是"本节分析销售情况"。

来源：`2020一季度经营分析及二季度规划.pptx`（2020.4.20）、`电商公司7月经营分析汇报.pptx`（2021）、`1-7月经营分析`、`3-4月双月报`、`上半年总结及下半年规划`、各部门 1–12 月月度分析。

## 一、经营分析七段（月度标准版）

1. **销售分析及未达成分析**（目录页直接写这两句，读者一秒知道要看什么）
2. **渠道达成表**：目标 / 实际 / 达成率 / 累计差额 / 同期 / 增减 / 增减比例；自营五部与经销商分两张表，最后合计
3. **1–N 月累计 + 年度进度**：年度目标 / 累计实际 / 累计达成率 / 时间进度（对照）
4. **产品销售汇总**：品类 × 同期 × 目标 × 达成 × 同比
5. **系列级拆解**：目标分解 / 累计销售 / 全年达成率 / 时间进度 / 月同比 / 同比增长率
6. **销售达成归因**：先给缺口绝对值（当月缺口、累计缺口），再给原因
7. **渠道损益 + 大项费用 + 未达成原因 + 瓶颈复述**

季度版在上面加一段"本季度重点工作的完成情况"，半年版加"下半年规划"。

## 二、利润四因子归因法（本技能最硬的一件工具）

做法：把预算与实际逐项对比，每个因子算出它对净利率的贡献（百分点），四项相加应等于净利率的总差额。

2020 一季度实测：

| 因子 | 预算 | 实际 | 对净利率影响 |
|---|---|---|---|
| 折扣率 | 19.6% | 23.5% | −3.9 pct |
| 成本率 | 46.7% | 49.2% | −2.5 pct |
| 物流费率 | 12.2% | 15.9% | −3.7 pct |
| 工资费销比 | 3.6% | 4.8% | −1.2 pct |
| **合计** | | | **−11.3 pct** |

排除这四项后的"结构性净利率"= 16.58%；实际净利 117.19 万、净利率 5.28%，主营成本占比 37.62%。

**结论写法**：亏损不是"卖得少"，是"折扣放大 + 物流涨价 + 人工效率下降"三件事各吃掉 2–4 个点。这样写，下一步动作才具体（收折扣、谈物流、控编制），而不是泛泛"加强管理"。

## 三、渠道损益口径

2021 年 7 月实测：

- 累计盈利 6.54%
- B 部（京东）−3.48%（负毛利，代运营/价格战导致）
- 经销商体系 20.14%（最高，因结算价与费用分摊方式不同）

规则：**渠道损益必须与销售额分开看**。卖得最多的部门不一定最赚钱；出现负毛利渠道，必须在同一页给"调价 / 换品 / 压佣金"三选一的动作。

## 四、费用分析：只分两栏

- **超预算**：写金额 + 原因（例：邮寄包材内部物流 16.65 万；广告 8.79 万，其中年货节推广 23 万 vs 预算 4.6 万；促销 9.57 万，为补提 2019 经销商返利；工资 6.4 万；福利 1.01 万）
- **节约**：交际 / 办公 / 差旅培训 / 销售服务 / 财务 / 客服

大项费用单列同比（例：人工费用同比节约 30.71 万，人数 50 vs 56）。不要把节约项写成成绩，节约过头往往意味着投入不足。

## 五、未达成归因五类（照这五类找，别自由发挥）

1. **目标类**：目标制定不合理、缺跟踪机制（2021 年 7 月第一条原因）
2. **资源类**：配合新项目（云肴南山）导致主业务不聚焦、缺线上品牌投放
3. **管理类**：部门管理缺失、遗留账务未清理（经销商账务、百草味尾款）
4. **市场类**：竞品签头部主播切割流量（潘祥记、happymiss）、618 后消费减弱、旅游季线下曝光缺失
5. **节奏类**：上半年无创新品、节庆上线晚、直播模型未建立

每条原因后面必须跟"责任部门 + 动作 + 完成时间"，否则不写。

## 六、月度报告必须回答的三问

1. 这个月**差多少**（绝对值 + 达成率 + 累计缺口）
2. 差在**哪个渠道、哪个品、哪一天**（拆到可操作粒度；嘉华拆到"9.12 起断播""鲜花饼下架"这种程度）
3. 下个月**补不补得回来**（补不回就改年度目标，并说明对全年利润的影响）

## 七、双月报/半年报的差异

- 双月报：省掉单月波动解释，只留趋势与偏差；增加"两月内已完成的动作清单"
- 半年报：必须给"下半年追赶方案"（月度倒排 + 资源需求 + 风险预案），并对全年目标做一次可行性重估
