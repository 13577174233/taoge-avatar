# 经销商与分销折扣体系

**判断要点**（配合 `ecom-thinking-models.md` M7）：让利是投资。额度、对象、条件三定，回报必须能算；返利以实收打款为基数，不达不给。经销商是补充盘还是主增量盘，先定性质再定政策。

来源：`2021年嘉华电商经销商折扣方案.doc`（v1）、`折扣方案 v2/v3/v5`（v5 于 2021.1.18 呈财务中心）、`2021销售折扣政策.xlsx`、`盈利分析-电商公司经销商2021v2.xls`、`盈利分析-经销商运营部2021.xls`。

## 一、先看清渠道结构（2020 实测）

| 类型 | 规模 | 占比 |
|---|---|---|
| 经销商 | 2,700 万 | 79% |
| 社交 | 421 万 | 12% |
| 400 团购 | 215 万 | 6% |
| 一件代发 | 70 万 | 2% |
| 合计 | 3,406 万 | 100% |

结论：经销商是最大单一渠道，**折扣政策写错一个点，全年利润就没了**。

## 二、四个问题（政策要解决的对象）

1. 总代模式下二级商缺动力，任务分解不合理导致内耗
2. 非经销商客户（短期合作）难成长，做一次就断
3. 经销付费推广无支持，导致低价竞争
4. 省外分销、特通渠道增多，原模式不适配

## 三、适用范围与准入门槛

- 适用：A/B/C/社交/经销商/400 全渠道；入仓 + 一件代发两种履约；线上 + 新零售/社区团购；鲜花饼 / 云腿小饼 / 节庆 / 外购品；中秋按集团政策执行（不套用本方案）
- 经销商准入：年销售结算价 **200 万**；一年未达取消资格
- 分销商准入：按各平台门槛执行

## 四、经销商三层折扣（v5 定稿）

**第一层 产品折扣**：入仓 30%（70 折）；一件代发 25%（75 折）

**第二层 季度返利**（基数为实收打款金额）

| 季度销售额 | 返利 | 推广支持 |
|---|---|---|
| 30 万以下 | 0 | 0.5% |
| 30–50 万 | 1% | 1.5% |
| 50–80 万 | 2% | — |
| 80–100 万 | 3% | 2.0% |
| 100–200 万 | 4% | — |
| 200 万以上 | 5% | — |

推广支持须凭据报销、以货补形式兑付；实际低于政策标准的按实际执行。

**第三层 年度超额返利**

| 年度销售额 | 入仓 | 一件代发 |
|---|---|---|
| 200 万以下 | 0 | 0 |
| 200–400 万 | 5% | 2% |
| 400–800 万 | 6% | 3% |
| 800–1200 万 | 7% | 4% |
| 1200–1600 万 | 8% | 5% |
| 1600 万以上 | 9% | 6% |

## 五、分销商两层折扣

**月度基础折扣**：2,000 元以下 20%；2,000–5,000 元 4%；5,000 元–2 万 5%；2 万以上 25%。
（原文口径如此，落地前必须按实际结算价复核，避免小额高折扣、大额低折扣的倒挂。）

**月度返利**：4% / 5% / 4%（按档位）。
**季度返利**：3 万以下 0；3–6 万 2%；6–12 万 3%；12 万以上 5%。

## 六、两条硬约束（最重要）

1. **年度折扣总额（基础折扣 + 月度/季度/年度返利）占销售比不得超过 40%**
2. 所有返利以**实收打款金额**为基数，不以发货额或含税金额为基数

落地检查：每个经销商建一张"折扣台账"，逐笔记录基础折扣、各类返利、推广支持，季度末算一次合计折扣率，超过 38% 即预警（留 2 个点缓冲）。

## 七、版本演进与留痕

v1 → v2 → v3 → v5 的演进说明必须留档：每版改了什么、为什么改、谁批的。嘉华的做法是同一目录并存多版 + 呈报财务中心，交接时可追溯。
写方案时同步做 `盈利分析`（按折扣率、退货率、履约成本三个变量算净利），没有盈利测算的折扣方案不予审批。

## 八、迁移提醒

"5 折拿货冲规模"在同类企业已被证伪（冠生园 2024 年 1100 万目标连续两年落空、2025 实际 529.68 万、毛利仅 5%）。折扣方案的价值不在让利幅度，而在**返利结构是否把钱给到真正做动销的人**。
