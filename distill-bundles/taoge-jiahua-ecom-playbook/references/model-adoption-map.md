## 二、维护规则

1. **单一事实源**：模型定义、举证、误用只在 `ecom-thinking-models.md`；下游技能只写编号 + 落点 + 不合格表现，不复制五段式。
2. **改动顺序**：先改模型文件 → 再按本表逐项检查下游表述 → 最后更新本表日期与变更行。
3. **新增技能**：按"任务 → 模型"补一行；一个技能最多接 3–4 个模型，接多了等于没接。
4. **冲突处理**：下游技能原有口径与模型冲突时，保留用户已拍板口径（如 41.5% 毛利率），只改方法表述，不改数字。
5. **验收口径**：任一技能若出现"只给表、不给判断"的模板化段落，视为未完成接入。
