## 九、引用纪律

1. 标口径：总销售 / 自营 / 经销商 / 某专项，四者不混。
2. 标期间：年 / 季 / 月 / 节庆档期。
3. 标来源文件名（例：`电商公司2020年度工作总结_V1.0.pptx`）。
4. PDF 类（如 2021 中秋总结）为自定义字体，中文正文不可机读，只采信数字，正文观点须人工核对。
