**用法**：先过 `ecom-thinking-models.md` M3（产品角色分工）、M4（渠道贡献毛利）。渠道表的价值在"谁养谁"的判断，不在罗列六个渠道的目标。

来源：`电商公司2021年度工作规划_V2.0.pptx`、`电商公司快速增长策略及方法汇报报告.docx`（呈总经办 2021.5.28）、`2021 7月经营分析`、`产品管理部`各节令立项文档、`抖音代运营方案`。

## 二、产品战略：3+N

- **3 条主线**：鲜花饼（含现烤）、月饼·汤圆·粽子、云腿小饼
- **N（非烘焙扩品）**：果干、菌菇、咖啡、榴莲代加工、青团、年糕、曲奇……按节令与产能逐个立项

2021 品类目标：鲜花饼 1.15 亿、月饼汤圆粽子 6000 万（+33.52%）、云腿小饼 2200 万（+31.91%）、饼干 100 万、其他 400 万。
三年节奏：2020 烘焙稳增 + 云饼战略 + 果干菌菇孵化 → 2021 云饼品牌认知 + 滇式月饼第一品牌 + 4 个非烘焙品类完成孵化 → 2022 四类产品持续提升 + 非烘焙迭代 + 品牌合作经营主体。

## 三、鲜花饼 11 个系列（系列化是考核前提）

`招牌经典 / 百花 / 甄选云南 / 塔 / 派 / 现烤 / 滇式中点 / 世界蛋糕 / 互动 / 外购 / 节庆`

每个系列必须写三样：**核心价值（一句话）+ 实施重点（可验收）+ 年度目标**。
例：招牌经典保盘（7400 万）；百花系列 5000 万、主打"缩短保质期、花含量 +20%"；甄选云南 3000 万、讲产地与稀缺。

2021 系列目标台账：招牌经典 7400 万、现烤 2800 万、百花 1200 万、云南甄选 600 万、云腿小饼 2650 万、洗沙 300 万、滇式中点 80 万、外购 80 万、曲奇 200 万、粽子 300 万、汤圆 50 万、年货 140 万、中秋 5200 万。

## 四、产品管理部：按节令立项

立项顺序即作战日历：青团（春）→ 果干/菌菇（全年孵化）→ 端午粽 → 云腿小饼（日常）→ 中秋月饼 → 汤圆/年糕（冬）→ 年货。
每个立项文档至少含：市场机会、目标人群、价格带与规格、毛利率测算、上市时间、首单量、失败退出条件。

**失败案例要写进制度**：海盐曲奇 2020 目标 600 万、实际 104.8 万（达成 17.47%，同比 −77.91%）——原因是没有渠道专款、没有内容预算、上市晚于节庆窗口。此后新品立项必须回答"哪个渠道专款、多少内容预算、几号上线"。

## 五、内容与曝光：四阶段节奏

以中秋为例（可套用到任何节庆）：

| 阶段 | 时间 | 任务 |
|---|---|---|
| 启势 | T-60 ~ T-45 | 品牌片、达人预热、搜索词铺设 |
| 引爆 | T-45 ~ T-30 | 直播集中、礼盒主推、平台大促叠加 |
| 加热 | T-30 ~ T-15 | 短视频轰炸、种草、跨平台抽奖 |
| 余热 | T-15 ~ T-3 | 追单、企业团购、返场 |

内容生产流程（嘉华固定用法）：`买点 → 文案 → 设计 → 视频 → 自媒体 → 运营上线 → 其他视频渠道分发`。缺一环就会出现在"详情页讲不清卖点"的低级问题上。

## 六、抖音/内容代运营的定位法（服务商 Brief 用）

抢占心智的七种定位：人无我有 / 人有我优 / 行业第一 / 类型第一 / 独创呈现形式 / 率先跨行业应用 / 独一标签。
流程：对内找优势闪光点 → 对外找对标竞品 → 寻找创新呈现方式 → 设定个性标签 → 按平台流量算法持续更新创意 → 评论人格化维护 → 为转化定制内容。

## 七、增长瓶颈四类（写策略前先自查）

1. 产品同质化、无护城河（鲜花饼 2017 起瓶颈，设计/营销/低价被复制）
2. 运营模式与人才跟不上（直播、内容、达人体系未成型）
3. 商业模式 2012–2020 未迭代（一直靠店铺+节庆）
4. 品类单一导致 Q3 占全年一半、上半年产能闲置、复购频次低 → "拓新—流失"循环

对应两条解法：①第二品牌做品类扩张（嘉华用云肴南山，2021 2000 万 / 2022 5000 万 / 2023 8000 万，独立核算+利润考核）；②单品牌内部扩品（传统糕点/节庆糕点/烘焙休食/蛋糕西点/冷冻五类）。**先算清新主体的团队、仓配、税务前提，再谈第二曲线。**
