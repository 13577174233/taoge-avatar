# 会员体系与私域（CRM）

**判断要点**（配合 `ecom-thinking-models.md` M5）：会员是资产不是名单。先算复购率、复购客单、会员贡献占比，再谈等级与权益；注册数不上结论页。

来源：`全平台会员方案-用户客服中心-2021.12.31.docx`、`用户运营中心`会员专项、`个人号矩阵`运营记录。

## 一、起盘现状（先算清家底再设计等级）

- 只有天猫 / 京东 / 微信旗舰店有会员体系，其他平台零会员
- 全年新增会员 16 万（+33%），会员贡献销售 650 万
- 结论：会员不是"锦上添花"，是**把平台流量转成自有资产**的唯一通道；不做就等于每年把 16 万用户还给平台

## 二、五级会员（等级即价格歧视的工具）

| 等级 | 名称 | 门槛（元） | 权益期 |
|---|---|---|---|
| V1 | 嘉华小吃货 | 0–30 区间 | 365 天 |
| V2 | 美食家 | 198 | 365 天 |
| V3 | 品鉴师 | 666 | 365 天 |
| V4 | 大食神 | 999 | 365 天 |
| V5 | 守护神 | 1988 | 365 天 |

设计规则：门槛按"客单价 × 年购买次数"推算，不拍脑袋；每级只加 2–3 项权益，避免权益通胀。

## 三、权益矩阵（可直接抄结构）

| 权益 | 内容 |
|---|---|
| 入会有礼 | 60−5 券 + 2 枚蛋黄酥 0.01 元 + 9.89 元包邮 |
| 专享礼券 | 60−5 / 100−10 / 169−20 / 199−30 / 199−40（按等级递进） |
| 会员专属价 | 4 个 SKU，每日限量 20 份 |
| 周三福利日 | 99−20，每周三 10:00 限量 20 份 |
| 生日礼 | 199−50 |

## 四、积分获取与消耗

获取：绑卡 +30 / 关注 +15 / 晒图 +20 / 完善信息 +20 / 签到 1（连续 7 天 +8、21 天 +30）/ 小游戏 1–20 / 邀请好友（10 人 +100；30 人送巧克力甘栗酥；50 人送桂花栗子酥礼盒；100 人送百花系列年货礼包）。

消耗：积分商城兑券（99−10 = 49 分、168−20 = 99 分）；积分加钱购 19 项商品（每项列价值 / 兑换积分 / 兑换金额 / 成本价 / 数量 / 合计费用，总成本 32,949 元）。

规则：积分成本必须进预算表，"送出去多少分、兑掉多少、成本多少"三列对齐，否则一年后算不清。

## 五、个人号矩阵（私域的毛细血管）

2021 年实际运营 7 个号：花食顾问-玫瑰（183）、贪吃兔（122）、美食达人-小嘉（210）、嘉华鲜花饼-饼子（4,079）、贪吃兔（4,370）、华小嘉（684）、嘉华鲜花饼小助理（1,374）。

结构建议：1 个品牌主号（内容+活动）+ 2 个产品号（鲜花饼 / 节庆）+ 1 个客服号（售后与复购提醒）+ N 个门店号（一店一人）。每个号必须有明确"人设 + 发什么 + 一天几条 + 谁回消息"。

## 六、费用预算（15 项，合计 74,769 元）

分摊规则：个人号运营 9,900 元、周边好物 10,650 元归用户服务中心；其余按平台（天猫/京东/拼多多/社交）销售占比分摊。
每一笔都要写"归口部门"，否则年底没人认账。

## 七、落地检查点

1. 会员贡献占比是否月度跟踪（嘉华口径：会员贡献 / 总销售）
2. 新增会员成本（拉新费用 ÷ 新增会员数）是否低于首单毛利
3. 高等级会员（V4+V5）人数与复购次数是否在涨
4. 个人号是否有"7 天不发内容"的断更预警
