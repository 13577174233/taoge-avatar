# 年度规划与年度总结骨架

**用法**：动笔前先过 `ecom-thinking-models.md` M1（收入形状）、M2（目标三关）、M8（编制匹配）。本文件只给骨架与章节顺序，判断结论必须由模型给出——先有判断，再套骨架。

来源：`电商公司2020年工作规划_V2.0.pptx`、`电商公司2021年度工作规划_V2.0.pptx`（汇报人唐海涛 2020.12.15）、`电商公司2020年度工作总结_V1.0.pptx`、部门规划报告 20+ 份。

## 一、年度规划两套骨架（按公司阶段选）

### A. 五段式（首次/big-bang 年，2020 用的就是这套）

1. **原理层**：核心价值 → 管理手段 → 核心公式
   - 公式：`用户 × 营销力 × 产品力 × 用户价值（复购 × 延展）`
   - 管理手段三条：产品思维构建 / 运营能力提升 / 优秀资源整合
   - 作用：先讲"凭什么能增长"，再讲"增长多少"，否则目标是无根数字
2. **三年目标与路径**：`打基础、调团队、做准备（第1年）→ 商业模式与管理模式变革（第2年）→ 价值体现、销售突破（第3年）`
   - 路径要写"从什么变成什么"：烘焙单品类电商 → 云南特色食品多品类电商，2 亿规模
3. **年度销售目标（五张表）**：①渠道 ②品类 ③节庆 ④O2O ⑤网络蛋糕/新业务
4. **年度工作计划（八项）**：找增量用户 / 老用户留存激活 / 构建品牌流量池 / 运营模式迭代 / 渠道结构与模式调整 / 产品运营重构 / 非烘焙品类扩展 / 团队架构
5. **收尾**：请总经办给予工作指导——把需要老板拍板的事项单列（预算、编制、跨公司协同），不要埋在正文里

### B. 四段式（承接年，2021 用的这套，更紧凑）

1. **核心工作四条**（每条一句判断 + 一条流程）：
   - 第二品牌加速：市场分析 → 产品孵化 → 产品上市 → 市场价值体现（流程化）
   - 嘉华烘焙 3+N 产品战略
   - 创新与卓越团队
   - 强化电商对集团全国品牌的价值
2. **年度目标**：分主体（嘉华 2.02 亿 / 云肴南山 2800 万 / 合计 2.3 亿）、分渠道、分品类、分节庆
3. **工作规划**：按产品线逐条写"核心价值 + 实施重点"（例：鲜花饼 11 个系列，招牌经典保盘、百花 5000 万、甄选云南 3000 万；实施重点写"缩短保质期、+20% 新花"这种可验收动作）
4. **团队与创新**：组织、编制、机制（独立核算/利润考核/集团内分销分成）

## 二、写规划前必须先定的四件事

1. **增长从哪来**（增量用户 / 复购 / 新渠道 / 新品类 / 新主体），每条给可验证的第一年信号；
2. **上限在哪**（产能、仓配、平台规则、现金流），嘉华的教训是目标年年定高、达成率长期 80–90%；
3. **单峰还是多峰**（节庆集中度），单峰必写"上半年怎么活"；
4. **谁负责**（部门 + 人名 + 时间点），没有责任人的规划条目不进入 PPT。

## 三、部门规划报告的编号法（多部门汇总时用）

年度规划目录下按序号排列，防止漏部门、方便点名：

```
12.运营A部  13.运营B部  14.平台运营C部  15.社交电商
18.客服中心  19.内容部  20.视觉设计部  22.产品运营
```

汇总时按序号对齐成一张"部门—目标—举措—资源需求"总表，缺号的部门当场补。

## 四、年度总结骨架（四段闭链 + 个人总结）

1. **经营分析**：总销售/自营/经销商达成与同比 → 渠道 → 品类 → 节庆 → 月度节奏（Q1-Q4 达成率）
2. **工作对标**：年初定的八项工作逐项打勾/打叉，写"做到什么程度"，不写"积极推进"
3. **工作总结**：亮点 3 条以内（带数字）、问题 3 条（带量化影响）
4. **次年策略**：直接接下一年的四段式，形成"总结即规划输入"
5. **个人工作总结**（管理者版）：业务结果 + 团队结果 + 个人不足 + 次年自我提升项

2020 总结原文的三条问题可直接当写法样例：
- 产品运营聚焦不够（海盐曲奇目标 600 万只做 104.8 万，−77.91%）
- 品销合一企图心不足（鲜花饼节大盘 +19.6%，专款仅占 4%）
- 部分团队执行效率低（下半年多个项目延期）

## 五、评审与收尾

- 每版规划交付前过一遍：目标能否被现有产能/预算支撑、节庆占比是否过高、每条举措是否有验收信号、老板能当场拍哪几个板。
- 结尾固定留一页"需总经办决策事项"，把预算、编制、跨公司协同三类事一次性提出来。
