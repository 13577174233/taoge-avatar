# 公司治理驱动认知包（Corporate Governance Driver）

> **一句话定位**：公司真正的生死线不在业务层，而在「权力归谁、利益归谁、谁被制度约束」；治理不是管人，是设计一套让各方不能作恶、也不至于散伙的规则。
> **来源**：刘松博·公司治理30讲（LSB001–LSB030，30项全量 S 级原文蒸馏，2026-11-07；页面口径「33/33 更新、共40讲」，目录实测恒 30 条，30–32 讲与加餐 3 讲在页面、抽屉与加载接口均不可见，登记为未上架不归档）。
> **同源接线**：MG（宁向东管理学）管高管之下的管理，本包管高管之上的治理；TX（田轩公司金融）管企业怎么融资投资，本包管权力怎么分配；GB（蒋文华博弈论）管局面结构，本包 LSB024 谈判力定控制权是其治理场景版；SW/BR 管商业与品牌打法，本包回答「这套打法由谁说了算」；FN 管账，本包管账背后的权力与责任。

## 一、总图（一句话记住）

**先问「这家公司的权力与利益是怎么被制度约束的」，再问「业务怎么做」。** 治理＝两条线：利益线（以谁的利益为中心）×权力线（谁是权力中心）。传统答案是股东利益中心＋董事会权力中心，本课给出一条正在成形的新答案：**客户利益中心＋事业合伙人权力中心**。

五层递进：
① **溯本清源**（LSB002–LSB004）：公司为何存在（降低交易成本＋有限责任＋永续）、天生三缺陷（企业家悖论/内部人控制/中小股东弱势）、靠制度信任而非人际信任。
② **股东治理**（LSB005–LSB016）：股权本质（剩余索取权＋控制权）→合伙与架构（退出、三条线）→控制权工具（比例/委托/一致行动/章程）→同股不同权→企业家悖论→上市（透明化溢价、时间维度）→制衡（系统胜于强权、累积投票、三道防火线、董事会独立性）。
③ **经理治理**（LSB017–LSB021）：CEO 与董事长的两职情境 → 职业经理人掐架的根因（心理所有权越界）→ 职业化三维 → 管理层俘获定薪 → 股权激励五种思维。
④ **下沉与外扩**（LSB022–LSB030）：混改管资本、家族宪法分界、门口野蛮人与谈判力、利益相关者倒 U、客户优先与公司至上、德国监事会、员工共决制、日本三理论、事业合伙人。
⑤ **两条线合流**（LSB024–LSB030）：控制权归属由谈判力决定；担更大风险者才配更大权力；治理焦点从「控制」转向「激活」。

## 二、核心律速查表（LSB系列30条，按模块分组）

### 模块零：发刊词（LSB001）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| LSB001 | 治理先于管理 | 高管之上是治理、高管之下是管理；公司的生死线不在业务层，而在权力与利益如何被制度约束。 |

### 模块一：溯本清源（LSB002–LSB004，3讲）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| LSB002 | 公司替代市场 | 企业因降低交易成本而存在，公司制度再用有限责任、独立法人、可转让股权把"做大事"变成可能。 |
| LSB003 | 三重缺陷必治 | 公司天生带三个缺陷：企业家悖论、内部人控制、中小股东弱势，只能靠治理机制对冲。 |
| LSB004 | 制度信任优先 | 公司靠信任维系，人际信任撑不过规模，只有制度信任（规则、契约、可核查）能把陌生人组织起来。 |

### 模块二：股东治理（LSB005–LSB016，12讲）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| LSB005 | 股权即剩余索取权 | 股权的本质是剩余索取权与控制权的组合，先算清这两项再谈比例，比例只是表象。 |
| LSB006 | 合伙先谈退出 | 和朋友合伙的第一步不是分钱而是写清退出：谁在什么条件下怎么走、股权怎么回购。 |
| LSB007 | 股权架构三条线 | 股权架构要守住控制权线、利益线、退出线；三条线混谈就会踩雷。 |
| LSB008 | 控制权四件套 | 创始人保控制权四件工具：股权比例、投票权委托、一致行动人、章程与董事会席位安排。 |
| LSB009 | 同股可不同权 | 股份少也能说了算，靠双重股权与投票权安排；代价是资本市场对治理折价的审视。 |
| LSB010 | 企业家悖论 | 企业家的能力与野心既创造公司也威胁公司，治理要让企业家不能懒、不能恶、不能为所欲为。 |
| LSB011 | 透明化溢价 | 上市不只是融资，更是用透明换公信力与权力制衡；溢价来自被看见，成本也来自被看见。 |
| LSB012 | 上市看时间维度 | 上市与否不看当下缺不缺钱，而看未来抗风险与竞争位势；态度反复是时间条件下的理性调整。 |
| LSB013 | 系统制衡胜于强权 | 制约权力的不是更大的权力而是一套内外系统；权力大小是伪问题，系统完善才是真问题。 |
| LSB014 | 累积投票争席位 | 小股东最硬的武器是投票权：媒体造势、股东联合、网络投票加累积投票，先把具体席位争到手。 |
| LSB015 | 三道防火线 | 外部治理三道线：信息披露是前提、市场认可是信号、司法环境是基础。 |
| LSB016 | 董事会独立为先 | 董事会的价值不在层级而在独立性；独董占比、提名权与薪酬来源决定它是压舱石还是花瓶。 |

### 模块三：经理治理（LSB017–LSB021，5讲）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| LSB017 | 两职随情境 | 董事长与 CEO 谁大看身份叠加与董事会支持；合一或分离取决于环境动荡度与企业规模。 |
| LSB018 | 心理所有权越界 | 经理人过高心理所有权会把责任心变成野心；要防的不只是做坏事的人，还有自以为在做好事的人。 |
| LSB019 | 职业化三维 | 职业化看职业技能、职业态度、职业道德；道德的本质是契约精神，检验标准是分手后能否彼此欣赏。 |
| LSB020 | 管理层俘获定薪 | 定薪权一旦被管理层俘获，薪酬只涨不降；判断合理性看薪酬与业绩、行业是否背离。 |
| LSB021 | 股权激励五思维 | 股权激励不能只讲合规，要配五种人力思维：绩效、估值、动态、梯队、沟通。 |

### 模块四：下沉与外扩（LSB022–LSB030，9讲）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| LSB022 | 混改管资本 | 改革方向是产权清晰到能担责的主体，划清行政治理与公司治理边界，监管从管企业转管资本。 |
| LSB023 | 家族宪法分界 | 破"富不过三代"靠两件事：家族治理与公司治理分开，接班人长期培养加创业精神传承。 |
| LSB024 | 谈判力定控制权 | 控制权归谈判力更强的一方；股权分散企业最大风险不是内部人控制，而是内部人失去控制。 |
| LSB025 | 相关者倒U | 利益相关者理论价值上成立、操作上失效，无法取代股东至上；社会责任与财务绩效呈倒 U 型。 |
| LSB026 | 客户优先 | 客户优先既解决相关者理论的操作难题，又把公司目的从为股东赚钱升为解决社会问题，利润只是结果。 |
| LSB027 | 监督看独立性 | 监事会层级再高，只要人选与薪酬受管理层影响就必然失灵；监督有效性取决于独立性而非地位。 |
| LSB028 | 共决换忠诚 | 员工共决用效率换忠诚与危机中的共进退；公平与效率无法两全，选择取决于社会愿牺牲哪一头。 |
| LSB029 | 蝴蝶·进化·路径 | 一国治理由偶然事件、效率选择与路径惯性共同塑造；同向美国趋同，德国守框架、日本破框架。 |
| LSB030 | 风险共担即权力 | 事业合伙人用出资、杠杆、劣后与对赌把雇佣改成合伙，担更大风险才配更大控制权；治理从控制转向激活。 |

## 三、五步SOP：用治理视角看一家公司（通用版）

**第1步 定位缺陷（LSB003）**：先判断这家公司最可能死在哪一类——企业家悖论（创始人/强势一把手）、内部人控制（经理层无人约束）、中小股东弱势（股权分散且无人出头）。三类缺陷对应三套药，开错药等于没治病。

**第2步 拆权力线（LSB008/009/016/017/024/027）**：列出股权比例、投票权安排（委托/一致行动/双重股权）、董事会席位与独董来源、董事长与 CEO 是否合一、监事/独董的提名与薪酬由谁定。控制权不看名义比例，看「谁能决定董事人选」；股权分散企业尤其要问：内部人是否反而正在失去控制。

**第3步 拆利益线（LSB005/011/020/021/025/026/030）**：确认公司实际以谁的利益为中心——股东、客户还是全员合伙人；再看分配机制：薪酬是否被管理层俘获、股权激励是否有绩效与退出约束、社会责任投入是否越过倒 U 顶点。利益线错位比权力线错位更隐蔽，通常表现为「业绩好但没人负责」。

**第4步 查机制有效性（LSB013/014/015/018/027/028）**：逐条验证治理机制是不是真的在运转：披露是否可核查、外部市场是否有约束力、独董与监事是否独立、员工是否有真实表达通道、经理人心理所有权是否越界。机制在纸上是设计，在事上才是治理；只看章程不看人事，等于没查。

**第5步 判演化方向（LSB022/023/029/030）**：把这家公司放进它的制度传统与生命周期——国企看混改与管资本进度，家族企业看家族宪法与接班安排，成熟上市公司看权力中心是否向人力资本迁移（合伙人制度）。治理改革的可行性取决于路径依赖强度，激进移植通常失败。

## 五、边界

- **本课是治理框架，不是法律意见。** 股权架构、章程条款、对赌与跟投涉及公司法、证券监管与税务，落地前须经专业律师与审计确认；本包只提供判断顺序（LSB007/008/030）。
- **案例时效性强。** 宝万之争、德银困境、Costco/信誉楼、万科合伙人数据均为课程讲述时点（2019–2020）的口径，引用时注明时间，不当成当下事实（LSB024/026/027/030）。
- **国别经验不可直接移植。** 德国垂直二元制与员工共决、日本可选董事会模式，均嵌在其法律传统与路径依赖中；中国监事会与独董并存的问题，课程给的是建议而非定论（LSB027/028/029）。
- **股东至上 vs 利益相关者仍无定论。** 倒 U 型是实证规律而非精确阈值，临界点因行业而异（LSB025）。
- **作者立场部分不作定论。** 「事业合伙人是未来趋势」「监事会可改为可选项」属课程主张，采纳前须结合自身规模与监管环境评估（LSB029/030）。
