# 编剧方法 · 写作自查清单

> 在具体处境里照着核对。每条都是「什么信号说明方法已失效应停 / 什么情况该找专业人士」。

- [ ] **节拍：戏剧冲突的最小单位** —— 把节拍理解为「台词的一问一答」——它计的是主角朝目标努力的次数，不等于对话回合；机械地凑对话回合数会导致节拍堆砌而人物没有目标。
- [ ] **节拍密度：神作与口水剧的硬指标** —— 把节拍密度当唯一标准，为凑数在一场戏里硬塞无关冲突，导致节拍堆砌牺牲人物逻辑——密度要服务于核心冲突。
- [ ] **过场戏是乏味的根源** —— 走向另一个极端，把所有背景信息全部塞进冲突戏里，导致信息过载、观众跟不上——背景信息可以给，但要拆散了附着在节拍上。
- [ ] **神作提供行业底层逻辑的知识** —— 为堆知识在戏里开科普课，知识若不成为冲突与节拍的燃料，同样会变成过场戏式的说教。
- [ ] **带着爱写所有人：弱点＋人性闪光点** —— 把「辩护」写成「洗白」，让恶行获得道德豁免——辩护的对象是人物动机的可理解性，不是行为正当性。
- [ ] **戏核：一句话说清核心创意** —— 把戏核写成剧情复述（「然后…然后…」）——戏核是概念不是梗概；也有人为追求一句话漂亮而空洞，看不出主角、对手与冲突。
- [ ] **不可逃避的困境** —— 把「不可逃避」写成外力强行绑架（如无来由的死亡威胁），困境若与主角的内在渴望无关，动力依然立不起来。
- [ ] **惊奇元素** —— 为惊奇而惊奇，元素猎奇但与主题无关，变成无意义的噱头；堆砌奇观而不回答「这些人为什么要做这件事」。
- [ ] **反讽性** —— 把反讽写成单纯的不合逻辑——矛盾双方必须有内在关联（化学老师的专业能力恰恰是制毒的本钱），否则是胡编。
- [ ] **商业片与文艺片的戏核边界** —— 把三要素当一切故事的通用门槛，逼着文艺题材硬加猎奇元素，两头不讨好。
- [ ] **让角色成为顶尖高手** —— 特长开挂过度变成无敌爽文，人物不再遇阻，冲突消失——高手必须配更强的障碍才有戏。
- [ ] **强烈个性与放大技巧** —— 全员 10 分个性则互相打架、个个聒噪——放大要错峰分配，一剧多角各放各的维度。
- [ ] **混搭：反差制造层次** —— 混搭元素与主线无关时沦为贴标签式猎奇（「杀人犯爱养花」但剧情从不展开），反差必须进入故事逻辑才有层次。
- [ ] **暴露弱点：弱点让人物有意思** —— 为弱点而弱点地堆「惨」，弱点若不解释后续行为，就只是卖惨而非塑造。
- [ ] **给主角找跟班和对手** —— 跟班写成纯工具人（只会捧哏），或对手智商随剧情需要忽高忽低——衬托失效，胜利廉价。
- [ ] **三幕戏框架与篇幅配比** —— 把 1/4—1/2—1/4 当铁律逐帧执行，教条化配比会扼杀特定故事需要的节奏（作者自己也强调「艺术最忌讳教条」）。
- [ ] **第一幕三件事：展现模式／打破模式／给出行动理由** —— 意外来得突兀但理由缺席——观众只看到「剧情需要他上路」，看不到「他非走不可」，共情断线。
- [ ] **虐待才智与恐惧清单** —— 虐待脱离人设与主题，变成无来由的惨案堆砌——虐要虐在主人公最怕的地方（恐惧清单的逻辑），不是随便加灾。
- [ ] **绝境出口不止一个** —— 临时空降解法（天降神兵、巧合救场）——出口必须由前文布线的细节长出来，否则反转变成作弊。
- [ ] **第三幕：反转与峰终完结** —— 为反转而反转，反转与前文逻辑断裂——观众先是惊讶、回想后是愤怒；暖心时刻若与全片基调断裂也会变成硬贴糖霜。
- [ ] **多米诺原则：情节间的强因果** —— 把多米诺原则执行成单线直线——没有支线与岔路的长因果链会变得可预测；因果密不透风还要与不可预测原则（A4）配合使用。
- [ ] **七句话故事模板** —— 模板只保结构不保新意——七句都通但每句都俗，故事依然平庸；填模板是底线检查，不是创作终点。
- [ ] **人设原则：性格决定命运** —— 把人设原则当成角色行为可以被完全预测——人物一成不变；或反过来，为剧情方便让人物降智、变脸，两种都是断链。
- [ ] **不可预测原则：奇葩方案与两种反转** —— 反转不是瞎转——两种反转都需要前文可回溯的伏笔支撑，纯靠隐瞒信息硬转的「为反转而反转」会引发观众被愚弄感；奇葩方案过度使用会让世界规则失真。
- [ ] **同情与爱慕：共情的两把钥匙** —— 把两把钥匙当开关一按就灵——若人物行为本身不可信，同情与爱慕都会瞬间蒸发；情感技巧不能替代人物真实性。
- [ ] **打压第一招：被误会、被羞辱、被忽视** —— 羞辱堆过头变卖惨，观众从同情转为怜厌——羞辱要服务于后续反弹，不是为惨而惨。
- [ ] **多重打击：把主角逼入绝境** —— 打击数量盖过质量，诸不幸之间无因果关联、像抽盲盒式的悲剧清单——观众会疲劳并质疑编剧刻意。
- [ ] **提高失败风险：失败成本决定关心程度** —— 为提高成本无节制地真杀真残角色，观众对「死亡flag」脱敏后，后续险境张力递减——成本工具要省着用。
- [ ] **爱慕：比普通人高一厘米的角色** —— 为接地气堆缺点堆到角色失去魅力，「高一厘米」要求缺点是「普通人的缺点」而非「令人生厌的恶习」，比例失衡两头落空。
- [ ] **增加障碍：障碍越多节拍越密** —— 障碍堆砌但彼此不联动——十个障碍若能逐个击破、互不纠缠，就退化成十场小战斗；高明的障碍应互相咬合、牵一发而动全身。
- [ ] **障碍来源多元化：对手、环境与内心** —— 内心戏过量会拖慢外部进度，观众从「紧张」变「着急」——内外配比要随场景类型调整。
- [ ] **增加策略：单回合变多回合** —— 变招变成不重样的耍宝，招与招之间没有逻辑递进（为什么利诱失败才威逼？），策略流于闹剧。
- [ ] **写出人物的每个情绪转折** —— 情绪转折没有事件支撑，为转而转——每次情绪变化都必须由场景内的具体刺激（老板的某个反应）触发。
- [ ] **找准落点：戛然而止或余音袅袅** —— 涟漪写过头变拖沓——「细写涟漪」的对象必须是高浓度事件，日常小事写三层余韵就是注水。
- [ ] **潜台词：激发观众的参与感** —— 暗示过度导致观众解码失败，看不懂即弃剧——潜台词的门槛要保证「提示可得、答案可猜」，不能加密成密码本。
- [ ] **潜台词三招：说一半、移花接木、木马计** —— 三招叠加过度，台词全是机锋、无一句实话，人物变得油滑失真；木马计的干扰信息若太抢戏，观众只记住房价忘了炫富意图。
- [ ] **金句：最简洁快速的方法是改写** —— 改写成瘾，句式雷同、比喻撞车（「生活就像 X」被用滥后反而廉价）；金句若与剧情无关，只是台词层面的装饰品。
- [ ] **台词要传达关系，不只是信息** —— 为传关系硬加机锋，案发现场还夹枪带棒会显得人物不专业——关系表达要符合场合与人物身份。
- [ ] **拆分问题：用问题统领故事** —— 问题拆得太碎、答得太密，观众刚起疑就被解答，钩子来不及咬合；核心悬念中途漂移则全剧失焦。
- [ ] **悬崖抓手：把主角逼到没有退路** —— 抓手虚张声势——下集开头的解法比危机更平淡（原来是做梦），或坑太大填不上只能强行降智，观众产生被套路感，两次之后就免疫。
- [ ] **提前埋线：编剧有时间慢慢想** —— 埋线埋成明线——铺垫太显眼，观众提前识破，揭晓时毫无惊喜；埋线也要控制信息披露的可见度，一闪而过是技术活。
- [ ] **拼图游戏：信息披露的五步规划** —— 掺水掺过头，误导线索占比过高，揭晓时观众发现大半程被喂了假信息，感觉被耍——误导要公平：真线索与假线索同场可见。
- [ ] **驱动故事的是人物，不是情节** —— 把「人物驱动」误解为只写内心不写事件——内在冲突仍需外化为行动与选择，否则变成心理独白集。
- [ ] **吸引观众的是情感，不是逻辑** —— 情感戏堆砌成煽情马拉松，无情节支撑的声泪俱下会透支观众情绪预算——「我们谈谈吧」有效的前提是前面有值得谈的事。
- [ ] **塑造人物的是「人物视角」，不是「作者视角」** —— 人物视角写成刻板标签（农村人必粗话、书生必文绉绉），忽视角色在具体情境中的变化——视角是底色，不是每句话的模板。
- [ ] **剧本呈现的是艺术加工，不是生活素材** —— 「高于生活」被理解为夸张失真、狗血洒无限——10 倍指情感浓度与戏剧强度的提纯，不是离谱程度；强烈的极端情境仍要服膺人物逻辑（A1）。
