# 量价研判规范（v5.3）

## 定位

以成交量与价格的配合关系判断资金行为与趋势健康度，输出"量价状态 + 关键信号 + ATR/RSI + 与技术位/缠论的印证结论"。适用于全部持仓股，重点股必查。

## 量价八种基本状态

| 状态 | 特征 | 含义 |
|---|---|---|
| 价涨量增 | 价升 + 量增 | 健康上涨，资金进场（趋势延续） |
| 价涨量缩 | 价升 + 量缩 | 上涨乏力，警惕滞涨/诱多 |
| 价跌量增 | 价跌 + 量增 | 恐慌出货或放量杀跌，弱势 |
| 价跌量缩 | 价跌 + 量缩 | 抛压减轻，回踩缩量则可能止跌 |
| 放量滞涨 | 量增 + 价平/微涨 | 顶部风险信号（天量见顶候选） |
| 缩量止跌 | 量缩 + 价止跌 | 底部企稳信号（地量见底候选） |
| 放量突破 | 量增 + 价突破关键位 | 突破有效（配合 R1/中枢上沿） |
| 缩量回踩 | 量缩 + 价回踩支撑 | 回踩不破则支撑有效 |

## 量比与换手参考（A 股日线）

| 指标 | 参考含义 |
|---|---|
| 量比 < 0.8 | 缩量（观望/惜售） |
| 量比 0.8~1.5 | 常态 |
| 量比 > 1.5 | 放量（配合方向判断） |
| 换手率 > 10% | 高换手（活跃/分歧加大），异动股重点核对 |

量比口径注意：卡面/速览表量比=当日成交量/近 5 日均量（qt 行情口径）；图内量能副图量比=KLINE_DATA.liangbi（data_raw 130 根窗口 90 的 vol[-1]/近 5 日均量，v31/v53 同逻辑）。两口径数值可能不同（如诺德 3.16 vs 0.76），日报内保持各自口径不混用。

## v5.3 新增指标（scripts/gen_kline_data_v53.py 输出，可复算）

- **ATR(14)**：14 日平均真实波幅 TR=max(H-L, |H-前收|, |L-前收|) 的简单平均；日报展示 `ATR 百分比=ATR/收盘×100`（波动率），如「ATR 6.71%」=高波动、小于 2% =低波动。
- **RSI(14)**：Wilder 平滑（初始 SMA14，后 α=1/14 递归），RSI=100-100/(1+RS)；日报展示数值（>70 超买、<30 超卖），如「RSI 38.3」。
- **RSI 背离**：价创新高而 RSI 未创新高=顶背离（上涨动能衰减）；价创新低而 RSI 未创新低=底背离（下跌动能衰减）；与缠论 MACD 背驰互相印证（rsi_div.state）。

## 关键信号规则

1. **放量突破**：成交额 ≥ 近 5 日均额 × 1.5 且收盘站稳压力位/中枢上沿 → 突破有效（与 technical-levels.md、chan-theory.md 三类买点印证）。
2. **天量见顶**：创阶段新高当日放天量（量比 > 2.5 或成交额为近 20 日最大）但价滞涨/收长上影 → 顶部风险。
3. **地量见底**：跌势末端量缩至近 20 日低位（量比 < 0.5）且价止跌 → 底部企稳候选。
4. **量价背离**：
   - 顶背离：价创新高，量不创新高（萎缩）→ 上涨动能衰竭。
   - 底背离：价创新低，量不创新低（萎缩）→ 下跌动能衰竭（与缠论背驰互相印证）。

## 每日研判流程

1. 计算当日量比 = 当日成交量 / 近 5 日均量（或成交额口径，注明）；标注换手率。
2. 对照八种状态表判定当日量价状态。
3. 检查关键信号（放量突破/天量见顶/地量见底/背离）是否触发。
4. 读 ATR% 与 RSI（+背离）：ATR 高=波动加剧（结合破位/突破判断）；RSI 超买超卖与背离辅助方向判断。
5. 与支撑压力位、缠论买卖点位置交叉印证，输出结论。

## 输出格式（v5.3 精简）

每只重点股 1 行：「量价状态 + 关键信号 + ｜ATR X.XX% ｜RSI XX.X（背离标注）」。示例：
- "价涨量增、量比 1.8，放量突破 R1 23.0 有效，与缠论三类买点共振，趋势健康 ｜ATR 3.4% ｜RSI 62.5"
- "价跌量增（放量下杀）→ 破 9.27 确认 ｜ATR 6.71% ｜RSI 38.3"

## 质量约束

- 量价判定必须用实际成交额/换手数据计算，不得凭感觉描述。
- 单一量价信号不单独定论，须与价位/缠论结构印证后输出。
- 量比、换手率口径在日报中注明；ATR/RSI 由脚本输出，不得手写。
