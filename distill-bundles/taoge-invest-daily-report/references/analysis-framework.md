# 涨跌归因分析框架

## 三维度交叉归因

对当日组合及重点个股的涨跌，按以下三个维度分别取证，再交叉判断主因：

### 1. 政策面
- 关注：当日或近三日发布的产业政策、监管动态、货币政策、财政/税收信号。
- 证据：政策原文链接/权威媒体报道，标注发布机构与日期。
- 判断：政策对相关行业是正向（补贴/规划/准入放宽）还是负向（限制/监管趋严）。

### 2. 行业消息
- 关注：行业景气数据、价格/订单变化、龙头公司动态、技术突破、海外产业链消息。
- 证据：行业资讯、公司公告、数据发布（如新能源装机、芯片出货、涨价函）。
- 判断：消息对行业供需、盈利预期的影响方向与幅度。

### 3. 资金流向
- 关注：板块主力资金净流入/流出、ETF 申赎、两融变化、北向资金（如有）、成交额环比。
- 证据：资金数据查询结果、成交额对比（放量/缩量）。
- 判断：资金行为是进攻（放量上涨/净流入）还是防守/撤离（放量下跌/净流出）。

## 归因输出规范

- **主因优先**：当日异动（±3% 以上）个股必须给出主因（维度 + 具体事件），次因可省略。
- **证据分级**：明确标注「已查证」（有来源原文）与「一方称」（单一信源未经证实）。
- **反证检查**：结论写出前自问——是否存在与结论矛盾的现象（如板块上涨但个股下跌、消息利空但股价反涨），如有必须说明。
- **证据不足时**：写「证据不足，待验证」，给出 1-2 个可验证信号（如次日量能、公告落地），不强行归因。

## 组合层面归因

- 先看组合整体涨跌贡献（按持仓市值加权），找出拖累/拉动最大的个股。
- 若组合当日整体波动主要由 1-2 只重仓股驱动，归因聚焦该股及其所属行业，避免泛泛而谈大盘。
