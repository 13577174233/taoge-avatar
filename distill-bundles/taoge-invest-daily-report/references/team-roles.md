# 专业股票分析团队角色定义

## 团队构成（6 角色，缺一不可）

| 角色 | 职责 | 产出 |
|---|---|---|
| 宏观策略师 | 判断当日宏观面（政策、流动性、外围市场、风险偏好）对组合的整体影响 | 宏观结论 1 条，注明影响方向 |
| 行业研究员 | 按持仓所属行业（如新能源/电力设备、半导体/消费电子、传媒、化工、食品饮料、有色等）逐一核对当日行业消息与景气变化 | 每个行业 1 条关键动态 |
| 资金面分析师 | 跟踪板块主力资金流向、北向/主力净流入流出、成交量能变化 | 资金面结论 1-2 条 |
| 技术面分析师 | 对重点关注个股（异动/放量/破位）做量价与趋势快评；按 [references/technical-levels.md](references/technical-levels.md) 测算全部持仓股次日支撑/压力/突破位与买卖点参考；按 [references/chan-theory.md](references/chan-theory.md) 做缠论走势结构研判；按 [references/volume-price-theory.md](references/volume-price-theory.md) 做量价研判 | 每只重点股 1 句技术快评 + 次日操作参考表 + 缠论与量价研判小节 |
| 个股研究员 | 逐只核对当日涨跌幅、成交量/成交额、异动原因（公告/消息/龙虎榜） | 行情表数据 + 异动标注 |
| 风控复核员 | 交叉核对数字与归因证据，剔除无来源结论，检查组合风险点（集中度、亏损扩大股） | 复核结论 + 风险提示 |

## 伙伴技能映射（v2.0，可选增强）

| 角色 | 挂载技能 | 用途 |
|---|---|---|
| 宏观策略师 | doubao-market-hotspot | 事件/宏观政策传导分析 |
| 行业研究员 | doubao-industry-analysis | 行业景气与产业链核对 |
| 资金面分析师 | doubao-daily-stock | 个股资金面/龙虎榜细节 |
| 技术面分析师 | doubao-daily-stock | 量价/趋势/均线技术面 |
| 个股研究员 | doubao-announcement-analysis、doubao-earnings-analysis | 公告解读、财报归因 |
| 风控复核员 | multi-stock-comparison | 跨股交叉核验与对比 |

## 每日执行时序

1. 个股研究员先取数建表（Step 0/2 数据源，异动股交叉验证）
2. 宏观策略师、行业研究员、资金面分析师并行做归因（Step 3）
3. 技术面分析师只对重点关注个股出手
4. 风控复核员最后交叉核验全部数字与结论，通过后进入输出（Step 5）
5. 全体给出明日观察信号（Step 4.5）；次日复盘验证（Step 6）

## 协同规则

- 各角色结论冲突时：以可追溯证据为准，证据同等时并列呈现并说明分歧，不强行统一。
- 所有角色共用同一份持仓清单与同一数据源口径，避免口径不一致。
- 团队产出在日报中体现为"团队构成"小节，注明各角色承担的部分。
