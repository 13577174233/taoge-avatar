# 日报输出模板（v5.3 三模块制 · 每股内嵌 K 线图 · 缠论算法精度升级）

**v5.1 起日报重构为三模块制**：①昨日市场分析（大盘视角）②今日资讯与预判（前瞻视角）③自选股逐股档案（个股视角，整合该股全部内容）。**v5.2（2026-10-27 用户确认）：模块三每张个股档案卡片内嵌该股 K 线分析图**，图与文字同卡呈现（一图看懂该股复盘）；个股排序固定 重点异动→常规。**v5.3（2026-10-27）：缠论/量价算法精度升级**——缠论行=中枢四值 ZD-ZG（附 DD/GG）+ 背驰状态（面积比）+ 三类买卖点；量价行追加 ATR%/RSI（+背离）；KLINE_DATA 由 scripts/gen_kline_data_v53.py 生成（K线包含处理/中枢四值/MACD 面积背驰/三类买卖点/ATR14/RSI14，可复算）。延续 v5.0 精简原则：专业评估只给结论行、删解释性长段、只保留核心建议（价位+动作+方向）。页面头部含 标题/版本/团队构成一行/大盘 KPI 卡（四大指数+两市成交+主力+组合当日盈亏）。

## 模块一 · 昨日市场分析

### 1.1 四大指数分析
表格（指数/收盘/涨跌幅/量能/结构与结论一行）：沪市上证、深市深成、科创50、创业板指；结构结论含缠论位置（中枢区间/关键位）一句 + 总量定性一句（如"权重护盘、成长杀跌、缩量分化——技术性回踩而非系统性转空"）。

### 1.2 美股市场（隔夜）
表格（对象/表现/对 A 股传导）：三大指数（道/纳/标普）、板块与事件（科技/光模块/IPO 等）、汇率商品（美元/离岸人民币/黄金/原油）；每条影响方向标注。

### 1.3 涨跌归因（每维度一行）
- 政策面：一行（事件+方向+来源分级）
- 行业消息：一行
- 资金流向：一行（主力净流入/流出 TOP、两融方向）
- 融资杠杆：一行（两融净偿还/净买入+资金情绪一句）

### 1.4 近期市场热点分析（2-3 条主线）
每条一行：主线名（性质：主线/防守线/主题线）→ 当日表现+资金证据 → 持续性判断+跟踪标的（已查证/一方称）。

## 模块二 · 今日资讯与预判

### 2.1 今日市场资讯（每类一句 · 附来源分级）
表格（类别/资讯/影响·分级）：政策宏观/外围市场/行业动态/资金情绪。

### 2.2 缠论分析
- **指数缠论研判**：沪/深 日线+15分钟 4 行表（收盘/走势类型/中枢区间/背驰状态/买卖点与关键位）+ 一句交叉结论。
- **重点个股缠论**：仅异动/放量/破位股（≤6 只），每只一行（完整版见模块三逐股档案，此处不重复展开）。

### 2.3 融资余额数据（10-XX 已公布 · T+1）
- 市场：两融/融资/融券余额（沪/深/京）、两融交易额与占 A 股成交比例、较前一日变化 → 一句资金情绪。
- 个股：重点异动股与权重前 5（融资净买入、融资余额、占流通市值比例、趋势）→ 一句杠杆行为结论。
- 宽基：6 指数一行（上证50/沪深300/中证500/中证1000/创业板指/科创50 收盘+涨跌）→ 一句风格结论。

### 2.4 今日走势预判（股指 · 可证伪）
表格（指数/方向/预期区间·关键位/依据+验证条件）：上证、深成、创业板指；方向=偏多/震荡/偏空；验证条件必须可证伪（收盘后验证）。

### 2.5 市场今日热点趋势（预判 2-3 条）
每条一行：主线名（概率评级）→ 预判逻辑（隔夜资讯+资金+技术位）→ 验证条件。

## 模块三 · 自选股逐股档案

### 3.1 分组
按 重点异动股（±3%/放量/破位/天量，通常 5-6 只）→ 常规个股 → ETF（净值口径）分组。

### 3.2 逐股档案卡片（核心）
每只股票一张卡片（两列 grid，`.grid2` 桌面两列/移动端单列），整合该股全部内容，**每行一个维度、只保留一行**：
1. 头部：代码 名称｜收盘 涨跌幅｜量比｜持仓盈亏
2. 技术位：S1｜R1｜突破位（破位股附"下看 S2"）
3. 缠论（v5.3）：**中枢 ZD-ZG（附 DD/GG）· 背驰状态（底/顶背驰·面积比）· 三类买卖点位置**（与价位重合位重点标注）；笔不足标「中枢待形成」
4. 量价（v5.3）：量价状态+关键信号（放量/天量/背离）+ **｜ATR X.XX% ｜RSI XX.X（背离标注）** + 印证一句
5. 资讯/融资：最新动态一行（来源·分级→影响方向）；融资余额（重点股）
6. 操作：价位+动作（低吸/减仓/观望/突破，不做风险提示话术）
7. 今日预测：方向+验证条件
8. **K线分析图（v5.2）**：卡片内嵌该股 90 日窗口 K 线图，容器 `<div class="kchart"><div id="k-CODE" class="chart"></div></div>`（仅个股，ETF 不产图）；渲染 JS 对每只个股直接 `buildKline('k-CODE', code, d)` 到卡片内容器（不再集中动态生成图卡）。

### 3.3 操作优先级（决策速览）
一行：T1 低吸（点名 3~4 只+价位）/ T2 低吸 / 减仓 / 破位警戒 各点名。

### 3.4 附节 · K线速览表与组合涨跌分布
- 速览表（15 行，ETF 不入表）：代码/名称/收盘/量比/方向着色/S1/R1。
- 组合涨跌分布图（chgChart：15 只个股涨跌幅横向条形图）。
- 每只个股 K 线分析图已嵌入模块三对应档案卡片，此节不再重复出图。
- 数据复用 scripts/gen_kline_data_v53.py（v5.3：K线包含处理/中枢四值/面积背驰/三类买卖点/ATR/RSI；兼容 v31 全字段，90 日窗口可复算），ECharts 内联本地文件、markArea 点级写法。

## 语言规范

- 用短句、一行式；专业术语准确（放量/破位/净偿还/底背驰等）。
- 数据必须带单位与口径（成交额亿元、涨跌幅%、融资数据日期、净值口径日期）。
- **精简**：删解释性长段、删重复表述；个股内容只在模块三出现一次，模块一/二不得重复展开个股明细（仅交叉引用）；只保留核心建议（价位+动作+方向）。
- 归因中的每个结论就近标注来源名+分级（已查证/一方称）。
- 复盘时如实标注未命中并附原因，不粉饰。
