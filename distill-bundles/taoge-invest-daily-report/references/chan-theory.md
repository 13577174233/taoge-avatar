# 缠绕（缠论）研判规范（v5.3）

## 定位

对持仓中的重点个股（异动/放量/破位/接近关键位）做缠论走势结构研判，输出"走势类型 + 中枢区间（四值）+ 背驰状态 + 三类买卖点位置"，与支撑压力位（technical-levels.md）互相印证。以日线级别为主，数据可得时可用 30/60 分钟线辅助确认。

## 算法基线（v5.3，scripts/gen_kline_data_v53.py 可复算）

**1. K线包含处理（缠论第 15 课，v5.3 新增）**

- 相邻两根 K 线存在包含关系（一根的高低点完全包住另一根：`h[i]>=h[j] and l[i]<=l[j]` 或反向）时先合并。
- 合并方向由前一根（非包含关系）决定：向上处理=取两根高点较高者与低点较高者；向下处理=取高点较低者与低点较低者。
- 分型基于**合并后 K 线**判定，避免毛刺分型（脚本输出 `merged_cnt`=合并次数，可复算）。

**2. 分型与笔**

- 顶分型：三根相邻合并 K 线，中间最高且低点也最高；底分型：中间最低且高点也最低。
- 笔：交替顶/底分型连线，间距≥2 根；同向分型取更极端值。
- 笔连线用于图内标注（图内减噪 v4.1：只画最近 3 笔）。

**3. 中枢四值（缠论第 20 课，v5.3 升级）**

- 中枢 = 至少 3 段次级别走势重叠区间（日线简化取最后 3 笔的重叠区间，笔≥4 端点）。
- 四值：`ZG = min(重叠段高点)`（中枢上沿）、`ZD = max(重叠段低点)`（中枢下沿）、`GG = max(全部笔段高点)`（中枢最高点）、`DD = min(全部笔段低点)`（中枢最低点）。
- 笔<4 端点时输出 null，图上标「中枢待形成」。
- 用法：现价>ZG 且回抽不破 ZG=三买候选区；现价<ZD 且反抽不回 ZD=三卖风险区；ZD~ZG 内=无明确三类买卖点。

**4. MACD 面积背驰（缠论第 24 课，v5.3 升级）**

- 取最近两个**同向**笔段为 A 段（更早）与 C 段（更近），另 B 段为中间反向段（A/B/C 三段）。
- 前提：MACD 黄白线（DIF/DEA）回拉 0 轴附近（面积法有效前提）。
- 标准背驰：C 段创出**新低/新高**，且 C 段 MACD 柱面积绝对值 < A 段柱面积绝对值（力度衰竭）→ 底背驰（下跌）/ 顶背驰（上涨）。
- 创新低但面积比>1 → 无背驰（下跌动能未衰竭）；不创新低 → 非标准背驰（暂不判）。
- 输出 `beichi.state ∈ {底背驰, 顶背驰, 无背驰, 新低未背驰, 新高未背驰}` + `beichi.area_ratio`（|C/A|，可复算）。

**5. 三类买卖点（缠论第 20 课，v5.3 升级）**

| 买卖点 | 买点 | 卖点 | 判定（可复算） |
|---|---|---|---|
| 第一类 | 一买=下跌段底背驰处（创新低且面积缩小） | 一卖=上涨段顶背驰处（创新高且面积缩小） | bsp_v53 底背驰+新低 |
| 第二类 | 二买=一买后回调低点不破前低 | 二卖=一卖后反弹高点不创新高 | 同向低点>前低 / 高点<前高 |
| 第三类 | 三买=向上突破中枢 ZG 后回抽不破 ZG | 三卖=向下跌破 ZD 后反抽不回 ZD | 中枢四值边界 |

## 均线缠绕（"吻"）速查

- 男上位：K 线运行于短期均线下方（弱势）；女上位：K 线运行于短期均线上方（强势）。
- 缠绕分型：湿吻（均线反复缠绕，常对应中枢震荡）、飞吻/唇吻（短线上穿后快速离开，趋势延续信号）。
- 判定：MA5 与 MA10（或 MA10 与 MA20）的缠绕状态 + K 线与均线位置关系。

## 每日研判流程（对重点股）

1. 辨走势类型：根据近 20 日高低点与中枢位置判断上涨/下跌/盘整。
2. 划中枢四值：ZG/ZD/DD/GG（脚本自动，可复算）。
3. 查背驰：对比 A/C 段 MACD 柱面积（面积比<1 且创新低/新高=背驰）。
4. 定买卖点：对照三类买卖点特征，给出当前所处位置（如"一买候选"）。
5. 结合技术位：缠论中枢上下沿与支撑/压力位（technical-levels.md）交叉验证，取重合区间为有效位，重合位在日报中重点标注。

## 输出格式（v5.3 精简）

每只重点股 1 行：「中枢 ZD-ZG（附 DD/GG 或省略）· 背驰状态 · 买卖点位置 + 关键价位」。示例：
- "中枢 9.58-10.47（DD 9.32）破位下行·反弹顶背驰（10.5 动能衰竭）·一卖候选；缩量回踩 9.27 止跌再低吸"
- "中枢 26.33-27.43·底背驰·一买候选（缩量回踩中枢下沿企稳）"

## 质量约束

- 缠论结论为技术研判参考，与基本面/资金面归因并列呈现，不单独作为操作依据。
- 分型/笔/中枢/背驰/买卖点必须由 scripts/gen_kline_data_v53.py 从实际 K 线数据判定（可复算）；数据不足（如次级别无法确认）时标注"待确认"。
- 不引用"玄学/预测"式表述，只输出可验证的结构判断。
