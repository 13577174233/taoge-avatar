# 融资余额与市场宽基数据规范（v5.0）

## 定位

盘前日报新增两个数据模块：**市场融资余额**（杠杆资金总量与方向）、**个股融资余额**（持仓标的杠杆资金趋势）、**市场宽基**（大小盘风格强弱）。数据必须可追溯、标注日期口径，未获取不凑数。

## 一、市场融资余额

### 数据源（已实测可用，2026-10-27）

- **主源**：东方财富数据中心「融资融券」页 `https://emdata.eastmoney.com/rzrq/index.html`（服务端渲染，web_fetch 可抓）。
- 抓取要点：页面标注「更新于 YYYY-MM-DD」（两融数据 T+1 公布，盘前用最近已公布日并标注日期）。
- 字段（表格「两融余额/融资余额/融券余额/两融交易额/融资买入额/融券卖出额」，分 全部/沪市/深市/京市 列）：
  - 两融余额（亿）、融资余额（亿）、融券余额（亿）
  - 两融交易额（亿）+ 占 A 股成交额比例（页内另有「截止 X 日，两融余额 X 亿，占 A 股流通市值 X.XX%，两融成交额 X 亿，占 A 股成交额 X.XX%」）
  - 融资买入额（亿）
- 变化口径：与上一公布日（前一日）比较——融资余额增减额=当日-前日；净偿还（减少）或净买入（增加），并给方向结论（如"连续 N 日净偿还，杠杆资金观望/撤离"）。
- 备用：证券时报数据中心 `https://www.stcn.com/dc/jcgj.html?tabIndex=1`（两融余额/融资余额/融券余额+环比），金融界两融新闻（今日头条转载）作交叉验证。

### 输出格式（1 屏内）

```
市场融资余额（数据日 10-26，T+1 公布）：两融 24261.79 亿（沪 12533/深 11650/京 78）· 融资 23970.69 亿（较 10-23 净偿还 55.94 亿）· 两融成交 1277.06 亿（占 A 股 7.86%）→ 融资连续净偿还，杠杆资金观望（东财数据中心·已查证）
```

## 二、个股融资余额

### 数据源（已实测可用）

- **新浪财经 AI 两融数据文章**：`finance.sina.com.cn/stock/aiassist/lr/...`，标题形如「XX：X月X日获融资买入X亿元，融资余额X亿元占流通市值X%，超过近一年X%分位水平」，含 融资买入/偿还/净买入、融资余额、占流通市值比例、分位。
- **证券之星/金融界**：`news.stockstar.com` 与今日头条转载「XX(X日)主力资金净卖出X万元」文末含融资融券信息（当日融资买入/偿还/净买入、融资融券余额、近5日一览）。
- 检索关键词：「代码 名称 X月X日 融资买入 融资余额 净偿还」。
- 覆盖范围：**重点异动股（±3%）与持仓权重前 5 必查**，其余按需；每日约 3-6 只即可，未获取标"未获取"。

### 输出格式（一行式）

```
诺德股份：10-26 融资净买入 +65.01 万、两融余额 5.14 亿（证券之星·已查证）
中天科技：10-26 融资净买入 -3997.37 万、融资余额 47.30 亿、占流通市值 5.20%、超近一年 50% 分位（新浪财经·已查证）
```

### 与量价/资金面印证

- 融资净买入+价涨量增 → 杠杆资金助推，趋势延续概率高；
- 融资净偿还+价跌量增 → 杠杆撤离+恐慌盘，弱势确认；
- 融资余额连续 N 日下降但价缩量止跌 → 抛压减轻，底部企稳候选（与量价研判交叉）。

## 三、市场宽基指数

### 数据源（已实测可用）

- 腾讯行情接口（与个股 K 线同一通道）：`https://ifzq.gtimg.cn/appstock/app/fqkline/get?param={code},day,,,10,qfq`，返回末根含日期/开/收/高/低/量。
- 标的 6 只：上证50 `sh000016`、沪深300 `sh000300`、中证500 `sh000905`、中证1000 `sh000852`、创业板指 `sz399006`、科创50 `sh000688`。

### 输出格式（表格+一句结论）

| 指数 | 收盘 | 当日涨跌 | 近5日 |
|---|---|---|---|
| 上证50 | 2769.05 | +0.41% | +1.2% |
| 沪深300 | 4103.54 | -0.04% | +0.1% |
| 中证500 | 6712.73 | -1.49% | -2.8% |
| 中证1000 | 6630.78 | -1.54% | -3.1% |
| 创业板指 | 2638.23 | -1.71% | -3.5% |
| 科创50 | 1315.50 | -2.23% | -4.2% |

结论句：**大盘价值（上证50/沪深300）抗跌、中小成长（中证500/1000/创业板/科创50）回调 → 风格偏向大盘价值/红利，与涨跌归因中"权重护盘、科技杀跌"印证**（方向按当日实际数据）。

## 质量约束

- 融资余额数据标注数据日期（T+1）；不得用旧数据冒充当日。
- 个股融资余额只列已查证标的，未获取标注"未获取"，禁止编造。
- 宽基近 5 日涨跌由实际日线计算，可复算。
- 融资/宽基结论须与量价研判、涨跌归因交叉印证后输出，单一数据不单独定论。
