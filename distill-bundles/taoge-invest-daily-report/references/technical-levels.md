# 次日技术位测算与操作参考规范（v3.2）

## 目的

为每只持仓股给出次日可执行的支撑位、压力位、突破位与参考买卖点，形成"价位参考 + 操作动作"的直接建议（用户明确要求：不做风险提示话术，直接给价位与动作）。

## 数据输入（Step 2.5）

- 近 60 个交易日 OHLC（开高低收）：用腾讯行情接口日线 130 根（scripts/data_raw_v32.py）获取；数据缺失时标注"数据受限"，不得编造。
- ETF/基金：用其跟踪指数近 60 日 OHLC 或净值序列同规则测算，标注口径。
- 派生指标：MA5 / MA10 / MA20（收盘价移动平均）、近 5 日最高 H5 / 最低 L5、近 60 日最高 H60 / 最低 L60、近 5 日均量（成交量）。

## 价位测算规则（可复算）

| 价位 | 计算规则 | 说明 |
|---|---|---|
| 支撑位 S1 | 近 5 日最低价 L5 | 短线第一支撑 |
| 支撑位 S2 | MA20（当 MA20 < 现价时），否则取 L60 | 中期支撑 |
| 压力位 R1 | 近 5 日最高价 H5 | 短线第一压力 |
| 压力位 R2 | MA20（当 MA20 > 现价时），否则取 H60 | 中期压力 |
| 上行突破位 | R1（收盘站稳 R1 上方，且当日成交量 ≥ 近 5 日均量 × 1.5） | 放量突破确认 |
| 下行破位位 | S1（收盘跌破 S1） | 破位确认 |

## 买卖点参考规则

| 场景 | 触发条件 | 操作参考 |
|---|---|---|
| 回踩买点 | 现价回落至 S1~S2 区间，且当日缩量（量 ≤ 近 5 日均量 × 0.8）止跌，配合 KDJ 低位金叉/MACD 绿柱缩短 | 参考买点 = S1 |
| 突破买点 | 放量（≥ 近 5 日均量 × 1.5）突破 R1 并站稳 | 参考买点 = R1 上方 1~2% 价位 |
| 冲高卖点 | 上行至 R1~R2 区间，放量滞涨（量增价不涨），配合 KDJ 高位死叉/MACD 红柱缩短 | 参考卖点 = R1 |
| 破位卖点 | 收盘跌破 S1 | 参考卖点 = S1 价位（破位离场） |

## 操作建议输出格式（v3.2）

每只股一句，格式：「[动作]：价位 + 触发条件」。日报表中参考买点=round((S1+现价)/2,2)（S1<现价时，否则=S1）、参考卖点=round((R1+现价)/2,2)（R1>现价时，否则=R1），可复算。示例：
- "回踩 21.5~21.6 缩量止跌可低吸，参考买点 21.6；冲高 22.8 放量滞涨可减，参考卖点 22.8；收盘破 21.2 离场。"

## 质量约束

- 所有价位必须由上述规则从实际数据算出；规则外调整（如整数关口、跳空缺口）需注明依据。
- 未获历史数据时：标注"数据受限"，只给方向性表述，不硬凑数字。
- 测算结果写入日报"次日操作参考"表：代码/名称/现价/支撑位/压力位/突破位/参考买点/参考卖点/操作建议。
