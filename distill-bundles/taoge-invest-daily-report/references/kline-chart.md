# K线分析图规范（v3.2）

> v4.3 增补（2026-10-16）：本规范在 v4.1 基础上新增「波浪理论标注」。实际执行以 90 个交易日窗口 + 两列网格 + 图内减噪（v4.1）为准，本文件顶部旧 v3.2 双图/MACD 内容为历史规范，执行时以任务 query 的 v4.1/v4.3 要求与下方「波浪理论标注」节为准。

## 波浪理论标注（v4.3 新增）

### 定位

在九节「K线分析图集」每只个股图内（90 个交易日窗口），用艾略特波浪理论（5-3 结构）标注最近一段推动浪与调整浪，一图看懂"当前处于大结构的哪一浪"。ETF 不做图形分析，不产图。

### 算法（确定性、可复算）

- 输入：90 日窗口内缠论笔端点序列（scripts/gen_kline_data_v31.py 已算好的 pens）。
- 输出（scripts/wave_theory.py，独立模块，gen_kline_data_v31.py 自动调用）：
  - `waves.status`：状态文本（如"下降推动第5浪（末端），调整待确认"、"上升推动完成·B浪中（第5浪延长）"）
  - `waves.trend`：上升推动 / 下降推动
  - `waves.points`：[{i, price, label}]，label ∈ 1/2/3/4/5/A/B/C
  - `waves.segs`：波浪连线段
- 识别规则（简化艾略特）：
  1. 推动浪 = 5 段方向交替（up/down/up/down/up 或反向），从窗口最近端向前找最近的完整结构。
  2. 第 3 浪 = 与第 1 浪同向的推动段（1/3/5）中价格绝对位移最大者；最大位移在第 1 段 → "第1浪延长"、第 5 段 → "第5浪延长"。
  3. 调整浪 A/B/C = 推动浪末段之后的反向交替段（A 与第 5 浪反向）。
  4. 笔 < 5 或找不到 5-3 结构 → status="待确认（笔不足）/（无 5-3 结构）"，图上不画波浪连线，标题行仅显示状态。
- 数据字段：`kline_data_v31.json` 每只个股含 `waves`，与 MA/S1/R1/缠论标注同源可复算。

### ECharts 实现

- 波浪连线：独立 line series（data=waves.points 映射到 xData 位置，其余 null + connectNulls），橙色 #f97316、宽 1.6。
- 浪点标签：markPoint（并入 K线 series 的 markPoint.data），圆形 symbolSize 14、橙色、白字 label（1/2/3/4/5/A/B/C）、position inside。
- 图卡标题行（kh）在「中枢」之后追加「波浪：{status}」，橙色 #ea580c；速览表不新增列（保持 v4.1 减噪）。
- 渲染注入点在构建脚本（build_html_XXX_am.py）：`series.push({name:'笔',...})` 锚点后插入波浪系列，`'<span class="kv">中枢 '+zs+'</span>'` 锚点后插入标题行状态。

## 目标

为**每只持仓个股生成两张 K 线分析图——60日线分析图 + 60周线分析图**，把复盘内容（均线、支撑压力、缠论结构、买卖点、量能、MACD/KDJ/RSI/BOLL 指标状态）全部标注在图内，并给出**买点/卖点建议价位线**，实现"一图看懂复盘"。**ETF 不做图形分析**（仅进行情总览表，净值口径）。

## 数据与可复算

- 数据源：`scripts/data_raw_v32.py`（腾讯行情接口 不复权，每只 日线130根 + 周线130根，2026-10-10 采集；10-09 收盘价/成交量与同花顺口径对账一致；量单位=股）。
- 生成：`python3 scripts/gen_kline_data_v32.py <输出.json>` → 每只个股输出 `{code, name, day:{60日窗口}, week:{60周窗口}}`，每周期含：K线 + MA5/10/20/21/99 + S1/S2/R1/R2/突破位 + 近5周期区间 + 缠论分型/笔/中枢 + 历史买卖点 + 量比 + **MACD/KDJ/RSI/BOLL 序列与信号 + 买点建议/卖点建议（价位+触发条件）**。
- 图形窗口=**近60个交易日 / 近60周**（指标与均线在 130 根/130周全量上计算，图上截取后 60 根；MA99 在窗口内后 32 根有效）。
- 数据受限时标注口径，不得编造。

## 指标模型（v3.2 引入，联网学习采纳）

| 指标 | 参数 | 用途 |
|---|---|---|
| MACD | (12,26,9)，BAR=(DIF-DEA)×2 | 趋势/柱体动能，红柱伸长=多、绿柱缩短=空头衰竭 |
| KDJ | (9,3,3)，J=3K-2D | 超买(>80/J>100)/超卖(<20)与金叉死叉 |
| RSI | (6,12,24)，简单均值 | 超买(>70)/超卖(<30) |
| BOLL | (20,2)，MID=MA20，UP/LOW=MID±2σ | 价格相对轨道位置（上轨上方=超买区/下轨下方=超卖区） |

- **共振买卖规则**：MACD+KDJ 双金叉 → 共振买点信号；双死叉 → 共振卖点信号；单一指标金叉/死叉 → 趋势待确认。
- **买点建议**：现价回踩 S1~S2 区间缩量止跌 + KDJ 低位金叉 / MACD 绿柱缩短 → 参考买点 = S1。
- **卖点建议**：现价冲高 R1~R2 区间放量滞涨 + KDJ 高位死叉 / MACD 红柱缩短 → 参考卖点 = R1。
- 建议价位线（S1/R1）直接画入图中（实线 + label「买点建议/卖点建议」）。

## ECharts 实现规范（单文件 HTML 内嵌）

### 通用设置
- 数据序：`[open, close, low, high]`（ECharts candlestick 官方顺序，交换 close/low 是常见渲染错误）。
- A股配色：阳线红（#d43a3a）、阴线绿（#1a9e5c）。
- **三 grid 布局**：主图（K线+均线+标注，高 50%）+ 量能副图（bar，高 13%）+ **MACD 副图**（bar+DIF/DEA 线，高 13%），三 x 轴联动（同一 dataZoom 控制 3 个 xAxisIndex）。
- dataZoom（inside+slider）+ tooltip axisPointer cross；日期标签显示 MM-DD；tooltip 展示 开/收/低/高/涨跌/量/MACD/KDJ/RSI。

### DK 点标注（v4.4，东方财富「DK操盘密码」风格，可复算）

东财 app 日线图在 K 线上标 D（买）/K（卖）提示机会与风险。本技能以可复算规则近似实现（MACD 改良 + 量价确认）：

| 点位 | 判定规则（在 90 日窗口内） | 样式 |
|---|---|---|
| D 点（买入机会） | 底分型成立，且满足任一：①低点 ≤ S1×1.02（接近支撑）②后 3 根内 MACD 金叉（DIF 上穿 DEA）③当日缩量（量 ≤ 近5日均量×0.8）且收阳 | 绿圆白字「D」，标于对应 K 线下方 |
| K 点（卖出风险） | 顶分型成立，且满足任一：①高点 ≥ R1×0.98（接近压力）②后 3 根内 MACD 死叉（DIF 下穿 DEA）③当日放量（量 ≥ 近5日均量×1.5）且收阴/长上影 | 红圆白字「K」，标于对应 K 线上方 |

- 数据字段：`dk: [{i, price, type:'D'|'K'}]`，由 `scripts/gen_kline_data_v31.py`（`dk_points()`）生成，排序按 i。
- 渲染减噪：只标最近 3 个 D 与最近 3 个 K（`lastN(dkD,3)` / `lastN(dkK,3)`）；无 dk 字段时回退到原 buy/sell（B/S）。
- 兼容：`fractals`/`buy`/`sell`/`pens` 字段保留（缠论笔/中枢仍需分型），但**图上不再标注顶▲/底▼分型**。

### 缠论简化算法（60根窗口，可复算）
- 顶分型：`h[i]>h[i-1] and h[i]>h[i+1] and l[i]>l[i-1] and l[i]>l[i+1]`
- 底分型：`l[i]<l[i-1] and l[i]<l[i+1] and h[i]<h[i-1] and h[i]<h[i+1]`
- 笔：交替顶/底分型，间距≥2 根；同向分型取更极端值。
- 中枢：最后 3 笔重叠区间 `[max(每笔低点), min(每笔高点)]`；笔<3 时输出 null，图上标「中枢待形成」。
- 背驰：简化对比最近两个同向分型处成交量/跌幅斜率，仅作文字标注。

### 数据受限处理
- ETF/基金：不做图形分析（净值口径仅进总览表，标注 T+1）。
- 历史K线缺失个股：数据源正常时走完整 K 线；仍缺失才用当日分时，标注「历史K线数据受限」。
- 买卖点规则：底分型低点 ≤ S1×1.02 → 历史买点 B；顶分型高点 ≥ R1×0.98 → 历史卖点 S；无满足分型则不标。

## 输出位置

日报「K线分析图集」小节（每只两张图：60日线图在上、60周线图在下，按持仓清单顺序），置于「技术指标研判（v3.2）」之后。卡片标题含：代码/名称/当日涨跌幅/收盘/量比/S1/R1/突破位/中枢/买点建议/卖点建议，卡片内另两行展示日线与周线的 MACD/KDJ/RSI/BOLL/共振信号状态。

## 质量约束

- 图中每个数字必须来自 kline_data_v32.json（可复算）；图与「次日操作参考」「技术指标研判」「缠论与量价研判」数值交叉一致。
- 标注不足（如分型太少）时保留 MA+S/R+区间+指标副图，不强行画缠论结构。
- 图表交互（tooltip/dataZoom）须可用；生成后按 html skill 跑 shot.py 自检。
