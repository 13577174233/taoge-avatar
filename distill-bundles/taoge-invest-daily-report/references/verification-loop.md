# 预测-验证闭环（v2.0）

## 目的

把"当日归因+明日信号"变成可检验的闭环：每日给 1-2 条可证伪信号，次日复盘命中情况，持续校准归因质量与前瞻能力。

## 信号规范（Step 4.5）

每条信号必须包含三要素：
1. **方向明确**：如"电子板块净流出收窄则退潮暂缓，否则延续"——不可写成"关注电子板块"。
2. **可证伪**：带量化阈值或明确现象（缩量止跌/放量上攻/资金收窄至 X 亿内）。
3. **判断依据**：引用当日归因（资金流向、板块结构、催化事件），说明为什么这个信号能证伪。

## 复盘规范（Step 6）

- 次日首节"昨日信号验证"：逐条标注 命中 / 部分命中 / 未命中 + 一句原因。
  - 命中：信号所述现象出现，且与判断方向一致。
  - 部分命中：方向对但幅度/个股/时间有偏差（如"板块对但个股歇脚"）。
  - 未命中：现象未出现或方向相反，如实标注，不粉饰。
- 每周日周度复盘：命中率 =（命中+部分命中）/ 信号总数；同步复盘归因质量三项：异动识别（±3% 捕捉是否完整）、板块判断（领涨领跌是否命中）、前瞻能力（事件是否点名到具体对象）。

## 已验证示例（2026-10-08 信号 → 10-09 实际）

| 10-08 日报判断 | 10-09 实际走势 | 结果 | 原因 |
|---|---|---|---|
| 资金高低切换：高位科技→低估值防御/电力化工 | 电子净流出 70 亿、算力硬件领跌；资金转向传媒/AI应用、电池、消费 | 命中 | 切换方向延续，主角由防御转向新热点 |
| 特变电工电力设备净流入+AI 电力扩散 | 电力设备净流入 21.67 亿（行业第二），但特变 -0.28% 歇脚 | 部分命中 | 板块对、个股节奏未延续 |
| 诺德电池净流入+铜箔提价逻辑 | 诺德 -3.25% 放量回吐；PET铜箔/覆铜板走弱 | 未命中 | 电池终端强但材料环节滞后，结构分化 |
| 商络电子 PCB/MLCC 链放量破位 | 商络 -2.07% 续跌 | 命中 | 链退潮延续 |
| 潍柴 H 股重挫归因待验证 | H 股再 -1.48%（恒指大涨下仍弱） | 部分命中 | 独立走弱确认，具体原因仍待验证 |
| 组合科技仓集中与切换相悖 | 立讯 -1.73%、中天 -1.31%、商络 -2.07% 续弱 | 命中 | 科技硬件仓连续两日跑输 |
| 未点名 AI 应用方向 | 10-09 传媒/AI 应用大爆发（蓝色光标 +6.80%、芒果超媒涨停） | 未命中 | 前瞻缺口：当日有芒果 AIGC 落地、出版规划催化信号未纳入 |

统计：命中 3 / 部分 2 / 未命中 2，有效命中率 5/7（71%）；其中前瞻类判断（点名具体催化）最弱。

## 常见偏差模式（复盘时优先检查）

1. **板块对、个股歇脚**：行业资金流入但组合个股次日回调——需在信号中加个股节奏条件（量能/均线）。
2. **材料环节滞后于终端**：电池终端涨而铜箔/PET 材料跌——产业链内部传导有时滞，归因时区分环节。
3. **前瞻未点名具体催化**：只写"关注风格切换"而未识别事件（AI 应用、财报、评级）——Step 4 强制事件点名。
4. **ETF 净值 T+1 失真**：净值滞后导致当日"无涨跌"——用跟踪指数估算补充，标注口径。
