# 盘前日报规范（v5.2 三模块制 · 每股内嵌 K 线图）

## 定位

每日 **8:30** 触发（A 股开盘前）生成「盘前日报」，页面按 **三模块制** 组织（v5.1 重构）：

- **模块一 昨日市场分析**：四大指数（沪/深/科创/创业）→ 美股市场 → 涨跌归因 → 近期市场热点分析。
- **模块二 今日资讯与预判**：今日市场资讯 → 缠论分析（指数+重点个股）→ 融资余额数据 → 今日走势预判（股指）→ 市场今日热点趋势。
- **模块三 自选股逐股档案**：按个股整合该股全部内容（行情/技术位/缠论/量价/资讯融资/操作/今日预测），K线图集附于模块末尾。

盘前版侧重"昨夜至今晨的新信息 + 基于前日走势对今日的预判"，预测必须可证伪、当日收盘后验证。

## 三模块内容规范

### 模块一 · 昨日市场分析
- **1.1 四大指数分析**：沪市上证/深市深成/科创50/创业板指，每指数一行：收盘+涨跌幅+量能+结构与关键位（含缠论位置一句）。
- **1.2 美股市场**：隔夜三大指数（道/纳/标普）、板块与事件（科技/光模块/IPO）、汇率商品 → 对 A 股传导方向。
- **1.3 涨跌归因**：政策面/行业消息/资金流向/融资杠杆，每维度一行（事件+方向+来源分级）。
- **1.4 近期市场热点分析**：2-3 条主线（主线/防守线/主题线）→ 当日表现+资金证据 → 持续性+跟踪标的。

### 模块二 · 今日资讯与预判
- **2.1 今日市场资讯**：政策宏观/外围市场/行业动态/资金情绪，每类一句（附来源·分级·影响方向）。
- **2.2 缠论分析**：指数缠论 4 行表（沪/深 日线+15分钟：收盘/走势类型/中枢区间/背驰状态/买卖点与关键位）+ 一句交叉结论；重点个股缠论 ≤6 只每行一句（完整版见模块三档案）。
- **2.3 融资余额数据**：市场两融（余额/净偿还/成交占比）+ 个股融资（重点异动股必查）+ 宽基 6 指数一句风格结论；按 [references/funding-broadbase.md](references/funding-broadbase.md)。
- **2.4 今日走势预判（股指 3 指数）**：每指数一行：
  `上证：震荡偏多，预期区间 3660-3720，关键位 3664.82/3700；依据=10-26 缩量分化+权重护盘+隔夜美股存储光通信大涨；验证=放量站稳 3700 且成交回升 1.9 万亿→延续看 3720；缩量破 3664.82→转弱下探 3648`
  结构：方向（偏多/震荡/偏空）+ 预期区间 + 关键位 → 依据（前日走势结构+隔夜资讯，一句）→ 验证条件（可证伪）。
- **2.5 市场今日热点趋势**：2-3 条预判主线（概率评级）→ 预判逻辑 → 验证条件。

### 模块三 · 自选股逐股档案
- 分组：重点异动（±3%/放量/破位/天量）→ 常规 → ETF（净值口径）；**个股排序固定 重点异动→常规**（v5.2）。
- **每只股票一张卡片**，8 行维度（整合该股全部内容，每行一行）：
  1. 头部：代码 名称｜收盘 涨跌幅｜量比｜持仓盈亏
  2. 技术位：S1｜R1｜突破位（破位股附"下看 S2"）
  3. 缠论：走势类型+中枢+三类买卖点位置（与价位重合位重点标注）
  4. 量价：量价状态+关键信号+印证
  5. 资讯/融资：最新动态一行（来源·分级→影响方向）+ 融资余额（重点股）
  6. 操作：价位+动作（低吸/减仓/观望/突破）
  7. 今日预测：方向+关键位+触发预案+验证条件（每只一行）：
  `000338 潍柴：偏多（增持托底+缩量回踩）；S1 20.14/R1 21.59；回踩 20.14 缩量低吸（20.64）、放量冲 21.59 减仓；验证=收盘站稳 21.59 且量>1.5 倍 5 日均量→看多延续`
  8. **K线分析图（v5.2）**：卡片内嵌该股 90 日窗口 K 线图（容器 id=k-CODE，`buildKline('k-CODE', code, d)` 渲染到卡片内容器；仅个股，ETF 不产图）。
- 预测依据必须显式引用前日走势（K 线结构+技术位+量价缠论+隔夜资讯交叉）。
- **操作优先级**：一行（T1/T2 低吸/减仓/破位警戒各点名 3~4 只+价位）。
- **附节 · K线速览表与组合涨跌分布**：速览表（15 行，ETF 不入表）+ chgChart 组合涨跌分布图；每只个股 K 线图已嵌入各档案卡片（v5.2），此节不再重复出图。
- 个股内容只在模块三出现一次，模块一/二不得重复展开个股明细。

## 数据与质量约束

- 盘前时点部分行情（美股/期指/融资余额）可能 T+1：标注口径（如"隔夜美股=最近一个交易日""两融=10-26 已公布"），不得用旧数据冒充。
- 每条资讯附来源与分级；证据不足明示，禁止编造。
- 预测与操作预案只给价位与动作（用户要求不做风险提示话术）；预测必须可证伪（验证条件+时间窗口=当日收盘）。
- 输出 HTML 按日归档 自选股日报/自选股行情日报_YYYYMMDD.html（盘前版与盘后版同日共存时按任务 query 指定处理）。
