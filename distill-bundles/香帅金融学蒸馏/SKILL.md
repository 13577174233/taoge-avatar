# 香帅金融学蒸馏（跨项目认知包）

> **一句话定位**：266篇课程正文蒸馏成一张可调用的金融认知地图——三要素看本质，八板块对位置，J模型给判断。
> **核心原理**：金融 = 时间 × 风险 × 杠杆；所有金融产品/现象/机构都是这三要素的不同组合。

---

## 一、金融三要素（先抓本质）

| 要素 | 核心问题 | 关键模型 | 一句话 |
|---|---|---|---|
| **时间** | 今天的钱和明天的钱差多少？ | J03时间价值/J071复利/J069债成本 | 远期承诺必折现；利率=时间的价格；复利=时间杠杆 |
| **风险** | 不确定性怎么定价？ | J108方差偏度肥尾/J122夏普比率/J111投资投机 | 收益必须配风险看；肥尾比正态分布更常见；零和博弈先识别 |
| **杠杆** | 借别人的钱放大收益/风险？ | J056债务通缩/J196委托代理/J220明斯基时刻 | 杠杆放大收益也放大危机；委托代理是公司治理根源；稳定孕育不稳定 |

**三实判断法**：列事实（数据/价格/利率）→ 归现实（三要素哪个在驱动）→ 达共识（行动/估值/风险位）。

## 三、关键模型速查（J系列高频）

| 场景 | 模型 | 一句话 |
|---|---|---|
| 算现值 | J03时间价值律 | 远期收益按利率折现，赠品/返利/积分全要折算 |
| 看风险 | J108方差偏度肥尾律 | 标准差≠全部风险；左尾事件比你想的频繁 |
| 评收益 | J122夏普比率律 | (收益-无风险利率)/波动率=风险调整后收益，越高越好 |
| 选资产 | J126规模价值因子/J127动量因子 | 小市值/低估值有溢价；追涨杀跌在A股短期有效长期失效 |
| 看市场 | J131有效市场律/J143修正 | 价格已反映大部分信息，但行为偏误造成系统性错位 |
| 防偏误 | J146过度自信/J156前景理论/J161羊群效应 | 单身男性交易过度频繁；损失厌恶=收益厌恶的2.5倍；模仿跟风有理性基础但会成灾 |
| 看公司融资 | J173 MM定理/J172优序融资 | 融资结构影响价值；内部融资>债>股（老干妈不上市逻辑） |
| 看分红回购 | J176分红/J177回购 | 分红=现金分配信号；回购=低估信号；高送转=数字游戏 |
| 看IPO | J181 IPO/J183抑价/J186溢价 | A股热衷上市=壳价值+融资便利；IPO首日抑价=信息不对称补偿 |
| 看并购 | J191并购逻辑/J194并购股价 | 并购=企业二手交易；溢价多来自协同预期，散户难赚 |
| 看治理 | J196委托代理/J198道德风险/J199大股东 | 管理层≠股东利益；大股东可隧道挖掘；股权激励是缓解手段 |
| 看危机 | J216信用崩塌/J218危机本质/J220明斯基 | 危机=信用周期破裂；现金为王；杠杆反转时无差别抛售 |
| 看科技金融 | J224科技金融/J226数据驱动/J236区块链 | 数据+算法=新风控；平台生态=网络效应；区块链=分布式信任但效率低 |

## 四、饕哥三场景应用范式

### 场景1：冠生园电商（昆明冠生园电商事业中心）
- **账期/预付/返利**：一律按J03折现到今天算真实成本（供应链占款=时间成本）
- **达播负毛利**：佣金42%>毛利=杠杆放大亏损；净ROI≥1:2才放量（J122风险调整后收益门槛）
- **礼盒净利率6-8%**：风险调整后收益过低，双轨货盘（礼赠+自食小克重）分散
- **低糖云腿爆品**：消费升级趋势下的"成长型资产"（J119估值逻辑：高增速给溢价）

### 场景2：18只A股持仓（每日8:30日报）
- **个股估值**：绝对估值（现金流折现J117）+相对估值（PE/PB J118）+成长型（PEG J119）三法互验
- **风险段**：J108方差偏度肥尾——单票仓位≤20%，左尾对冲用ETF
- **择时vs选股**：J148-J149——普通投资者择时能力≈0，专注选股+长期持有
- **行为纠偏**：日报末尾加"偏误扫描"——是否过度自信（加仓频繁）/羊群（追热点）/损失厌恶（死扛亏损股）

### 场景3：唐翌轩教育（2029届高考）
- **教育投资=长期复利**：J03——越早投入的认知/健康/能力，复利效应越大
- **选专业=资产配置**：J63分散原则——不把所有筹码押在单一热门专业
- **风险偏好匹配**：J107——孩子性格（稳/闯）决定专业风险敞口，不逆着天性选

## 八、金融判断五步 SOP（跨项目复用）

遇到"钱怎么算/风险多大/值不值得投/危机来了吗"类问题时按序走：

1. **抓三要素（J03/J108/J056）**：这笔交易在加工时间、分散风险、还是放大杠杆？哪个要素在主导？
2. **对板块位置（八板块表）**：问题属于机构/工具/投资者决策/公司决策/监管科技哪一块？用该板块的高频模型套。
3. **定估值锚（J117/J118/J119）**：绝对（现金流折现）+相对（PE/PB）+成长（PEG）三法互验，明确估值区间。
4. **测风险边界（J108/J122/J220）**：波动率/偏度/肥尾是什么？风险调整后收益（夏普）达标吗？明斯基信号（杠杆/信贷/资产价格）亮灯了吗？
5. **落饕哥三场景（电商/投资/教育）**：结论→证据→行动项，三场景至少落一个可执行动作。

输出格式：结论先行 → 每步证据（J编号）→ 落点行动项。
