## 二、五门课速查（53 条律：DMS 12 / ALG 15 / MCC 8 / REG 8 / TIM 10）

### 离散数学概论（陈斌，第 26—27 集，约 17.5 小时）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| DMS01 | 语法优先律 | 离散数学不教「算什么」，教「怎么严谨地说」；符号规则是所有算法描述的共同语法 |
| DMS02 | 集合地基律 | 集合、映射、关系、函数是一条链，后面所有结构都是这条链的加料 |
| DMS03 | 关系即结构律 | 等价关系切分世界，偏序关系排定层次；先认关系类型，再谈结构 |
| DMS04 | 证明四式律 | 直接、反证、归纳、构造，四式之外别无他法；写不出证明通常是没选对式 |
| DMS05 | 归纳锚点律 | 数学归纳法的力气全在「奠基 + 递推」两步，跳过奠基的证明一律无效 |
| DMS06 | 计数两问律 | 先问「是否有序」再问「是否可重复」，四象限定完才选公式 |
| DMS07 | 鸽笼存在律 | 存在性命题不靠构造，靠容量矛盾；抽屉原理是「证明有，但说不出是哪个」 |
| DMS08 | 图即关系律 | 图是把二元关系画出来；路径、连通、着色都是在问关系的传递与冲突 |
| DMS09 | 树无环律 | 树的定义是「连通且无环」，n 个点 n-1 条边是结论不是定义 |
| DMS10 | 布尔代数律 | 逻辑运算与集合运算同构，德摩根律在两处通用 |
| DMS11 | 复杂度前置律 | 渐进记号（O/Ω/Θ）在离散课上先立规矩，算法课才有共同语言 |
| DMS12 | 抽象代价律 | 代数结构（群/环/域）抽象度最高、直觉最弱，非科班按需取用即可，不必硬啃 |

### 大数据分析中的算法（文再文，第 35—39 集，约 6.7 小时）

官方章节（标题原文）：第一章 课程简介与大数据分析的最优化理论；第二章 线性规划、二次锥规划、半定规划；第五章 压缩感知与稀疏优化基本理论；第六章 稀疏优化算法；第八章 最优运输算法；第九章 随机优化算法；第十章 随机特征值算法；第十一章 图与网络流（最短路径、最大流、组合优化）；第十三至十五章 强化学习。

| 编号 | 模型名 | 一句话 |
|---|---|---|
| ALG01 | 优化统一律 | 大数据算法九成可写成「min 目标 + 约束」，先认目标函数形态再选算法 |
| ALG02 | 凸性分界律 | 凸问题有全局最优且可解，非凸只能求局部；判断凸性是选算法的第一道闸 |
| ALG03 | 线性规划律 | 线性目标 + 线性约束，解必在顶点；单纯形与内点是两条路径，不是两个答案 |
| ALG04 | 锥规划升级律 | 二次锥/半定规划把约束从「线性」放宽到「锥」，表达力换求解成本 |
| ALG05 | 稀疏先验律 | 压缩感知成立的前提是「信号本身稀疏」，不是算法神奇；先验错了算法必失效 |
| ALG06 | L1 换稀疏律 | L1 正则给出稀疏解、L2 给出平滑解；要可解释选 L1，要稳定选 L2 |
| ALG07 | 随机降维律 | 大规模问题用随机采样/随机梯度换速度，代价是方差，靠步长与平均控制 |
| ALG08 | 随机特征律 | 核方法算不动时用随机特征近似核，把 O(n²) 降到线性，精度是可调的 |
| ALG09 | 运输距离律 | 最优运输在比「分布之间差多少」，Wasserstein 距离因此比逐点差更稳 |
| ALG10 | 图流三问律 | 最短路径、最大流、最小割是同一个网络问题的三种问法 |
| ALG11 | 组合近似律 | 组合优化多为 NP 难，工程上要的是「有保证的近似」而不是最优 |
| ALG12 | 强化学习试错律 | RL 靠与环境交互拿回报，样本效率是它的死穴；能监督就别用 RL |
| ALG13 | 强化学习三件套 | 状态、动作、回报定完，算法才有意义；三件套含糊的策略一定学不出来 |
| ALG14 | 算法选型律 | 先看数据规模与结构（稀疏/低秩/图），再看精度要求，最后才看实现难度 |
| ALG15 | 别当调包律 | 这五集给的是「问题归类能力」，不是 sklearn 参数手册；不会归类，调包必错 |

### 中华文化大师课（8 讲，第 57—64 集，约 8 小时）

八位已故学者：汤一介（1927—2014，孔子与老子思想名篇导读）、白化文（1930—2021，汉化佛教寺院与佛像造像）、乐黛云（1931—2024，大禹治水）、周一良（1913—2001，诸葛亮）、褚斌杰（1933—2006，屈原）、孟二冬（1957—2006，李白）、邓广铭（1907—1998，王安石）、季羡林（1911—2009，从西域文化的传入谈起）。

| 编号 | 模型名 | 一句话 |
|---|---|---|
| MCC01 | 一手底稿律 | 这批是学者本人的原始讲授录音，不可再生；引用价值高于任何二手解读 |
| MCC02 | 人物即入口律 | 八讲各锁一个人物/母题，人物是进入一个时代的门，不是知识点 |
| MCC03 | 思想对读律 | 孔子与老子对读，才看得见「秩序 vs 自然」两种中国式答案 |
| MCC04 | 制度剖面律 | 王安石讲的是改革者的制度处境：立意、阻力、执行与反噬四段 |
| MCC05 | 文本细读律 | 屈原、李白两讲落在作品本身；不读原文只听讲解，等于没学 |
| MCC06 | 外来输入律 | 佛教造像与季羡林的西域，讲的是中华文化「被输入」的一面，不是单向输出 |
| MCC07 | 神话即观念律 | 大禹治水不是故事会，是「治水—国家—秩序」的观念原型 |
| MCC08 | 判断力边界 | 大师课给的是见识与语感，不给结论；把学者观点当定论引用是误用 |

### 课程：回归分析的道与术（王汉生，4 集，短）

集标题原文：①如何分析业务的核心诉求 ②有趣的案例教会你如何分析业务的核心诉求 ③回归分析中的 x 与 y ④最后一讲：如何让数据产生价值。

| 编号 | 模型名 | 一句话 |
|---|---|---|
| REG01 | 诉求先行律 | 先问「业务真正要回答什么」，再问「用哪个模型」；顺序反了必做出漂亮的无用分析 |
| REG02 | 案例校准律 | 案例的作用不是举例，是校准你对「什么叫好问题」的判据 |
| REG03 | XY 定义律 | 回归只做一件事：给定 x 解释 y 的变化；x 选错，后面全是噪声 |
| REG04 | 相关性非因果律 | 回归系数是条件相关，不是因果效应；要因果得靠设计与识别策略 |
| REG05 | 变量三重律 | 变量分三类：结果变量、解释变量、混淆变量；混淆不控，结论必歪 |
| REG06 | 残差诊断律 | 看残差形态判模型是否成立，比看 R² 高低更可靠 |
| REG07 | 过拟合警戒律 | 变量越多拟合越好、解释越差；样本小时尤其要减变量 |
| REG08 | 数据价值律 | 数据的价值不在「有多少」，在「能不能回答那个被定义清楚的问题」 |

### 课程：时间管理与效率提升（6 集，短）

集标题原文：①如何进行时间管理与提升效率（一）②时间管理的精髓是什么（二）③什么是价值回避/寻求行为？哪些行为容易上瘾 ④如何进行习惯的改变和养成 ⑤如何管理好自己的时间 ⑥从习惯变成精通。

| 编号 | 模型名 | 一句话 |
|---|---|---|
| TIM01 | 效率定义律 | 效率不是「做得快」，是「把时间放在自己要的事上」；先定要什么，再谈快慢 |
| TIM02 | 精髓取舍律 | 时间管理的精髓是取舍与拒绝，不是把日程塞满；排满的日程等于没有优先级 |
| TIM03 | 回避识别律 | 拖延常是「价值回避」：回避的是那件事带来的不适感，不是事情本身 |
| TIM04 | 上瘾替代律 | 上瘾行为提供即时确定回报，用来替代长期不确定回报；不换回报源，戒不掉 |
| TIM05 | 习惯三件套 | 触发、行为、奖励；改习惯先改触发条件，别先立志 |
| TIM06 | 环境优先律 | 改变靠环境与机制，不靠意志力；把诱惑移出视线比对抗它有效 |
| TIM07 | 时间块律 | 同类任务打包进固定时段，减少切换成本；碎片化的不是时间，是注意力 |
| TIM08 | 边界外化律 | 「免打扰时段 + 可被打扰窗口」写出来公开，别人才知道何时找你 |
| TIM09 | 精通反馈律 | 从习惯到精通靠反馈回路：记录—复盘—微调，没有度量就没有精通 |
| TIM10 | 带走一条律 | 六集只该留下一条到三条能执行的动作，全记等于没记 |

## 五、红线

1. **不许伪造原话**。老师原话未采集，只能转述结构，不能加引号冒充引用。
2. **不承诺教学效果**。本包是问题归类与骨架，不是「学完就会」。
3. **不把大师课当定论**。学者观点有时代与学派立场，引用须标注来源与年份。
4. **算法课不等于工程实现**。要落地必须回原论文与教材，五集视频给不了参数与收敛证明。
5. **不鼓励刷完**。74 集约 470 小时（推算），按需取段是唯一可持续用法。

## 六、文件结构与使用

- `references/`：五门课各一篇，含要点、机制、误用、自测。
- `assets/checklist.md`：选课决策表 + 每门课自测题 + 误用信号速查。
- 每次只读用户当前问的那一篇，不要通读。
- 输出保持简体中文、零 emoji、结论先行、表格优先，不写「赋能/抓手」。

## 运行检查点与失败处置（2026-11-13，统一纪律）

四个 STOP 与三条失败分支见调度层 `taoge-cognitive-os/references/06-run-checkpoints.md`：数据缺失写「数据缺口」不补零｜口径冲突两口径并列不二选一｜真实下单与对外发布只给方案、执行由本人确认｜超边界明说并指向对应包。

失败分支：数据接口失败 → 用最近一次可用数据并标注日期，不虚构当期数值｜模型算不出 → 输出「模型不可用 + 缺哪些输入」｜被要求超能力 → 退回边界声明并指向对应包。
