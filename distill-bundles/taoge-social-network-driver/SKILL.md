# 社会网络驱动认知包（Social Network Driver）

> **一句话定位**：把「人」看成节点、把「关系」看成连接，很多解释不了的事立刻有解——机会不在个人努力里，而在你站在网络的哪个位置。
> **来源**：郑路·社会网络课（SN001–SN027 共 27 篇 S 级归档，2026-11-07 全量收官；「共29讲」多出的毕业考试与直播全文按纪律登记不归档）。

---

## 一、总图（一句话记住）

**网络分析 = 看节点（SN003–SN005）× 看连接（SN006–SN008）× 看结构（SN009–SN015）× 看动态（SN016–SN020）× 看学科与位置（SN021–SN027）**

五个模块递进：**思维（SN002）→ 节点（谁重要）→ 连接（怎么连）→ 静态结构（网络长什么样）→ 动态网络（网络怎么变）**。落到行动只有一句：**要改变结果，先改变位置**（SN022/SN023）。

## 二、核心律速查表（SN系列27条）

### 发刊词与思维（SN001–SN002）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| SN001 | 网络视角律 | 把孤立的原子换成人际网络里的节点与连接，视角一变世界就变；肥胖、吸烟、恐慌、幸福感的传染只有网络层面能解释 |
| SN002 | 参照群体律 | 人的偏好与选择受身边人影响；很多生意能成，靠的正是老乡网络这类社会网络 |

### 模块二 节点（SN003–SN005）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| SN003 | 中心度三维律 | 节点重要性看数量（度）、位置（中介）、质量（特征向量）三维，选谁当关键人取决于要解决什么问题 |
| SN004 | 结构洞律 | 升职最快的是跨部门、或部门与市场之间的连接者；中介位置之所以值钱，是因为两边话语体系差异大、彼此缺桥 |
| SN005 | 多重网络律 | 企业错过的是一个网络而不是一项技术；个人成长本质是网络切换 |

### 模块三 连接（SN006–SN008）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| SN006 | 同质性律 | 婚姻与友谊遵循同类相吸；正确口径是「伴侣找相似、合作找互补」，并结合具体问题选关键维度 |
| SN007 | 强弱关系律 | 强关系传递影响、弱关系传递信息；健全市场里先弱关系广取信息、再用强关系施影响 |
| SN008 | 小世界律 | 六度分隔在数字时代缩到四度；启示是善用短链与桥节点，不是只指望熟人传话 |

### 模块四 静态网络（SN009–SN015）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| SN009 | 幂律优先连接律 | 财富、点击、引用、城市人口都是网络现象、服从幂律；成因是优先连接，静态看是不公平，动态看新超级节点总在涌现 |
| SN010 | 布雷斯悖律 | 增加一条新通道可能因整体过度依赖它而降低效率；加资源不等于加效率，向自然界的网络学设计 |
| SN011 | 网络密度律 | 社会资本＝愿帮你的人数×帮忙强度×其掌握的资源，本质都是密度；互联网提高了社会密度 |
| SN012 | 网络韧性律 | 提升韧性三法：降低关键节点重要性、增加冗余连接、增强节点自主运作；代价是成本上升 |
| SN013 | 非正式网络律 | 组织真实运作靠非正式网络，其核心人物未必是正式领导；管理者要识别并调动他们 |
| SN014 | 多模网络律 | 一模、二模、多模逐层嵌套，维度线性增加而复杂度指数增长；理解异类个体之间关系要用多模 |
| SN015 | 差序格局律 | 内圈情感性、外圈工具性、中间混合性；熟人圈始终是个人社会资本最重要的来源 |

| 编号 | 模型名 | 一句话 |
|---|---|---|
| SN016 | 三度影响力律 | 行为与观念可传染到三度，且影响不对称：强势方影响弱势方更容易 |
| SN017 | 理性从众律 | 从众与信息瀑布常是理性的信息决策；传染本质是决策过程，不是盲目跟风 |
| SN018 | 门槛模型律 | 扩散取决于每个人的参与门槛分布；中心突破还是边缘突破，要看创新特征 |
| SN019 | 复杂网络律 | 复杂系统有自同步、自适应、自组织、自演化四特征；网络是研究复杂系统最重要的工具 |
| SN020 | 动态网络律 | 网络会经历形成、演化、本质变化，但一定窗口内性质可不变；让组织脱胎换骨靠持续动作 |

| 编号 | 模型名 | 一句话 |
|---|---|---|
| SN021 | 学科汇聚律 | 2005 年网络科学成学科、各领域共享同一套工具；谢林模型提醒：个体容忍度不低，宏观仍会收敛到隔离 |
| SN022 | 位置决定律 | 同样节点与连接，只是位置不同性质就变；留人最好的办法是让人与优秀者共事 |

## 三、网络分析 SOP（6 步）

1. **画图**（SN001/SN002）：把目标问题涉及的人、部门、渠道、客户画成节点与连接，先分清谁是节点、谁是连接，别急着评价个人能力。
2. **定关键节点**（SN003/SN004）：按目的选维度——要传得快看度中心度，要信息优势看中介中心度，要看声望看特征向量；再看谁站在结构洞上（跨部门、跨渠道、跨圈层的那个人）。
3. **看连接质量**（SN006/SN007/SN008）：把连接分成强／弱、同质／异质两轴。取新信息走弱关系，要落地走强关系；合作找互补、情感找相似，别用一套标准套两种关系。
4. **读结构**（SN009–SN015）：判断这是不是幂律结构（少数节点吃掉多数流量）；判断密度够不够（愿帮你的人有多少、帮多深）；判断韧性够不够（关键节点是否可替代、有没有冗余）；把非正式网络与正式架构分开画一遍，找出「影子核心」。
5. **看变化**（SN016–SN020）：判断扩散是在几度内发生、门槛分布在高位还是低位、该中心突破还是边缘突破；组织变革按动态网络节奏设计持续动作，不指望一次会议改命。
6. **改位置**（SN022–SN024）：任何改善方案都落到位置动作——把边缘节点拉进中心、给关键人装冗余、把自己连到超级节点或成为新网络早期节点。改不动位置就改不动结果。

## 四、应用场景映射

| 场景 | 适用律 | 落地 |
|---|---|---|
| 电商内容团队与达人矩阵 | SN003 SN004 SN024 | 先找带货网络的度中心（头部达人）与中介中心（跨类目选品人）；自建矩阵要抢新兴平台早期节点位，不在红海做第 100 名 |
| 经销商与渠道管理 | SN011 SN013 SN022 | 渠道社会资本按「愿帮你的经销商数×配合强度×其资源」评估；正式合同之外画出非正式网络，找出真正带节奏的经销商 |
| 招聘、留人与晋升 | SN004 SN007 SN022 | 招人看候选人的弱关系广度（信息来源）与结构洞位置（跨部门经验）；留人靠让他与优秀者共事，不只靠加薪 |
| 新品与活动扩散 | SN016 SN018 | 判断创新门槛高低再选中心突破或边缘突破；借三度影响力设计「朋友带朋友」的机制，而不是只投一次广告 |
| 孩子选科与升学 | SN002 SN023 SN024 | 参照群体影响选科意愿，先看他的朋友圈在谈什么；把孩子从班级边缘推向中心（社团、竞赛、小组角色），比单纯补课有效 |
| 个人IP与职业转型 | SN006 SN024 SN027 | 转型期靠弱关系取信息（行业人、前同事），落地靠强关系；主动连超级节点、提高被连接的效用，不做无效社交的另一种解释是别急着判定无用 |
| 组织流程低效与越改越堵 | SN010 SN012 | 新增流程/系统前先看是否会造成单点依赖；提效优先降关键节点负荷、加冗余与自主权 |

## 五、边界

- **网络视角不是万能解释**：它擅长解释「位置带来的机会差异」，不擅长解释个体能力、制度约束与运气；把一切归因于「关系」会滑向宿命论，也会为不努力找借口。
- **数据与隐私**：画组织或客户网络需要关系数据，涉及个人信息时必须脱敏、限定用途，不采集聊天内容与私人关系细节。
- **因果不能只靠相关**：中心度与成功常同向变动，但可能是成功者才被更多人连接（反向因果）；干预前先做小范围试点。
- **中国情境的差异**：差序格局、关系运作在民企与国企、城市与县域差别很大，课程结论以中国城市样本为主，跨文化场景需重估（SN015/SN027）。
- **不替代制度设计**：反恐、反腐、公司治理等结论属学术讨论范畴，实际制度安排须由法律与合规框架决定。
- **免 AI 化输出**：简体中文、零 emoji、结论先行、表格化，不写「赋能／抓手」类空话。

## 运行检查点与失败处置（2026-11-13，统一纪律）

四个 STOP 与三条失败分支见调度层 `taoge-cognitive-os/references/06-run-checkpoints.md`：数据缺失写「数据缺口」不补零｜口径冲突两口径并列不二选一｜真实下单与对外发布只给方案、执行由本人确认｜超边界明说并指向对应包。

失败分支：数据接口失败 → 用最近一次可用数据并标注日期，不虚构当期数值｜模型算不出 → 输出「模型不可用 + 缺哪些输入」｜被要求超能力 → 退回边界声明并指向对应包。
