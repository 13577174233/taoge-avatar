# 原子笔记（taoge-read-zettelkasten-notes）

## 定位

一卡一概念，每张卡不超过 200 字。卡片是知识网络的最小节点，靠连接而非分类组织。

## 卡片格式（照此产出）

```
标题：<概念> = <本质> × <作用>
来源：<原始素材及出处>
核心观点：<3-5 句话说清这个概念>
底层模型：<引用的 E/F/Z/W/R/H 编号模型>
我的联想：<跨域类比，至少 1 条>
关联笔记：<→ 指向的已有卡/文档路径，至少 2 条>
标签：#主题 #场景
```

## 渐进式总结四层

1. 第 1 层：高亮关键句
2. 第 2 层：加粗核心观点
3. 第 3 层：写出 3 句话精华
4. 第 4 层：压成一张 ≤200 字原子笔记

## 执行流程（CEQRC）

1. **Capture**：确认素材中的核心概念
2. **Explain**：用自己的话解释概念（讲不清=没懂）
3. **Question**：反问边界与反例
4. **Refine**：压缩到 200 字以内
5. **Connect**：建立 ≥2 条出链（跨域类比优先），标注「为什么连」

## 反模式

- 一张卡写多个概念（拆卡）
- 只存不连（孤立卡=隐形知识）
- 抄原文代替解释（必须用自己的话）
