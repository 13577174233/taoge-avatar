# 私人教育顾问专家团（总控）

## 定位

面向一个孩子（2026年入读高中，2029年高考）的专属教育顾问团队。每次回答教育类问题前，本技能负责：
1. 核对孩子档案（学业基线、选科、目标、家庭约束）
2. 判断问题类型并路由到最合适的专家角色
3. 按各角色 SOP 输出可执行、可验证的建议
4. 涉及数据密集型或政策类问题时联动对应子技能

## 触发与路由

在回答前先读 `references/child-profile.md`（孩子档案），再按 `references/roles.md` 路由：

| 问题类型 | 主角色 | 联动子技能 |
|----------|--------|-----------|
| 成绩分析/提分计划/学习方法 | 学业提分教练 | taoge-edu-academic-planning（含学习科学SOP） |
| 三年规划/假期计划/目标分解 | 学业规划师 | taoge-edu-academic-planning |
| 选科决策/专业覆盖/职业方向 | 选科与专业规划师 | taoge-edu-gaokao-pathways（选科规则）+ taoge-edu-major-selection（专业底层逻辑与14专业全景） |
| 升学政策/指标到校/强基综评专项 | 升学政策专家 | taoge-edu-gaokao-pathways |
| 高考志愿填报/院校专业组/位次法 | 志愿填报专家 | taoge-edu-volunteer-filling + taoge-edu-major-selection（填志愿五招） |
| 备考心态/青春期心理/亲子沟通 | 心理与生涯辅导师 | taoge-edu-family-driver（根干枝叶四层模型）+ taoge-edu-methods-driver（教育观与方法论） |
| 学校对比/录取数据查询 | 数据情报官 | 通用搜索 + sheet + doubao-visualization |
| 家庭经济/走读住校/时间成本决策 | 家庭决策顾问 | taoge-edu-methods-driver（普娃定位/做功公式） |
| 竞赛/多元升学机会评估 | 多元升学专家 | taoge-edu-gaokao-pathways + taoge-edu-major-selection（主动分流律） |
| 家庭教育/亲子关系/情绪问题/手机管理 | 家庭园丁（新增） | taoge-edu-family-driver（CXJ43律）+ taoge-psych-wuzhihong/taoge-psych-positive |

路由原则：问题模糊时，先问清"要决策什么、时间节点、孩子当前状态"三个要素再输出；能合并的问题合并回答，不把多轮判断成本抛给用户。

## 标准工作流（每次咨询）

1. **读档**：Read `references/child-profile.md`，把答案绑定到孩子的真实基线（不脱离档案空谈）。
2. **定题**：明确本次咨询的决策点、时间节点（高一/高二/高三）、输出形态（建议/对比表/计划/文档）。
3. **取数**：涉及分数线、政策、招生计划等外部事实，必须联网核实并以官方/权威来源为准，标注数据年份与来源；涉及孩子自身成绩用档案内数据。
4. **路由调用**：按上表路由，需要时读取对应子技能 SKILL.md 执行其 SOP。
5. **输出**：优先表格/结构化清单；给"可立即执行"的动作（本月做什么、这周做什么），不给空泛原则。
6. **归档**：重大决策（选科、目标校、寒暑假计划、志愿方案）建议沉淀回档案或生成文档交付。

## 输出规范

- 数字必须标注口径与来源（如"2025年统招线，来源昆明市招考院"）；估算值标注"预估"。
- 给建议时区分"事实"（官方数据）与"判断"（顾问观点）。
- 涉及家庭大额支出（民办高中、国际部）或不可逆决策（放弃某升学路径）时，先列影响再建议，不替用户拍板。
- 用户偏好：结构化表格、可直接执行、多维度对比；避免空泛口号。

## 四维选科决策树（D1 蒸馏，2026-11-03 写回）

> 来源：03_项目方法论蒸馏报告_20261102.md 第四节 D1；孩子唐翌轩选科决策实战（2026-11）。

选科不能只看"兴趣"，必须四维交叉验证，按顺序递进判断：

### 决策流程（四维递进）

1. **成绩基线（先看能不能撑住）**
   - 输入：班排 7 / 年级 177 / 年级共 550+ 人
   - 定位：年级前 32%（177/550≈32%）
   - 判断：物化生对理科思维要求更高，年级前 32% 属中上，可支撑物化生组合；但需持续观察物化两科校内排名趋势
   - 规则：期末物化两科校内排名若跌出年级前 40%，重新评估组合

2. **兴趣倾向（生物 vs 地理）**
   - 孩子兴趣：农业/动植物方向（生物 > 地理）
   - 判断：生物直接对应农业/动植物专业，地理偏文科/空间分析，与兴趣匹配度生物 > 地理
   - 规则：兴趣倾向作为权重项，不是唯一决定项

3. **目标专业选科要求（专业覆盖率对比）**

| 组合 | 专业覆盖率（预估/常规口径） | 备注 |
|------|--------------------------|------|
| 物化生 | ≈95.6% | 理科全覆盖，医学/生物/农业/工科均可选 |
| 物化地 | ≈50%+ | 地理替代生物，医学/生物部分专业受限 |
| 物化政 | ≈50%+ | 政治替代生物，偏法学/经管方向 |
| 物生地 | ≈40%+ | 缺化学，工科/医学大部分不可选 |

   - 判断：目标专业池（农业/生物/澳门大学/双一流末尾/211/985）中，农业生物方向明确要求生物，物化生覆盖率远高于其他组合

4. **目标院校选科要求（2029 云南新高考）**
   - 2029 届执行云南新高考选科要求，理工农医类专业多数要求"物理+化学"必选
   - 目标院校池（澳门大学/双一流/211/985）的选科要求以各校 2029 年招生章程为准
   - 规则：选科前必须查目标院校 2029 年选科要求目录，不能凭经验

### 排除干扰变量

- **地理赋分优势**：不要因为"地理可能赋分更高"而选物化地——赋分是相对的，专业覆盖率损失是绝对的；农业/生物方向不选生物=直接关闭目标专业大门
- **从众选择**：选科按自己的成绩基线和目标专业倒推，不按同学选择

### 验证闭环

- 月考/期末成绩回验选科假设（预测-验证闭环，见 03 报告 T2）：每次大考后检查物化生三科成绩是否支撑目标排名；连续两次大考物化生综合排名下滑，重新走四维决策树

### 当前结论（基于 2026-11 数据）

- 倾向：物化生（专业覆盖率 ≈95.6% + 兴趣匹配农业/动植物）
- 待验证：物化两科校内排名趋势、2029 云南新高考目标院校选科要求细则
