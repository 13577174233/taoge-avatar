# 标准工作流（典型咨询场景）

> 按需读取。每个场景给出"输入→动作→输出"的标准流程，确保顾问团输出一致、可执行。

## 场景A：成绩分析与提分建议（高频）

```
输入：最近一次月考/期中/期末成绩单（科目分数、班级排名）
动作：
1. 读档案，对比入学基线，计算各科离目标差距
2. 识别"强科拉分项"与"弱科短板项"（优先提升性价比最高的科目）
3. 结合物化生组合，判断赋分科目实际位次影响
4. 输出：科目优先级表 + 每周提分动作 + 下次考试目标分
输出：提分计划表（可直接打印/存sheet）
联动：edu-academic-planning、sheet
```

## 场景B：选科复议咨询（高二确认前）

```
输入：高一阶段各科成绩、兴趣信号、专业方向初步想法
动作：
1. 复核物化生 vs 物化地的覆盖率差异（医学vs工科）
2. 评估生物科目实际赋分竞争力
3. 若孩子明确不学医、生物赋分吃亏 → 建议物化地并给出切换窗口
4. 若仍想学医 → 坚定物化生，强化生物投入
输出：选科建议书（含切换截止时间、各科现状证据）
```

## 场景C：升学路径盘点（高一寒暑假做一次）

```
输入：孩子当前成绩位次、家庭资源（户籍学籍、经济、人脉）、兴趣
动作：
1. 盘点6条路径：普通高考 / 强基计划 / 综合评价 / 专项计划 / 竞赛保送(极少) / 港澳升学
2. 逐条评估适配度（门槛、时间投入、回报概率）
3. 排出"主路径+备路径"，标注各路径关键时间节点
输出：升学路径规划表
联动：edu-gaokao-pathways
```

## 场景D：高考志愿预案（高三上学期启动）

```
输入：高二期末/高三一模位次、专业方向、地域偏好、家庭约束
动作：
1. 位次法锁定"冲稳保"三档院校范围（冲：位次上浮10-15%；稳：±5%；保：下浮15-20%）
2. 按院校专业组逐校核对选科要求（物化生可报95.6%专业）
3. 结合孩子兴趣收敛专业清单（医学/CS/电子/师范等）
4. 输出志愿预案表（Excel），随每次模考更新
输出：志愿预案表（sheet交付）
联动：edu-volunteer-filling、sheet
```

## 场景E：亲子沟通/心态疏导

```
输入：家长描述的冲突场景或孩子状态信号
动作：
1. 先共情、还原孩子视角，不直接站队评判
2. 给出家长话术模板（说什么、不说什么）
3. 设定观察窗口与复盘点（如两周后回顾）
4. 严重信号（持续失眠、自伤、厌学加重）→ 建议专业心理咨询/就医
输出：沟通策略卡 + 话术模板
```

## 场景F：学校/机构对比决策

```
输入：待比较的学校或升学产品清单
动作：
1. 数据情报官联网取数（分数线、一本率、学费、招生计划）
2. 统一维度表格对比（升学质量/成本/管理/通勤/住宿）
3. 结合孩子基线给出推荐排序 + 理由
4. 涉及大额支出（民办、国际部）→ 家庭决策顾问补成本测算
输出：对比表（表格交付）
```

## 通用铁律

1. 每次咨询输出前，检查：数字有来源吗？动作可执行吗？时间节点明确吗？
2. 不要替用户做不可逆决策；给"推荐+理由+替代项"。
3. 重大结论变化（政策变动、孩子成绩大波动）须回写 child-profile.md。
