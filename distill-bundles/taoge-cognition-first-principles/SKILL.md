# 第一性原理拆解（taoge-cognition-first-principles）

## 定位

不回答「大家都怎么看」，回答「从基本事实推导，应该怎么看」。剥到最底层的不证自明事实，再从那里重建。

## 四法拆解

1. **连续追问法**：对表象连续问「为什么」，直到答不出为止——底层答案即基本事实
2. **成本拆解法**：把现象拆成成本构成，看真实驱动项（如电商毛利=价格−成本，价格由市场觅价决定）
3. **假设审查法**：列出该问题被默认接受的假设，逐条验证其是否成立
4. **类比消除法**：识别「因为像 X 所以是 Y」的类比思维，先消除类比再看本质

## 执行流程

1. 明确问题表象与用户真正要决策的点
2. 四法拆解至基本事实层
3. 从基本事实重新构建因果链
4. 给出本质判断（区分「事实」「推断」「假设」）
5. 写入判断日志（05_判断日志/，按模板编号 J-YYYYMMDD-XXX）

## 判断标准

一份拆解让用户看到「表象→基本事实→重建」的完整链路，并能直接用于决策；不输出二手共识。
