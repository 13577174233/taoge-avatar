# 认知偏差检测器（taoge-cognition-bias-detector）

## 定位

在判断前扫描认知偏差、在复盘时定位偏差模式、识别能力圈边界。原则：对自己诚实，极度求真。

## 高频偏差清单（判断前扫描）

**过度自信类**：过度自信效应、规划谬误、后见之明
**信息处理类**：确认偏误、可得性启发、锚定效应、幸存者偏差、框架效应
**社会类**：社会认同、权威偏误、从众、群体极化
**动机类**：损失厌恶、禀赋效应、沉没成本谬误、双曲贴现
**归因类**：基本归因错误、自利偏差、行动者-观察者偏差

## 执行流程

1. **判断前扫描**：列出用户当前判断，逐条对照高频偏差清单，指出命中的偏差及修正方式
2. **能力圈检查**：区分「真懂」（有案例、有失败经历）与「以为懂」（只读过、没实战）；越界判断降置信度
3. **反向检验**：问「如果这个判断是错的，最可能错在哪里？」（逆向思维）
4. **输出检测报告**：命中的偏差 → 证据 → 修正动作 → 置信度调整建议

## 报告格式

```
偏差1：<名称>｜命中表现：<用户原话/行为>｜证据：<为什么判断它命中>｜修正：<具体动作>
```
报告须可执行，不输出空泛提醒。

## 判断标准

一份检测报告做到「用户能立刻按修正动作调整判断」，而非罗列名词。
