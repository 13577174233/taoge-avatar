# 创新驱动认知包（Innovation Driver）

> **一句话定位**：一套把"创新"从口号变成可诊断、可执行、可复用的判断工具——知道什么创新值得做、什么组织能做成、什么人能做成。
> **来源**：何刚·财经大课主题6「如何走出公司创新的窘境」（157/336讲阶段归档，2026-10-23），五本书蒸馏16个模型（H97-H112）。

## 二、创新链16律速查（H97-H112）

### ②人的推动（熊彼特）

| 编号 | 模型 | 一句话 |
|---|---|---|
| H97 | 新组合创新律 | 创新=已有要素新组合+增量收益；发明≠创新（发明是无中生有，创新是经济组合） |
| H98 | 企业家功能律 | 企业家=实现新组合的人（功能非身份）；企业家精神=谋利+创新组合 |
| H99 | 创造性破坏律 | 市场经济本质=创造-破坏动态；主动自我破坏者活，被动被破坏者亡 |
| H100 | 创新波浪周期律 | 周期主因=企业家创新集群的波浪（货币金融只是过程结果）；扩散期繁荣/耗尽期衰退 |

### ③组织承接（克里斯坦森）

| 编号 | 模型 | 一句话 |
|---|---|---|
| H101 | 颠覆性创新判据律 | 颠覆性创新=对颠覆性技术的创新商业应用；判据=低端/新市场切入→迭代→上攻（非技术先进） |
| H102 | 组织能力三因素律 | 组织能力=资源+流程+价值观（RPV）；成功组织的流程价值观=能力陷阱，颠覆需独立组织承接 |
| H103 | 任务思维产品律 | 客户雇产品完成"任务"（JTBD）；画像调研≠真实需求，以任务为中心开发 |
| H104 | 双轮颠覆律 | 颠覆性创新=产品体验+商业模式双轮；好产品必须配好商业模式，一条腿走路必败 |

### ④实践验证（乔布斯传）

| 编号 | 模型 | 一句话 |
|---|---|---|
| H105 | 极致产品哲学律 | 极致创新=把激情/情绪化倾注产品；单点纵深（乔布斯）vs 多点跨界（马斯克）两种路径 |
| H106 | 破坏式管理律 | 管理二分：维持型（流程激励）vs 破坏型（重组重构）；转型期用创造性破坏，阻力巨大需权威+零容忍 |
| H107 | 特质转化律 | 缺陷能量导向：敏感→直觉/掌控欲→极致；评估人看"缺陷能量"被导向哪里 |
| H108 | 传承补位律 | 选继任=创新基因+组织能力整体交接；先识体系最缺能力再补位 |

### ⑤团队支撑（硅谷钢铁侠）

| 编号 | 模型 | 一句话 |
|---|---|---|
| H109 | 跨界迁移律 | 多点跨界创新=同一套第一性原理+工程能力跨行业复制；不逐利而逐行业变革 |
| H110 | 资源选址律 | 实现远大目标=主动进入资源密度最高的生态/地理；选址是战略不是通勤 |
| H111 | 至暗韧性律 | 方向正确也会濒死；创新者用加倍努力+迭代输入+一线管理扛过至暗时刻 |
| H112 | 人才体验招聘律 | 招聘=吸引与筛选组合（尊重/稀缺/场景/严考）；领导力=让高手愿意为你工作 |

## 三、创新诊断五步 SOP（跨项目复用）

遇到"要不要做创新/这个创新能不能成/我们组织为什么做不成"类问题时，按序走：

1. **判方向（H97+H100）**：是不是新组合？增量收益在哪？当前处于创新扩散期还是耗竭期？
2. **辨真伪（H101+H104）**：从低端/新市场切入还是主流升级？产品体验与商业模式是否双轮齐备？
3. **查组织（H102+H106）**：现有流程/价值观会不会成为能力陷阱？是否需要独立组织/破坏式重构？
4. **定产品（H103）**：客户雇它完成什么任务？画像调研结论能否被任务验证替代？
5. **配团队（H112+H108）**：谁来做？用什么招聘/激励让高手愿意来？创新基因能否延续？

输出格式：结论先行 → 每步证据 → 落点（应用领域行动项）。

## 四、应用场景映射（蒸馏到其他项目）

| 项目 | 应用 |
|---|---|
| 电商（ecommerce-* 系列） | 新品创新成色判断（滇式健康点心=低端/新市场切入？）；组织变革（SKU 100+→50+=破坏式管理）；产品定义（低糖云腿=客户任务"控糖还想过瘾"）；团队搭建（内容盘独立组织逻辑） |
| 投资（何刚投资筛选） | 识别真伪颠覆股（H101）；周期位置=创新集群扩散/耗竭（H100）；企业组织能力诊断（H102） |
| 教育（taoge-edu-private-advisory） | 容错文化培养创新思维（H99/冒险基因）；引导孩子"幻想→工程拆解"（H109/第一性原理） |
| 个人成长（taoge-avatar分身） | 创新链16律并入分身速查表；决策框架"现象→本质→判断"增加创新维度 |
| 读书系统（taoge-distill-bottle） | 五本书蒸馏内容回挂：主题6创新链作为整体知识块 |

## 五、边界

- 本包是**判断框架**，不替代具体行业数据调研（需求规模/竞争格局请用 taoge-ecom-product-market-analysis 等证据型工具）。
- 模型置信度：H97-H100/H101-H104/H105-H108/H109-H112 均为 S级归档蒸馏（何刚财经大课，2026-10-23）。
- 更新规则：认知革命项目每新增创新相关模型，同步追加本包速查表与接线。
