# 政经周期与价值投资驱动包（Hegang History & Value Driver）

> **一句话定位**：一套把"周期、泡沫、估值纪律"变成可诊断、可执行、可复用的判断工具——先定仓位总开关，再排雷，最后才谈选股。
> **来源**：何刚·财经大课336讲收官批（2026-10-24 S级归档），新增模型 H113-H202 共90条，本包取其中跨项目复用率最高的32条为核心律。

---

## 一、总图（一句话记住）

**判断顺序不能反：宏观周期（仓位）→ 泡沫温度（逃顶/排雷）→ 价值纪律（选股买卖）→ 激素自查（别把投机当投资）**

| 层 | 核心问题 | 核心模型群 |
|---|---|---|
| ①周期政策 | 现在处在周期哪一段？央行和政策在干什么？ | H115压制-反弹/H120右侧入场/H124政策结构/H126政策底市场底/H135央行放水路径依赖/H147口头缓释/H149利率三对表 |
| ②泡沫排雷 | 市场是不是在叙事末期？手里的票是不是投机盘？ | H131庞氏三特征/H133泡沫自强化/H134信息瀑布/H138媒体催化/H141群体癫狂三段/H142泡沫三招/H143合谋结构/H144三动机自查 |
| ③价值选股 | 这家公司值不值得拿、什么价格拿？ | H182 ROIC-WACC/H187利润稳定/H191蜡笔业务/H192消费体验/H194三因验证/H195沙漠之花/H196运通检验 |
| ④买卖纪律 | 什么时候动手、拿多少现金？ | H120右侧入场/H184投机账户隔离/H186安全边际30%/H190业余者自由优势/H197战术空仓权 |

## 二、核心律速查（32律）

### ① 周期政策层——仓位总开关

| 编号 | 模型 | 什么时候用 / 看到什么信号 / 怎么用 |
|---|---|---|
| H115 | 压制-反弹周期律 | 紧缩/管制压得越久，松绑后反弹越猛。信号：政策压制时长+放松信号同现时，短期爆发力看势能不看当前增速。用法：A股择时——紧缩极致+放松信号=高峰前夜 |
| H120 | 右侧入场律 | 等不起拐点也猜不准。信号：价格从底部回升约10%趋势确认。用法：放弃复苏初段10%-15%涨幅，右侧再进；不预测、只验证 |
| H124 | 政策结构阅读律 | 读配套体系结构找重心，不按舆论热度排序。用法：先查"配套体系第一次分配在哪" |
| H126 | 政策底市场底律 | 政策底到市场底隔着盈利底。信号：放水信号密集但企业盈利未验。用法：仓位跟盈利验证走，不跟放水信号冲 |
| H135 | 央行放水路径依赖律 | 每次危机都救→市场学到"跌了有托底"→投机更肆无忌惮。信号：央行政策转向=短期涨跌头号变量。用法：仓位总开关先盯央行 |
| H147 | 权威口头缓释律 | 喊话没有真金白银购买计划=口头缓释片。信号：公告只提原则不提资金。用法：读政策先问"他的真金白银在哪" |
| H149 | 利率三对表律 | 基准利率必须同时对得上经济增速、通胀、财富分配三张表。信号：利率与三表错配=风险积累。用法：宏观判断/政策转向预警的对账工具 |
| H150 | 先发展后规范律 | 规范永远赶不上发展，创新永远找监管空白。信号：新玩法刚起、监管未到。用法：电商玩法抢时间窗，但靠预警机制不抱侥幸 |

### ② 泡沫排雷层——逃顶与识别投机

| 编号 | 模型 | 什么时候用 / 看到什么信号 / 怎么用 |
|---|---|---|
| H131 | 庞氏识别三特征律 | 排雷用。三特征：收益高得稳从不波动+模式说不清钱从哪来+熟人链扩张。两条命中即拉黑 |
| H133 | 泡沫自强化循环律 | 价格涨→热情起→故事扩散→再涨。发动机是叙事不是基本面。用法：不接叙事末期的盘 |
| H134 | 信息瀑布律 | "别人排队"成了我的决策依据。用法：电商把渠道订单瀑布与终端需求分开看，别拿渠道库存当市场需求 |
| H138 | 媒体催化律 | 媒体是泡沫的一部分。信号：唱多文章密集到非专业人士天天刷到=反馈环第三阶段。用法：全网刷屏方向自动降半仓 |
| H141 | 群体癫狂三段律 | 同时发疯→集体维持→逐个恢复；恢复是现金流物理过程不是认知觉醒。用法：逃顶只看自己现金流不崩 |
| H142 | 泡沫三招组合拳律 | 三招：鼓吹宏大未来+杠杆化权证+承诺高额股息。信号：三招齐发=顶部；命中2招以上即锁仓不加 |
| H143 | 合谋结构律 | 特许投机者+无约束政策者+先知先觉内部人三方合谋时，民众最后知道最先埋单。信号：政策风口+货币宽松+大股东减持三标签叠加=预警 |
| H144 | 三动机自查律 | 每次重大操作前查三动机：怕踏空+想暴利+觉得自己能跑掉。占两条即停手 |
| H136 | 心理锚定律 | 写下"觉得它该值多少"，检验是锚定还是算出来的价值。两者与估值无关却主导买卖 |
| H137 | 回弹预期谬误律 | "暴跌后两三年必回弹"是错觉。日经1989、上证6124十几年回不去。跌70%不是买入理由 |

### ③ 价值选股层——巴菲特系纪律

| 编号 | 模型 | 什么时候用 / 看到什么信号 / 怎么用 |
|---|---|---|
| H182 | ROIC-WACC价值线律 | 企业生死线=ROIC持续高于WACC（约7%-8%）。信号：ROIC跌破WACC=价值毁灭。用法：18只持仓逐只体检 |
| H187 | 利润稳定性优先律 | 连续稳定盈利比高增长重要。用法：压舱石仓选稳定盈利股，不选故事股 |
| H191 | 蜡笔简单业务律 | 不能用蜡笔画清楚怎么赚钱的公司不投。用法：清仓看不懂的概念股，聚焦看得懂的品类 |
| H192 | 消费体验选股律 | 从自己天天用、真心喜欢的产品里发现牛股。用法：用电商终端销售数据反推品类投资机会 |
| H194 | 三因验证律 | 决策=灵感(艺术)+数据(科学)+现场事实(调研)，缺一最贵。用法：买入/重仓前过清单；调研找证伪证据不证实自己 |
| H195 | 沙漠之花律 | 行业被全市场抛弃时，挑成本最低、份额逆势扩张的龙头。用法：周期股底部持仓不割肉，反转弹性数倍 |
| H196 | 运通检验律 | 暴雷分两类：伤情绪（核心用户行为没变=加仓机会）/伤商业模式（本质受损=立刻走）。用法：持仓暴雷先查核心用户行为是否变化 |
| H193 | 办公室奢华反向律 | 总部越奢华、排场越大，管理层回报股东意愿越弱。用法：选股第一眼办公室，简陋务实=好信号 |
| H199 | 蹭信用识别律 | 需要傍大佬午餐/站台背书才能涨的=投机标的。用法：大V消息股排雷 |

### ④ 买卖纪律与自查层

| 编号 | 模型 | 什么时候用 / 看到什么信号 / 怎么用 |
|---|---|---|
| H184 | 投机账户隔离律 | 投资与投机物理分账户、投机额度封顶绝不混仓；杠杆=投机红线；没有事先写下的止损/盈利线就是投机 |
| H186 | 安全边际30%介入律 | 任何低等级品种买入前必须确认被严重低估30%以上，否则就是投机。用法：错杀龙头分批买的门槛 |
| H190 | 业余投资者自由优势律 | 无强制分散/可空仓/无季度排名=结构优势。用法：持仓砍到5-6只集中，高估时敢于空仓 |
| H197 | 战术空仓权律 | 找不到好标的就把现金当仓位。用法：常年保留20-30%现金，满仓是散户病 |
| H198 | 浮存金杠杆律 | 无息资金（保费/预收/经销商打款）=零成本本金。用法：冠生园预收账款可规划长期投资小池 |
| H202 | 决策权重错配律 | 人在小钱上理性、大钱上轻率。用法：任何重仓/大额投入前过"我的了解配得上这笔钱吗"检验 |
| H201 | 财富来源代际迁移律 | 父辈劳动攒钱买房、我们这代房产+股市、年轻人先靠人力资本。用法：孩子第一笔钱是把自己变成稀缺人才 |

## 三、政经周期与价值投资诊断六步 SOP

1. **定周期位置（H115+H135+H149）**：政策压制多久、央行放水还是收水、利率三表对得上吗？→ 仓位总开关（进攻/防守/空仓）。
2. **读政策含金量（H124+H126+H147）**：配套体系重心在哪？盈利底验没验？喊话背后真金白银在哪？→ 政策可不可信。
3. **测泡沫温度（H133+H141+H142+H143+H144+H138）**：泡沫三招命中几条？三动机自查占几条？全网刷屏？→ 叙事早段还是末期。
4. **筛标的质地（H182+H187+H191+H192+H194+H193）**：ROIC>WACC？利润稳定？蜡笔画得清？自己用过？三因验证过？→ 进不进观察池。
5. **定买卖纪律（H120+H186+H197+H184）**：右侧确认？安全边际30%？现金20-30%？研究仓投机仓隔离？→ 买多少、什么价、止损线。
6. **暴雷与排雷预案（H196+H195+H131+H199+H202）**：伤情绪还是伤模式？沙漠之花？庞氏/蹭信用？功课配得上钱？→ 加仓/持有/清仓。

输出格式：结论先行（仓位总开关+核心动作）→ 每步证据 → 落点行动项。

## 五、边界

- 本包是**判断框架**，不预测点位、不替代实时行情与券商研报。
- 不做创新链判断（去 taoge-cognition-innovation-driver）；不做产品定义/用户洞察（去 taoge-cognition-product-growth-driver）。
- 模型置信度：H113-H202 均为 S级归档蒸馏（何刚财经大课336讲收官批，2026-10-24）；本包取跨项目复用率最高32条为核心律。
- 更新规则：认知革命项目每新增周期/投资/经营制度相关模型，同步追加本包速查表与接线。
