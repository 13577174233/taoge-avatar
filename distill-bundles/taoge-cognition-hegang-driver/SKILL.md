# 政经周期与价值投资驱动包（Hegang History & Value Driver）

> **一句话定位**：一套把"周期、泡沫、估值纪律"变成可诊断、可执行、可复用的判断工具——先定仓位总开关，再排雷，最后才谈选股。
> **来源**：何刚·财经大课336讲收官批（2026-10-24 S级归档），新增模型 H113-H202 共90条，本包取其中跨项目复用率最高的32条为核心律，其余为可选接线。

---

## 一、总图（一句话记住）

**判断顺序不能反：宏观周期（仓位）→ 泡沫温度（逃顶/排雷）→ 价值纪律（选股买卖）→ 激素自查（别把投机当投资）**

|---|---|---|

| ②泡沫排雷 | 市场是不是在叙事末期？手里的票是不是投机盘？ | H131庞氏三特征/H133泡沫自强化/H134信息瀑布/H138媒体催化/H141群体癫狂三段/H142泡沫三招/H143合谋结构/H144三动机自查 |
| ③价值选股 | 这家公司值不值得拿、什么价格拿？ | H182 ROIC-WACC/H187利润稳定/H191蜡笔业务/H192消费体验/H194三因验证/H195沙漠之花/H196运通检验 |

## 二、核心律速查（32律）

### ① 周期政策层——仓位总开关

| 编号 | 模型 | 什么时候用 / 看到什么信号 / 怎么用 |
|---|---|---|
| H115 | 压制-反弹周期律 | 紧缩/管制压得越久，松绑后反弹越猛。用法：A股择时——紧缩极致+放松信号=高峰前夜 |
| H120 | 右侧入场律 | 等不起拐点也猜不准。信号：价格从底部回升约10%趋势确认。用法：放弃复苏初段10%-15%涨幅，右侧再进 |
| H124 | 政策结构阅读律 | 读配套体系结构找重心，不按舆论热度排序。用法：先查"配套体系第一次分配在哪" |
| H126 | 政策底市场底律 | 政策底到市场底隔着盈利底。用法：仓位跟盈利验证走，不跟放水信号冲 |
| H135 | 央行放水路径依赖律 | 每次危机都救→市场学到"跌了有托底"→投机更肆无忌惮。用法：仓位总开关先盯央行 |
| H147 | 权威口头缓释律 | 喊话没有真金白银购买计划=口头缓释片。用法：读政策先问"他的真金白银在哪" |
| H149 | 利率三对表律 | 基准利率必须同时对得上经济增速、通胀、财富分配三张表。用法：A股宏观判断对账工具 |
| H150 | 先发展后规范律 | 规范永远赶不上发展，创新永远找监管空白。用法：电商玩法抢时间窗但建预警 |

## 三、政经周期与价值投资诊断六步 SOP

遇到"现在大盘什么位置/这只票能不能买/要不要加减仓/这笔生意要不要投"类问题时按序走：

1. **定周期位置（H115+H135+H149）**：当前政策压制了多久、松绑信号出没？央行在放水还是收水？利率与三表对得上吗？→ 输出：仓位总开关。
2. **读政策含金量（H124+H126+H147）**：政策配套体系的重心在哪？政策底之后盈利底验没验？喊话背后真金白银在哪？→ 输出：政策可不可信。
3. **测泡沫温度（H133+H141+H142+H143+H144+H138）**：泡沫三招命中几条？身边人是不是开始讲故事拉人？三动机自查占几条？→ 输出：叙事早段还是末期。
4. **筛标的质地（H182+H187+H191+H192+H194+H193）**：ROIC>WACC吗？利润连续稳定吗？蜡笔画得清怎么赚钱吗？三因验证过了吗？→ 输出：进不进观察池。
5. **定买卖纪律（H120+H186+H197+H184）**：右侧确认了吗？安全边际够30%吗？现金仓位留了20-30%吗？研究仓和投机仓物理隔离了吗？→ 输出：买多少、什么价买。
6. **暴雷与排雷预案（H196+H195+H131+H199+H202）**：已持仓暴雷先分伤情绪还是伤模式？周期股是不是在沙漠之花状态？庞氏三特征和蹭信用信号查了吗？→ 输出：加仓/持有/清仓动作。

输出格式：结论先行（仓位总开关+核心动作）→ 每步证据 → 落点（18只持仓/冠生园经营/孩子教育 行动项）。

## 五、边界

- 本包是**判断框架**，不预测点位、不替代实时行情与券商研报；具体买卖仍需结合 doubao-daily-stock / doubao-earnings-analysis 等证据型工具。
- 不做创新链判断（去 taoge-cognition-innovation-driver）；不做产品定义/用户洞察/增长飞轮设计（去 taoge-cognition-product-growth-driver）；不做行业需求规模与竞争格局调研（去 taoge-ecom-product-market-analysis / taoge-ecom-product-intelligence）。
- 模型置信度：H113-H202 均为 S级归档蒸馏（何刚财经大课336讲收官批，2026-10-24）；本包选取其中跨项目复用率最高的32条为核心律，其余58条保留在 模型地图.md 备查。
- 更新规则：认知革命项目每新增周期/投资/经营制度相关模型，同步追加本包速查表与接线。
