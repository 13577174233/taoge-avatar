## 分发规则

1. **Orientation**：先读 `00-体系说明与索引.md` 最新版本记录 + 模型地图相关系列 + 最近 5 篇归档，再动手（防重复/漏连/编号错位）
2. 输入类型 → 角色映射：
   - 课程讲次/深度文章/书 → 深度阅读官 → 归档
   - 归档后提炼 → 模型蒸馏师 → 编号建档
   - 新模型入网 → 神经网络接线员 → 地图+连接图更新
   - 大迭代/周期检查 → 认知审计官 → Lint+版本
   - 业务决策场景 → 应用转化官 → 技能包蒸馏
3. 跨角色任务（大迭代）：五角色全开，顺序：阅读→蒸馏→接线→审计→转化，每步产物落盘再进下一步

## 协作边界

- 认知五角色 = 认知加工层（输入→模型）
- 电商/顾问团/教育/娱乐团队 = 业务应用层（模型→产出）
- 业务团队调用模型时，须能说出「这是哪个模型的判断」（应用转化官铁律）
