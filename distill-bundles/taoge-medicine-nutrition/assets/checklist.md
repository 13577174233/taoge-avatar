# 营养科学 · 行动清单

> 打印出来贴冰箱。每条都是「什么情况下不能做 / 必须就医」。

- [ ] **身体识别营养需求总是滞后** —— 关节疼痛经医院检查确认无炎症、无骨质疏松后，可从营养角度排查；若疼痛持续加重、伴随红肿热或外伤史，须先就医排除器质性病变，不能只靠补营养。
- [ ] **供给原则：供给要在需求识别之前** —— 预防性供给不等于盲目加量；出现持续症状先就医明确诊断，排除疾病后再调整饮食，不能跳过诊断直接自行大剂量补充。
- [ ] **干预原则：干预要有仆人领导力** —— 糖尿病患者改变进食顺序或加餐后，仍须按原有方案监测血糖；出现心慌、出冷汗等低血糖信号，或血糖持续异常波动，及时就医，不可自行调整胰岛素剂量。
- [ ] **零散知识靠不住，要建整体知识网络** —— 本条为学习方法论，不涉及操作风险。
- [ ] **成为营养素的两个必要条件** —— 本条为定义认知，不涉及操作风险。
- [ ] **现实形态影响吸收效率，不影响最终功能** —— 本条为吸收原理，不涉及操作风险；不建议自行研磨鸡蛋壳等非常规来源补钙。
- [ ] **膳食纤维：靠肠道菌群间接成为营养素** —— 本条为定义认知，不涉及操作风险。
- [ ] **比较营养价值必须在同一食物类别内** —— 本条为比较方法，不涉及操作风险。
- [ ] **营养素有协同：蛋白质的互补作用** —— 本条为搭配方法，不涉及操作风险；互补提升的是蛋白质质量，不改变蛋白质总量上限。
- [ ] **营养代谢的影响分三个时间尺度** —— 长期高盐饮食者若出现血压升高、头痛头晕，应就医测量血压并排查，而不是只靠自己"吃得清淡点"观察。
- [ ] **规则一：零存整取，多退少补（有储存池的营养素）** —— 缺铁症状（乏力、面色苍白、活动后心慌）持续存在时应就医查血常规和铁代谢指标，明确缺铁原因（尤其消化道失血可能），不要自行长期补铁。
- [ ] **规则二：按需摄入，即产即用（无储存池的营养素）** —— 出现乏力、牙龈出血等缺乏症状时应就医排查（牙龈出血也可能是血液系统疾病信号），确认缺乏后再补充并观察恢复情况。
- [ ] **规则三：单向转化，各司其职** —— 长时间极低热量饮食导致明显消瘦、乏力、免疫力下降时须就医评估；蛋白粉等补充剂量和频次应与营养师确定（见第 5 讲）。
- [ ] **规则四：稳态可调节，失衡可致病** —— 长期极端节食者若出现明显消瘦、闭经、晕厥等信号，提示稳态调节已接近极限，必须就医，不能靠"再扛扛"。
- [ ] **酶活性差异决定营养利用能力的个体差异** —— 孕期叶酸补充方案（补不补、补多少）须经产科或妇幼保健机构评估，检测风险高者按医生指导加量，不可自行大幅加量——加量会干扰锌代谢。
- [ ] **营养基因组学检测：特殊人群需要，普通人不必** —— 本条为消费决策判断；若做检测后对结果有疑虑，应找有资质的临床遗传或营养专业人员解读，不要按检测机构的市场话术自行调整饮食。
- [ ] **苯丙酮尿症：不能治愈，但可以靠控制摄入避免恶化** —— 确诊患儿的膳食管理必须在专科医生和营养师指导下长期执行；擅自恢复正常饮食会导致苯丙氨酸堆积、神经损伤。若新生儿筛查未通过，尽快到专科复诊确诊。
- [ ] **代谢影响表达（一）：转录因子通路** —— 吃得很清淡却查出脂肪肝、肝功能异常时，应就医查明原因（还可能有其他病因），不要自行归因或停食。
- [ ] **代谢影响表达（二）：表观遗传学印记可传三代** —— 孕期营养干预应由产科医生指导，刻意节食或大补都属极端信号变化，均有风险。
- [ ] **碳水是供能性价比最高的"清洁能源"** —— 执行生酮饮食期间出现明显乏力、恶心、意识模糊等酮体累积信号须立即停止并就医。
- [ ] **碳水吃多少：跟需求不跟欲望，按活动量调整** —— 大幅削减碳水出现乏力、头晕、注意力涣散时，说明摄入已低于需求，须回调并就医排查；本条不适用于未经评估的糖尿病患者自行执行。
- [ ] **你以为的"低碳水饮食"其实并不低** —— 本条为认知纠偏，不涉及操作风险；真想执行严格低碳水（生酮）须先评估并监测酮体（见 A1 安全栏）。
- [ ] **好碳水 = 全谷物：差别在加工方式** —— 从精米精面突然全换全谷物可能引起腹胀、消化不良，应逐步替换；胃肠术后患者饮食须遵医嘱。
- [ ] **添加糖控制在总能量 10% 以下，5% 以下更好** —— 本条为摄入上限建议，不涉及急症；糖尿病患者对添加糖须按医嘱更严格限制。
- [ ] **碳水总量不变，分到 5～6 餐平抑餐后血糖** —— 加餐要计入全天碳水总量，不是额外多吃；糖尿病患者分餐后仍须监测血糖，出现心慌出冷汗等低血糖信号及时处理并就医。
- [ ] **蛋白质缺乏表现多样，常被误认成其他病** —— 关节疼、胎儿发育偏小、注意力不集中都必须先经医院检查排除器质性疾病，不能直接归因于营养；排查无果后应到营养科（临床营养）评估膳食，而不是自行诊断。
- [ ] **补蛋白质：吃什么不重要，吃足量才重要** —— 长期明显蛋白质摄入不足（水肿、伤口愈合慢、反复感染）应就医评估，不要只靠自行加量；蛋白粉属膳食补充，不可替代正餐，超量补充的风险应咨询专业人员。
- [ ] **食物蛋白含量估算三数：肉 20、蛋 6、奶 3** —— 估算值是粗略参考，不能用于临床营养治疗的精确计算；肾病等须精确控蛋白的人群以医院营养科处方为准。
- [ ] **不那么优质的蛋白，靠多元组合凑成优质** —— 本条为搭配方法，不涉及操作风险；互补提升的是质量而非允许无限量，总量仍按 A2 标准。
- [ ] **两个搭配之一：碳水和脂肪充足，蛋白质才能干正事** —— 长期热量摄入过低、肌肉流失明显（乏力、免疫力下降）时须就医评估，恢复正常碳水脂肪摄入。
- [ ] **发胖的根源是总热量超标，不是脂肪本身** —— 本条为饮食认知；若采用高脂代餐方案后出现消化不良、血脂升高，停止并就医复查血脂。
- [ ] **脂肪有不可替代的功能：激素合成与脂溶性营养素吸收** —— 低脂饮食期间出现月经周期紊乱、头发干枯、皮肤变差等信号时，应停止极端低脂并就医评估激素与营养状况。
- [ ] **脂类代谢分"出入"两路，输出出问题吃得再低脂也没用** —— 体检发现脂肪肝或血脂异常时，应就医明确是代谢输出问题还是其他病因，在医生指导下治疗与调整饮食，不可只靠"吃清淡点"自行处理；血脂报告中低密度脂蛋白升高是心血管风险信号，须随访。
- [ ] **反式脂肪酸是头号反派：人造黄油的教训** —— 购买包装食品看配料表，出现"氢化植物油""植脂末""人造奶油"等字样要提高警惕；已有心血管疾病或血脂异常者应尽量不接触油炸加工食品。
- [ ] **挑油不看动植物，看烹饪方式匹配** —— 任何油反复高温使用都会加速劣变，炸过东西的油不建议重复多次使用；油锅冒烟再下菜的习惯应改掉。
- [ ] **血液胆固醇不等于食物胆固醇** —— 体检发现血液胆固醇升高时须就医评估心血管风险，不能因为"血液胆固醇与食物关系不大"而忽视异常指标。
- [ ] **膳食纤维的地位翻转：两次认知升级** —— 本条为历史认知，不涉及操作风险。
- [ ] **不溶性与可溶性膳食纤维：两种功能两条路** —— 长期便秘突然加重、便血、排便习惯明显改变时先就医排查肠道疾病，不要只靠多吃纤维自行处理。
- [ ] **肠道菌群吃纤维产短链脂肪酸，菌群吃不到就啃肠黏膜** —— 长期腹泻、便血、反复肠道感染须就医，不要自行归因于菌群失调。
- [ ] **每天多少纤维：25～30 克，红富士苹果 250 克约 5 克** —— 短期内大幅增加纤维摄入可能引起腹胀胀气，应循序渐进；出现持续腹泻、腹痛须减少摄入并就医。
- [ ] **补充剂效果不确定，且上限只有 75 克——易吃过量** —— 吃补充剂期间出现持续腹泻、腹痛、体重下降、营养不良信号时立即停用并就医；胃部手术后的患者饮食方案须经医生确认。
- [ ] **水参与代谢全过程，是代谢顺利的基础** —— 运动中大量出汗后出现腿部抽筋，提示离子浓度失衡，应及时补水并观察；抽筋反复发作或伴心慌、意识改变须就医。
- [ ] **渴感滞后 500 毫升，喝水不能跟感觉走** —— 婴儿腹泻失水过多时，捏起腹部皮肤可见皮褶回弹速度变慢，提示代谢平衡已被打破，必须尽快寻求专业医生帮助。
- [ ] **慢性脱水：每天液体不足 1.5 升，肾脏迟早受损** —— 出现尿量明显减少、腰痛、血尿、反复尿路感染时及时就医查肾功能与泌尿系统；确诊肾病后饮水量由医生个体化制定，不可照搬通用标准。
- [ ] **尿液颜色是最直接的补水仪表盘** —— 尿液持续无色透明（可能过量）或深褐色、伴皮肤黏膜明显干燥、精神差→调整饮水并就医；婴儿皮褶回弹变慢属急症信号，立即就医。
- [ ] **含酒精咖啡因的饮料别算进液体摄入量** —— 大量饮酒后出现明显口渴、尿多、头痛是脱水叠加信号，须补充白水；有失眠、心悸等咖啡因不耐受表现者减少相关饮料。
- [ ] **两个极端：水中毒与矿泉水矿物质误区** —— 长时间运动中补水应分次、适量，不要短时间豪饮；运动后出现头痛、恶心、呕吐、意识模糊（低钠血症信号）立即就医。
- [ ] **维生素遍布各大类食物，光吃蔬果解决不了** —— 长期素食者出现精神差、手脚麻木等神经症状时及时就医并检测 B12；孕期与特定疾病人群的补充方案遵医嘱。
- [ ] **维生素 D 靠晒太阳（80%），K 靠肠道菌群** —— 佝偻病、骨质软化相关症状（儿童骨骼变形、成人骨痛）提示维生素 D 缺乏，就医检测后再补充；新生儿未注射维生素 K 者向产科医生确认；不明原因出血倾向、割伤后难止血须就医。
- [ ] **烟酒、加工方式、缺水都会额外损耗维生素** —— 本条为损耗因素认知；长期吸烟者出现伤口愈合慢、牙龈出血等信号时就医评估，同时应优先戒烟而非加量补维生素。
- [ ] **补剂只能当辅助：小药片模拟不了食物的营养世界** —— 补剂不能替代药物治疗；服用期间出现不适（如大剂量维生素C引起腹泻）应停用并咨询医生。
- [ ] **脂溶性维生素 A/D/E/K 过量会中毒，无处方别大剂量** —— 过量中毒信号：头痛、恶心呕吐、皮肤干燥脱屑（A）、高钙血症表现（D）等，出现可疑症状立即停用并就医；儿童误服维生素补剂按误服药物处理，立即就医。
- [ ] **矿物质分类：教科书看含量，实用看饮食还是环境相关** —— 本条为分类框架；盲目补充矿物质（尤其微量元素）有过量风险，补充前先评估饮食与体检指标。
- [ ] **饮食相关型：只记一条习惯，就叫"不偏食"** —— 孩子出现反复生病、生长迟缓、发育落后时先就医做鉴别诊断，缺锌只是可能原因之一，不可自行诊断并盲目补锌制剂。
- [ ] **成对矿物质"此长彼消"：钠钾与钙磷** —— 已确诊高血压、骨质疏松者调整钠钾钙磷摄入前咨询医生，正在用药者不可自行停药换药；血钾异常（乏力、心悸）须就医，不可自行大量补钾。
- [ ] **环境相关型：地域缺乏由国家宏观调控兜底** —— 心悸、呼吸困难、不明原因休克史者及时就医排查心脏疾病；甲状腺疾病患者是否食用碘盐须咨询内分泌医生，不要自行切换。
- [ ] **想摄入更多元的环境相关矿物质：换产地吃** —— 本条为采购习惯建议，不涉及操作风险；购买渠道须正规，保证食品安全。
- [ ] **评价饮食模式先看宏量营养素比例** —— 本条为评价视角，不涉及操作风险。
- [ ] **碳水占比与死亡风险呈U型** —— 本条为人群统计关联，不等于个体预测；本身患病（如糖尿病、肾病）者碳水目标须由医生或营养师确定，不要自行向两个极端调整。
- [ ] **中国人的推荐比例：碳水50%-65%** —— 疾病状态（如糖尿病、肾病、痛风）下自行套用通用比例可能加重病情，须先经医生或临床营养师评估。
- [ ] **圆形餐盘法则：半盘菜、两个四分之一** —— 本条为搭配方法，不涉及安全红线；若执行后出现持续乏力、体重快速下降等信号，说明比例或总量不适合，应就医评估。
- [ ] **生酮（阿金）饮食：短期减重，长期获益存疑** —— 执行极低碳水饮食期间若出现明显乏力、便秘、月经紊乱等信号，应停止并就医评估；原文未给该模式的执行时长上限。
- [ ] **脂肪别压得太低** —— 本条为方向提醒，不涉及红线；已确诊需低脂饮食（如胰腺、胆囊疾病）者遵医嘱，不适用此条。
- [ ] **日常饮食不必计算食物热量** —— 本条为方法取舍，不涉及安全红线。
- [ ] **控热量看热量密度，不看热量** —— 本条为选择标准，不涉及红线；但只吃低密度食物会饿得快，执行时须配合 A4 的时机策略。
- [ ] **热量密度三组划分** —— 本条为分类知识，不涉及安全红线。
- [ ] **时机策略：高密度食物留给"只有食欲"时** —— 本条为进食时机安排，不涉及红线；若频繁出现餐前心慌、手抖、出冷汗等低血糖信号，应就医而不是靠加餐硬扛。
- [ ] **热量释放速度：远离"空白卡路里"** —— 本条为供能机制认知，不涉及红线；糖尿病患者调整碳水种类与量须遵医嘱监测血糖。
- [ ] **手掌估量法：一顿吃多少** —— 本条为估量工具，不涉及红线；按此执行仍出现体重持续上升或下降、月经紊乱等信号时，应就医评估。
- [ ] **优先选新鲜、多样、完整的普通食材** —— 本条为选择原则，不涉及红线；但"完整"须以食品安全为前提（生食风险见下一讲）。
- [ ] **贵的食材不一定营养更高** —— 孕期与儿童长期食用大型掠食鱼类有重金属蓄积风险；若食用后出现不明原因神经症状（麻木、协调异常），就医并告知饮食史。
- [ ] **判断加工程度：认原料、数配料表** —— 本条为筛选规则，不涉及红线；配料表不能替代对变质、过敏原的检查。
- [ ] **多样的价值：缺陷食材互相组合** —— 本条为搭配原则，不涉及红线；食物过敏者组合时须先排除自己的过敏原。
- [ ] **抗氧化剂：食物有相关红利，补充剂连相关都没有** —— 大剂量抗氧化补充剂并非无害（原文未展开具体风险）；已确诊疾病者不得用补充剂替代规范治疗。
- [ ] **膳食补充剂只补缺口** —— 补充剂不能替代治病；长期大剂量补充任何单一营养素前应咨询医生，出现便秘、结石史等信号（补钙相关）先就医评估。
- [ ] **头号风险：食物中毒，不确定就不吃** —— 食用可疑食物后出现呕吐、腹泻、口唇麻木、呼吸困难等信号，立即就医并保留剩余食物；怀疑毒蘑菇中毒即使症状缓解也要就医（原文强调致死率高）。
- [ ] **一类致癌物：分类看证据，危险看频率剂量** —— 发现自家榨油或谷物坚果有霉变（黄曲霉素高风险）立即整批丢弃，不可加热后继续食用；黄曲霉素耐高温，常规烹煮不能破坏（推断）。
- [ ] **酒精的安全剂量是0** —— 饮酒后出现面色极快潮红、心悸、呕吐等强烈反应者应立即停止；长期饮酒者戒酒时若出现手抖、幻觉等戒断反应，须就医，不可自行硬戒。
- [ ] **三号风险：高钠、高添加糖、反式脂肪** —— 本条为长期风险认知，不涉及急症红线；已确诊上述慢性病者按医嘱执行更严格的膳食限制。
- [ ] **营养成分表三看：钠、添加糖、反式脂肪** —— 本条为筛选技巧，不涉及红线；婴儿配方食品等特殊品类按国家标准选购，不只看这三个值。
- [ ] **过敏完全避免，不耐受可以练耐受** —— 过敏反应出现荨麻疹、呼吸困难是急症信号，立即就医；既往有严重过敏史者须随身遵医嘱备急救药物，不可用"练耐受"方式试探过敏原。
- [ ] **蛋白质是免疫系统的基石** —— 长期蛋白摄入不足叠加反复感染、伤口不易愈合等信号，应就医评估营养状况，不要自行大量补充蛋白粉。
- [ ] **免疫力不是越强越好，营养素可双向调节** —— 大剂量补充单一"免疫营养素"（如锌、硒）可能中毒或干扰其他矿物质吸收，须在缺口内补充。
- [ ] **肠道是营养吸收与免疫反应的共同场所** —— 持续腹泻、便血、明显消瘦不是"肠胃不好"能解释的，须就医排查。
- [ ] **成人吃免疫球蛋白产品用处不大** —— 本条为消费判断，不涉及红线；购买前注意此类产品不能替代治病，出现反复感染应就医。
- [ ] **提高免疫力没有特殊食物，均衡饮食就是方案** —— 本条为日常策略；出现反复严重感染、长期低热等免疫异常信号，就医而不是靠食疗。
- [ ] **免疫异常疾病不归营养管** —— 正在使用免疫抑制剂者不可自行停药、换药或加量；出现感染加重、关节红肿热痛明显恶化等信号，立即复诊。
- [ ] **干预分两层：治疗与支持，鸡汤属支持** —— 把"食疗"当唯一治疗而延误就医是最大风险；高热不退、呼吸急促、精神萎靡等信号必须就医。
- [ ] **营养可直接治疗的三类疾病** —— 疾病治疗决策必须就医；用营养手段替代规范治疗导致病情延误是最重要的红线。
- [ ] **营养素缺乏类：补足缺乏的部分** —— 贫血先就医查因再补铁，自行长期补铁可掩盖失血性疾病的诊断；补铁后症状不改善或出现黑便、持续乏力，立即复诊。
- [ ] **消化道损伤类：提供黏膜修复原材料** —— 出现呕血、黑便、持续上腹痛、体重明显下降等报警信号，立即就医，不能靠食补扛。
- [ ] **代谢异常类：糖尿病指南第一位是改饮食** —— 已在使用降糖药或胰岛素者不可自行停药、换药；调整饮食期间出现低血糖（心慌、出汗、手抖）按医嘱处理并及时复诊。
- [ ] **"某种食物治某病有奇效"基本不靠谱** —— 用"奇效食物"替代规范治疗会直接延误病情；肿瘤患者出现治疗不耐受时找主管医生与临床营养师调整，不要自行改用食疗。
- [ ] **恶液质导致五分之一的恶性肿瘤患者死亡** —— 患者体重持续下降、进食量明显减少、呕吐无法进食，须尽快联系主管医生与临床营养师，不要等。
- [ ] **患者的第一目标：热量和蛋白质吃足量** —— 为让患者吃足量而放松的健康标准不等于放弃食品安全；出现完全无法进食、持续呕吐，须就医评估，可能需要升级支持手段。
- [ ] **营养支持5级台阶：达不到60%就升级** —— 管饲与静脉营养属医疗操作，必须由医院执行；居家患者出现呛咳、腹胀、导管口红肿、发热等信号，立即联系医疗团队。
- [ ] **口服营养补充剂不是保健品** —— 选用须遵临床营养师处方；出现腹胀、腹泻、血糖异常波动等不耐受信号，反馈医生调整配方。
- [ ] **营养支持不替代原发病治疗** —— 以"营养支持"为由推迟、拒绝放化疗或手术，是最危险的错误；治疗决策变更必须回到主管医生。
- [ ] **体型管理 = 能量缺口 + 营养改善** —— 节食期间出现乏力、脱发、月经紊乱、便秘等信号，说明方式不健康，应停止并就医评估。
- [ ] **体重变化看一周趋势，不看单日波动** —— 本条为监测方法；若趋势持续上升伴明显口渴多尿或持续下降伴乏力，尽早就医排查。
- [ ] **腰围过大是独立于肥胖的健康风险** —— 体重正常但腰围持续增大、体检发现脂肪肝，应就医并做代谢评估，不要因"不超重"而忽视。
- [ ] **减肥没法指哪儿瘦哪儿** —— 本条纠正认知，不涉及红线；腰腹训练中出现腰痛、颈椎痛应停止并调整动作或就医。
- [ ] **能量过剩不等于营养过剩，胖人常营养不良** —— 长期节食减肥叠加乏力、贫血、口腔溃疡等信号，应就医查营养状况，不要继续加码节食。
- [ ] **减内脏脂肪的循证方式** —— 执行中若出现头晕、心悸、月经紊乱、持续乏力，立即停止当前方案并就医；减重期间不追求快速掉秤。
- [ ] **食物分三档，按档定频率** —— 本条为频率管理，不涉及急症红线；已确诊与饮食相关疾病者按医嘱收紧分档。
- [ ] **每天吃出"一道彩虹"：15种以上，优先深绿和橙色** —— 本条为多样性策略，不涉及红线；食物过敏者按自己的过敏原排除后执行。
- [ ] **每周复盘热量，体重骤变超15%要警惕** —— 饮食运动未变而3个月内体重变化超15%，尽早就医排查甲状腺、消化道、肿瘤、糖尿病等问题，不要先自行调整饮食了事。
- [ ] **热量系数匹配需求：轻度30、中度35、重度40** —— 本条为估算工具，数值粗糙；按估算执行后体重持续下降或明显上升，重新评估系数或就医。
- [ ] **按环境变化调整，按体检结果修正** —— 体检指标异常须由医生判断是否用药，不可只用饮食调整拖延治疗；尝试新饮食模式期间不适加重，停用并就医。
- [ ] **大脑耗20%葡萄糖且无法储备，血糖过高低都犯困** —— 规律进食仍持续犯困、伴口渴多尿或注意力显著下降，就医排查血糖异常等疾病，不要只靠咖啡硬撑。
- [ ] **早餐碳水搭蛋白质与膳食纤维，放慢升糖速度** —— 本条为搭配策略；出现餐前心慌、手抖、出冷汗等低血糖信号，立即进食并就医查明原因。
- [ ] **MIND饮食模式：健脑食物组与损脑食物组** —— 本条为长期饮食模式，不涉及急症红线；已出现明显记忆减退应就医，不能靠饮食模式替代诊治。
- [ ] **中餐的损脑坑与个人方案设计** —— 本条为饮食安排，不涉及红线；坚果热量密度高，加餐量不宜随意放大（见012讲）。
- [ ] **修复受损脑细胞：两个思路都还没有实际应用** —— 不要因"营养素能修复大脑"而自行大剂量补充叶酸、B族维生素等；已确诊神经系统疾病者治疗遵神经科医生，出现症状加重及时复诊。
- [ ] **改变行为：触发时机加最小行动方案** —— 本条为行为方法，不涉及红线；依赖行为改变处理成瘾（如戒烟）困难时，寻求专业戒烟门诊帮助。
