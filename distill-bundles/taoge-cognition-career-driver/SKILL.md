# 职业路线驱动包（Xue Yiran Career Driver）

> **一句话定位**：一套在不确定性中把握职业确定性的思考工具——向内看定优势（天赋×投入），向外看定层级与快车道，动态互证没有康庄大道。
> **来源**：薛毅然·怎样找准你的职业路线（得到，人才发展专家，12000次面试+700人辅导实证，2026-10-27 S级归档ZL01-ZL18共18篇）。

---

## 一、总图（一句话记住）

**职业发展=你作为人力资源与市场"整合"的过程；先看自己定优势（天赋×投入），再看职场定层级（四阶图谱+3个GAP），再看市场定快车道（同事都比你牛+可带走的能力资源）；向内看与向外看动态互证，没有一劳永逸的康庄大道**

| 三段 | 三个关键词 | 核心问题 |
|---|---|---|
| 看自己 | 天赋×投入 / 自我洞察+他人眼光+测评 / 立足优势 | 你的护城河在哪个领域？哪类事你做起来时间飞逝？ |
| 看职场 | 四阶能力图谱 / 四圈层能力库 / 最小可行性单元 | 你现在到哪一级？下一级要补哪3个GAP？ |
| 看市场 | 宽胶带 / 四问还原岗位 / 接触点价值呈现 | 你的快车道在哪？怎么让机会主动找上门？ |

## 三、职业定位五步 SOP

1. **墓志铭定方向（ZL01+ZL11+ZL14）**：闭眼想"如果衣食无忧你最想做什么"+墓碑上希望写什么+五年后三场景哪个状态你喜欢。不是拍"哪个工作好"，是拍"我要成为什么样的人"。
2. **素质模型倒推（ZL03+ZL04）**：锁定目标方向后，找该路径上"准高手/目标岗位"的能力素质模型（看招聘JD+观察上级+找圈内人聊），按四圈层（自我管理/人际交往/思维决策/领导团队）打分，定3个能力GAP。
3. **定位能力层级（ZL02+ZL03）**：用四阶图谱定位你现在到哪一级（小白/独当一面/准高手/高手），警惕两个陷阱：独当一面别当流程搬运工，准高手阶段要尽早进入。同时用优势三问+他人眼光+测评重合区校验方向是否在你的天赋×投入领域。
4. **找发力点补短板（ZL05+案例方法律）**：动机先开USB接口，认知建构（主题阅读/培训/观察交流），再用最小可行性单元日常刻意练习10天起；动机不足的GAP不硬补，换方向。
5. **选市场快车道（ZL06+ZL07+ZL08）**：用两标准筛具体岗位（同事都比你牛+可带走的能力资源），四问还原岗位真相；同时建接触点做价值呈现（工作标签+作品/线下留钩子/互联网持续输出），收敛成一句话个人产品说明书。最后回到第一步，动态循环验证。

输出格式：结论先行（你要成为谁→目标方向→现在卡在哪一级→3个GAP→第一份/下一份工作该满足哪两条）→ 每步证据 → 落点（唐翌轩升学规划/冠生园团队用人/个人IP 行动项）。

## 五、边界

- 本包是**职业认知框架与决策工具**，不替代具体行业情报、机会判断与薪酬谈判（那是猎头/行业研报/实地调研的活）。ZL06"四问还原岗位"必须真去问在读生/圈内人，不能拿本包结论当事实。
- 案例方法论≠个人照搬：ZL09-ZL18每个案例都是特定测评（MBTI/九型）+特定家庭/经济/年龄背景下的建议，迁移时必须先校验"这个人/这个孩子"的动机、长板短板、家庭负担是否吻合，尤其是ZL15考研建议与ZL16高学历转向都有明确适用边界。
- 测评工具（MBTI/九型/盖洛普/DISC/BIG FIVE）测的是当下状态不是永久特质，社会化面具会让结果趋同；ZL02的"多测评+多咨询师重合区"才是高置信路径，单次测评结果别当判决书。
- 模型置信度：ZL01-ZL08 正课8律为S级归档（薛毅然7讲完整方法论，2026-10-27）；ZL09-ZL18 案例十讲为极短音频（40秒-1分09秒），已合并提炼为5条案例方法律（转型路径/理想并行/专业路线/愿景倒推/长期当断），原始案例细节见各md；ZL01发刊词与ZL08总结为总纲律不单列工具。
- 更新规则：认知革命项目每新增职业规划/人才发展/教育升学类模型，同步追加本包。
