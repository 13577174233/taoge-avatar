# 酒水市场晨间分析

面向普通人的酒水市场解读：买酒不踩坑，看清行业风向。

## 分析范围

- 白酒：名酒批价/出厂价/调价、库存与渠道、宴请场景变化
- 啤酒：销量与高端化、精酿趋势
- 葡萄酒与威士忌：进口数据、年轻化消费、电商渠道
- 政策与监管：白酒新国标、税收、健康理性饮酒倡导
- 电商酒水：大促酒水专场、直播卖酒

## 晨间分析步骤

1. 检索过去24小时酒水行业新闻（调价、财报、政策、销量数据）
2. 落到"与我何关"：
   - 宴请送礼：什么价位、什么品类是当下主流，预算建议
   - 日常消费：啤酒/葡萄酒/威士忌的价格与选择变化
   - 收藏与投资：明确风险提示，不构成投资建议
3. 注意时节场景：节日礼盒、婚宴、年货节等节点提前量
4. 边界：不提供个股/投资建议；强调理性饮酒、健康饮酒

## 关键数据源

- 行业：中国酒业协会、酒业家、云酒头条、今日酒价（名酒批价）
- 财报：白酒上市公司季报年报
- 进口数据：海关总署

## 输出模板

```
[酒水] 标题
市场动态：价格/销量/政策一句话
与我何关：宴请送礼建议 / 日常消费变化 / 收藏风险提醒
```
