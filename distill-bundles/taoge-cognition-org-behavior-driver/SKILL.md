# 组织行为驱动认知包（Org Behavior Driver）

> **一句话定位**：一套把"人、团队、组织"变成可诊断、可执行、可复用的战术手册——公司是生物有自己的行为规律，你有你的逻辑，组织另有逻辑。
> **来源**：李育辉·组织行为学（2026-10-26 S级归档LY01-LY29共29篇），李育辉为中国人民大学劳人院教授/博导。

---

## 一、总图（一句话记住）

**个体（情绪/动机/角色/承诺）→ 群体（匹配/融入/认同/凝聚力/决策）→ 组织（搭班子/节点/授权/冲突/政治/心智/自上而下）→ 前沿交叉（环境/强互惠/负向激励/意义感）；三条暗线：环境大于激励、团结是双刃剑、变革必须自上而下。**

| 模块 | 核心问题 | 核心模型群 |
|---|---|---|
| ①激发个体 | 怎么把个体潜能激发出来？ | 情境强度塑人/情绪资源有限/主角合伙人动机/角色中心性/职业承诺/工作嵌入/彩虹年龄锚点 |
| ②领导团队 | 团队怎么建、领导怎么当？ | 三种新匹配（人-人/角色/潜力）/非正式合群/露情绪留空间/相对剥夺快速凝聚/团体迷思三破解 |
| ③重塑组织 | 组织变革怎么搞？ | 先搭班子再定战略/节点人物/心理授权三维/冲突不个人化/政治三分类划红线/共享心智地图/高阶理论自上而下 |
| ④最前沿 | 学科最前沿突破是什么？ | 启动效应环境先行/强互惠利他惩罚/基因控制变量/负向激励建设性批评/意义感透明化+重建阶梯 |

## 二、核心律速查（24律）

### ① 激发个体

| 编号 | 模型 | 一句话 |
|---|---|---|
| LY01 | 信息河流律 | 绩效差异跟非正式聊天机会多不多唯一相关。组织中除了物质能量流动，还有一条看不见的信息河流 |
| LY02 | 权变无绝对真理律 | 组织行为是权变的——A导致B，但必须加一句"在C条件下" |
| LY04 | 情境强度塑人律 | 改变性格的不是时间长短，是情境强度。四维：明确性/一致性/约束性/严重性 |
| LY05 | 情绪资源有限律 | 情绪不是用来平复的感受，是有限资源——会耗竭需要补充。派活不只看谁能力强，还要看谁的情绪资源还有余量 |
| LY06 | 主角合伙人动机律 | 新生代天生要当主角。解法：把自己当投资人，把员工当创业合伙人——一起定目标、给资源做投后管理 |
| LY07 | 角色中心性律 | 工作生活冲突本质不是时间不够分，是角色打架。解法不是划时间边界，是管理角色 |
| LY08 | 职业承诺律 | 组织承诺（员工忠于公司）过时了——企业平均寿命越来越短。新逻辑：员工忠于职业赛道不忠于公司 |
| LY09 | 工作嵌入律 | 组织可以跨出工作边界，帮员工搞定社区地位和家庭需求——成本极低效果极强 |
| LY10 | 彩虹年龄锚点律 | 学习欲望最高峰不在18岁而在45岁。45岁左右极其看重"持家者"角色 |

### ② 领导团队

| 编号 | 模型 | 一句话 |
|---|---|---|
| LY11 | 领导力互动律 | 真正的领导力不在老板一个人身上，在他和团队的互动关系里 |
| LY12 | 三种新匹配律 | ①人-人匹配（照着最牛的人招同类）；②角色匹配（招鼻子眼睛眉毛，走一个只补一个零件）；③潜力匹配（不为现在招为未来战略招） |
| LY13 | 非正式合群律 | 新人先和1-2个人配对→组成小型网络→再靠这个网络打入大群体。别搞全员正式团建 |
| LY14 | 露情绪留空间律 | 主动暴露情绪让追随者觉得"老板有些地方搞不定得我来"。红线：只暴露情绪，绝不暴露能力 |
| LY15 | 相对剥夺凝聚律 | 领导在态度上狠一点，大家觉得"我们都是被压迫的人"从而抱团。四条红线：剥夺要公平/只碰自尊不碰钱/会后给足资源/赢了分果实 |
| LY16 | 团体迷思律 | 越团结的团队越容易决策失误。三破解：指定唱反调的人、引入外部视角、弱化强势者（领导最后发言） |

### ③ 重塑组织

| 编号 | 模型 | 一句话 |
|---|---|---|
| LY17 | 先搭班子优先律 | 先搭班子再定战略。人事变动牵动整个领导力关系网，调整效果天然滞后 |
| LY18 | 节点人物律 | 拉平之后资源配置依据从"谁是部门经理"变成"谁是互动网络里的节点人物" |
| LY19 | 心理授权律 | 授权关键是让他产生"心理授权"——三维度：目标内化/控制感/效能感。授权真正目的是培养人不是把事办好 |
| LY20 | 冲突不个人化律 | 冲突多≠内耗大，冲突增多反而降低内耗。内耗不是因为冲突多，是冲突被个人化了 |
| LY21 | 政治三分类律 | 政治是一种技能不是专门搞破坏的动机。第三类排除异己+实质利益交换=红线必须坚决制止 |
| LY22 | 共享心智地图律 | 不共享知识本身，共享"知识地图"——遇到问题时能准确找到对的人 |
| LY23 | 高阶理论自上而下律 | 公司出大问题大概率是上面的问题——"问题出在前三排，根子还在主席台"。成功变革走阶梯式传导：CEO→高管团队→中层→基层 |

### ④ 最前沿

| 编号 | 模型 | 一句话 |
|---|---|---|
| LY25 | 启动效应环境律 | 环境不是加成项是先决条件——环境直接启动你的认知模式。圆桌/绿植/暖色调 |
| LY26 | 强互惠利他惩罚律 | 企业做了不道德的事，即使工资没变员工离职率飙升。企业社会责任做得越多团队效能反而提高 |
| LY27 | 基因控制变量律 | 别信"基因算命招聘"——基因预测复杂行为准确度不到3% |
| LY28 | 负向激励创造律 | 处理创新行为的脑区和处理消极情绪的脑区是重合的，负面情绪和创新高度相关。运营岗多夸创意岗多争论 |
| LY29 | 意义感重塑律 | 员工要产生工作意义感+主动性需要两个条件——外部环境提供宽容的价值评价体系、外部有进步榜样/努力阶梯 |

## 三、组织诊断五步 SOP

1. **先站组织逻辑（LY01+LY02+LY11）**：信息河流流向哪里？管理动作是普世口号还是权变因人？
2. **盘个体（LY04+LY05+LY06+LY07+LY08+LY09+LY10）**：情绪资源还有余量吗？动机是配角诱饵还是主角合伙人？他忠于公司还是忠于职业赛道？
3. **配团队（LY12+LY13+LY14+LY15+LY16）**：招人是照着最牛的人招同类，还是补角色缺口？有没有团体迷思症状？
4. **塑组织（LY17+LY18+LY19+LY20+LY21+LY22+LY23）**：先搭班子还是先定战略？节点人物是谁？授权前答三问了吗？
5. **造前沿环境（LY25+LY26+LY28+LY29）**：环境启动效应做到了吗？社会责任红线守住了吗？创新岗有没有建设性争论？

输出格式：结论先行（团队能打什么仗/组织健康红灯绿灯）→ 每步证据 → 落点（三场景行动项）。

## 五、边界

- 本包是**战术手册**，不做战略判断与财务分析；不做产品定义与增长设计。
- 学科立场：权变——A导致B必须加"在C条件下"，没有绝对真理。组织行为学是偏战术学科，别因战术勤奋掩盖战略懒惰（LY23终极忠告）。
- 模型置信度：LY01-LY29 均为 S级归档蒸馏（李育辉·组织行为学，2026-10-26）；本包选取其中跨项目复用率最高的24条为核心律，其余保留在 模型地图.md 备查。
