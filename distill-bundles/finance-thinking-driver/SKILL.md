# 财务思维驱动认知包（Finance Thinking Driver）

> **一句话定位**：一套把"财报"从会计报表翻译成经营诊断书的判断工具——看穿表内三表、追问表外藏物、选对钱的性格、给项目排兵布阵，一切数字与商业模式互证。
> **来源**：贾宁·财务思维课（FN01-FN42共41篇S级归档，2026-10-24全量收官），三模块：表征13讲+融资管理13讲+投资分配10讲+结束语加餐。

---

## 一、总图（一句话记住）

**财务 = 三表体检 × 负债两分 × 利润质量 × 现金生死 × 钱的性格匹配 × 项目排兵布阵**

财报是体检表不是公司本身——先剔非经常性损益、再拆有息无息、再验经营现金流；融资不是拿到钱而是拿对钱（期限/风险/耐心匹配项目）；投资不是算准价值而是发现市场错误；并购里商誉是灰犀牛，分红多寡看自由现金流而非当期利润。

## 二、核心律速查表（FN系列41条，按模块分组）

### 模块一：表征——三表怎么看（FN02-FN14，13讲）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| FN02 | 报表边界律 | 公司能装进报表的只是部分，品牌/私域/团队在表外 |
| FN03 | 未来收益律 | 能生未来钱的才是资产；滞销库存果断费用化 |
| FN04 | 资产结构律 | 固资存货占比=经营战略心电图；应收账龄每拖半年回收率腰斩 |
| FN05 | 负债两分律 | 负债率先看行业再拆性质：无息占款是模式，有息负债才是风险 |
| FN06 | 表外负债律 | 行业隐性债+应并表未并表+ABS要加回再算 |
| FN07 | 利润革命律 | 近似的正确好过精确的错误；利润是观点 |
| FN08 | 利润质量律 | 只盯主要+经常性利润；利润决策相关性从61.4%（1960s）降到33.6%（2010s），现金/研发/销售权重上升 |
| FN09 | 现金水平律 | 利润决定发展现金决定生死；现金比率畸高反而要查投资效率 |
| FN10 | 现金结构律 | 经营现金流为负先定位生命周期：成长期负+输血跟上=成长股 |
| FN11 | 财报实战律 | 凡有表象必有秘藏；数字必须与商业常识互证 |
| FN12 | 造假三线索律 | 数字反常→单位常识拆解→收现能力互证→实地验证（蓝田标本） |
| FN13 | 附注腾挪律 | 主表是结果附注是方法；会计政策变更是合法利润调节阀（折旧年限延长=利润变脸） |
| FN14 | 审计独立性律 | 非标意见直接pass；审计师独立性看声誉/任期/业务往来/旋转门四维 |

| 编号 | 模型名 | 一句话 |

| FN20 | IPO抑价律 | 首日大涨不是卖便宜是信号投资——留钱买信心/后续增发/员工期权 |

| FN24 | 反噬效应律 | 局部财务优化会引发全局反噬；研发资本化/利润调节要横比竖比 |
| FN25 | 利润中心律 | 人人都是自己的CEO；把成本中心改成利润中心+转移定价 |
| FN26 | 股权质押律 | 质押=大股东用股票借债；高质押率+股价下跌=爆仓连锁 |

| 编号 | 模型名 | 一句话 |
|---|---|---|

| FN31 | 风险点线面律 | 点=保本底线，线=双向波动，面=情景组合；财务怕的不是风险是盲目 |
| FN32 | 实物期权律 | 高不确定性项目买"投资柔性"；爱尔眼科并购基金模式 |

## 三、财务全链路诊断 SOP（6步）

遇到"这家公司/这笔融资/这个项目靠不靠谱"类问题时按序走：

1. **体检三表（FN02/FN08/FN11）**：主表+附注一起看——剔非经常性损益算主业经常性利润占比；查附注会计政策近三年有无单方变更；异常好看先假设包装。利润决策相关性已从61.4%降到33.6%，现金/研发/销售权重上升。
2. **拆资产负债（FN04/FN05/FN06/FN21）**：资产端看固资存货结构与应收账龄；负债端先行业基准再拆有息/无息，加回表外隐性债。杜邦分解ROE=净利率×周转率×权益乘数，判断公司靠什么赚钱。
3. **验现金（FN09/FN10）**：算现金转化周期=应收天数+存货天数-应付天数；现金红线=3个月固定支出；经营现金流为负先定位生命周期。
4. **查信任背书（FN12/FN13/FN14/FN18）**：造假三线索筛查（应收增速>收入增速、经营现金流持续低于净利润、毛利率远高于行业）；审计意见非标直接pass；审计师独立性四维排查；其他应收款异常升高警惕隧道效应。
5. **评钱与项目（FN15/FN29/FN30/FN32）**：融资先看期限/风险/耐心是否匹配；投资不预测价值，从股价反推市场隐含增长率，判断市场假设错在哪；项目PK看溢出效应与实物期权价值。
6. **排雷与分红（FN26/FN27/FN34/FN35/FN36/FN37）**：股权质押率高+股价下行=爆仓风险；解禁窗口前后是减持密集期；商誉/净资产占比高的公司查对赌期与减值迹象；新官上任年利润过山车警惕洗大澡；分红看自由现金流与连续性，突然不分红警惕。

输出格式：结论先行 → 每步证据（FN编号）→ 落点行动项。

## 四、应用场景映射

| 场景 | 应用 |
|---|---|
| 电商（冠生园） | 经营会语言统一到毛利/净利/现金流（FN01）；月度"收入-应收-现金流"三角对账，背离超20%必须解释（FN12）；无息占款率=（应付账款+预收）/月营收列健康指标（FN05）；杜邦分解拆冠生园ROE——净利率低就提价/加小料，周转率低就压库存（FN21）；现金转化周期逐项压缩（FN10）；新品立项跑赢现有爆品补货收益（FN22相关信息律）；上游供应商反向保理把冠生园信用变议价筹码（FN19）；关联交易定价/合同/决策全留痕（FN18）；大促定价留让利空间换复购而非一锤子买卖（FN20） |
| 投资（18只持仓） | 持仓股造假三线索筛查（FN12）；查附注折旧年限/坏账计提有无单方变更（FN13）；审计意见非标或事务所频繁更换列入观察（FN14）；短贷长投迹象=财务脆弱（FN15）；AB股公司按治理折价查实控人诚信（FN17）；其他应收款占比异常=隧道效应（FN18）；新上市不追首日爆炒，90天后动量再判断（FN20）；杜邦分解看持仓股靠什么赚钱，高杠杆地产股去周期降级（FN21）；股权质押率>50%列入爆仓观察（FN26）；解禁窗口前减仓锁利（FN27）；商誉/净资产>30%查对赌期与减值（FN35/FN36）；分红看自由现金流，突然停分红减仓（FN37）；从股价反推市场隐含增长率判断错价（FN29）；并购型公司收入集中度判断新店是否真孵化（FN34） |
| 教育（唐翌轩） | 选科选志愿做机会成本对照（FN22）；家庭财务纪律=3个月现金垫+闲钱才投资（FN09/FN15）；"听其言观其数"——孩子说的目标先看历次成绩数据（FN11）；用蓝田案教常识拆解故事（FN12）；用安达信案讲"权威也可能被收买"（FN14） |

## 五、边界

- 不教做账、不教准则条文——它是决策者的诊断视角，不是会计操作手册。
- 不预测股价、不做精确估值模型——它给"看穿数字"的尺子，估值交给香帅J系列。
- 财务数据永远滞后于经营——表外的品牌势能、团队状态要靠行业体感补。
- 跨行业比较天然失真——脱离行业基准的任何财务比率都是误判。
- 模型置信度：FN01-FN42 均为S级归档蒸馏（贾宁财务思维课，2026-10-24全量收官41篇）。
