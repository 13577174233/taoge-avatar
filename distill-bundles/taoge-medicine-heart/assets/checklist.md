# 心脏行动红线清单

> 打印出来贴冰箱。每条都是「什么情况下不能做 / 必须就医」。

- [ ] **心血管病可以预防，也可以康复** —— 正在胸痛发作、静息时胸闷气短、或术后尚未出院者，不可自行开始运动康复，须由主管医生评估。此为作者所在学科立场，不等于任何心脏病都能治好。
- [ ] **心脏健康要看四个维度** —— 四维度是认知框架，不是自诊工具；用它给自己下"心脏没事"的结论会漏掉病变。出现胸痛、活动后气促仍须就医。
- [ ] **门诊时间决定了医生只能给你碎片** —— 本条不构成"自己看病"的理由；原文在 005 讲明确说，买本书、百度一下、听完课就给自己下诊断，"咱还是歇一歇吧"。
- [ ] **后悔药买不到，只能提前** —— 把"提前"理解成"多体检"不够；有症状时的就医动作不能被"我平时很注意"替代。
- [ ] **心血管是网络，不是心脏这个器官** —— 这解释了为什么"心脏检查正常"仍可能有血管问题；出现活动后胸痛、走路腿疼（走走停停）须就医，不能靠"心脏没事"自我排除。
- [ ] **起于微末：毛细血管的广度决定影响力** —— 本条为结构认知，不涉及操作风险；原文未给安全红线。
- [ ] **层递通畅：到毛细血管前，血液成分不变** —— 本条为结构认知，不涉及操作风险。
- [ ] **信息闭环：回收得回来，才谈得上按需分配** —— 本条为结构认知，不涉及操作风险。
- [ ] **备胎机制：多数器官有两套以上供血** —— 备胎不是安全垫。冠脉主干急性闭塞时侧支往往来不及代偿，突发胸痛、大汗、濒死感必须立即呼叫急救，不能等"备胎顶上"。
- [ ] **心梗是慢性病的终点，起点在二十几岁** —— 急性心梗的求救信号是持续胸痛、胸闷伴大汗、恶心，出现立即拨打急救电话；不要自行开车去医院，也不要"再观察一下"。
- [ ] **身体的控制权在心血管，不在大脑** —— 正因为大脑感知滞后，"没感觉"不能当成"没病"。持续胸闷、活动耐力下降、伤口久不愈，须就医而不是等疼痛出现。
- [ ] **一快一慢两套调节：神经 0.5 秒，体液接力** —— 安静坐着也反复心慌、出汗、手抖，是应激通路被误启动，须就医查因，不能当作"我抗压能力强"。
- [ ] **只调两个维度：变时与变力** —— 150 次/分是极端应激下的瞬时值，不是任何人的运动目标；运动中若心率骤升伴胸痛、气短、头晕，立即停止并就医。
- [ ] **变时出问题＝心律失常，变力出问题＝心衰或高血压** —— 心慌伴黑矇、晕倒，或活动后气促加重、夜间憋醒，是两个维度失代偿的信号，须尽快就医；不要自行服用心律失常药物或调整降压药。
- [ ] **一套基本动作：收缩与舒张** —— 本条为机制认知，不涉及操作风险。
- [ ] **适应的本质是一把天平** —— 出现活动后胸闷、气短、头晕，说明天平已不平衡，须就医评估，不能靠"我指标正常"继续加码。
- [ ] **适应有上限，超过就直面生死** —— 出现呼吸急促到说不出整句、胸闷胸痛、头晕、判断力下降，立即停止并撤离或呼救——这是三类信号里最紧迫的一档（见 A5）。
- [ ] **适应的预判只能是概率** —— 概率不是个人结论。检查显示"低风险"不等于可以无视症状；出现 A5 的警灯或危机信号仍须就医。
- [ ] **自我认知两步：先观察，再评价** —— 自我评价不能替代检查。评价的结论是"该不该就医"，不是"有没有病"。
- [ ] **三类信号：基本、警灯、危机** —— 出现胸闷、胸痛、呼吸特别急促，立即停止当前活动并坐下；若胸痛持续不缓解、伴大汗、恶心或濒死感，立即拨打急救电话。危机信号出现时不要独自行动。
- [ ] **猝死 1 小时内，八成发生在医院外** —— 有人突然倒地、无反应、无正常呼吸，立即呼叫急救并开始胸外按压，同时取 AED；不要掐人中、喂水、等他自己醒。
- [ ] **猝死是储备坍塌，不是被最后一根稻草压死** —— 储备下降没有痛感。活动耐力明显下降、夜间憋醒、下肢水肿，须就医评估心功能。
- [ ] **三种预防策略，拓展储备最重要** —— 第三条策略不是自行加量运动。长期不活动者突然剧烈运动，心脏性猝死概率增加 17 倍（见 A5）。
- [ ] **储备透支的信号，两个和心率有关** —— 这些是预警信号，不是诊断。出现运动时血压下降、运动后 1 分钟心率几乎不降，须到心内科评估，不可自行加练"练回来"。
- [ ] **长期不动的人突然剧烈运动，风险增 17 倍** —— 不要用"周末勇士"方式补运动量。运动中出现胸痛或压迫感、气短、头晕、冷汗，立即停止并就医。
- [ ] **静态检查正常，不等于储备正常** —— 负荷试验必须在有急救条件的医疗机构进行，不可自行用爬楼、冲刺来"自测储备"；试验中出现胸痛、室速即终止。
- [ ] **心内科门诊里四成患者伴发心理疾病，八成没被认出** —— 反复胸闷、心慌但多项检查未见异常，不等于"没病"，也不等于"一定是心脏病"；出现自伤念头、持续两周以上情绪低落，须立即就诊精神心理科。
- [ ] **躯体化：查不出病因的症状，本身就是病** —— 必须先排除器质性病变再谈躯体化。胸痛持续、伴大汗恶心、活动后加重，按心脏急症处理、立即就医，不要先归因为"心理问题"。
- [ ] **焦虑是冠心病的独立危险因素** —— 心梗后出现持续情绪低落、失眠、兴趣丧失，须同时处理心脏与心理，不能认为"病好了心情自然就好"；抗抑郁药与心血管药物可能相互作用，须由医生开具，不可自行加减或停药。
- [ ] **三问自筛：两个"是"，八成可能是心理疾病** —— 这是自筛提示，不是诊断。任一问题答"是"且已影响工作生活，或出现自伤念头，须就医（精神心理科或心身医学科）；不要自行服用安眠药或抗抑郁药。
- [ ] **运动让心脏反过来塑造心理** —— 运动不能替代抗抑郁药物治疗与心理治疗；中重度抑郁、有自伤风险者须在医生监护下运动，不可自行停药改运动。运动中胸痛、黑矇立即停止。
- [ ] **心血管病只有三类，治疗思路完全不同** —— 分类是治疗战略层面的划分，不是自我分型工具；已确诊者不可因"我这属于能治愈那类"而停药。
- [ ] **战略五个字：打断事件链，且从源头打断** —— 急性期"活着高于一切"，此时不可为了"顾全大局"延误急救；胸痛发作先救命，再谈长期管理。
- [ ] **危险因素的七个"主公"** —— 这些是长期管理的对象，不是"消灭"的对象；不要为追求指标完美自行加药、换药或停药。
- [ ] **降压本身就能减少 38% 心血管死亡** —— 这是群体层面的收益，不是个人承诺；不可因"降一点就有收益"自行调整药量，更不可自行停药。
- [ ] **支架解决的是狭窄，不是为什么狭窄** —— 本条不是"支架没用"。急性心梗时支架是救命手段；已放支架者不可自行停用抗血小板药，停药可能引发支架内血栓。
- [ ] **急性心衰：减负荷，等它自己恢复** —— 本条只解释治疗逻辑。家中出现端坐呼吸、夜间憋醒、下肢水肿迅速加重，立即就医；不可自行用"少活动、少吃饭"来给心脏"减负荷"。
- [ ] **最好的药加最好的手术，术后生活质量依然差** —— 术后仍有胸痛发作不等于"手术失败"，但新发或加重的胸痛须复诊；不可因"已经放了支架"自行停用抗血小板药。
- [ ] **心脏康复是治疗的终极途径，因为它治标也治本** —— 康复必须在医生制定的方案下进行；康复中出现胸痛、明显气促、头晕、心悸不缓解，立即停止并就医。
- [ ] **九久方案：九个方面，长久地做** —— 九项里的"药物管理"包含不可自行停药或换药；出现药物不良反应（如干咳、肌痛、心率过慢）应联系医生调整，不可自行停。
- [ ] **运动是处方，不是爱好** —— 不要照抄他人处方。出现胸痛、胸闷、气短到说不出整句、头晕、冷汗，立即停止并就医；长期不运动者突然剧烈运动风险显著升高（见 004 讲）。
- [ ] **判断饮食只有一个字：自然** —— 不要用保健品替代药物；合并肾病、糖尿病者不能直接套用"金字塔比例"，须遵医嘱。
- [ ] **治疗主体从医生单方，变成患者和医生** —— 这不是"医生不重要"。药物与手术仍是必需手段，本条讲的是分工与责任，不是替代。
- [ ] **与慢病相处要走过四个阶段** —— 若长期停在否认或极度焦虑，出现持续失眠、无法工作、自伤念头，须就医（心身医学科或精神心理科），不要独自硬扛。
- [ ] **越压着不想，反弹越厉害** —— 如果已出现持续两周以上的情绪低落、失眠、无法工作，或自伤念头，这已超出"想开点"的范围，须就医。
- [ ] **两个出口：关注当下，或转向更有意义的事** —— 这是自我调节方法，不替代治疗。若两周后担忧不减轻、睡眠持续恶化或有自伤念头，须就医。
- [ ] **越优秀的人越难和病相处** —— 示弱不等于放弃治疗。若出现"我拖累家人"的强烈自责、拒食拒治，须家属陪同就医。
- [ ] **先做 21 天，别先说一辈子** —— 三周是启动期，不是疗程终点；降压、降脂、抗血小板等药物不能因为"三周感觉好了"而停用。
- [ ] **健康的六成由生活方式决定，医疗不到 8%** —— 原文未给就医信号。本条是归因比例，不是筛查工具；出现胸痛、活动后气短、夜间不能平卧，别继续算比例，直接就医。
- [ ] **越克制越难坚持，要给天性留出口** —— 原文未给就医信号。若「出口」已经变成每天饮酒、暴食、通宵，说明出口开得太大：出现体重短期快速上升、夜间憋醒、下肢水肿要就医。
- [ ] **戒烟靠专业医疗帮助，不靠个人毅力** —— 戒断期出现持续心悸、胸痛、血压明显升高、严重失眠或情绪低落，要到戒烟门诊或就医；不要自行加大尼古丁替代品的用量。
- [ ] **体重指数控在 18 到 25，别对体重和食物有执念** —— 原文未给体重相关的就医阈值。出现不明原因体重下降、持续乏力、女性月经紊乱，要就医查原因，不要靠继续减重解决。
- [ ] **每天坐超过 8 小时就算久坐，动起来就比不动好** —— 久坐后起身若出现单侧小腿肿痛、胸闷气短，要就医排查血栓，不要用「多站起来」自我处理。
- [ ] **先察觉再调整，比先立规矩更容易做到适量** —— 察觉心跳时若发现反复心慌、漏跳、伴头晕黑矇，要就医做心电图，不要只靠呼吸放松；察觉呼吸时若家人发现夜间呼吸停顿，要就医查睡眠呼吸暂停。
- [ ] **养心的本质是把心血管储备练大** —— 训练中出现胸痛、胸闷压迫感、头晕黑矇、心悸持续不退，立即停止并就医；安静心率长期低于每分钟 50 次，按原文要考虑是不是生病了。
- [ ] **每周有氧总量 1000kcal，是养心的基本运动量** —— 运动中或运动后出现胸痛、压榨感、异常气短、冷汗、晕厥先兆，立即停止并就医；不要在感染发热期、血压未控制时硬凑总量。
- [ ] **每周 2 到 3 次力量训练，覆盖所有大肌肉群** —— 用力时长时间憋气会瞬间升高血压，出现头痛、胸闷、视物模糊、眼前发黑立即停止；具体动作与负荷由康复师或教练定，不要自行冲极限重量。
- [ ] **睡 6 到 8 小时风险最低，睡过头反而升高** —— 打鼾伴呼吸停顿、白天嗜睡、晨起头痛、夜尿增多，要就医查睡眠呼吸暂停；不要靠延长睡眠时间解决，也不要用安眠药自行加量。
- [ ] **卧床 1 天肌肉就流失 3% 到 11%，静养不养心** —— 卧床期间出现单侧小腿肿痛、胸闷气短、发热咳嗽、痰量增多，立即报告医生排查血栓与肺部感染。
- [ ] **腹式呼吸每天两组各 10 分钟，把安静心率练慢** —— 练习中出现头晕、眼前发黑、手脚发麻（过度通气的信号）立即停下、恢复自然呼吸；安静心率持续低于每分钟 50 次，按原文要考虑是不是生病了，去就医而不是继续练。
- [ ] **新药研发进瓶颈，2000 到 2009 年上市数降了约 33%** —— 原文未给就医信号。本条是产业趋势判断，不构成对个人用药的意见；已在服药的人不可因此自行停药或换药。
- [ ] **支架量涨了，但它改不了心血管病的终局** —— 突发持续胸痛、大汗、濒死感、恶心呕吐，立即呼叫急救，本条不是拒绝急诊介入的理由；支架术后不可自行停用抗血小板药物，出现黑便、皮下大片瘀斑、牙龈持续出血要就医。
- [ ] **换得了心脏，换不了全身血管** —— 原文未给就医信号。出现活动后气促、晕厥、下肢水肿加重、夜间不能平卧，要尽快就医评估，不要等「以后换个瓣膜就好了」。
- [ ] **心肌细胞每年只更新约 1%，再生追不上损伤** —— 遇到承诺「打干细胞长出心肌」「修复梗死区」的机构要警惕——原文记录的正是 31 篇论文撤稿事件；已确诊冠心病或心梗者按医嘱用药与康复，不要用未获批的细胞治疗替代规范治疗。
- [ ] **未来的突破口更可能在生活方式管理，不在新药** —— 原文未给就医信号。不要把「未来会有更好的办法」当作推迟今天干预的理由；已确诊者仍按现有规范治疗。
- [ ] **查心脏科普认机构主管的来源，别认搜索结果** —— 出现胸痛、呼吸困难、晕厥、言语不清、一侧肢体无力，先打急救电话，不要先上网查；网上结论与面诊冲突时以面诊为准。
- [ ] **选心血管医院看第三方专科排名，不看广告** —— 持续胸痛不缓解、大汗、濒死感，就近急诊，不要为了「去排名第一的医院」长途转运。
- [ ] **找心脏康复中心，用阜外康复中心小程序查附近** —— 到中心后先确认有没有运动测试与监护条件；训练中出现胸痛、异常气短、头晕、心悸不止，立即停止并就医。
- [ ] **急性心梗别挑医院，最近的能手术的医院就是最优** —— 持续胸痛不缓解、大汗、濒死感、恶心呕吐、放射到左臂或下颌的疼痛，立即呼叫急救，不要自行开车跨城转运；到医院后不要因为犹豫签字而延误。
- [ ] **结构损坏类手术不做损伤持续，要尽早做** —— 出现活动后气促、夜间不能平卧、下肢水肿加重、晕厥，要尽快就医评估，不要等到「实在不行了」；术后出现发热、切口渗液、心悸加重，要及时复诊。
- [ ] **选术者看年手术量：成熟手术差别小，复杂心外科找量大的团队** —— 原文未给就医信号。择期手术前若出现症状加重（静息胸痛、晕厥、呼吸困难），不要等排期，先就诊；术前谈话要把风险问清楚再签字。
- [ ] **术前睡好觉，必要时用医生开的药助眠** —— 助眠药物须由医生开具，不可自行加量或与酒精、其他镇静药同服；出现白天嗜睡、意识模糊、跌倒，要告诉医生调整。
- [ ] **术前能练就练：呼吸训练加运动，为手术存体力** —— 训练中出现胸痛、胸闷、异常气短、头晕，立即停止并报告医生；所有训练必须在「医生允许的范围内」，不要自行加量。
- [ ] **心血管手术占比高是技术进步，不是过度医疗** —— 原文未给就医信号。本条不构成「该做手术」的结论——是否手术仍按 A1、A2 判断，出现急症按 A1 处理。
