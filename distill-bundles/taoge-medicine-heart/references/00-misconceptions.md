# 常见误区对照表

> 越相信左边，右边那条知识就越点不亮。逐条自查。

## 第 000 讲

| 常见错误信念 | 纠正 |
|---|---|
| 心脏好不好看体检报告就行，指标正常就说明心脏健康。 | 适应与储备在静态检查里看不出来，要靠负荷试验和日常信号；四维里漏掉两维就会误判。 |
| 得了心血管病就只能越来越差，治不治都一样。 | 可预防、可康复，但"康复"指功能与生活质量的改善，不等于治愈。 |

## 第 001 讲

| 常见错误信念 | 纠正 |
|---|---|
| 心脏就是心血管，心脏检查没问题就说明血管没问题。 | 功能来自整张网络，心脏彩超与射血分数只覆盖泵与部分结构，血管要单独评估。 |
| 反正身体有侧支有备胎，堵一根血管不要紧。 | 备胎是生存冗余，不是免死金牌；斑块仍在长大，主干急性闭塞时侧支来不及代偿。 |
| 心梗是突发的急病，防不胜防。 | 它是慢性病的终点，斑块在二十几岁就开始长，可改变的节点在青年期。 |

## 第 002 讲

| 常见错误信念 | 纠正 |
|---|---|
| 心慌、胸闷是我想多了，忍忍就过去了。 | 大脑对病变的感知本来就滞后，调度权在心血管；反复出现的心慌要就医查因。 |
| 心跳快就说明心脏强。 | 变时与变力是两维，快不等于有力，乘积才是每分钟射血量。 |
| 高血压是血管的事，跟心脏泵血能力无关。 | 力的维度失配就是高血压，它与心衰是同一个维度的两种表现。 |

## 第 003 讲

| 常见错误信念 | 纠正 |
|---|---|
| 体检指标都正常，就说明我什么强度都能干。 | 适应是功能与需求的匹配，指标正常仍可能不适应，越界后最先崩的是判断力。 |
| 我身体好，扛得住。 | 适应有明确上限，消防员的心脏比常人好也可能倒在火场。 |
| 心跳快只是累了，歇一会儿就好。 | 心跳快＋行动迟缓＋头晕无力是危机信号，提示供血不足，须立即停下并求助。 |

## 第 004 讲

| 常见错误信念 | 纠正 |
|---|---|
| 体检一切正常，就不会猝死。 | 静态检查看不到储备，负荷试验才暴露问题；24 小时心电图正常也不算过关。 |
| 猝死是运气不好，防不了。 | 85% 有心血管基础，多数是储备坍塌，可通过信号与储备拓展提前识别与改善。 |
| 开始锻炼总是好事，越猛越好。 | 长期不动者突然剧烈运动，心脏性猝死概率增加 17 倍，必须从低强度起步。 |
| 心慌就是咖啡喝多了。 | "以前没有、最近才有"的心慌是储备透支信号，须就医查因。 |

## 第 005 讲

| 常见错误信念 | 纠正 |
|---|---|
| 检查都正常，说明我没病，就是想多了。 | 躯体化本身就是病，且门诊漏诊率约八成；"查不出病因"是线索不是结论。 |
| 心情不好跟心脏没关系，是两回事。 | 焦虑是冠心病独立危险因素，抑郁使心梗患者死亡率增加至 2 倍以上。 |
| 运动能治抑郁，可以不吃药。 | 运动不能替代抗抑郁药物与心理治疗；中重度抑郁须在医生监护下进行。 |

## 第 006 讲

| 常见错误信念 | 纠正 |
|---|---|
| 放了支架、做了手术，病就治好了。 | 支架解决狭窄不解决原因，事件链没断，复发只是时间问题。 |
| 没有症状就不用管危险因素。 | 危险因素可控且收益明确——单靠药物降压就减少 38% 心血管病死亡、16% 冠心病发生。 |
| 住院时最重要的是把长期该做的检查都做全。 | 急性期活着高于一切，先打断急性事件，全局管理放到稳定期。 |

## 第 007 讲

| 常见错误信念 | 纠正 |
|---|---|
| 手术做完了，治疗就结束了。 | 术后仍有 34% 心绞痛、40% 无法工作；结构修复不等于功能恢复。 |
| 日行万步就是在做运动治疗。 | 没有强度、频率、时间的活动不构成处方；四要素缺一不可。 |
| 康复就是多吃粗粮、多散步。 | 粗粮过量照样主食超标；康复要有方案、有参数、有复评。 |

## 第 008 讲

| 常见错误信念 | 纠正 |
|---|---|
| 想开点就好了，别老想着病。 | 压抑会反弹，正确做法是关注当下或转向更有意义的事，而不是强行不想。 |
| 我这么能干，这点病不算什么，我自己扛。 | 越不接受低能状态越难康复；示弱与原谅自己才是过关的方式。 |
| 要么断根，要么放弃，没有中间路。 | 四阶段里没有"根除"，相处是长期过程，目标是把它变成人生的一部分。 |

## 第 009 讲

| 常见错误信念 | 纠正 |
|---|---|
| 健康靠医院，体检加项、买保健品、有病再治就行。 | 人群归因里医疗不到 8%、生活方式约 60%；医院收入来自治疗与检查，预防不形成收益，制度上不会替你补这一块。 |
| 想健康就得样样严格，一口油、一口酒都不能碰。 | 过度克制会把人逼到索性不管；正确做法是守住三条高压线，红线之外留出口。 |
| 戒烟靠决心，忍一忍就过去了；实在不行换电子烟。 | 尼古丁像毒品一样形成依赖，戒烟要求助专业医疗；原文给的路径是戒烟门诊，不是自我宣誓。 |
| 木耳、绿豆能防心血管就天天吃；蛋黄致病就只吃蛋白。 | 原文点名这两种吃法都「非常不正确」；食物讲适度，体重看区间，别在单一食物上押注。 |

## 第 010 讲

| 常见错误信念 | 纠正 |
|---|---|
| 养心就是吃补品、做检查，或者干脆少动多躺，让心脏省着用。 | 养心是扩大射血量储备，必须给心脏负荷；储备的两端靠有氧、力量与深度安静一起拉开。 |
| 运动越多越好，练到极限才有效。 | 过量运动会带来心肌纤维化、心律失常、血管钙化，职业运动员的寿命并不更长；目标是每周 1000kcal 这个基本量。 |
| 睡得越多越养心脏，周末补觉能把一周的觉补回来。 | 6 到 8 小时风险最低，8 到 9、9 到 10、10 小时以上风险依次增加 5%、17%、41%；午睡超过 30 分钟风险也上升。 |
| 大病要卧床静养，能不动就不动。 | 卧床 1 天肌肉流失 3% 到 11%，还带来血栓、肺部感染、心肌萎缩；静要的是深睡眠与呼吸训练，不是躺着不动。 |

## 第 011 讲

| 常见错误信念 | 纠正 |
|---|---|
| 现在的治疗都只是过渡，等新药、新技术出来再管。 | 新药上市数十年内降了约 33%，投资在缩减；三条路径同时撞墙，等不来「一次性解决」。 |
| 放了支架，血管通了，病就好了。 | 支架开通的是一段血管，动脉粥样硬化是全身持续进展的过程；手术是治疗的开端，不是终点。 |
| 心坏了换一个，血管堵了换一段，总能换完。 | 血管总长能绕赤道四圈半，整个心血管系统无法被完全替代；能换的是零件，换不了整条管路。 |
| 干细胞能长出新心肌，打一针就把心梗修好。 | 心肌细胞每年只更新约 1%；被寄予厚望的心脏干细胞研究已有 31 篇论文因数据问题被撤稿。 |

## 第 012 讲

| 常见错误信念 | 纠正 |
|---|---|
| 网上搜到的第一条就是最权威的，专家号难挂就先在网上自己诊断。 | 原文的名单按主管机构分层（医科院、人民日报社、核心期刊、三甲官微）；搜索排序与权威性无关。 |
| 看病就得去排名第一的医院，哪怕跨省、哪怕等三周。 | 榜单用来缩小候选范围，且 2017 年的名次已过时；急症按就近原则，稳定期再看专科排名。 |

## 第 013 讲

| 常见错误信念 | 纠正 |
|---|---|
| 心梗了要赶紧转到最好的医院，路上多花两小时也值。 | 开通越早，梗死面积越小；急性期只认最近的能手术的医院，没有手术条件就用药物溶栓，也比错过时机强。 |
| 没症状就不用做手术，等严重了再说。 | 结构损坏不做，损伤始终存在；拖到年纪大、身体差，手术耐受更差。原文的忠告是尽早做。 |
| 手术成败全看主刀，找名气最大的医生就行。 | 成熟手术各家差别不大；复杂心外科要看年手术量与整套团队（麻醉、体外循环、监护、康复）的经验。 |
| 心血管手术比例这么高，肯定是过度医疗。 | 心血管疾病占疾病谱 1/3，阜外手术占住院病人 51.7% 以上、克利夫兰 74% 以上；原文的判断是技术进步而非过度医疗，但是否该做仍要按指征判断。 |

## 第 014 讲

| 常见错误信念 | 纠正 |
|---|---|
| 药吃一两年就该停，总不能吃一辈子。 | 切断危险因素的药，危险因素消失才停；防结局的药没有期限，因为冠心病目前还治不好。 |
| 支架放完，血管通了，药可以慢慢减。 | 支架只是治疗的开端；自行停药导致支架术后突发心梗的患者，每年都不在少数。 |
| 血脂正常了就没必要再吃他汀。 | 他汀还负责稳定斑块、防止破裂；血脂正常只说明降脂目标达成，不代表斑块不需要维持。 |
| 吃了没感觉的药就是没用，能立刻舒服的药才是好药。 | 能短期缓解症状的药通常没有长期延缓生存的功效；改变结局的药收益要按年看。 |
| 说明书上写的副作用我都有，得赶紧停；网上说另一种药更好，我换那个。 | 不对号入座说明书副作用，也不拿百度去 PK 医生的选择；患者要做的是记录真实反应并反馈。 |

## 第 015 讲

| 常见错误信念 | 纠正 |
|---|---|
| 血管堵了就只能放支架，运动顶多是辅助。 | 稳定心绞痛的运动康复能抬高缺血阈值、延缓甚至逆转斑块、建立侧枝；原文个案三年从 80% 降到 50%，但须在监护下起步。 |
| 房颤做完消融就好了，复发是运气不好。 | 任何治疗方式的复发率都高达 50%；上游是交感与 RAAS，压力、睡眠、吸烟、肥胖都在给它加油。 |
| 减重就是管住嘴迈开腿，做不到是意志力不够。 | 对重度焦虑的人，熬夜、暴食、抽烟是缓解压力的出口；不改变对待压力的方式，减重无法持续。 |
| 心衰要少动多躺，省着用心脏。 | 心衰康复是一增一减——练呼吸增加氧供、练肌肉提高用氧效率；躺下只会让肌肉继续流失。 |
