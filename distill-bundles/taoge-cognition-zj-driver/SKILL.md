# 政经判断驱动包（Ma Jiangbo Political-Economy Driver）

> **一句话定位**：一套把"每天刷到的政经热点"变成"自己决策坐标"的翻译器——先用国家=公司框架读出政策真假，再用周期律判断电梯升降，最后把传导落点换算成冠生园选品、持仓仓位、孩子选科三个动作。
> **来源**：马江博·政经参考（2025）（得到，2026-10-26 S级归档ZJ01-ZJ262共257篇；发刊词ZJ01/加餐ZJ02为总纲与资料页不入律；缺ZJ212-ZJ216共5讲由同主题篇覆盖）。

## 一、总图（一句话记住）

**收缩时代不拼速度拼判断：先看国家给没给钱（政策真假），再看资源往哪个最强子公司集中（周期方向），然后站在离钱最近的那个区域/产业/人群里，同时给资产和家庭留好安全冗余**

| 模块 | 核心问题 | 核心律群 |
|---|---|---|
| 政策读法 | 怎么看懂政策背后逻辑 | ZJ-传导全组 |
| 周期定位 | 未来十年大势是什么 | ZJ-周期全组 |
| 区域城市 | 哪些城市有未来 | ZJ-区域全组 |
| 产业红利 | 新质红利在哪 | ZJ-产业全组 |
| 中美博弈与安全 | 外部环境顺风逆风 | ZJ-博弈全组 |
| 财政货币化债 | 钱往哪流 | ZJ-财货全组 |
| 资产财富 | 资产配置时机 | ZJ-资产全组 |
| 就业教育 | 孩子选科选城市 | ZJ-人全组 |

**底层认知（三根支柱）**：
- 国家=公司框架：中央是集团总公司，地方是独立核算子公司；政策博弈=母子公司四种情形，考核双轨（GDP/化债是KPI必须达标，新质生产力是OKR鼓励试错）。
- 政策传导链：中央定调→部委部署（财政给多少钱）→地方博弈落地→市场印证（汇率/利率/资产价格/消费数据）。越往下游信号越真。
- 安全逻辑显性化：公司框架之外还有一条看不见的红线——国家安全。大国博弈下，卡脖子产业备份、战略腹地、出口管制、去美元化备份，这些不是经济账是生存账。

## 二、核心律速查（58律）

### 板块一：政策读法（ZJ-传导，7律）

| 编号 | 短名律 | 一句话 | 什么时候用 / 怎么用 |
|---|---|---|---|
| ZJ-传导-01 | 母子公司四情形律 | 中央=总公司地方=子公司，先归类再跟 | 每条新政先分四种情形：①母子都想做=红利政策资源最多，紧跟；②总公司想做子公司不想=看集团决心；③子公司偷做总公司没批=机会但小心被扔出来顶责；④都说要做但钱和决心没到=先提一嘴跟了踩空 |
| ZJ-传导-02 | 给钱验真律 | 真要做看财政，喊口号看文件 | 判断"一般号召"还是"确定性红利"最硬指标：财政给没给钱+有没有配套奖惩。给钱+加奖惩=真红利；只发文件不提钱=观察 |
| ZJ-传导-03 | 会议金字塔律 | 中央定调、政治局定季、部委定操作 | 中央经济工作会议定来年总调→政治局会议定季度方向→国常会和部委例会定操作；部委吹风不算数，政治局定调才算 |
| ZJ-传导-04 | 看会三点律 | 谁来了、说什么、谁跟进 | 看重要会议三点：①形势——谁坐在C位；②趋势——讲了什么新提法；③进度——部委地方有没有跟进文件 |
| ZJ-传导-05 | 四本账读钱律 | 钱往哪走，方向就在哪 | 财政四本账：一般公共预算/政府性基金（土地）/国有资本/社保；读支出增速结构——钱往哪加=政策方向 |
| ZJ-传导-06 | 文件三类型律 | 规则/资源/呼吁，含金量不同 | 大文件分三类：规则文件（定规矩）、资源文件（分钱）、呼吁文件（喊口号）；先判类型再投注意力 |
| ZJ-传导-07 | 吹风试点证真律 | 政策很少突变，先吹风后铺开 | 官员吹风→部委试点→地方铺开→全国立法；新政策出台先找出处和试点城市，不被标题党带节奏 |

## 三、政经热点五步诊断 SOP

1. **定性（ZJ-传导全组）**：这是吹风、文件、会议还是真给钱？先归类母子公司四情形，再看有没有财政真金和配套奖惩；定位它在会议金字塔哪一层。
2. **定位（ZJ-周期全组）**：当前是扩张还是收缩？资源在往哪个最强子公司集中？五分化里哪个在加速？
3. **传导（ZJ-区域+ZJ-产业）**：钱从中央到地方落到哪个省/哪个产业/哪个人群？谁受益谁受损？
4. **博弈（ZJ-博弈+ZJ-财货）**：外部环境是顺风还是逆风？汇率/美联储/关税战什么阶段？
5. **落点（ZJ-资产+ZJ-人）**：换算成三个场景各一个可执行动作（冠生园选品/持仓仓位/孩子选科）。

输出格式：结论先行（这条政策真不真、顺风逆风、跟不跟）→ 五步证据 → 三场景行动项（每条只给最关键动作）。
