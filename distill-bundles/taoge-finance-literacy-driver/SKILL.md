# 财商训练驱动认知包（Finance Literacy Driver）

> **一句话定位**：财商不是「怎么多挣钱」的技巧，而是一套独立于学历、智力、努力的乘数——先辨资产、再算成本、守住自制力，最后让钱服务于你想要的生活。
> **来源**：吴军·财商训练40讲（CSH001–CSH051 共 51 篇 S 级归档，2026-11-07 全量收官；「专属福利」资料领取页 1 项登记不归档）。

---

## 一、总图（一句话记住）

**财商 ＝ 破局（CSH001–CSH004）× 理解财富（CSH005–CSH015）× 获取财富（CSH016–CSH023）× 增值财富（CSH024–CSH037）× 使用财富（CSH038–CSH046）× 问答收口（CSH047–CSH051）**

五模块递进：**先承认财商是独立维度 → 看懂财富与资产的本质 → 学会挣钱与拒绝 → 学会让钱生钱并避开估值陷阱 → 学会在人生各阶段使用财富**。前四模块解决「钱怎么来、怎么长」，第五模块解决「钱最终为谁服务」。

| CSH002 | 创造优先律 | 高财商靠主动创造而非一味省钱，知道钱在哪、肯到钱多的地方去，并分清哪些问题该用钱解决 |

## 三、财商决策 SOP（6 步）

1. **先自查维度**（CSH001–CSH004）：把当前财务结果拆成学历、智力、能力、努力、财商五项，问「我这次判断错在哪一项」；翻出近三年三笔最大的花钱决定，看是「挣钱不足」还是「用法不当」。
2. **辨资产类型**（CSH005–CSH009）：把手上每一项列成「资产类型—流动性—真实价值来源」三列，把没有真实价值来源的一律标为伪资产（CSH015）。
3. **把成本摆上桌**（CSH012–CSH014）：任何一笔万元以上决策，写清显性成本、隐性成本（时间/关系/机会/健康）、不卖不算亏的心理账，再决定。
4. **先把挣钱效率提上去**（CSH016–CSH023）：算单位时间收益，判断是深耕主业还是补副业；对不产生效率的事直接拒绝（CSH018）。
5. **配置而非预测**（CSH024–CSH037）：给每类资产定一个目标比例，只调整比例不预测涨跌；对企业类资产按自由现金流与护城河两条筛。
6. **按阶段定策略**（CSH038–CSH051）：30 岁前重积累与闯关（婚房、起步），50 岁后转守，60 岁后防「再搏一把」；婚恋、教育、养老三件事按结构性支出提前排。

| 场景 | 适用律 | 落地 |

| A股/基金持仓复盘 | CSH025 CSH030 CSH031 CSH048 | 先看是否因喜得厌失做反；再看是否在追「赢大盘」；最后按预设比例调，不预测 |
| 企业基本面筛选 | CSH033 CSH035 CSH041 CSH028 | 财务三指标做筛子，护城河与自由现金流做结论；警惕摊长成本做出的账面利润 |
| 副业与时间分配 | CSH016 CSH018 CSH019 CSH023 | 单位时间收益排序，先保主业复利，再谈副业；拒绝不增值的占用 |
| 婚恋与家庭财务 | CSH040 CSH042 CSH049 | 看对方怎么花钱（是否在能力之内），婚前把财务结构与边界谈清 |
| 子女教育与传承 | CSH043 CSH050 CSH012 | 传能力与规则不传数字；学费买房列为计划内变数，不做无限开口 |
| 40–60 岁财富防守 | CSH044 CSH045 CSH046 CSH051 | 50 岁转守、60 岁服老，健康优先；养老按 73–85 岁真实寿命测算 |

## 五、边界

- **课程是单一讲师的个人经验体系**：吴军的判断多来自个人投资与观察（含「超过 30 年投资经验」自述），不是学术结论；宏观判断、行业判断须以当期数据复核。
- **中国市场特殊性**：房产、教育、婚恋的成本结构与中国一线城市现实强绑定，跨地区使用须重新校准（如换房成本、学区房溢价）。
- **不构成投资建议**：本包提供判断框架与提问顺序，不提供具体标的、仓位与时点；实际决策需结合个人现金流、风险承受力与合规要求。
- **问答类内容为特定提问者情境**：CSH047–CSH051 的结论针对提问者家庭条件（如负债结构、年龄、城市），迁移时须替换前提再判断。
- **年龄分段是粗粒度**：50/60 岁分界只是叙事锚点，真实转守时点应由现金流缺口与负债结构决定。
- **免 AI 化输出**：简体中文、零 emoji、结论先行、表格化，不写「赋能／抓手」类空话。
