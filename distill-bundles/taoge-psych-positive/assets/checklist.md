# 积极心理学 · 自助与就医清单

> 在具体处境里照着核对。每条都是「什么信号出现就停 / 什么程度必须就医」。

- [ ] **积极心理学的目标是自主行动，不是必须快乐** —— 把「积极心理学」误用成「我必须时刻积极」，反过来压抑真实情绪、为情绪低落自责——这本是本域最常见误用。若出现持续两周以上情绪低落、睡眠改变或社会功能下降，应就医评估，而不是加倍强迫自己积极。
- [ ] **改善情绪最简单的入口是身体，不是想法** —— 把「动一动就好」绝对化，运动了几天没见效就自责「连走路都做不好」。若情绪低落持续两周以上、睡眠明显改变或工作生活功能下降，须就医评估，而非仅靠散步。
- [ ] **积极心理学诞生于 1998 年塞利格曼的 APA 主席演讲** —— 把 1998 年当成「积极心理学由塞利格曼一人发明」，忽视此前马斯洛 1954 年已首次使用该词（见第 1 讲）以及几代学者的积累；用学科史光环替代对具体研究证据的审查。
- [ ] **这门课的地图：自主 + 行动，三模块二十余个积极小行动** —— 只听课不做小行动，把「知道武器库」当成「拿到武器」；若学习期间情绪持续低落超过两周并影响睡眠与工作，应先就医而非继续赶进度。
- [ ] **马斯洛 1954 年首提「积极心理学」，针对的是「人不能自主」这一共同前提** —— 反向误读成「童年阴影完全不重要、想开就行」——马斯洛恰恰承认自我实现者也经历过创伤。若因纠结「过去是否毁了我」而持续两周以上情绪低落、睡眠改变，应寻求心理咨询或就医，而不是靠一套理论自我了断。
- [ ] **消极效应更易测量，是半个世纪里研究偏向消极的技术原因** —— 把「负面信息更抓注意力」误用成个人生活策略——多刷负面新闻、多挑错，会放大焦虑；若因此持续两周以上情绪低落、睡眠改变，应减少负面信息摄入并就医评估。
- [ ] **塞利格曼 1998 年复兴积极心理学，关键不止理念而是行动力** —— 把「从 0 到 +100」误读成「治好了也白治，还要更幸福」——先解决 -100 到 0 仍是第一位的；若自己或家人处于持续两周以上情绪低落、社会功能下降，第一步是就诊精神科，不是追求 +100。
- [ ] **幸福公式从 1.0 升级到 2.0：加入人际关爱与成就** —— 拿公式 2.0 反过来给自己打分，五项不全就判定自己「不蓬勃」、产生新的自我批判；若自我不满已伴随持续两周以上情绪低落、睡眠改变，应寻求专业评估。
- [ ] **积极心理学的三大研究结论** —— 把第三点「道路不止一条」读成「怎么舒服怎么来」；把第一点读成「不积极是你不肯选」——忽视贫困、压迫等结构因素。若因强求积极而持续两周以上情绪低落、睡眠改变，须就医而非继续加码。
- [ ] **人是被未来吸引，不是被过去驱使** —— 把此论误用成「你的痛苦都是你自己想象出来的、想开就好」——对深陷创伤者二次伤害。若对未来绝望伴随持续两周以上情绪低落、睡眠改变或自伤念头，立即就诊精神科。
- [ ] **创伤后成长：约半数人经历创伤后反而成长** —— 把「创伤让人成长」读成「所以创伤是好事、你应该感恩」——否认痛苦、阻断求助；若创伤后出现持续两周以上情绪低落、噩梦闪回、睡眠改变或自伤念头，立即就诊精神科。
- [ ] **大脑靠主动预测而非被动反应工作** —— 懂了预测编码就拿它当万金油解释一切心理现象——它是有力的理论框架但仍有待完善之处，具体现象（如抑郁的成因）需专门证据；若自我解读引发持续两周以上情绪低落、社会功能下降，应就医而非继续自我诊断。
- [ ] **大脑每秒只处理 1000 万比特中的 50 比特** —— 把「意识带宽极窄」误读成「思考没用、跟着感觉走」——恰恰相反，正因带宽窄，把注意力分配给什么才是关键决策点；若刻意屏蔽所有负面信息求轻松，风险来临时毫无准备，长期焦虑升高、睡眠改变超过两周应就医评估。
- [ ] **模型由过去训练，但可以主动重建** —— 把「主动建模」当成想改就能立刻改——模型训练以「数不清的经历」为单位，几次练习没效果就自我否定「我果然改不了」；若伴随持续两周以上情绪低落、睡眠改变，应寻求专业帮助而非独自硬练。
- [ ] **主动性由三个因素构成，是塞利格曼一生学问的总结** —— 把「要有主动性」变成新的自我指责标准——「我不行动是因为我不够主动」；若行动困难已伴随持续两周以上情绪低落、睡眠改变或社会功能下降，先就医评估，再谈主动性。
- [ ] **认知与行动是同一个心理过程，行动可以重塑认知** —— 把「行动万能化」，用战术忙碌掩盖真正的认知问题；若大量行动后情绪仍持续低落两周以上、睡眠改变，说明问题超出自我调节范围，须就医。
- [ ] **行为激活疗法：不用改认知，直接行动也能治抑郁** —— 误把此条读成「抑郁症不用治认知也不用吃药，动起来就好」，自行停药或拒绝就医；抑郁伴持续两周以上情绪低落、自伤念头者立即就诊精神科。另须指出：贫困、失业等结构困境造成的低落，不能只用行为激活解决，须同步处理外部因素并使用社会支持渠道。
- [ ] **知而不行，是为不知：没内化进模型的知识等于不知道** —— 用「知行合一」苛责自己或他人，把每一次没做到都判定为「假知道」，制造自我批判循环；若自我否定伴随持续两周以上情绪低落、睡眠改变，应寻求支持而非继续加码自责。
- [ ] **积极心理学是一门关于积极行动的科学** —— 把「只要做积极的事就有积极心态」绝对化，行动了仍低落时责怪自己做得不够——情绪反应有其生理与情境底线；持续两周以上情绪低落、睡眠改变或社会功能下降，须就医评估。
- [ ] **多巴胺是「期待使者」，不是「快乐使者」** —— 误信「多巴胺=快乐」去追求刺激型快乐（刷短视频、购物），结果是只强化期待回路、永不满足；若发现自己无法停止某行为并伴随睡眠改变、社会功能下降持续两周以上，须就医评估。
- [ ] **多巴胺过多：只顾追逐，不能享受当下** —— 拿「我多巴胺太多」当借口合理化停不下来的追逐行为；若某类追逐已导致睡眠改变、社会功能下降持续两周以上，或伴随自伤念头，立即就诊精神科。
- [ ] **催产素是「爱的激素」，不限于分娩和女性** —— 把「爱的激素」神话成关系万能药，以为送礼物、强拥抱就能修复破裂关系，忽视关系中的结构性问题；若关系冲突已导致持续两周以上情绪低落、睡眠改变，应寻求伴侣咨询或心理门诊。
- [ ] **内啡肽：长跑与坚持的奖赏，最好的来源是有氧运动** —— 为追求 Runner's high 强迫性加量运动，出现运动成瘾、过度训练；若停不下来并伴随睡眠改变、体重骤降、社会功能下降，须就医。慢性疼痛者不能用内啡肽机制替代规范镇痛治疗。
- [ ] **血清素与多巴胺相互抑制：一个争取，一个享受** —— 把「血清素好、多巴胺坏」简单化，压抑一切进取心；也可能误信网络「补血清素偏方」。长期失眠、情绪持续低落超过两周或自伤念头出现，立即就诊精神科，不要自行调节神经递质。
- [ ] **目标不是某种递质越多越好，而是四种通力合作的平衡** —— 把「平衡」当成又一次自我要求——「我必须四项全优」，反而制造焦虑；若长期只剩「进取」一项、伴随持续两周以上情绪低落、睡眠改变或自伤念头，立即就诊精神科。
- [ ] **人天生爱挑战：儿童自发选择「最佳学习区」任务** —— 发现「奖励毁动机」后走向另一极端，对孩子的一切努力都不给任何反馈——问题在「控制性的外部奖励」，不在反馈本身；若亲子冲突导致孩子持续两周以上情绪低落、拒绝上学、睡眠改变，须寻求儿童心理专业帮助。
- [ ] **助人是进化出来的天性：亲缘选择加互惠理论** —— 把「助人有利基因」读成功利算盘，助人前先计算回报，反而失去助人的自然愉悦；或反过来用「天性自私」为不助人找借口。若因人际关系疏离持续两周以上情绪低落、社会功能下降，应寻求心理支持。
- [ ] **情绪的功能是快速协调行动：恐惧逃、愤怒反击、悲伤停下** —— 理解了消极情绪的功能，不等于所有消极情绪都健康——持续的、与现实不匹配的恐惧或悲伤可能是障碍症状；情绪低落、恐惧、难过持续两周以上，或伴随睡眠改变、自伤念头，立即就诊精神科。
- [ ] **回避性目标与趋近性目标：如释重负和由衷快乐是两种奖励** —— 把「积极目标高级」绝对化，否定还债、治病这类回避性目标的正当价值——它们常常是当下最该做的事；强行把一切目标「积极化」反而虚假。若自我施压导致情绪低落持续两周以上，须就医评估。
- [ ] **扎根与开花：消极心理保生存，积极心理引发展** —— 把「为积极而活」变成对消极状态的道德审判——「有消极情绪就是不上进」；本课最常见误用正是要求自己必须积极。若长期压抑真实情绪并出现持续两周以上情绪低落、睡眠改变或自伤念头，立即就诊精神科。
- [ ] **收入与幸福分三段：高收入组钱与幸福不再相关** —— 把分段结论记反，以为自己还差一点钱就该拼命内卷到高收入组——前 1/3 段的代价（时间、健康、关系）常常超过收益；若为赚钱长期透支并出现持续两周以上情绪低落、睡眠改变，须就医并重新评估生活方式。
- [ ] **相关不等于因果：幸福也能反过来预测收入** —— 读成「穷是因为不够快乐」，把结构问题个人化——原文同时承认父母有钱的孩子整体挣钱更多；若因收入困境持续两周以上情绪低落、睡眠改变，优先解决现实问题并寻求社会支持渠道，同时就医评估情绪。
- [ ] **把钱花在别人身上比花给自己更幸福** —— 为「买幸福」超出能力地花钱助人，反而添财务压力；若陷入「不花钱助人就愧疚」的强迫模式并伴随持续两周以上情绪低落、睡眠改变，须就医评估。
- [ ] **买经历不买物品：经历难攀比、促连接、构成自我认同** —— 把「买经历」消费升级成打卡式体验竞赛（网红地打卡、昂贵旅行），重新落入攀比；若靠不断消费才能维持情绪且财务持续恶化、情绪低落超过两周，须就医并检视消费模式。
- [ ] **幸福是动词：重要的不是拥有什么，而是拿它去做什么** —— 把「幸福是动词」变成对自己「还不够幸福是因为不够努力行动」的审判；若行动了仍持续两周以上情绪低落、睡眠改变或自伤念头，须就医评估——幸福方法不是治疗替代品。
- [ ] **修女研究：年轻时的积极情绪能预测寿命** —— 读成「活不久是因为你不乐观」，对病患和家属造成二次伤害——群体相关不决定个体寿命；若因健康焦虑或自责出现持续两周以上情绪低落、睡眠改变，应就医。
- [ ] **机制：消极激活交感神经，积极激活副交感神经** —— 把「放松就行」当成慢病处方，延误规范治疗；若长期紧张伴随持续两周以上情绪低落、睡眠改变或躯体症状，须就医评估。
- [ ] **积极情绪拓宽思维：从局部取向到整体取向** —— 把「积极才有的创造力」当成职场筛选标准，强迫团队表演快乐、压抑真实的风险讨论；若工作中长期伪装积极并出现持续两周以上情绪低落、睡眠改变，应调整环境或寻求心理支持。
- [ ] **积极情绪让人更愿助人：硬币实验 87% 对 4%** —— 用「给点甜头就能让人干活」的管理术滥用此结论，把积极情绪当操纵工具，员工识破后信任崩塌；若职场长期依赖此类手段且员工出现持续两周以上情绪低落、社会功能下降，属组织问题，须从环境改起。
- [ ] **积极与成功是双向因果，不能写成「积极就成功」** —— 对失败者说「你只是不够积极」，把结构问题（就业环境、疾病、歧视）个人化——这是积极心理学被滥用时最常见的伤害；被如此对待而持续两周以上情绪低落、睡眠改变或自伤念头者，须就医并向可信渠道求助，问题未必在你。
- [ ] **三件好事：每晚 5 分钟，效果可持续到 6 个月后** —— 把练习变成打卡任务，写不出三件就自我批评「连好事都找不到」——注意：写不出本身可能就是情绪状态信号，连续多日写不出并伴随持续两周以上情绪低落、睡眠改变，应就医评估而非加码自责。
- [ ] **消极情绪有功能：愤怒让老板尊重你的时间** —— 给消极情绪「正名」后走向放任，任由愤怒冲动行事伤人伤己；情绪爆发后人际冲突持续恶化、睡眠改变超过两周，应寻求心理咨询。
- [ ] **积极情绪过多也不行：躁狂式自信爆棚** —— 本条的镜像误用是把真实的躁狂发作当成「我状态好」——若出现连续数天睡眠明显减少却精力异常旺盛、冲动决定不断，立即就诊精神科；家人出现此类信号要陪同就医。
- [ ] **洛萨达比例 3:1 到 11:1 已被撤稿，数字不靠谱** —— 用 3:1 给自己或伴侣、团队打分——「你今天消极话太多了」——制造监控式焦虑；若关系或团队因互相计账紧张升级，且个人出现持续两周以上情绪低落、睡眠改变，应寻求专业帮助。
- [ ] **负面偏差刻在 DNA 里：消极情绪的脑区激活更大、记忆更深** —— 拿「天生负面偏差」当宿命——「我就是消极体质改不了」；若因长期沉溺负面信息与反刍思维导致持续两周以上情绪低落、睡眠改变或自伤念头，立即就诊精神科。
- [ ] **压制情绪只会让它敲门更凶** —— 把「不压制」误解为「随便发泄」，对身边人倾倒情绪；或反向把「觉察」变成必须时刻做对的任务。若情绪失控频繁、伴随持续两周以上情绪低落、睡眠改变或自伤念头，立即就诊精神科。
- [ ] **RAIN 四步：认识、接纳、探索、分离（外部化）** —— 练习中沉浸痛苦情绪过深、被反刍带走；若练习后情绪反而持续恶化，出现持续两周以上情绪低落、睡眠改变或自伤念头，停止自行练习并立即就诊精神科。
- [ ] **没有感性就做不了任何决定：达马西奥的病人** —— 误把「感性决策」读成「跟着冲动走」——本条说的是情感参与决策的必要性，不是取消理性分析；重大决策（投资、离职、婚姻）仍须充分理性推演。若发现自己或家人情绪剧烈波动且决策能力明显受损超过两周，须就医评估。
- [ ] **情绪觉察，理性思考，感性决策：军队三层分工** —— 把「感性拍板」当成为冲动决策开脱——框架里感性是消化了理性分析之后的收敛，不是跳过分析；若反复冲动决策造成重大损失并伴随持续两周以上情绪低落、睡眠改变，须就医评估冲动控制问题。
