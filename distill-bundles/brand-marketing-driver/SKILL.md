# 品牌营销驱动认知包（Brand Marketing Driver）

> **一句话定位**：一套把"打广告"翻译成"建资产"的判断工具——先找文化母体寄生，再造超级符号压缩信息，用刺激反射让顾客条件反射下单，把每一分广告费从费用变成品牌资产，一切传播降成本、一切花费变投资。
> **来源**：华杉·跟华杉学品牌营销·30讲（BR01-BR32共32篇S级归档，2026-10-25全量收官），六模块：超级符号原理8讲+品牌三原理6讲+传播三原理7讲+营销原理2讲+消费者3讲+企业4讲+加餐。

---

## 一、总图（一句话记住）

**品牌营销 = 文化母体寄生 × 超级符号压缩 × 刺激反射触发 × 成本原理降本 × 资产原理保值 × 4P联动 × 消费者四角色 × 企业三定律**

品牌不是logo不是广告，是"降低社会监督成本、选择成本、传播成本"的资产。先寄生在不可抗拒的文化母体上（中秋/春节/母婴），再造一个人人秒懂的超级符号（I LOVE莜=西贝），然后用压倒性重复把符号钉进人脑，让顾客看到符号就条件反射下单。花1元建品牌省3元交易成本拿2元溢价——广告费花出去要能收回来变成资产，收不回来的就是买流量，流量会停资产不会停。

## 二、核心律速查表（BR系列，按六模块分组）

### 模块一：超级符号原理——品牌的原力（BR02-BR09）

| 编号 | 模型名 | 一句话+应用 |
|---|---|---|
| BR02 | 十二字法门律 | 文化母体+品牌寄生+超级符号——找母体、寄上去、造符号，三步建品牌 |
| BR03 | 符号文明律 | 商业文明就是符号文明——人靠符号识别一切，符号不对信息全废 |
| BR04 | 超级符号律 | 把品牌寄生在人人熟悉的符号上——用现成的文化记忆，别从零教育 |
| BR05 | 超级符号三标准律 | 明确指称+浓缩巨大信息量和感情能量+强烈行动指令——三标准缺一不可 |
| BR06 | I LOVE莜标本律 | 西贝把"莜面村"翻译成I LOVE YOU——原始符号改造，零基础沟通 |
| BR07 | 营销日历律 | 固定时间做固定的事——中秋月饼/春节礼盒，重复50年成民俗 |
| BR08 | 重复成民俗律 | 重复是传播的最大杠杆——同一动作重复到顾客替你传播 |
| BR09 | 原始本能律 | 设计越原始越打动人——用人类共通的原始纹样/色彩，别玩小众艺术 |

### 模块二：品牌三大原理——品牌的商业本质（BR10-BR15）

| 编号 | 模型名 | 一句话+应用 |
|---|---|---|
| BR10 | 社会监督原理律 | 品牌是社会监督机制——出事先买单别公关，一次投诉换一个终身客户 |
| BR11 | 成本原理律 | 品牌降三种成本：监督成本/选择成本/传播成本——不能降成本的品牌是假品牌 |
| BR12 | 资产原理律 | 花费变投资——广告花出去要沉淀成品牌资产，否则就是消耗 |
| BR13 | 信息露出律 | 品牌信息露出越多越好——知名度是终极优势，停止打广告就是放弃知名度 |
| BR14 | 资产保值增值律 | 品牌资产两效益：降低成本+提高溢价——每年要问资产增值了没 |
| BR15 | 现身说法律 | 华与华自己就是案例——咨询公司也用超级符号+持续改善 |

### 模块三：传播三大原理——怎么传得开传得久（BR16-BR22）

| 编号 | 模型名 | 一句话+应用 |
|---|---|---|
| BR16 | 刺激反射律 | 叫座先于叫好——广告是条件反射训练，不是艺术作品；广告语用填空法 |
| BR17 | 修辞四要领律 | 普通道理+简单字词+节奏押韵+使人愉悦——好广告四特征 |
| BR18 | 播传原理律 | 传达率>到达率——口语>顺口溜>歌诀，去文字思考，让人能口口相传 |
| BR19 | 信号能量律 | 刺激越强反射越大——媒介越贵能量越强，压倒性投放胜过撒胡椒面 |
| BR20 | 信号能量实战律 | 字大/声大/色纯——要广告不要窄告，视觉锤要够狠 |
| BR21 | 流量成本律 | 流量三来源：自有/赢得/购买——谁担风险谁挣钱，不买关键词 |
| BR22 | 流量主权律 | 流量吸毒vs流量主权——自己就是最大媒体，别把命脉交给平台 |

### 模块四：营销原理——4P最高纲领（BR23-BR24）

| 编号 | 模型名 | 一句话+应用 |
|---|---|---|
| BR23 | 4P律 | 产品Product/价格Price/渠道Place/推广Promotion——完全穷尽相互独立，解释一切营销问题 |
| BR24 | 4C批判律 | 产品不是顾客价值/价格不是顾客成本/渠道不是方便性/推广不是沟通——别被4C带偏，4P才是纲领 |

### 模块五：重新认识消费者——四角色分工（BR25-BR27）

| 编号 | 模型名 | 一句话+应用 |
|---|---|---|
| BR25 | 受众角色律 | 当头棒喝+重复刺激——知名度是终极优势，先让人记住你 |
| BR26 | 购买者角色律 | 压倒性信息优势+三个购买（指令/理由/指南）——给足三个理由让人快速选你 |
| BR27 | 体验者传播者律 | 体验三阶段：来之前/来之中/走之后——带走信物乐于谈论，才是免费传播 |

### 模块六：重新认识企业——品牌的根（BR28-BR31）

| 编号 | 模型名 | 一句话+应用 |
|---|---|---|
| BR28 | 交易成本定律律 | 企业存在因为降低社会交易成本——规模有边界，内部交易成本决定扩张极限 |
| BR29 | 社会职能定律律 | 企业本质=为社会解决问题——经营使命=社会责任=企业战略 |

## 三、品牌全链路诊断 SOP（6步）

遇到"品牌没记忆点/新品卖不动/广告投了没沉淀/品牌老化"类问题时按序走：

1. **找母体（BR02/BR09）**：先问你的产品寄生在哪个不可抗拒的文化母体上？云腿月饼寄生中秋送礼母体，读书IP寄生"知识改变命运"母体。母体找错，符号再美也是无根之木。
2. **造符号（BR04/BR05/BR06）**：符号过三标准——能不能明确指称你？有没有浓缩信息量和感情能量？有没有行动指令？用原始纹样/人人熟悉的符号改造，别玩现代艺术。
3. **写话语（BR16/BR17/BR18/BR32）**：广告语用填空法——XX就选XX；修辞四要领自查（普通道理/简单字词/节奏押韵/使人愉悦）；口语化能口口相传；好口号要不花钱+押韵+行动指令。
4. **查成本资产（BR11/BR12/BR13/BR14）**：品牌降了哪三种成本？这笔广告费是沉淀成资产还是消耗成流量？信息露出够不够（停止打广告=放弃知名度）？品牌资产今年增值了没？
5. **过4P联动（BR23/BR24）**：产品/价格/渠道/推广四者是否一致？新品上市别只调推广，4P要联动改（参考西贝mall店化案例）。
6. **对消费者四角色（BR25/BR26/BR27）**：受众记住你了吗（当头棒喝+重复7次）？购买者拿到三个购买理由了吗？体验者带走信物乐于谈论了吗？客诉24小时主动赔到位（BR10社会监督）。

输出格式：结论先行（品牌缺哪一环）→ 每步证据（BR编号）→ 落点行动项。铁律：出事先买单别公关；要广告不要窄告；自己就是最大媒体。

### 品牌自检十问（新品上市/年度复盘通用）

1. 我的品牌寄生在哪个文化母体上？这个母体明年还在吗？
2. 我的超级符号能不能被一个3岁小孩画出来并说出我的品牌名？
3. 我的口号有没有行动指令？能不能押韵？能不能被顾客口口相传？
4. 顾客看到我的包装，3秒内知不知道我卖什么、给谁买、为什么选我？
5. 这笔广告费花出去，明年还在的资产是什么？
6. 我是在买流量还是在建资产？停投后销量掉多少？
7. 我的4P（产品/价格/渠道/推广）是不是在说同一件事？
8. 受众记住我了吗？购买者选我了吗？体验者愿意推荐我吗？
9. 出负面新闻时我的第一反应是认赔还是公关？
10. 我的企业使命是"为社会解决什么问题"还是"赚多少钱"？

十问里有三问答不上来，品牌就还没立住。

## 四、应用场景映射

| 场景 | 应用 |
|---|---|
| 冠生园品牌年轻化 | 云腿月饼寄生中秋母体（BR02），符号用云南民族织锦/火腿木架原始纹样而非现代艺术照（BR09）；超级口号填空法："中秋送云腿，就选冠生园"（BR16）；营销日历：每年中秋固定动作重复50年成民俗（BR07）；低糖云腿新品：三个购买理由（低糖/正宗云腿/老字号）放详情页第一屏（BR26）；客诉24小时主动赔，禁删差评（BR10）；4P联动：新品价格/渠道/推广一起调（BR23）；停止投流前先问品牌资产还剩多少（BR13）；使命定"让全国人民吃到正宗云南云腿月饼"（BR29） |
| 个人IP「读书的饕哥」 | 定死品类=商业认知类书籍（BR25受众当头棒喝）；固定栏目时间每周三=营销日历（BR07）；"饕"字做成固定符号（BR04）；每条笔记结尾加购买理由（为什么读这本书）（BR26）；提炼≤15字金句让人愿意截图转发=播传原理（BR18）；口语化去文字思考（BR18）；体验者走之后乐于谈论=金句信物（BR27）；自己就是最大媒体，别把流量命脉交给平台算法（BR22） |
| 投资（消费股检验） | 两把尺子：①有没有寄生不可抗拒的文化母体（茅台寄生白酒母体）②销售费用率对应的成本效率——降选择成本的是品牌资产，降不了的是买流量（BR11/BR12）；负面新闻应对是分水岭：第一时间认赔的加分，抵赖甩锅的是真雷（BR10）；看广告投放：停止打广告的品牌在放弃知名度（BR13）；看使命：为社会解决问题的是国民企业，喊赚多少钱的是生意（BR29）；餐饮扩张看4P是否联动（BR24） |

## 五、边界

- 华杉方法偏符号学+心理学（荣格一线），适合品牌建设期——对纯渠道驱动、短期冲量的电商打法不是万能解，短期ROI交给business-practice-driver。
- "重复50年"是品牌长期主义——短期要平衡好现金牛与品牌投入，别拿长期主义当不看当期账的借口。
- 不做西方品牌理论教科书——它是华与华17年实战倒出来的方法，不是学院派体系。
- 符号设计需要专业创意执行——本透镜给判断标准和方向，具体设计稿要找设计师落地。
- 模型置信度：BR01-BR32 均为S级归档蒸馏（华杉品牌营销30讲，2026-10-25全量收官32篇+1视频彩蛋不归档）。
