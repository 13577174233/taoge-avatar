# 电商内容运营体系（冠生园 2027 内容叙事专用）

面向昆明冠生园食品有限公司·电商事业中心。核心：母题「云南的好食材，做给今天的人——老滇味的底子，今天的讲法」，小编制 + AI 内容工厂，内容服务毛利与转化，不考点赞。项目实体在报告体系 `12-内容运营/`。

## 判断模型接入（来自 taoge-jiahua-ecom-playbook）

内容服务于货盘角色与战役节奏，不服务于点赞。

- **M3 产品角色**：每个栏目绑定一个产品角色，禁止"全品类种草"式排期。
- **M6 节庆倒排**：内容节点与货盘、备货同表倒排（T-90 定货盘、T-60 锁内容与达人），不各排一套。
- **M4 渠道经济学**：投放复盘算获客成本与贡献，不只看播放与互动。

模型全文见 `../taoge-jiahua-ecom-playbook/references/ecom-thinking-models.md`。

## 三、品牌叙事基本法（口径上位法，不得自造主张）

- 定位：世界级云南美食人文品牌、滇式糕饼品类代表；1939 年创立、省级非遗云腿月饼制作技艺传承单位；
- 四关键词取材：云南风物文化（根/溯源）、健康天然（配料表/低糖/短保）、新鲜手作（现烤/老师傅/非遗动态叙事）、温暖松弛（老街坊/乡愁/日常自食）；
- 三层内容：视觉统一（封面/纸包怀旧）→ 品牌叙事（百年/非遗/创始人母版）→ 产品溯源人文（一产品一条溯源线）；
- 产品叙事：山珍云腿=货架盈利盘；滇式健康点心=内容创新盘；低糖云腿=第二增长点爆品（减糖不减味，只说减糖/低糖）；小克重=自食引流（"自己吃别买礼盒"）；礼盒=只讲体面不硬囤货；
- **2025品牌手册权威口径（最新，冲突以此为准）**：主Slogan「我们从一九一五年开始做饼」（讲根脉，与内容母题分工不混用）；文化战略「云南物·中国风·世界潮」（2024.7发布）；起源1915上海→1925长江而上开分号→1939昆明金碧路首店（店址金碧路/金马碧鸡坊两说待核）；品质「质量就是生命，产品就是人品」；ISO9001/HACCP/食品安全三认证；云南唯一云腿月饼出口卫生注册证、连续出口40多年、累计超亿枚；荣誉有效期核过再用（国礼品牌授权2025.11.14到期待续期，不得直接用LOGO）；资产=人民糕点厂/1915时光/称斤如意主题店、食光照相馆快闪、省博《壹盒珍宝》联名；原料矩阵松茸/鸡枞/宣威火腿/黑松露/重瓣玫瑰/普洱茶；品牌色深蓝+橙红。
- **红线**：不碰功效词（降糖/减肥/养生/治疗/增强免疫）；不写无糖；无证据不宣称（source-verification 留痕）；2027.3 强制标糖后低糖表述以包装实测为准；不用极限词；非遗只讲已认定范围；不虚构产地、不冒用地理标志。

## 四、支柱配比与六栏目

- P1 风物溯源 25% / P2 非遗手作 20% / P3 健康测评 30% / P4 日常场景 25%；节庆月战役栏目临时提到 40%；
- 栏目：《火腿从哪来》(P1)、《老师傅的手》(P2)、《配料表说话》(P3)、《今天吃点滇的》(P4)、《冠生园朋友圈》(UGC)、《节庆新讲法》(战役)。

## 五、平台分工（一鱼多吃≠一稿多发，每平台重写开头结尾）

- 抖音1店：品牌主阵地，自播≥60%，达播净 ROI≥1:2 不达标即停，直播切片二次裂变；
- 抖音2店：自食走量、纸包怀旧，复制1店模型；
- 视频号：私域社交/团圆礼赠/中年人群，可双开，社交转发语收尾；
- 快手：本地市井日播补位，不硬投；
- 小红书：主号种草测评+8月前置蓄水（2026验证）、2-3篇万级爆文、店铺分修复4.6；关联号差异化不重发；
- 货架（天猫三店/京东/拼多多）：头图视频、详情页卖点条目化、三池素材赛马、数字人试点。

## 六、生产七步 SOP

选题（月度会/差评回流/新品节点/热点）→ 立题（一个主张+人群+转化动作）→ 脚本（红线自查）→ 品牌中心预审留痕 → 实拍/AI生产（母版优先复用）→ 分平台改写分发 → 数据复盘入库（爆品裂变/沉题归档）。

## 七、节庆三波次（年货/端午/中秋共用）

- 预热 T-30~T-15：非遗产地故事、达人寄样、小红书前置种草、加购收藏；
- 爆发 T-7~T：直播密集、切片裂变、自播为主、达播集中；
- 收尾 T+1~T+7：买家秀、差评答疑、转日常自食、素材入库、结算淘汰达人。
- 2027 已核日期：春节 2/6（除夕2/5）、端午 6/9、中秋 9/15；618=6/18、双11=11/11。

## 七补、市场情报话术库（V1.1 接入 12-市场情报）

- **成分话术**：减糖量化数字 + 核心成分含量≥X% + 清洁配料表，替代「健康/养生」模糊词；健康概念优先级 0蔗糖/减糖量化＞高纤维/低GI＞成分标注；无检测不写数字。
- **标题**：优先提问式（点击率约+30%）；资源向短视频倾斜（比图文转化约+40%）。
- **COKE 脚本框架**：Context 场景 / Objectives 单一目标 / Knowledge 有据品牌知识 / Emotion 情绪；AI 统一供稿保调性。
- **三档SKU**：礼盒款100-300元主流带（体面+老字号+精致可二次利用盒）/ 自食款60元以下 / 尝鲜小克重低价试错；分轨不混价，裸标品不打底价，B端团购走定制专供。
- **节令节奏**：T-8周定品定价 → T-4周AI工厂备素材+KOC铺量 → T-2周集中投放转化（自播≥60%、达播净ROI≥1:2）→ T+7复盘入库。春节重礼赠、中秋重团圆、端午轻试新。
- **品效配比**：常态60:40（品牌:效果），大促月向效果倾斜；达人预算从头部迁至中腰部主体+腰尾部KOC，KOC转化效率约明星3.2倍。
- **AI合规**：合成内容做标识、禁AI外呼骚扰、不炒作AI替代员工、不夸大AI能力；0-6小时舆情值守。

## 八、月度复盘口径（R7）

漏斗四层（曝光→互动→进店→成交，分平台）；自播占比≥60%；达播净ROI≥1:2；月产出条数；素材复用率；选题命中率；小红书店铺分4.6；品牌搜索指数环比；统一口径覆盖率100%。不单独考核点赞播放。
