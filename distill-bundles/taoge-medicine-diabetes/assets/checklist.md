# 糖尿病 · 行动清单

> 打印出来贴冰箱。每条都是「什么情况下不能做 / 必须就医」。

- [ ] **糖尿病是"慢病之王"：三大凶险特征** —— 早期毫无症状意味着不能靠感觉判断病情；体检血糖超标即应遵医嘱复查与干预；出现视力模糊、足部伤口不愈、皮肤瘙痒等信号须尽快就医。
- [ ] **合并糖尿病会放大其他疾病的治疗难度** —— 就诊其他疾病或手术前务必告知医生糖尿病史与用药情况，不可自行停药换药；出现伤口不愈、反复感染须及时就医。
- [ ] **三种典型心态都会加速病情恶化** —— 凡宣称能"包好糖尿病"的偏方秘方都不可信；放弃正规治疗期间出现视力模糊、多饮多尿加重、体重快速下降须立即就医。
- [ ] **对糖尿病的合理预期是控制而非治愈** —— 以"治愈"为目标的求医观极易落入偏方陷阱；正规路径是内分泌科随访；出现意识模糊、严重脱水等急症信号立即就医。
- [ ] **糖尿病症状复杂，病因却简单** —— 出现"三多一少"时病情往往已较重，不能等症状才查血糖；视力模糊、皮肤瘙痒、足部伤口不愈须就医。
- [ ] **诊断就是几个血糖数字** —— 单次血糖异常不能自行下诊断，须遵医嘱复查确认；达到诊断界值应尽快到内分泌科就诊。
- [ ] **血糖是身体能量的"价格信号"** —— 本条为机制认知，不涉及操作风险。
- [ ] **升糖与降糖：胰岛里两套相反的系统** —— 本条为机制认知；顺带记一组低血糖信号——剧烈运动后心慌、手抖、强烈饥饿感应尽快进食并排查原因。
- [ ] **糖尿病的病灶在降糖系统一侧** —— 血糖长期居高不下并出现多饮多尿、体重下降、视力模糊须尽快就医，不要等症状齐全。
- [ ] **一个名字，两种疾病** —— 分型错误会导致治疗方案错误；青少年出现"三多一少"须尽快就医排查 1 型，不能按"中老年慢性病"拖延观察。
- [ ] **一杯糖水一针胰岛素：西姆沃斯实验** —— 此为历史研究场景，普通人绝不可自行用胰岛素做"测试"；胰岛素是处方药，使用不当可致低血糖（心慌、出汗、手抖），出现须立即处理并就医。
- [ ] **1 型：感受器失灵的自身免疫病** —— 1 型患者中断胰岛素可迅速恶化甚至危及生命，绝不可自行停药；出现恶心呕吐、呼吸带烂苹果味（酮症气味）、意识模糊须立即急救就医。
- [ ] **2 型：效应器失灵的全身性疾病** —— 2 型早期可无症状，须靠体检血糖发现；出现"三多一少"或并发症信号（视力模糊、足部麻木、伤口不愈）须就医。
- [ ] **2 型激增指向现代生活方式** —— 处于快速增长环境中的每个人都应定期查血糖，高危人群更须查糖耐量（见第 9 讲）。
- [ ] **肥胖是 2 型糖尿病最重要的风险因素** —— 本条为风险认知；减重须循序渐进，出现头晕、乏力等异常须就医，不可极端节食。
- [ ] **从相关到因果：生物学家的三板斧** —— 本条为方法论认知，不涉及操作风险。
- [ ] **内质网应激：一个候选机制及其困境** —— 本条为前沿机制认知，不构成任何行动依据；勿据"应激"概念自行购买"抗应激"保健品。
- [ ] **节俭基因：演化视角下的现代病** —— 本条为解释框架，不构成行动方案；据此自责"意志力差"反而有害，应借助环境与工具管理。
- [ ] **2 型激增是演化与文明的必然碰撞** —— 本条为宏观判断；个人层面仍应落实筛查与生活方式干预，不能因"大势如此"而放弃。
- [ ] **早期毫无征兆：三多一少出现时已晚** —— 不能等"三多一少"才查血糖，高危人群应主动筛查（见第 9 讲）；已出现视力模糊、皮肤瘙痒、足部伤口不愈须就医。
- [ ] **正反馈循环：发病后几乎不可逆** —— 正反馈意味着拖延的代价指数增长；确诊后立即启动规范管理，血糖持续失控、明显消瘦须尽快复诊。
- [ ] **并发症：糖网、糖肾、糖足与心脑血管** —— 每天观察双脚伤口与皮肤，每年查眼底与尿蛋白是底线；出现视力骤降、足部破溃不愈、尿量改变须立即就医。
- [ ] **三段心理轨迹与精神疾病风险** —— 出现持续情绪低落、失眠、自杀念头须立即就医（精神科/心理科），这和控糖同样紧急。
- [ ] **可控：正确态度是把病当邻居** —— 控制不等于无风险：出现心慌、出汗、手抖、意识模糊等低血糖信号须立即处理并就医；不可为"控好"而自行加药。
- [ ] **胰岛素在两类糖尿病中的角色不同** —— 胰岛素属处方药，不可自行停药换药或调整剂量；注射后出现心慌、出汗、手抖、意识模糊等低血糖信号，立即进食糖类并就医。
- [ ] **从屠宰场到药房：动物胰岛素的诞生与缺陷** —— 本条为药物史认知；提示今人：来源与纯度可疑的"胰岛素制品"绝不可自行使用，用药须走正规处方渠道。
- [ ] **第一次进化：重组 DNA 造出人胰岛素** —— 人胰岛素仍是处方药，不可自行停药换药；低血糖信号（心慌、出汗、手抖）出现须立即处理并就医。
- [ ] **第二次进化：短效+长效模拟人体节律** —— 剂量与时机错配会低血糖——心慌、出汗、手抖、意识模糊须立即进食糖类，反复发作或意识不清立即就医；不可自行停药换药。
- [ ] **给药方式进化：胰岛素泵与其极限** —— 泵位皮肤出现红肿、化脓等感染信号须就医处理；机械故障或持续高/低血糖时立即联系医生；不可自行停泵。
- [ ] **人工胰腺：闭环机器已上市** —— 设备存在机械电子故障、长期佩戴感染风险；血糖持续异常、佩戴处红肿化脓须就医；不可因依赖设备而撤掉手动应急预案。
- [ ] **胰腺移植：有效但被供体与排斥卡死** —— 移植后长期服用免疫抑制药物者感染风险高，出现发热、伤口不愈等信号须立即就医；一切用药遵移植团队安排，不可自行调整。
- [ ] **混合胰腺：多孔薄膜盒骗过免疫系统** —— 植入装置属手术操作，须在正规临床试验/医疗渠道进行；植入处感染、血糖失控等装置失效信号须就医。
- [ ] **生物胰腺：干细胞重造 beta 细胞** —— 该技术尚未大规模临床应用，切勿购买任何宣称"干细胞治糖尿病"的服务；现行正规治疗不可中断。
- [ ] **最后一关：让新胰腺躲开自身免疫** —— 属前沿研究，无任何可自行尝试的途径；1 型患者现行治疗（胰岛素）不可中断，出现酮症气味、意识模糊立即急救就医。
- [ ] **二甲双胍：2 型糖尿病的第一处方** —— 属处方药，不可自行停药换药；常见副作用为腹痛腹泻、恶心呕吐等胃肠道反应；肾功能不全者可能肾病加重，须监测肾功能，出现持续呕吐、少尿、乏力须就医。
- [ ] **从毒草到神药：偶然的发家史** —— 山羊豆碱能剧烈降血糖、毒死牲畜，误食有毒植物可致严重低血糖（心慌、出汗、意识模糊），须立即急救就医。
- [ ] **机制成谜：连 AMPK 模型也靠不住了** —— 机制不明不等于可以乱用——它仍是处方药，副作用与禁忌见 A1，不可自行加量。
- [ ] **炼金术的代价：成功无法复制** —— 氯胺酮是受管制物质（毒品 K粉），任何自行获取与使用都违法且危险。
- [ ] **意外的彩蛋：延寿可能与滥用风险** —— 处方药，不可自行停药换药、更不可无处方自购；出现腹痛腹泻、恶心呕吐等胃肠道反应须告知医生；肾功能不全者风险更高，须监测肾功能。
- [ ] **反常识起点：口服糖比静脉注射更促胰岛素** —— 本条为机制史认知；不构成"吃糖比注射好"的行动含义，糖尿病治疗决策须遵医嘱。
- [ ] **GLP-1：肠道直通胰腺的预警信号** —— 本条为机制认知；涉及 GLP-1 类药物时（见 A3），用药须处方，出现持续恶心呕吐、剧烈腹痛须就医，不可自行停药换药。
- [ ] **改造一：化学修饰把半衰期拉长到一周** —— GLP-1 类为处方药，不可自行停药换药；用药期间出现持续呕吐、剧烈腹痛（警惕胰腺炎信号）须立即就医。
- [ ] **改造二：锁住 DPP-4 这把降解剪刀** —— 处方药，不可自行停药换药；出现过敏样反应、持续不适须就医；具体副作用原文未列，须看说明书并遵医嘱。
- [ ] **末端战场：格列净让肾脏"少回收"血糖** —— 处方药，不可自行停药换药；尿糖增加可能伴随泌尿生殖道感染风险，出现尿痛、发热、外阴瘙痒等信号须就医。
- [ ] **糖尿病前期是流动的窗口期** —— 前期一般无症状，须靠化验发现；若已出现"三多一少"或视力模糊、伤口不愈，须立即就医而非自行"调理"。
- [ ] **空腹血糖会漏诊：糖耐量检查更可靠** —— 检查须在医疗机构进行；过程中出现心慌、出汗、头晕等不适立即告知医护；本检查无治疗作用，异常结果须交医生判读。
- [ ] **高危人群每年一次糖耐量** —— 检查发现异常数值时不可自行诊断或用药，须交由医生判读并复查。
- [ ] **生活方式干预：被三大研究验证的预防法** —— 增加运动量要循序渐进，出现胸闷、头晕、关节疼痛须暂停并就医；不可为防病采取极端节食。
- [ ] **中国人的特殊战场：精制淀粉与阿卡波糖** —— 阿卡波糖不可自行停药换药；服用后腹胀、腹泻明显或持续不适须告知医生；主食骤减须防低血糖（心慌、出汗、手抖）。
- [ ] **控制的金指标：糖化血红蛋白** —— 单次血糖高不必恐慌、单次正常不可松懈，以 3 个月维度评估；出现心慌、出汗、手抖等低血糖信号立即处理并就医。
- [ ] **四层递进的控制阶梯** —— 任何一层药物调整都须医生执行，不可自行停药换药或跳层加药；出现低血糖信号（心慌、出汗、手抖、意识模糊）立即进食糖类，反复发作或意识不清立即就医。
- [ ] **减肥手术：超 80% 缓解但有硬门槛** —— 属重大手术，有围手术期风险；术后出现剧烈腹痛、呕吐、发热（警惕堵塞、泄露）或明显营养不良信号须立即就医。
- [ ] **缓解新曙光：低能量饮食与进食时间** —— 极低能量饮食可致低血糖（心慌、出汗、意识模糊）与营养不良，必须在医疗监督下进行，出现不适立即就医并恢复常规饮食。
- [ ] **控制的现实预期：小输当赢** —— 为追求"逆转"而停药、断食、试偏方是最大的安全风险；低血糖信号（心慌、出汗、手抖）与酮症信号（烂苹果味呼吸、恶心呕吐、意识模糊）须立即就医。
- [ ] **困境一：个人难以克服演化本能** —— 把"管不住自己"归为道德失败会加重心理负担（见第 4 讲精神负担）；依赖环境与工具才是可持续路径。
- [ ] **困境二：公权力无从下手** —— 本条为公共政策认知；个人不可据"政府会管"而放弃自我管理。
- [ ] **出路一：疾病教育已被验证有效** —— 教育须来自权威渠道；被"养生自媒体"误导本身就是风险（偏方、断食逆转之类）。
- [ ] **出路二：个性化的生活方式管理** —— App 提醒不能替代医嘱与药物；出现低血糖信号（心慌、出汗、手抖）仍须立即处理并就医；不可因软件提示自行改药。
- [ ] **三高同源：一套办法打三种病** —— 三高共存者用药复杂，任何调整须医生执行，不可自行停药换药；任一指标剧烈波动或出现胸痛、视物模糊、肢体无力须立即就医。
- [ ] **体格检查是基石，趋势重于单点** —— 体重无因骤降、视力视野快速下降、血压心率显著异常→体检后尽快到专科复查，不要等下一年。
- [ ] **第二层：选能直接对应干预的项目** —— 血脂等指标异常须交医生评估用药，不可自行买他汀服用；服药中不可自行停药换药；出现胸痛、肢体无力等心脑血管信号立即就医。
- [ ] **并非越先进越好：CT 与超声的取舍** —— CT 等有辐射的检查不宜无指征反复做；检查发现结节、肿块须到专科复查随访，不要自行搜索吓自己。
- [ ] **并非越频繁越好：肠镜的节奏** —— 出现便血、排便习惯改变、不明原因贫血消瘦，不等复查周期立即就医；麻醉肠镜须评估麻醉风险。
- [ ] **并非越多越好：肿瘤标志物的陷阱** —— 肿瘤标志物异常不要恐慌也不要无视，应及时就医用直肠指检、前列腺活检等确认；切勿据单项指标自行下癌症结论。
- [ ] **定制化：散瞳、认知量表与女性项目** —— 散瞳后当天怕光、视近物模糊属正常，避免驾驶；眼底检查发现黄斑变性、视网膜脱离风险须尽快专科处理，拖延可致不可逆视力损伤。
