# 娱乐行业晨间分析

面向普通人的文娱市场解读：帮你看什么、避什么、怎么花钱。

## 分析范围

- 电影：单日/周末票房、新片口碑与排片、档期（国庆/贺岁/暑期）
- 剧集与动漫：热播榜、平台会员剧、国创动漫动态
- 综艺与短剧：新综艺开播、短剧爆款、微短剧监管
- 演出：演唱会/音乐节开票、票务动态
- IP与衍生：周边、联名、游戏影视化

## 晨间分析步骤

1. 检索过去24小时文娱市场动态（票房数据、开播开票、平台榜单）
2. 判断可看性与消费价值：
   - 周末观影/追剧推荐：依据口碑与评分
   - 会员决策：哪家平台值得开、什么内容独占
   - 演出抢票提醒：开票时间、票价区间
3. 给出消费提醒：档期选择、票价套路（黄牛/溢价）
4. 硬性过滤：明星私生活、绯闻八卦一律不纳入；只选作品与市场层面

## 关键数据源

- 票房：猫眼专业版、灯塔专业版
- 剧集动漫：云合数据、骨朵热度、平台榜单
- 行业：艺恩、娱乐资本论、证券时报文娱

## 输出模板

```
[娱乐] 标题
市场数据：票房/榜单/开票一句话
值得关注：周末看什么、追什么
与我何关：消费建议（观影/会员/演出）与避坑提醒
```
