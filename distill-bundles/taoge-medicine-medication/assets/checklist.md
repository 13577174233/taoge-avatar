# 日常用药 · 红线清单

> 打印出来贴冰箱。每条都是「什么情况下不能做 / 必须就医」。

- [ ] **安全险中求：不良反应是药物的基本属性** —— 涉及具体药物时，以说明书的不良反应栏和医生交代为准；服药后出现说明书未提示或明显加重的不适，应停药并咨询医生或药师。
- [ ] **药商：不背药学知识也能避开药害的能力** —— 服用喹诺酮类（如左氧氟沙星）期间出现跟腱疼痛、肿胀，立即停止运动并就医评估；家人突发晕倒时，把用药照片发给急救医生帮助判断。
- [ ] **药商三段论：先排除药害，再谈用药，最后问能否不吃药** —— 持续胸痛、呼吸困难、意识改变等急症不适用"先想能不能不吃药"，应立即拨打 120 或就医；服药后新出现的症状先怀疑药物因素再决定是否加药。
- [ ] **行动：给家人建一份用药照片档案** —— 家人晕倒、意识不清、说话含糊时，第一动作是拨打 120，用药照片在救护过程中交给医生；不能因为"先找照片"延误呼救。
- [ ] **用药安全素养有三个层级** —— 三个层级都覆盖不了急症场景——持续胸痛、呼吸困难、意识改变时直接拨打 120，不做自我判断。
- [ ] **紧急时刻：过期几天的未开封硝酸甘油可以吃** —— 可观察信号——服药后胸痛不缓解、大汗、濒死感：先吃药、吃完后赶紧拨打 120，不等"看有没有效"；不能自行开车去医院。
- [ ] **硝酸甘油要随身携带，优先铝箔单片包装** —— 含服后胸痛未缓解或加重、伴大汗，立即拨打 120；发现药片外观、气味变化即停用更换；不能因怕变质而把药锁进家中药箱。
- [ ] **选药原则：选对你服用代价最小的药** —— 服药期间出现黑便、胃痛加重（提示胃肠出血风险）或心跳明显加快、口干严重（抗胆碱类反应），停药并就医；换药、停药必须由医生决定，不可自行调整。
- [ ] **隐患一：多药同吃会在体内互相影响** —— 可观察信号——开始一种新药后出现新症状（记忆力明显变差、嗜睡、异常行为），即使说明书没写，也要带着全部用药清单去问医生或药师，不要自行归因为"老糊涂"。
- [ ] **隐患二：西柚会让药物在体内蓄积** —— 服药期间吃西柚后出现明显头晕、肌肉疼痛、心慌等异常，立即就医；开始服任何处方药前，问一句医生或药师"这个药和西柚能不能同吃"。
- [ ] **吃药之前没有、吃药之后才有的不舒服，先怀疑药** —— 可观察信号——吃保健品后心慌、出冷汗提示低血糖，立即进食含糖食物并就医；服药后新出现的水肿、头疼加重超过 3 天不缓解，带着用药清单去医院，不要自行停药换药。
- [ ] **双膦酸盐类骨质疏松药：整粒吃、200 毫升水、半小时别躺下** —— 可观察信号——服药后马上胸口疼、烧心、吞咽疼痛：停止再按错误方法服用，及时找医生或药师；不能掰开嚼碎，也不可只抿一口水就躺下睡觉。
- [ ] **天然安全的保健品可能非法添加了降糖处方药** —— 可观察信号——服保健品后心慌、出冷汗、手抖、乏力（低血糖表现），立即吃含糖食物并就医，带上该保健品；不要再继续服用。
- [ ] **胃药分两种：抗酸型饭后吃，胃粘膜保护剂饭前吃** —— 可观察信号——按正确时辰服药 3 天烧心仍不缓解，或出现黑便、呕血、体重下降，及时去医院找医生，别长期靠非处方胃药硬撑。
- [ ] **止泻药没效果，先想是不是细菌性腹泻** —— 可观察信号——腹泻超过 2 天不缓解、便中带脓血、发热、明显口渴尿少（脱水表现），立即就医，不要继续自行换止泻药；老年人防脱水优先。
- [ ] **抗过敏药看场景选：开车避开扑尔敏，换氯雷他定** —— 可观察信号——服扑尔敏后明显犯困、乏力时不得开车；服药 3 天过敏症状不缓解或出现皮疹加重、胸闷，及时去医院找医生。
- [ ] **不适应是身体状态没跟上切换** —— 可观察信号——不适应伴随高热、剧烈头痛、意识模糊（如高原脑水肿征兆）时不是"适应问题"，立即下撤就医；症状持续超过 1 周不缓解也要就医。
- [ ] **抗生素拉肚子：杀菌的同时打乱了肠道菌群** —— 可观察信号——抗生素使用期间腹泻超过 2 天、便中带血或伴发热，立即联系医生，不要自行停药或加止泻药了事。
- [ ] **加巴喷丁、激素这类药绝不能突然停** —— 可观察信号——突然停药后疼痛突然加重、乏力、恶心等反跳表现，立即就医并说明停药经过；此后任何减量动作都要先问医生。
- [ ] **几个科室的药合着吃，取完药直接去问药师** —— 可观察信号——新加一种药后出现头晕目眩、浑身没劲、心慌等新症状，带着全部药物去药师门诊或就医；不可自行停掉其中任何一种处方药。
- [ ] **安眠药是管制精神类药物：按"入睡难"还是"易醒"选；褪黑素不是药** —— 可观察信号——服安眠药后夜间异常行为、次日严重嗜睡、记忆断片，立即停药就医并告知医生；安眠药不可自行加量、不可与酒精同服、不可分享给家人。
- [ ] **乙酰唑胺防高反：提前一天吃，到了海拔再吃两天就停** —— 可观察信号——服药期间出现剧烈头痛、呕吐、走路不稳、意识模糊，这不是靠药能扛的高原反应，立即下撤并就医；对磺胺类药物过敏者用药前必须告知医生。
- [ ] **强壮感由骨骼、肌肉量、心肺功能三根柱子撑起** —— 可观察信号——轻微活动就气喘吁吁、翻身腰背痛、体态明显垮塌，先就医查骨密度与心肺，再谈"变强壮"，不要直接上补剂。
- [ ] **这些药和食物在偷走你的钙和力气** —— 可观察信号——腰酸背痛、翻身困难、轻微磕碰即骨折，立即就医查骨密度；不可因担心不良反应自行停糖皮质激素（须遵医嘱逐渐减量）。
- [ ] **贝特和他汀要分开吃：早上贝特，晚上他汀** —— 可观察信号——服药期间出现肌肉酸痛、频繁抽筋、乏力加重甚至酱油色尿，立即就医并告知正在联用贝特与他汀；绝不能自行停药或自行加量。
- [ ] **大部分人不需要钙片，重点是补维生素 D** —— 可观察信号——自购钙片长期大量服用后出现便秘、肾结石史者尿砂石样疼痛，停用并就医；补维生素 D 过量同样中毒，补充剂剂量遵医嘱。
- [ ] **肌酸能增肌，但肾功能不好必须先问医生** —— 可观察信号——服用肌酸期间出现腰痛、尿量明显减少、尿色加深、水肿，立即停用并就医查肾功能；服用期间保证充足饮水。
- [ ] **不吃药变强壮：运动、高蛋白饮食、户外晒太阳** —— 可观察信号——运动后持续关节痛、胸闷、心悸，停止运动就医；晒太阳后皮肤红肿脱皮属于晒伤，调整时长与时段。
- [ ] **情绪失控有三种形态：对外爆发、对内低迷、长期低位** —— 可观察信号——情绪低落持续超过 2 周、出现自伤念头或行为，立即就医（精神科/心理科），不要当作"性格问题"硬扛。
- [ ] **两种药会让情绪失控：糖皮质激素和孟鲁司特** —— 可观察信号——孩子服孟鲁司特期间出现自伤行为（割伤、咬伤自己）、异常愧疚恐惧，立即停药就医并告知医生；成人服激素后出现明显情绪波动，联系医生调整，不可自行停药。
- [ ] **"关节不疼了但脾气变坏"，警惕保健品掺了激素** —— 可观察信号——吃某保健品后"效果奇快"同时出现脾气变坏、失眠、脸变圆等变化，立即停用，带产品就医并举报。
- [ ] **抗抑郁药：经前期综合征不值得吃，产后抑郁确诊就要用** —— 可观察信号——产后持续情绪低落、觉得自己没用、照顾不了孩子超过 2 周，立即就医评估；服药期间出现自伤念头立即停药就医。
- [ ] **男性也有更年期；性激素能救情绪，但雄激素有前列腺癌风险** —— 可观察信号——用雄激素期间排尿困难、血尿、骨盆疼痛，立即就医查前列腺；用性激素期间异常出血、乳房胀块，立即就医。
- [ ] **不吃药先解决情绪问题：去诱因、运动、皮筋提醒** —— 可观察信号——情绪低落持续超 2 周、影响进食睡眠、出现自伤念头，立即就医，不再停留在自助方法；运动中出现胸闷心悸立即停止。
- [ ] **光敏性药物：晚上用、吃完关灯、白天出门物理遮挡** —— 可观察信号——服药后日晒出现皮肤发红发痒、发黑脱皮，记录药名并就医确认是否光敏反应；不要自行当作皮炎涂药膏。
- [ ] **不知不觉吃进去的药：联用出皮疹，保健品掺药致浮肿** —— 可观察信号——新增一种药后数日内出现红斑皮疹，或服保健品后体重增加、浮肿，停用可疑保健品并带全部药就医；皮疹伴口腔糜烂、发热须立即就医（重症药疹信号）。
- [ ] **刷酸一周最多一次；维 A 酸乳膏晚上涂才十几块钱** —— 可观察信号——刷酸或涂维 A 酸后持续脱皮、刺痛、发红加重，停用并就医；使用维 A 酸期间白天严格防晒，出现日晒反应立即停用。
- [ ] **玻尿酸只能注射起效，面膜里的是智商税** —— 可观察信号——注射后视力模糊、眼周剧痛、皮肤发白发紫，立即就地急诊（血管栓塞征象）；注射须选正规医院和临床经验丰富的医生。
- [ ] **减肥药只有奥利司他获批，且只给 BMI 大于 30 的人** —— 可观察信号——服减肥药后心慌、口干、失眠（提示违禁成分）立即停用；奥利司他服用后排油失控属预期反应，出现严重腹泻脱水须就医。
- [ ] **不吃药变好看：防晒霜涂够一元硬币，运动别脉冲式** —— 可观察信号——运动后胸闷、心悸、关节持续疼痛，降低强度并就医；防晒霜过敏泛红立即停用该产品。
- [ ] **性烦恼分"不能"和"不想"，两者互相转化** —— 可观察信号——性功能突然明显改变且找不到生活原因，先排查用药变化；伴排尿疼痛、会阴胀痛（提示尿道炎等疾病）须就医，不是"买药解决"的事。
- [ ] **抗抑郁药和降压药都可能带来"不能"和"不想"** —— 可观察信号——开始新药后性功能明显下降，记录药名带全清单找医生或药师；不可自行停降压药（血压反跳可致中风），不可自行停抗抑郁药（病情复发）。
- [ ] **换成"降压保健品"比不换药更危险** —— 可观察信号——吃保健品期间血压失控波动、出现浮肿或性功能下降，立即停用并带产品就医；任何时候不自行停处方降压药。
- [ ] **希爱力（他达拉非）：提前 20 分钟吃，有效 36 小时** —— 可观察信号——服药后头部胀痛属已知不良反应，严重胸痛、胸闷、视觉异常（尤其合用硝酸酯类药物者可致致命性低血压）立即就医；硝酸甘油与"伟哥类"严禁同用。
- [ ] **必利劲治射精过快；女性可用药物目前很少** —— 可观察信号——服药后头晕、恶心、心悸明显，停止用药并复诊；达泊西汀与希爱力联用方案必须由医生开具，出现晕厥立即就医。
- [ ] **源头管控性烦恼：戒烟、别频繁节食、运动释压** —— 可观察信号——戒烟、运动、减压执行 3 个月性功能仍持续恶化，就医查血管与激素水平；运动中胸闷心悸立即停止。
- [ ] **爆发力是峰值状态与平时状态的差值** —— 可观察信号——关键时刻前出现心慌、手抖、出冷汗（可能低血糖），先进食再上场；持续力不从心且休息不缓解，就医排查基础病与用药。
- [ ] **这些药和用法在拖你潜力的后腿** —— 可观察信号——服药后心慌、手抖、出冷汗（低血糖表现）立即进食含糖食物；滴眼药水后持续头晕乏力，检查是否漏按内眼角并咨询医生，不可自行停降压降眼压类处方药。
- [ ] **"聪明药"不提高智力，只集中注意力，且是管制精神药品** —— 可观察信号——使用来历不明"聪明药"后失眠、心悸、情绪暴躁，停用并就医；中枢兴奋剂滥用有成瘾与精神症状风险，发现依赖及时求助精神科。
- [ ] **感冒药不能提高潜力，但能保住正常水平** —— 可观察信号——服药 3 天症状不缓解、高热超过 3 天或出现脓涕、胸痛，及时就医；复方感冒药含相同成分时不可叠加服用，防过量肝损伤。
- [ ] **平时喝茶，咖啡留给关键时刻** —— 可观察信号——大量摄入咖啡因后心悸、手抖、失眠，减量并停止当晚摄入；咖啡因不解决睡眠不足的根本问题，连续依赖须调整作息。
- [ ] **困了打盹 7 到 10 分钟；峰值靠平时拉高平均线** —— 可观察信号——打盹超过 30 分钟醒来昏沉加重，下次缩短时长；长期靠打盹补偿睡眠不足且白天嗜睡加重，就医排查睡眠障碍。
- [ ] **健康的终极目标是维持更长时间的生活质量** —— 可观察信号——记忆力明显下降影响生活、老人性格行为突变，及早就医评估认知，不要等"老了都这样"。
- [ ] **抗生素滥用有三种：吃多、吃少、没选对** —— 可观察信号——按疗程足量服药 3 天感染症状不缓解或加重（高热不退），复诊换方案而非自行加量；绝不可自行购买抗生素或自行停药。
- [ ] **慢性损害的药吃不吃，看它是不是治病必须** —— 可观察信号——长期服药者出现眼黄、尿黄、乏力、尿量减少或泡沫尿，立即就医查肝肾功能；不可因担心肝肾损伤自行停必须的处方药。
- [ ] **效果和不良反应都不明确的药：别信、别买、别吃** —— 可观察信号——服用此类产品后任何新发不适都无说明书可对照，立即停用并就医、保留产品；购买前先查有没有人体临床证据。
- [ ] **用药层面只推荐打疫苗：带状疱疹、HPV、流感** —— 可观察信号——接种后 48 小时内出现高热、呼吸困难、全身皮疹，立即就医（严重过敏反应）；发热急性期应推迟接种，咨询接种点。
- [ ] **不吸烟、不熬夜、常运动、精准体检** —— 可观察信号——体检发现异常指标后必须完成复查与随诊，不能"查完就完"；运动中出现胸闷、关节持续痛，减量并就医。
