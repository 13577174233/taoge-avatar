# 电商市场晨间分析

面向普通人的电商市场解读：帮消费者省钱，帮从业者看风向。

## 判断模型接入（来自 taoge-jiahua-ecom-playbook）

每条结论加一句"与我何关"，并标明信号类型：结构信号（M1 收入形状）、渠道信号（M4 贡献毛利）、口径或规则变化（M10）。三类都归不上的资讯不进正文，只进素材库。

模型全文见 `../taoge-jiahua-ecom-playbook/references/ecom-thinking-models.md`。

## 分析范围

- 大促节点：双11/618/年货节等倒计时、玩法（预售/现货/立减/凑单）、关键时间点
- 平台动态：淘天/京东/拼多多/抖音/快手规则变化、补贴与价格战
- 品类趋势：数码家电、生鲜食品、服饰美妆等价格与新品动向
- 行业监管：直播带货新规、仅退款规则、虚假宣传治理、物流快递新规
- 消费环境：消费券发放、以旧换新、消费品补贴政策

## 晨间分析步骤

1. 检索过去24小时电商相关新闻：平台公告、监管文件、行业数据、大促节点
2. 判断对两类人的影响：
   - 消费者：什么时候买最划算、怎么防套路（先涨后降/凑单陷阱/预售风险）
   - 从业者：平台政策变化、品类趋势、流量规则变化
3. 结合物流与天气（如台风影响快递时效）给出实用提醒
4. 过滤：重复的促销通稿、明星带货八卦

## 关键数据源

- 平台官方公告（淘宝/京东/拼多多/抖音商家后台）
- 行业媒体：36氪、亿邦动力、电商报、晚点LatePost
- 监管：市场监管总局、商务部

## 输出模板

```
[电商] 标题
节点提醒：当前大促阶段、下一个关键时间点
规则变化：平台新规一句话
与我何关：消费者省钱建议 / 从业者应对提醒
```
