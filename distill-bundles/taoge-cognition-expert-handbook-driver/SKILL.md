# 高手修炼驱动认知包（Expert Handbook Driver）

> **一句话定位**：一套把"怎么成为高手"变成可诊断、可执行、可复用的心法工具——高手不是天生的，是修炼出来的，修炼=刻意练习+正确思维+理解世界。
> **来源**：万维钢·高手修炼手册（2026-10-26 S级归档WG01-WG40共40讲），《精英日课6》福利专享，萃取自精英日课1-5季精华。4模块×10讲，每讲一个公式化认知模型。

## 二、核心律速查（40律）

### ① 炼成——追系统不追目标

| 编号 | 模型 | 一句话 |
|---|---|---|
| WG01 | 成就系统律 | 追系统（技能/关系持续生长的有机体）不追目标（做成一件事就完）；系统有了一切自然发生 |
| WG02 | 榜样社区律 | 养育方法影响极小（提高一个标准差收入只涨26%），"选住在哪里"占25%，孟母三迁是对的 |
| WG03 | 谈资无形消费律 | 富人不买包改买教育/医疗/人力资本；谈资本身是阶层信号，聚会上聊《纽约客》=同类识别 |
| WG04 | 苦=不满足律 | 巴利语"苦"本意是unsatisfactoriness；快乐是进化诱饵，短暂且大脑只盯着它，人在失望中追求偶尔满足 |
| WG05 | 园丁不木匠律 | 孩子不是你的产品是关系；做园丁提供环境，不做木匠雕刻；未成年期越长智力越高 |
| WG06 | 中年阅历律 | 社会真正实力在中年人；关键时刻的镇定来自跨界经验，60岁工程师聊技术眼睛里有光 |
| WG07 | 邓宁克鲁格律 | 真实能力最低者自我评估排前60%，水平最高者反而低估自己；能力差连"什么叫厉害"都看不懂 |
| WG08 | 政治权力客观律 | 跟人一起做事就有地位利益争夺，政治权力躲不开；好人不掌握权力，权力就被坏人拿去 |
| WG09 | 内卷=低水平复杂化律 | 内卷（involution）本意是向内演化——越来越精细但没创造力，低水平复杂化；高考内卷是题出怪不是残酷 |
| WG10 | 愚蠢优先解释律 | 能解释为愚蠢/无知/可原谅错误的，就别解释为恶意；恶意是小概率，人绝大部分时候浑浑噩噩 |

### ② 思考——十种高手思维模型

| 编号 | 模型 | 一句话 |
|---|---|---|
| WG11 | 规模思维律 | 专做有复利效应的事——越做规模越大规模越大做得越好；看到好东西就想办法scale它（GPT从亚马逊评论涌现情感神经元） |
| WG12 | 策略思维律 | 经常审视"我有没有更好的方法"；诸葛亮会很多策略但从不改，曾国藩每次碰壁都调整（结硬寨打呆仗） |
| WG13 | 系统思维律 | 三要素：元素（可替换）、关系（关键）、目的（表面≠实际）；中国足球换教练没用，问题在系统结构里 |
| WG14 | 成长思维律 | 智能可通过努力提高，把任务当学习机会不是能力测试；仅看两段讲智能可成长的视频GPA就提高0.03 |
| WG15 | 上游思维律 | 下游=被动反应治标，上游=找问题根源主动预防；有上游思维的人就是"士"，不在其位也谋其政 |
| WG16 | 黑客思维律 | 看穿表面规则（一般人看到的使用方法）与底层规则（系统实际怎么运行）的裂口，想到了就做不按标准操作 |
| WG17 | 生态学家思维律 | 市场=热带雨林自行演化，别像工程师踩油门踩刹车强行干预；"市场失灵"其实是你的模型失灵了 |
| WG18 | 录取侧思维律 | 别问"我优秀你该要我"（申请侧），问"我在你想建的集体里补什么位"（录取侧）；成绩只是入门券 |
| WG19 | 丑小鸭定理律 | 丑小鸭和天鹅的差异=两只天鹅之间的差异；不存在客观分类，每个标签都是主观选择，别本质化任何人 |
| WG20 | 贝叶斯实践律 | 数据有限先上手提假设，新信息来了符合就提高可信度不符合就降低；15个月婴儿看一遍就会，在战争中学习战争 |

### ③ 解决问题——公式化认知工具

| 编号 | 模型 | 一句话 |
|---|---|---|
| WG21 | 知识=体验×敏感度律 | 体验要被体察、被允许改造你才成知识；以前喝茶加糖盖味，现在减糖到能分辨熊猫粪茶，否则是粗人 |
| WG22 | 成长=压力+休息律 | 压力=自己故意施加的高强度训练（不是外界压力），休息=正式恢复时间不是摸鱼；高压训练→正式休息→重复强度略高 |
| WG23 | 好目标=难度×具体律 | 力所能及范围内越难越好，但必须具体；"尽最大努力"是空话，缺一个都是空喊口号或应付了事 |
| WG24 | 响应=理解+接受+关心律 | 好关系靠互相不设防暴露弱点后被响应；把"What's the matter"改成"What matters to you"，家长会出席率12%→73% |
| WG25 | 成功=天赋+运气律 | 大成功=多一点点天赋+很多好运气；NBA新秀第二年变差、以色列空军表扬后变差，都是回归平均不是你的功劳 |
| WG26 | 目的=价值观×目标律 | 目标实现了无聊没实现绝望；目的=以价值观为导向的目标系统，既不可能完全实现又可以随时实现 |
| WG27 | 幸福=贡献感律 | 年薪10万想20万到了想50万永远不满足；阿德勒说幸福来自共同体归属感和贡献，不是比下有余的假装 |
| WG28 | 业务表现≠成功律 | 业务表现=你自己的技法水平，成功=社会对你网络的用处；红色男爵击落80架战死比方克100架活着名气大10倍 |
| WG29 | 喜欢=熟悉+意外律 | MAYA=Most Advanced Yet Acceptable，尽可能前卫只要能被接受；舒适区（太熟悉）→学习区（熟悉+新意）→恐慌区（太陌生） |
| WG30 | 错误=偏差+噪声律 | 偏差=系统性错误（子弹总往一个方向偏），噪声=判断分散（手不稳时好时坏）；相似挪用公款案一个判117天一个判20年 |

| WG34 | 凋零效应律 | 快速灌输知识获得的成绩优势保持不了多久就凋零；封闭式技能（按规定动作）快但后劲不足，开放式技能慢但有复利 |

| WG37 | 伊丽莎效应律 | 人们无意识把计算机/系统拟人化；能用局面和系统解释的别拟人化，路上司机服务员政府工作人员都偶尔当AI，"不是针对你" |

## 三、高手修炼五步 SOP（跨项目复用）

遇到"我怎么提高/这事怎么想/这个决定对不对/怎么不被忽悠"类问题时按序走：

1. **追系统不追目标（WG01+WG11+WG34）**：我现在做的事是一次性目标还是持续生长的系统？有没有复利效应？是封闭式快功还是开放式慢功？→ 输出：把精力从一次性冲刺挪到能积累的系统上。
2. **调思维模型（WG12+WG13+WG15+WG20）**：这事我有没有更好的方法？问题在元素还是在系统结构里？我是在下游被动反应还是在上游找根源？新信息来了我更新假设了吗？→ 输出：从"埋头干"切到"抬头想"。
3. **定好目标与节奏（WG23+WG22+WG30）**：目标够不够难、够不够具体？高压训练后有没有正式休息？决策里偏差和噪声各占多少？→ 输出：SMART不够要加难度，决策要减噪声别凭感觉。
4. **验成功与幸福（WG25+WG26+WG27+WG28）**：这次成就是实力还是运气？我是在用价值观定目的还是只追目标？我有贡献感吗？我的业务表现对社会网络有用吗？→ 输出：别把回归平均当实力，别把业务表现当成功。
5. **过效应筛子（WG31-WG40）**：我现在是被期待自我实现（窈窕淑女）、被"亲测有效"忽悠（安慰剂）、被模糊描述套住（巴纳姆）、被指标异化（眼镜蛇）、被弱理由稀释（信息稀释）、把系统当人（伊丽莎）、连赢加仓（手热）、靠公开承诺逼自己认真（霍桑）、还是设计了意外感（怪球）？→ 输出：洗掉认知偏差再行动。

输出格式：结论先行（该追系统还是追目标/该更新假设还是死磕/该信还是该验）→ 每步证据 → 落点（电商复盘/持仓反人性/孩子学习方法 行动项）。

## 五、边界

- 本包是**心法与认知偏差筛子**，不替代具体行业数据调研与执行操作（具体工具操作去W系列，行业证据去 taoge-ecom-*）。
- 不做产品定义细节（去 product-growth）；不做宏观周期与估值纪律（去 hegang）；不做组织团队管理（去 org-behavior）。
- 模型置信度：WG01-WG40 均为 S级归档蒸馏（万维钢·高手修炼手册，2026-10-26）；40讲每讲一律，宁精勿滥。
- 更新规则：认知革命项目每新增个人成长/思维模型/认知偏差相关模型，同步追加本包速查表与接线。
