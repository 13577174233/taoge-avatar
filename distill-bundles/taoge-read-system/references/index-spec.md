# 检索总表字段规范（HTML 版）

文件：`个人读书系统/01-读书检索总表.html`（每本书一行，按「读毕日期」追加，已存在行不覆盖）。总表与 `读书笔记/` 目录整体保留，笔记链接用相对路径，点击直达对应四合一 HTML。

## 列定义

| 列 | 内容 | 示例 |
|---|---|---|
| 序号 | 按读毕顺序递增 | 1、2、3… |
| 书名 | 书名 + 封面缩略图 `<img class="cover-thumb" src="<序号>-<书名>/<书名>.jpg">` | 简单致富 I&II（两卷） |
| 作者 | 姓氏即可，多卷可并列 | J.L.柯林斯 |
| 豆瓣 | 平台评分，多卷并列用 `/` | 8.0 / 6.1 |
| 饕哥 | 个人评分，多卷并列用 `/` | 8.2 / 7.0 |
| 终判 | `<span class="tag">精读</span>` 等，可多个 | 卷一精读 / 卷二泛读 |
| 读毕 | 读毕日期 YYYY-MM-DD | 2026-10-10 |
| 笔记文件 | `<a class="note-link" href="<序号>-<书名>/<书名>-读书笔记.html">` 相对路径 + 一句话说明 | 四合一：笔记+平台书评+朋友圈+小红书 |

## 封面缩略图

- 封面图统一存 `<序号>-<书名>/<书名>.jpg`（每本书独立目录，含四合一 HTML、封面与小红书配图）（真实封面优先：`image_search` 检索 → 下载；检索不到或无版权图时用创意设计生成）。
- 缩略图样式 `.cover-thumb{width:44px;height:60px;object-fit:cover}`，与 HTML 总表同目录用相对路径引用。

## 页面统计

`header .stats` 随书目数量更新：`<b>N</b>本已读`、`<b>N</b>本精读`。

## 证据纪律

每行评分/终判均来自对应四合一笔记的「平台书评」与「专业书评（饕哥）」板块，不另编字段；查不到的平台评分留空并说明，不编造。
