# 高血压行动红线清单

> 打印出来贴冰箱。每条都是「什么情况下不能做 / 必须就医」。

- [ ] **高血压是全球死亡的头号单一因素** —— 本条是风险认知，不替代就诊。出现胸痛、单侧肢体无力、言语不清、剧烈头痛，立即就医，不要等下一次体检。
- [ ] **没症状不等于没病** —— 不能用“有没有不舒服”判断血压。出现剧烈头痛、视物模糊、胸痛、呼吸困难、单侧肢体无力，立即就医。
- [ ] **知道不等于达标** —— 本条指出的最大漏点是“知道了不动”。用药调整必须由医生决定，不可自行停药或自行换药。
- [ ] **高血压前期是逆转窗口** —— 窗口期不等于可以自己硬扛。血压持续偏高，或伴头痛、头晕、胸闷，要到医院评估；不可自行买药，也不可放任。
- [ ] **瓶颈是认知，不是医学** —— 这条不能用来替代就医。作者说“医学能控制”指规范诊疗路径，不等于自己买药、自己调量能控制；必须遵医嘱，不可自行停药或换药。出现胸痛、意识改变、剧烈头痛立即就医。
- [ ] **血压是连续波形，两个数字只是切片** —— 理解波形不改变就诊判断。出现胸痛、意识改变、剧烈头痛、呼吸困难，立即就医，不要先反复量血压。
- [ ] **血压随时辰与情形大幅波动** —— 单次偏高不必惊慌，也不能忽略。静息状态下反复偏高，或伴胸痛、剧烈头痛、视物模糊、呼吸困难，立即就医。不可因一次读数自行加药，也不可因一次正常自行停药或换药。
- [ ] **全身各处血压不同** —— 本条不用于自我诊断。一侧手臂测不出或数值异常低，应就医查因，不要按“正常波动”处理，也不要自行调药。
- [ ] **高血压是血管病，不是心脏病** —— 这条不是让患者自行停用控制心率或降压的药。用药必须由医生决定，不可自行停药或换药。
- [ ] **管径的四次方是最大变量** —— 不要把这条理解成“血管越粗越好”去买扩血管产品。血压突然升高伴胸痛、剧烈头痛、视物模糊、单侧肢体无力，立即就医。
- [ ] **血压是能量，一过性偏高不等于不好** —— 这条最容易被读成“高低都无所谓”。已确诊高血压、正在服药的人不能据此停药或减量，必须遵医嘱；出现胸痛、剧烈头痛、意识改变立即就医。
- [ ] **直立行走靠长期升高的血压** —— 体位性头晕若伴晕厥、跌倒、持续数分钟的黑蒙，要就医查因，不要当成“正常现象”。
- [ ] **肾-体液机制：钠留水留，血压升高** —— 这条不能用来自行补盐，也不能用来自行极端限盐。已确诊高血压、心衰、肾功能不全的人，限盐幅度由医生定。
- [ ] **短期调配靠交感神经，1 秒到全身** —— 这条是生理机制，不是用药依据。降压药作用在不同环节，必须由医生开具与调整，不可自行停药或换药。
- [ ] **精准靠受体，不靠信号本身** —— 受体知识属机制理解，不构成自行选药依据。作用于 α、β 受体的处方药必须由医生开具与调整，不可自行停药或换药。
- [ ] **血流分配不搞平均主义** —— 这条不能推出“为了保脑就要让血压高一点”。高血压患者仍以血压达标为目标，用药遵医嘱。
- [ ] **升压机制是适应，也是今天的祸根** —— 不要把这条读成“反正躲不过”而放弃监测。已确诊高血压者必须规范治疗，遵医嘱用药，不可自行停药或换药；出现胸痛、剧烈头痛、视物模糊、单侧肢体无力立即就医。
- [ ] **高血压不是一种病，是一个非稳态环境** —— 本条是认知框架，不能拿它替代诊断。出现剧烈头痛、视物模糊、胸痛、意识改变，按急症就医，不要用「非稳态」解释过去。
- [ ] **诊断界值是人为规定，一直在变，各国不同** —— 不要因为「标准是人定的」就自行否定诊断或停药。已确诊者调整治疗必须由医生做；出现血压骤升伴头痛、胸闷、视物模糊要急诊。
- [ ] **血管重建：血管越练越硬，血压越推越高** —— 本条解释的是长期损害，不是当下症状。出现胸痛、单侧肢体无力或言语不清、视力突然下降、尿量明显减少，按急症就医，不要等血压「慢慢调」。
- [ ] **界值随年龄放宽：年轻要低，老年可松** —— 此为作者临床立场，非指南推荐，不能替代医生定的目标值。按更低目标加药后出现头晕、乏力、站起时眼前发黑、走路不稳，提示可能降压过度，须就医调整；不可自行停药或换药。
- [ ] **界值要相对自己的基础血压看** —— 升幅判读不能替代测量与诊断。若短期内收缩压较基础值升高超过 20mmHg 并伴头痛、胸闷、视物模糊、恶心，须立即就医，不要在家反复测着观察。
- [ ] **降压有下限：够供血就行，不是越低越好** —— 出现站起时头晕眼黑、走路发飘、明显乏力、反应变慢、跌倒，提示可能降压过度，须就医评估；不可自行停药或换药，也不可自行加量追求更低数字。
- [ ] **诊室血压要「每次都达到」，且仍会错** —— 单次诊室读数偏高不等于确诊，不要据此自行买药吃；也不算「没事」，须按规程复测。若读数 ≥180/110mmHg 或伴剧烈头痛、胸痛、视物模糊、言语不清，须立即急诊，不适用「再观察几次」。
- [ ] **家用血压计只买上臂式、有认证的** —— 设备选错会给出错误读数，进而误导用药。袖带过小、绑得过紧或隔着厚衣测量都会偏高；发现家庭读数与诊室读数长期相差 20mmHg 以上，带设备去医院校对，不要自行调药。
- [ ] **居家七天规程：连测 7 天再去掉第一天** —— 测出 ≥135/85mmHg 不要自行用药，带着完整记录就医确诊。测量中若出现胸痛、明显气短、头晕，停止测量并就医；两侧上臂压差明显（超过 20mmHg）应告知医生排查血管问题。
- [ ] **动态血压三个平均值，任一超标即算** —— 佩戴期间袖带充气频繁，若出现手臂麻木、明显疼痛、夜间无法入睡致血压普遍偏高，应告知医生判读时考虑；出现胸痛、意识改变立即就医而不是等报告。
- [ ] **五档分级：1 级是逆转黄金期** —— 分级只是第一步，最终风险还要叠加危险因素、器官损害与合并疾病。达到 3 级（≥180/110mmHg）或伴胸痛、剧烈头痛、呕吐、视物模糊、肢体无力，须立即急诊；已在服药者不可自行停药或换药。
- [ ] **收缩压舒张压不同级，按高的算** —— 判为更高级别意味着更高的风险分层与更积极的治疗，不要因为「高压才 150」就自我降级。出现 ≥180/110mmHg 或靶器官症状须急诊；不可自行停药或换药。
- [ ] **预防的成功标准是「拖晚」，不是「不得」** —— 本条是目标设定，不能替代筛查与就医。出现持续头痛、头晕、心慌、视物模糊，或家庭自测多次 ≥135/85mmHg，须就医确诊，不要用「反正是衰老」拖着。
- [ ] **升压只有三条通路，风险点都挂在这三条上** —— 怀疑睡眠呼吸暂停不要只靠手环数据下结论，须到医院做睡眠监测；出现夜间憋醒、晨起头痛、白天无法控制地嗜睡，应尽早就医。已确诊高血压者不可自行停药去「先治打鼾」。
- [ ] **烟：一口都别碰，二手也一样** —— 戒烟期间若出现血压波动、心悸、焦虑，属常见戒断反应，可就医寻求戒烟门诊支持；出现胸痛、持续心悸、呼吸困难须立即就医。不可用「少抽几根」替代戒烟，也不可因担心戒烟发胖而继续吸。
- [ ] **酒：只看酒精量，每周 7 杯是条线** —— 饮酒后血压短期波动、心悸、面部潮红明显者应停饮并就医评估；服降压药期间饮酒可能引起低血压与跌倒，须咨询医生。不可用「红酒护血管」作为每日饮酒的理由。
- [ ] **咖啡：喝纯的，别喝咖啡类饮料** —— 喝咖啡后出现明显心悸、手抖、失眠、血压骤升，应停用并就医；已确诊高血压且未控制者，不要用「纯咖啡没问题」作为加量的理由。
- [ ] **PM2.5：每升 10ug/m3，收缩压升 1.3mmHg** —— PM2.5 爆表日出现胸闷、气短、心悸、咳嗽加重，应减少外出并就医；已有冠心病、哮喘者不要在此类天气户外锻炼。空气净化器需定期换滤芯，否则失效。
- [ ] **治愈做不到，逆转做得到** —— 逆转的前提是「不吃药但有期限、有监测」；期限内不达标必须开始药物治疗，不可为了追求逆转拒绝用药。
- [ ] **能不能逆转看危险分层，不看血压高低** —— 自己算分层最危险；危险因素要医生按完整项目评估，缺了血糖、血脂、吸烟任一项都可能低估。
- [ ] **超过 160/100mmHg 就不可逆，必须马上用药** —— 已经开始用药的，不可自行停药、换药或减量——停药后血压会反弹。出现胸痛、呼吸困难、说话不清、单侧肢体无力、视物模糊，立即急诊。
- [ ] **低危观察 3-6 个月，中危只观察 1 个月** —— 观察期不是「这段时间不用管」；期间要按期复测，出现头痛、胸闷、视物模糊随时就医，不要等期满。
- [ ] **高血压前期是黄金期，25 岁后每年量一次** —— 「绝大多数都能逆转」是群体概率，不是个人保证；前期也可能因合并其他危险因素升级，量出来偏高要去医院分层，不能只靠生活方式自我安慰。
- [ ] **目标值按年龄分层，且要持久同时达标** —— 目标值由医生按年龄和合并疾病定，不可自己按「越低越好」加药；出现头晕、乏力、站起眼前发黑，可能是降得过低，要就医调整，不可自行停药。
- [ ] **没有一种单一食物能降压** —— 买保健品先查批准文号与成分表；遇到「降压效果特别灵」的产品要怀疑偷加药物，立即停用并就医。不可因为吃了保健品就自行停降压药。
- [ ] **肥胖者减重 1kg，血压降 1mmHg** —— 减重出现乏力、脱发、月经紊乱说明吃得太少，应就医；不可用代餐完全替代正餐，也不可为了血压数字脱水减重。
- [ ] **每天吃盐 3.5g 到 6g，别低于 3.5g** —— 出现明显乏力、头晕、肌肉痉挛，可能是盐吃得太少或与利尿剂叠加，要就医查电解质；正在服利尿剂的人减盐前先问医生。
- [ ] **多吃钾，能再降 4mmHg** —— 肾功能不好的人盲目补钾可能致命；出现心悸、手脚麻木、肌肉无力要立即就医查血钾。已在服降压药的人加钾（含钾盐、钾片）前先问医生。
- [ ] **隐形盐三类，买之前看钠含量** —— 不要用「没咸味」判断低盐；严格限盐又服降压药的人出现乏力、嗜睡要就医，警惕低钠。
- [ ] **DASH 饮食：按份搭配，单用降 11mmHg** —— 同时在用降压药的人，饮食改善叠加可能让血压偏低，出现头晕、乏力要复测并就医调整药量，不可自行停药。
- [ ] **运动当场升血压，长期才降血压** —— 运动中出现胸痛、胸闷、明显气短、头晕、说话不清或单侧无力，立即停止并就医；不要在不适时用「运动会降压」说服自己硬撑。
- [ ] **4 周以上，高血压者收缩压降 8.3mmHg** —— 这是人群平均值，不是个人承诺；4 周没降到位不等于无效，也不能因此自行加药或停药。难治性高血压者必须在医生监护下运动。
- [ ] **每周至少 5 次，最好天天动** —— 不要为了凑次数在血压明显偏高（头痛、面红、测出来高）时硬练；出现胸闷、心悸立即停止并就医。
- [ ] **强度取中等，用公式算心率区间** —— 出现胸痛或压榨感、明显气促、头晕、冷汗，立即停止并就医；不要凭「感觉还行」越过医生给的强度上限。
- [ ] **每次有效 30 分钟，一周 150 到 210 分钟** —— 单次超过 210 分钟不带来额外收益，反而增加心血管与关节负担；运动后胸闷、心悸持续不缓解要就医。
- [ ] **等长力量训练是黑马，但会憋气** —— 训练全程不要憋气，保持呼吸；出现头痛、眼前发黑、胸闷立即停止；建议先在医院康复中心或有医学监护下做几次再回家练。
- [ ] **入静能降压，但指南只当替代处方** —— 入静不能替代降压药。已在服药者不可因为开始练入静就自行减药或停药，减停必须由医生决定。练习中出现头晕、眼前发黑、胸闷、胸痛、呼吸困难，立即停止并就医。
- [ ] **冥想只认超验，正念没有统一证据** —— 冥想是辅助手段，不可替代药物，处在用药期的人不可自行减药或停药。练习中出现心悸、胸闷、气短、明显头晕，停止练习并就医。
- [ ] **生物反馈加肌肉放松，只对小部分人有效** —— 训练中出现头晕、心慌、胸闷或血压异常升高，停止并就医。不可用它替代降压药，也不可因血压下降自行减药、停药或换药。
- [ ] **慢呼吸：最简单，证据最充分** —— 练习中出现头晕、眼前发黑、手脚发麻、胸闷、胸痛、呼吸困难，立即停止并就医——过度深呼吸可能引起头晕。慢呼吸不能替代药物，服药者不可自行减药或停药。
- [ ] **太极勉强、瑜伽不定、打坐气功不主张** —— 这些方法不能替代降压药，服药者不可因练功自行减药或停药。练功中出现胸痛、心悸、晕厥、呼吸困难，立即停止并就医；老年人练太极注意跌倒风险。
- [ ] **所有降压药只有两条来路** —— 这是理解框架，不是用药方案。不可按机制自行买药、换药或停药；出现血压骤升伴剧烈头痛、胸痛、肢体无力、言语不清，立即就医。
- [ ] **利尿剂：最便宜，降压不输贵药** —— 出现明显乏力、心慌、肌肉无力或抽筋（可能低钾）、起身头晕甚至跌倒，要就医查血钾；出现关节红肿疼痛（可能高尿酸）要复查。是否换药由医生判断，不可自行停药或换药——骤停后血容量回升，血压会反弹。
- [ ] **地平类：适用最广，缓释剂型容错高** —— 出现踝部或下肢水肿、持续脸红头痛眩晕、心慌，且两周以上不缓解，要就医评估；不可自行停药或换药——换剂型、换大类都要医生决定。出现血压过低表现（头晕、乏力、眼前发黑）立即就医。
- [ ] **普利类与沙坦类：多一层器官保护，孕妇禁用** —— 出现口唇、舌头、面部肿胀或呼吸困难（血管性水肿），立即急诊；备孕、已怀孕或哺乳期要立刻告知医生，此类药孕期不适合；出现明显乏力、心悸（可能高钾）或尿量明显减少，要就医查血钾与肾功能。是否停药换药由医生决定，不可自行停药或换药。
- [ ] **洛尔类：已从一线退出** —— 出现心率明显变慢、头晕黑矇、活动后气短或哮喘发作，要就医；有哮喘史者就诊时必须主动说明。已在使用的人不可自行停药或换药——骤停可能引起心率、血压反跳，加药减药都要医生决定。
- [ ] **选药五原则：有效、对病、不拘小节、方便、用老药** —— 五原则用于和医生讨论，不是自行购药清单。不可自行停药或换药；出现血压不达标、明显副作用或新发疾病（如查出糖尿病、痛风、怀孕），要复诊让医生重新选大类。
- [ ] **没有症状也要吃药** —— 是否用药、用多久由医生决定，不可因为「没症状」自行停药，也不可因为「怕后患」自行加药。出现剧烈头痛、胸痛、视物模糊、肢体无力、言语不清，立即就医。
- [ ] **副作用不随时间累积** —— 出现尿色变深、皮肤或眼白发黄、明显乏力食欲差、下肢浮肿、皮疹，要就医查肝肾功能；服药后 2 到 4 周需复诊复查血压、心率、血生化。不可自行停药或换药——觉得「伤肝肾」就停药，风险大于继续按医嘱服用。
- [ ] **该联合就联合，别先加量** —— 联合方案由医生开，不可自行把两种药叠着吃，也不可自行减掉其中一种。出现头晕、乏力、下肢水肿加重、心率明显变慢、尿量减少，要复诊；出现意识模糊、晕厥、胸痛立即就医。不可自行停药或换药。
- [ ] **血压平稳不是治好了，别私自停药** —— 出现血压回升伴头痛、头晕、视物模糊、胸闷，要立即复测并就医；出现胸痛、肢体无力、言语不清立即急诊。任何停药、减药、换季调整都必须由医生决定，不可自行停药或换药——延迟作用会掩盖反弹，等发现时往往已经回到治疗前水平。
- [ ] **睡前吃药，护住夜间和清晨** —— 改成睡前服药后若出现夜间起床头晕、跌倒、清晨明显乏力，要复诊评估，不可自行把药停掉或改成隔天吃；调整服药时间也建议先问医生。出现夜间胸痛、呼吸困难立即就医。不可自行停药或换药。
- [ ] **吃上药只是开始：三项观察与测压频次** —— 测出血压持续高于目标值，或出现头晕、乏力、水肿、心悸，要提前复诊而不是等下次；出现胸痛、剧烈头痛、视物模糊、肢体无力立即急诊。频次是底线不是上限，不可因为「还没到复查时间」硬扛，也不可自行加药。
- [ ] **血压界值现在按电子血压计算** —— 家庭自测血压持续偏高，去医院确诊，不要按网上说法自行买药吃；已在服药者不可自行停药或换药。
- [ ] **血压认知：从诊室一个点到一生一条线** —— 动态血压报告要交给医生解读；读数偏高不等于要立刻加药，读数偏低也不等于可以自行减药，不可自行停药或换药。
- [ ] **二十几岁预测你哪年得高血压（作者预测）** —— 预测结果不是诊断。被标成高风险，不等于已患病，更不能据此自行服药；被标成低风险，也不能省掉每年的实测。
- [ ] **个性化治疗靠大数据，不靠基因编辑** —— 未来能精准选药，不等于现在可以自行换药。正在服用的处方必须由医生调整，不可自行停药或换药；出现不良反应要记录并复诊，而不是自己减半片。
- [ ] **把四高当成一类共病，在源头拦截** —— 共病同治是方向，不是现在可以只吃一种药的许可。任何一味药要停要减，必须由医生判断，不可自行停药或换药；四高并存时治疗目标更严，不是更松。
- [ ] **四高不是罕见组合，是常见状态** —— 这些是群体统计，不是个人风险值。查出任意一高，要同时查其余三项，不要只处理查出来的那一项；已在用药者不可自行停药或换药。
- [ ] **三条能量通路互通，坏一条拖累两条** —— 确诊一高之后要主动筛查其余三项，不要等出现症状；指标异常要靠复查确认，不要凭一次结果自行买药。
- [ ] **尿酸升压走两条路：搅乱 RASS + 伤肾** —— 尿酸高合并血压高，要同时就诊，不要只降压不查尿酸；已在服降压或降尿酸药者不可自行停药或换药；出现少尿、下肢浮肿要尽快就医。
- [ ] **高尿酸把斑块时间从五到十年压到三五年** —— 斑块不靠感觉发现。已确诊斑块或心脑血管病的人，降脂、抗血小板等处方必须按医嘱执行，不可自行停药或换药；出现胸痛、肢体无力、言语不清立即急诊。
- [ ] **尿酸先造胰岛素抵抗，再造糖尿病** —— 尿酸高的人要定期查空腹血糖与糖化血红蛋白，不要等出现典型症状；已确诊糖尿病者不可自行停药或换药，也不要因为「怕依赖胰岛素」自行减量。
- [ ] **四高的伤害都落在血管，走的是慢性炎症** —— 结局是心梗、脑梗、肾衰——胸痛胸闷、口角歪斜、言语不清、单侧肢体无力、尿量骤减或下肢浮肿，出现任一条立即急诊，不要在家观察。
- [ ] **四高的方案不能相加，只能取交集** —— 合并多高时不要自行把几套方案叠加执行（例如同时高蛋白又限蛋白、既上力量训练又严格限力量），出现关节痛、痛风发作、乏力要就医；用药者不可自行停药或换药。
- [ ] **动：练到心肺极限，剂量按心率算** —— 运动中出现胸痛、胸闷、晕厥、异常心悸、濒死感，立即停止并就医；有基础心脏病者不得自行上高强度；感冒发热期间不做高强度。
- [ ] **静：每天 10 分钟深长腹式呼吸** —— 出现持续早醒、情绪低落、兴趣丧失、自伤念头，立即看精神心理科，不能靠呼吸训练硬扛；呼吸练习中出现头晕、手足发麻、胸闷，停下恢复自然呼吸。
- [ ] **能量先看结构：55%-75% / 20%-30% / 1g-1.5g/kg** —— 肾功能不全、糖尿病用胰岛素或磺脲类药物者，调整碳水比例要防低血糖，须由医生或营养师定量；出现明显乏力、脱发、月经紊乱提示比例或总量过度，要复诊。
- [ ] **压力先看两个映射：早醒，和中午前就累** —— 早醒伴情绪低落、兴趣丧失、食欲体重下降，或出现自伤念头，立即看精神心理科；不要用酒精助眠；安眠药不可自行购买服用。
- [ ] **明确失衡必须用药，合并糖尿病尿酸要更低** —— 处方药必须由医生开方与调整，不可自行停药、减量或换药；出现肌肉酸痛、明显乏力、尿量减少、下肢浮肿、皮疹，尽快就医查肝肾功能；不可因为「是药三分毒」自行停掉。
