# 团队管理教练驱动认知包（CEO-Coach Management Driver）

> **一句话定位**：管理的第二方案不是「怎么管好别人」，而是先把自己当资源管好（时间、缺点、说明书），再用角色、选人、信息与责任、任命与控制，把团队带成不需要你也能跑的组织。
> **来源**：衡量·团队管理20讲（TM001–TM023 共 23 篇 S 级归档，2026-11-07 全量收官；期末考试 1 项登记不归档）。

---

## 一、总图（一句话记住）

**管理 = 管好自己（TM002–TM007）× 定清角色（TM008）× 选对人（TM009–TM011）× 定清信息与责任（TM012–TM013）× 用培养心态任命（TM014–TM015）× 管住自己的暗面（TM016–TM018）× 成就自己（TM019–TM023）**

四模块递进：**管好自己 → 提升绩效 → 成就他人 → 成就自己**。前三模块解决「团队怎么跑」，第四模块解决「你为什么值得继续带」。

## 二、核心律速查表（TM系列23条）

### 课前必读与导论（TM001–TM003）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| TM001 | 第二方案律 | 别只学「怎么管好别人」的第一方案；第二方案是先掌控自己（时间、缺点、说明书），再通过角色、选人、信息与责任、任命与控制带出团队 |
| TM002 | 掌控自己律 | 管理者的成长分两段：先掌控自己的时间与情绪，才可能掌控团队；自我管理不是修养，是管理的前置条件 |
| TM003 | 教练三事律 | CEO 教练只做三件事：让你看见盲区（你可能就是问题本身）、让你问对问题、让你对自己的选择负责 |

### 模块一 管好自己，成就团队（TM004–TM007）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| TM004 | 缺点筛选律 | 不是每个缺点都值得改：先分清「妨碍目标达成的缺点」与「只是让人不舒服的特点」，只改前者 |
| TM005 | 时间主定律 | 不能让下属随便占用你的时间：你的时间是最稀缺的组织资源，谁都能截取，就等于组织没有优先级 |
| TM006 | 说明书律 | 给自己写一份使用说明书：把偏好、禁区、擅长与不擅长讲清楚，让团队知道怎么与你协作，减少反复试探与内耗 |
| TM007 | 被使用律 | 让团队学会「使用你」：明确什么情况该找你、找你时该带什么、多久给一次反馈，把管理者变成可调用的接口而不是黑洞 |

### 模块二 管好团队，提升绩效（TM008–TM013）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| TM008 | 角色先于目标律 | 忽略角色，团队目标很难统一：先把「谁负责什么结果」定清，再谈目标拆解，否则目标只是一句口号 |
| TM009 | 面试三看律 | CEO 亲自面试要看三件事：能不能干（能力证据）、愿不愿干（动机与稳定性）、合不合（价值观与协作方式） |
| TM010 | 选人可解律 | 「选人困难症」一定能解：把选人拆成「画像—渠道—评估—试用」四步，靠流程而不是靠感觉 |
| TM011 | 牛人不解律 | 招牛人解决不了团队问题：一个牛人救不了系统缺陷，反而会掩盖角色不清、责任不明的病 |
| TM012 | KPI双柱律 | KPI 立得住靠两根柱子：信息共享（大家知道为什么是这个数）与责任划分（谁对哪个数负责） |
| TM013 | 培训失效律 | 想用培训提升能力时先问：是要提升能力，还是要解决实际问题？绝大多数时候只需解决问题，不必上课 |

### 模块三 管好团队，成就他人（TM014–TM018）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| TM014 | 培养式任命律 | 好的任命给方向：不是全面提高，而是提高优势的利用效率，最大化其对组织的价值 |
| TM015 | 标签使用律 | 标签两面看：伤你的那个特质背后力量也大，正确引导可「变废为宝」，把缺点转成岗位优势 |
| TM016 | 领导力暗面律 | 团队积极性不足，有时不是你做得少，而是你的聪明能干在压制他们：找出这些行为并停手 |
| TM017 | 温柔控制律 | 掌控是管理者的天然防御机制，也是企业财富；但组织长大后，掌控会变成团队表现的障碍，须升级为「机制控制」 |
| TM018 | 对人不对事律 | 高管冲突不要只就事论事：本质是找到新的合作机制，让「不同」从障碍变成财富 |

### 模块四 管好团队，成就自己（TM019–TM023）

| 编号 | 模型名 | 一句话 |
|---|---|---|
| TM019 | 性格非命律 | 不存在完美的个人领导者：团队扬长避短、彼此支持，才能产生团队领导力 |
| TM020 | 改变非意志律 | 改变失败不是意志力不够，而是环境与机制没改：先改触发条件、流程与反馈，再谈「我要改」 |
| TM021 | 提问清单律 | 管理从提问开始：先问「最重要的1～2件事」，再问「是不是真问题、值不值得我解决、最高效解法是什么」，最后把排序交回团队 |
| TM022 | 锦囊清单律 | 全课压成一张清单：管好自己、定清角色、选人看三件事、信息与责任定KPI、以培养心态任命、用提问代替指挥 |
| TM023 | 测评用法律 | 测评报告不是标签而是使用说明：只取「我与他人不同」的少数几条，转成协作动作（怎么沟通、怎么派活、怎么反馈），其余忽略 |

## 三、带团队 SOP（6 步）

1. **先管自己**（TM002–TM007）：写下自己的时间黑洞清单、只保留 3 件必须自己做的事；给自己写一页「使用说明书」发到团队；列出「值得改的缺点」与「不必改的特点」两栏。
2. **定清角色**（TM008）：用「角色—结果—权限—协作者」四列表把团队画一遍，任何两个角色结果重叠就当场拆开。
3. **选人**（TM009–TM011）：先写岗位画像（要什么结果、什么能力证据），再定渠道与评估题；**不要用一个牛人去补系统漏洞**。
4. **定信息与责任**（TM012–TM013）：每个 KPI 都写清「为什么是这个数」与「谁负责」；能力问题先按「解决实际问题」处理，确证是能力缺口再培训。
5. **任命与控制**（TM014–TM018）：任命时说明「培养意图」；对特点用标签引导而非压制；把「靠你盯」升级成「靠机制」（例会、看板、决策权限表）；高管冲突先改合作机制。
6. **成就自己**（TM019–TM023）：用提问代替指挥（五个问题清单）；测评只取差异项转动作；每季度复盘「我哪些行为在压制团队」。

## 四、应用场景映射

| 场景 | 适用律 | 落地 |
|---|---|---|
| 电商事业中心 7 角色内容团队 | TM008 TM012 TM014 | 每个角色写清「对什么结果负责」，内容排期与销量目标分别挂人；任命时说明培养意图而非「你先顶着」 |
| 产品管理团队搭建 | TM009 TM010 TM011 | 先写岗位画像与能力证据，别用「招个牛人」解决流程缺失；试用期设明确的三个验收点 |
| 市场部与运营跨部门协作 | TM018 TM021 | 冲突先改合作机制（共同目标、共同指标、决策边界），再用提问清单定优先级 |
| 个人时间被下属/群消息切碎 | TM005 TM006 TM007 | 设「可被打扰窗口」与「免打扰时段」，说明书里写明什么事找谁、什么情况才找自己 |
| 性格测评（北森等）应用 | TM023 TM019 | 只取差异项，转成三条协作动作；不用测评给人贴死标签，也不指望靠测评选人 |
| 刚接手团队、先管人还是先管自己 | TM001 | 先走第二方案：把自己的时间、缺点、说明书管好，再动角色、选人、信息与责任；一上手就想着「怎么管好别人」，通常先把团队管成对抗 |
| 团队绩效不达标复盘 | TM012 TM013 TM020 | 先查信息共享与责任划分，再查能力；改机制（指标、流程、反馈频率）而不是喊「要努力」 |

## 五、边界

- **教练方法的适用前提**：CEO 教练法假设被辅导者有基本自省能力与改变意愿；对严重人格冲突、组织政治斗争、合规问题，须配套制度与第三方介入，不能只靠「提问与觉察」。
- **「对人不对事」不是和稀泥**：指先理解人的差异与动机再设计机制，不等于放弃事实与标准；冲突涉及原则与合规时仍须就事追责。
- **掌控升级不是放权表演**：把「人盯」换成「机制盯」需要真实的信息系统与决策权限表，否则只是把失控藏起来。
- **不适用于纯执行型岗位管理**：流水线式、标准化程度极高、容错极低的岗位，更依赖流程与培训体系而非教练式提问。
- **课程为单一讲师经验**：衡量为 CEO 教练，样本以民营企业高管为主，国企/外企/公共部门的科层约束下需重新校准。
- **免 AI 化输出**：简体中文、零 emoji、结论先行、表格化，不写「赋能／抓手」类空话。
