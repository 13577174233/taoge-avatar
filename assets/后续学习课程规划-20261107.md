## 四、每门课的验收标准（沿用三课已跑通的做法）

1. **S 级归档**：每篇六段结构齐备（元信息五行含来源 URL / 分节核心观点 / 一句话结论 / 原文结尾摘录引用块 / 对我的用法四条），`## 对我的用法` 必须逐篇存在，S 级统计用不带括号后缀的「S级」。
2. **编号规则**：一律「编号＝讲次＋1」，发刊词占 001；资料领取页、工具手册、毕业测试等非知识项登记不归档，在 `_catalog` 写明。
3. **分律表**：十讲一批一份 `_laws_XX_bN.md`，四列（编号 / 短名 / 一句话 / 来源），语义源必须取自各篇 `## 一句话结论`，不得自撰。
4. **入图**：模型地图六列表头（编号 / 模型名 / 一句话 / 置信度 / 领域 / 日期），区块尾部加一段 `> **日期 说明**` 汇总，并把全库口径写进去。
5. **连接图**：每次升版同步 header 文案、stats 七格、lens 数组、POS 坐标、LINKS 突触四处；升版前用 node 校验（透镜数 / 接线数 / 坐标命中）与 `node --check` 语法检查，别只改文案不改数据。
6. **蒸馏 skill**：五段结构（总图 / 核心律速查表按模块分组 / 五步 SOP / 应用场景映射 / 边界），边界段必须写清「不预测、不替代专业判断、作者观点要标注」。
7. **体系说明与分身**：`00-体系说明与索引.md` 加版本条目＋台账行＋页脚，`taoge-avatar/SKILL.md` 追加进度段并同步透镜表与连接图路径。

## 五、风险与口径提醒

| 风险 | 现状 | 应对 |
|---|---|---|
| 得到登录态失效 | 网页版会话会因「另一台设备登录」被踢 | 采集前先确认登录；失效即走 `interaction.request_action(type="browserControl")` 让用户扫码，不用文字请求替代 |
| 侧栏懒加载／目录抽屉不渲染 | 021 讲后目录不渲染、懒加载需派发 scroll 事件 | 先点「展开目录」，滚动用 `dispatchEvent(new Event('scroll',{bubbles:true}))`；仍不行就切全站搜索 |
| 磁盘余量 | 4.8Gi 可用 / 73%（2026-11-07 清理后），本轮读写正常 | 降到 3.9Gi 以下会全超时；已清浏览器自动化缓存与 uv 缓存，后续优先清 `/tmp/build` 与 `~/Library/Caches` |
| 讲次口径不一致 | 课程页标称 ≠ 实采（CXJ 41/43、WJ 63/60、何帆 30/33、蒋文华 50/51） | 一律按实采记，`_catalog` 写「页面标称 / 实采」双列对照，不按宣传口径填数 |
