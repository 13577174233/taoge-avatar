## 二、下一阶段任务单（8 项，按优先级）

### W1 重叠课卡律对齐表（P0，第 1 月）

| 项 | 内容 |
|---|---|
| 目标 | 把两侧重叠的约 12 门课按"讲次"对齐，回答"这张卡对应哪条律、是否一致" |
| 输入 | 卡层 `distill/cNN/NNN.md`；本机 `05_自主学习/03-蒸馏入库/*.md` 速查表「来源」列（形如「家庭 001」「高血压 07」）；`_laws_index.json`（4616 条，只有题名与文件名，**无讲次字段**） |
| 做法 | ①**前置**：解析速查表来源列，生成 `_laws_lecture_index.csv`（D号, 模型名, 课简称, 讲次, 文件）；②建课简称↔WB课程名对照表（家庭=冯雪家庭健康100分、高血压=冯雪高血糖？须逐条核，不许猜）；③先做 3 门样板：冯雪·高尿酸、蔡钰·批判性思维、华杉·新品牌营销；④按 (课名, 讲次) 精确匹配，匹配不上再按标题语义匹配；⑤每条标状态：一致 / 表述冲突 / 仅卡侧 / 仅律侧 |
| 产出 | `mapping.csv`：course, lecture, card_id, law_id, status, note；加一份冲突清单（逐条给两侧原文） |
| 验收 | 3 门样板讲次覆盖率 ≥90%；冲突项 100% 列原文；`mapping.csv` 可被脚本读取（UTF-8、无合并单元格） |
| 阻断 | 速查表无「来源」列的批次标 unknown，不猜讲次；课简称映射必须逐条核对，不得按字面近似自动匹配 |
