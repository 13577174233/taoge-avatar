# 四档场景短名单（2027 电商年度规划调用层）

> 来源：C 试点（2026-11-10）暴露的卡点——30 条全表扫描命中率 43.3%，17 条需人工判掉。本文件把「按场景取 8–10 条」固化，替代全表扫。
> 全部编号取自主表并逐条核准；2026-11-10 起 TM 23 条已升六列（C 级锚点），仍按「可指认不可当原话」引。

## 使用规则

1. 先判当前问题属于哪一档，**一次只读一档**，不要四档混读。
2. 每档给的是「问题特征 → 该调的律 → 落到哪个动作」，不是律名清单。
3. 跨档复用同一条律（如 TX011 同时在货盘与现金流）时，按当次问题选一个视角引用，不要重复计数。
4. 一档 10 条仍不够用时，按第七节「全文级律表对接」回源表取号，不要凭记忆引。

## 一、货盘档（10 条）

**触发**：SKU 太多卖不动、砍了怕丢量、不知道哪个品该给资源、毛利高但不赚钱。

| 问题特征 | 调哪条律 | 落到哪个动作 |
|---|---|---|
| 毛利高但资金不转 | HB001 库存周转优先律 | 按「毛利率×年周转次数」排货盘优先级，算每 100 元资金年产出；低糖云腿这类高周转品优先于高毛利慢销礼盒 |
| 品太散、每支都不强 | HB004 选品加减二分律 | 先判集中型还是分散型市场：集中型按功能需求每需求留 1–2 支；分散型靠奇特口味＋更新率≥30% |
| 不知道每个品类该背什么指标 | HB005 生鲜八角色分工律 | 给品类定角色：拉新／引流／增粘／得利润／做差异／促复购／扩传播，一品一角色，不许全品背毛利 |
| 损耗和退货吃掉毛利 | HB006 生鲜六步控损律 | 下单准、收货鲜、定价含损耗、陈列稳、添货勤、控损狠六步逐条挂责任人；定价先把损耗率加进成本 |
| 靠感觉选品、周月数据不会用 | HB007 小数据选品律 | 周数据按三段式读（周一至周五 17 点／周五 17 点至周日 18 点／周日晚后）；月数据同比去年同月，按四种周期定上新 |
| 坑位／首页资源分不公 | HB009 货架三定律 | 先按支持率（销量＋转化）定面积，再分主动搜索区与被动推荐区，最后设中高低三档价格带（±10% 三次递进） |
| 只看销售额，说不清哪里出问题 | HB002 人货场三指标诊断律 | 人看坪效／坑位产出、货看商品健康度、场看连带率，三指标并列报，缺一项不下结论 |
| 单位产出算不清、费用摊不下去 | HB003 坪效租金锚定律 | 把日坪效换成「日 GMV÷占用坑位数」，租金（流量成本）占比超 5% 就必须抬高单位产出才盈亏平衡 |
| 该不该砍一个 SKU，算不出账 | TX011 净现值律 | 用 NPV 口径算：这个品未来现金流折现是否为正；为负就砍，别用「去年卖过」当理由 |
| 资源摊平、每个品都做一点 | WJ021 押注主干 / WJ049 只做可叠加 | 80% 资源压 20% 主干品（山珍云腿＋低糖云腿）；只做高回报可叠加的动作，方向错的努力立刻停 |

## 二、节令档（10 条）

**触发**：中秋／端午排期、主销品定几个、要不要泛投流、老客怎么激活、客诉怎么处理。

| 问题特征 | 调哪条律 | 落到哪个动作 |
|---|---|---|
| 节令想全品类一起上 | HB011 时段与节令营销律 | 六季分主销（集团军）与清仓（单兵）：中秋只设 2 个主销，其余进清仓单；52 周表找坡道品类再放量 |
| 想靠打折拉连带 | HB010 三定价法分工律 | 主卖品用倒算定价提销量、封顶定价（10／100 前数）提连带、高质低价提复购；三种目标不许混在一个品上 |
| 非刚需品想广撒网 | AN001 单点突破洞察律 | 聚焦基本盘客户，拓展围绕客户特点而不是产品特点；先定「谁是我的基本盘」再谈拉新 |
| 情感营销只停在文案 | AN003 情感落地四步律 | 线上走到线下→建公共空间→让活动自己长出来→造节日沉淀固化，四步缺一步就不算落地 |
| 客诉处理只看当次赔付 | AN008 客诉三原则律 | 不看当下看长期、公开处理从点到面、目标从客户满意升到客户共创；赔付金额之外必须留改进动作 |
| 服务质量靠事后评估 | AN006 边服务边监控律 | 客户在当下即时监督：社群、意见箱、外部舆情三渠道同时开，不等月度报告 |
| 新区域／新渠道要不要投 | W688 临界比例律 | 先在一个文化脚本对路的小区域打透，凑够关键密度（少数派占 1/4–1/3）再扩散，别全网平铺 |
| 投流 ROI 越来越差 | W689 超级传播者律 | 找能转发的关键人（达人／老客意见领袖），把预算从广撒改为集中打这几个点 |
| 节令靠天吃饭、气候不确定 | ZXY021 天气衍生律 | 把气候当独立风险列出来做预案（备货节奏、替代品、清仓窗口），不当作价格风险处理 |
| 增长卡住、不知道瓶颈在哪 | HB013 四阶段瓶颈律 | 按阶段定位：新店撒网聊天→平稳期找差异→增长期从限制条件找解法→扩张期设年度课题 |

## 三、现金流档（10 条）

**触发**：备货压资金、账期拉长、要不要借钱扩张、分红怎么定、开新店／建仓该不该投。

| 问题特征 | 调哪条律 | 落到哪个动作 |
|---|---|---|
| 不知道先管什么风险 | ZXY002 两步风控律 | 先识别风险、定目标敞口，再选工具；风险管理目标是保障未来现金流，不是消灭波动 |
| 备货杠杆大、怕资金链断 | ZXY020 展期爆仓律 | 做三档压力测试（基准／-20%／-35% GMV），算最坏情况下现金能否撑到回款；保证金式每日结算的品类单列 |
| 该借钱还是该让股 | TX007 债股权衡律 | 发债成本低但有违约风险、股权贵但不压现金流；按现金流稳定性选，别按利率高低选 |
| 想用负债放大收益 | TX009 税盾杠杆律 / TX010 财务困境律 | 税盾只在盈利且现金流稳时有效；杠杆一旦触发财务困境成本，价值反向缩水，先算困境概率再算税盾 |
| 要不要开新店／建新仓 | TX011 净现值律 | 正 NPV 才做；用「增量现金流折现 - 投入」算，不用「同行都开了」当依据 |
| 退出自建仓／剥离资产 | TX013 协同效应律 | 并购与剥离都看协同：1+1>2 才留，否则毁灭价值；退出决策按此口径写清「不协同在哪」 |
| 利润怎么分、要不要稳定分红 | TX016 分红信号律 | 稳定分红是对外的价值承诺；节令赚的钱先补现金流缺口，再谈分红节奏 |
| 公司钱和家里的钱混着用 | ZYU046 四笔钱 | 活钱／稳健／长期／保险四账户分开，节令备货资金绝不进长期池 |
| 能承受多大亏损没定过 | ZYU022 先定回撤 | 先定「能忍受的最大回撤」再定目标；顺序反了会在最差时点被迫出货 |
| 收入、房产、股权看着分散其实同涨同跌 | ZYU058 风险敞口 | 先算相关性再谈分散：主业收入＋自住房＋公司股权若同源，实质是同一个敞口 |

## 四、团队档（10 条）

**触发**：7 角色怎么分工、招人招不到、KPI 定不下去、跨部门冲突、自己时间被切碎。

| 问题特征 | 调哪条律 | 落到哪个动作 |
|---|---|---|
| 刚接手团队就想先管人 | TM001 第二方案 | 先管自己（时间／缺点／说明书），再动角色、选人、信息与责任 |
| 下属总在猜我的偏好和禁区 | TM006 使用说明书 / TM007 透明沟通 | 给自己写一页说明书（偏好、禁区、擅长、不擅长、找我的正确方式），团队共读一次 |
| 目标统一不了、各说各话 | TM008 角色决定目标 | 目标天然叠加个人角色：先写清每个角色「对什么结果负责」，再谈统一 |
| 招不到合适的人 | TM010 选人困难症 / TM011 | 跳出来先定岗位画像与能力证据，别用「招个牛人」解决流程缺失 |
| KPI 定了不认 | TM012 信息共享与分清责任 | 先共享信息、再分清责任，最后才落 KPI 数字；顺序反了 KPI 一定被质疑 |
| 任命后下属不知道往哪走 | TM014 培养式任命 | 任命时说明培养意图与三个验收点，不说「你先顶着」 |
| 跨部门／高管冲突反复 | TM018 新合作机制 | 对人不对事：先找一个新的合作机制（共同目标、共同指标、决策边界），再谈谁对谁错 |
| 事情太多、优先级定不下来 | TM021 管理从提问开始 | 先问「最重要的 1–2 件事是什么」，再问「不做会怎样」；两问定不下来就不开会 |
| 性格测评拿来贴标签 | TM023 测评当使用说明 | 只取「我与他人不同」的差异项，转成三条协作动作，不做优劣评判 |
| 想要一张全课清单 | TM022 下山锦囊 | 管好自己→定好角色→选对人→分好信息与责任，四段压成一张自查表 |

## 六、边界

- 本短名单只覆盖 2027 电商年度规划的四个高频场景，不替代完整律表；其他场景按包内第七节回源表取号。
- 边界口径：团队档 TM 23 条已于 2026-11-10 升六列（C 级笔记近似句，锚点 23／23），可指认「意思是这句」，不可当讲师逐字原话；W6 32 条提炼段无对应原文句，只能引断言不加引号；索引级其余条目未纳入本短名单。
- 每条动作须带可量化口径（数值、责任人、时点），否则退回上一条重取。
