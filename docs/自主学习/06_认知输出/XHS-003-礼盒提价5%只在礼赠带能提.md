# 礼盒提价 5%：礼赠带能提，自食带一提就掉量

**结论先说**：2027 中秋礼盒均价上调 5%，只在礼赠主价格带可提；自食价格带不要提，提了大概率掉量超过 5%，收入反而下降。

## 一、为什么是两个价格带、两种结论

收入＝价×量。

- 礼赠带（200–400元）：替代品少、占送礼预算比例小、决策周期短 → 弹性低，提价能增收。
- 自食带（小克重、50元以下）：替代品多、支出占比直观、平台比价工具在场、可延后购买 → 弹性高，提价就是掉量。

弹性三因子（替代品、支出占比、可延后）决定你能不能涨价，不是「成本涨了所以我要涨」决定（D3127 弹性三因子律）。

## 二、同一个商品，身份随价格变

弹性不同于斜率：同一条需求曲线上，价格高的部分弹性大于 1，价格低的部分小于 1。礼盒和小克重不是同一件商品的两个规格，是两个身份（D301 弹性处处不等律）。

## 三、提价前先算三条线

1. 礼赠带竞品有没有同步涨？没有，你的 5% 就是替对手让出的价差。
2. 自食带做测试组：跌幅能不能守住 5%？守不住就别提（D3126 弹性定价律：弹性<1 提价增收，弹性>1 提价减收须靠量补）。
3. 提价部分会不会被平台活动折扣和达播佣金吃掉？吃掉就不是增收，是替平台涨的。

## 四、最容易错的地方

最容易错在「礼赠带也敏感」。企业团购按预算总额采购，提价 5% 直接触发降规格或换供应商——掉量不是渐进下滑，是整单消失。

**所以提价节奏应是**：先礼赠带、先团购外、先小批量测试，确认预售转化率 ≥ 去年同期的 95% 再全面铺。
