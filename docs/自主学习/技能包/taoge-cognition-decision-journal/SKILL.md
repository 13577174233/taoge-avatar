# 判断日志（taoge-cognition-decision-journal）

## 定位

每次重要判断都记录，事后回看对错，校准判断力与模型置信度。原则：极度求真，极度透明——对自己诚实。

## 判断记录格式（做出判断时立即填写）

- 编号：J-YYYYMMDD-XXX（每日自增）
- 判断主题：一句话
- 判断内容：当时的结论
- 依据：关键理由 + 用到的思维模型编号
- 当时置信度：0-100%
- 关键假设：成立依赖的前提
- 可能出错的地方：苏格拉底反向检验

## 事后复盘（T+30 天 / T+90 天）

1. 记录实际结果，判定 ✅正确 / ❌错误 / ⚠️部分正确
2. 若错误，归因四问：模型不对？场景不匹配？遗漏变量？纯粹运气？
3. 更新对应模型的置信度（在模型地图或技能包中标注）
4. 提炼教训，写入复盘归档

## 执行流程

1. 新判断 → 按模板建日志页
2. 到期复盘 → 逐条回看，按归因四问分析
3. 月度/季度 → 生成判断审计报告：命中率、高频偏差模式、需校准的模型清单
4. 审计报告输出到 `07_认知复盘/`，并同步模型置信度

## 判断标准

日志做到「任何人翻到这篇，都能复现你当时怎么想的、依据什么模型、后来对不对」。

## 适用边界

- 适用：重要判断留痕、T+30/T+90 复盘、月度季度判断审计。
- 不适用：日常闲聊式选择、无需回看的即时操作。
- 硬标准：记录时必须写「当时置信度」和「关键假设」，事后不许改写原始判断内容（只能追加复盘）。

## 失败模式与兜底

- 到期但结果未明 → 标「结果未定」，顺延一期，不强行判对错。
- 判断被事后合理化 → 回看原始记录，以当时写下的话为准。
- 归因四问都答不上 → 判为「运气」，并降低该模型在此场景的权重。
