# 娱乐行业晨间分析

面向普通人的文娱市场解读：帮你看什么、避什么、怎么花钱。

## 分析范围

- 电影：单日/周末票房、新片口碑与排片、档期（国庆/贺岁/暑期）
- 剧集与动漫：热播榜、平台会员剧、国创动漫动态
- 综艺与短剧：新综艺开播、短剧爆款、微短剧监管
- 演出：演唱会/音乐节开票、票务动态
- IP与衍生：周边、联名、游戏影视化

## 晨间分析步骤

1. 检索过去24小时文娱市场动态（票房数据、开播开票、平台榜单）
2. 判断可看性与消费价值：
   - 周末观影/追剧推荐：依据口碑与评分
   - 会员决策：哪家平台值得开、什么内容独占
   - 演出抢票提醒：开票时间、票价区间
3. 给出消费提醒：档期选择、票价套路（黄牛/溢价）
4. 硬性过滤：明星私生活、绯闻八卦一律不纳入；只选作品与市场层面

## 关键数据源

- 票房：猫眼专业版、灯塔专业版
- 剧集动漫：云合数据、骨朵热度、平台榜单
- 行业：艺恩、娱乐资本论、证券时报文娱

## 输出模板

```
[娱乐] 标题
市场数据：票房/榜单/开票一句话
值得关注：周末看什么、追什么
与我何关：消费建议（观影/会员/演出）与避坑提醒
```

## 适用边界

- 适用：票房/榜单/开票等公开数据解读、看什么与避什么的消费决策。
- 不适用：明星私生活与绯闻、作品投资并购、影视公司财报深度分析（走财务类包）。
- 数据口径：票房以猫眼/灯塔专业版为准；无当日权威数据时标注「未获取」，不估算。

## 失败模式与兜底

- 票房/榜单数据取不到 → 只输出已知的开播与开票信息，明确写「当日票房数据未获取」。
- 平台榜单互相矛盾（如站内热度 vs 豆瓣口碑）→ 两套都列，标明口径，不二选一。
- 涉及涨价、黄牛溢价 → 只描述机制与风险，不给购票渠道建议。

## 速查表

| 用户问 | 先看什么 | 落到哪 |
|---|---|---|
| 周末看什么 | 新片口碑 + 排片占比 | 推荐 1 部 + 避雷 1 部 |
| 哪家会员值得开 | 平台独占内容 + 到期时间 | 开/不开 + 何时开 |
| 演唱会值不值 | 开票时间 + 票价区间 + 场馆 | 抢票窗口 + 溢价风险 |
