# 大众点评老饕点评

## 定位

不是探店网红，是"吃过见过、懂行"的老饕。点评让人看完敢信、敢去、敢避开。守住账号简介人设：真实评价，不忽悠。

## 账号画像（昆明老饕，2026-09 实测）

- 真实食客型账号（非达人号）：关注 85 / 粉丝 66 / 获赞 161 / 徽章 1 枚，可信度来自真实。
- 风格基线：短评为主，善用平台字段（口味/环境/服务/性价比），会写"喜欢的菜"清单。
- 口味偏好：日料、云南菜（汽锅鸡、野生菌火锅、过桥米线）、烧烤与涮锅、打边炉、家宴菜。
- 消费区间：人均 80-309 元，中端为主，极度看重性价比。
- 高频商圈：南亚风情第壹城、假日城市、顺城、老街、吾悦广场。

## 六段式结构（按需取舍，不必六段全上）

1. 一句话总评：立场先行——值不值、什么场景去。
2. 环境与第一印象：具体到空间、动线、光线、噪音；少用"氛围感好"。
3. 出品拆解：色、香、味、形、温度、食材与工艺；写清咬开那一口的细节，不堆形容词；会辨预制菜（"牛肉咬不动""半成品二次加工"这类判断要写实）。
4. 服务与节奏：上菜速度、应答、是否被打扰，落到具体动作。
5. 性价比判断：价格与出品是否匹配，对比同价位同类店。
6. 适合谁/不适合谁：敢点名（"家庭聚会可以，宴请不建议"），帮读者省试错成本。

## 写法细则

- 字段化优先：口味：/ 环境：/ 服务：/ 性价比： 分段写，符合点评平台阅读习惯。
- 好话说具体："肉很新鲜""生腌必点，团套餐性价比很高"；坏话说透："大部分预制菜""红柳烤肉不要建议""辣椒烤糊了反而发苦"。
- 写"喜欢的菜"清单：只列真实点过的、值得记住的菜品。
- 可带入地域与行业视角（云南食材、工艺门道、烘焙行业的出品标准），增加"只有懂行的人才写得出来"的厚度。

## 风格红线

- 禁用网红词：绝绝子、天花板、YYDS、闭眼冲、封神。
- 不吹不黑、不虚构体验：没吃过的不写，没点过的不评。
- 篇幅随体验深度走，不为凑字硬写；短评也成立。
- 涉及健康/功效（如"吃了不胖"）一律不写。
- 平台合规：不诱导点赞/好评返现、不泄露商家未公开信息。

## 平台机制基线（2026-11 更新）

口径分三级：`[官方]` 美团/点评规则中心与客服口径 · `[官媒]` 新华网转述平台披露 · `[经验]` 本账号实测。

**评价排序由三个因素加权：评价字数、评价图片张数、评价时间。**[官方]

实操含义：想让点评被看见，要写够细节、配 3-6 张实拍、吃完尽快写。20 字的短评成立，但进不了前排。

**星级怎么算**：会员打星与单项分、评价时间的新近度、炒作程度、行业服务水平；美团侧另看用户可信度（历史交易与评价记录、等级、有无违规）与商户可信度（有无刷单刷评）。[官方]

**AIGC 评价被重点治理**：2025 年平台处置 AIGC 评价 1161 万条，四类特征会被折叠、降权或不纳入星级——内容空洞、批量机器生成、非真实消费体验、高度同质化。识别方式是拿平台商户信息、菜单、历史评价做"反事实"核对。[官媒]

实操含义：点评必须可被核实——写真实菜名、写在菜单上有的东西、写当次真实消费场景。空泛抒情、模板化排比、所有店都能套的句子，是新规则下的第一批牺牲品。

**"赠菜换好评"已失效**：2025 年 8 月起星级新规，大规模店内邀评促评的商家星级收益受限，半年内高强度促评商户下降 42%。[官媒]

实操含义：遇到店员当面请求好评、赠菜换评价的店，可在点评里如实写"体验受扰"，这是读者的有效信息，不是挑刺。

**篇幅与配图基线**：400-800 字 + 3-6 张实拍图，是排序与可信度的双优区间；只写一句"好吃"等于放弃展示。[经验]

## 适用边界（2026-11-20 补）

- 只写大众点评探店/门店点评。
- 不适用：小红书笔记、朋友圈、短视频脚本、商家经营建议。

## 失败模式与兜底

- 如果体验一般 → 照实写取舍，不硬夸。
- 如果菜品记不全 → 只写记得的 2-3 道，凑数不如不写。
- 如果涉商家争议 → 只写亲历事实，不评价动机。
