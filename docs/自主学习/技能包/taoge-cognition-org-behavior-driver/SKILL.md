# 组织行为驱动认知包（Org Behavior Driver）

> **一句话定位**：一套把"人、团队、组织"变成可诊断、可执行、可复用的战术手册——公司是生物有自己的行为规律，你有你的逻辑，组织另有逻辑。
> **来源**：李育辉·组织行为学（2026-10-26 S级归档LY01-LY29共29篇），李育辉为中国人民大学劳人院教授/博导（《华为基本法》参与制定方），给阿里/建行/壳牌等百余家企业做过咨询。学科立场：实证主义、权变、站组织这边。

## 一、总图（一句话记住）

**个体（情绪/动机/角色/承诺）→ 群体（匹配/融入/认同/凝聚力/决策）→ 组织（搭班子/节点/授权/冲突/政治/心智/自上而下）→ 前沿交叉（环境/强互惠/负向激励/意义感）；三条暗线：环境大于激励、团结是双刃剑、变革必须自上而下。**

| 模块 | 核心问题 | 核心模型群 |
|---|---|---|
| ①激发个体 | 怎么把个体潜能激发出来？ | 情境强度塑人/情绪资源有限/主角合伙人动机/角色中心性/职业承诺/工作嵌入/彩虹年龄锚点 |
| ②领导团队 | 团队怎么建、领导怎么当？ | 三种新匹配（人-人/角色/潜力）/非正式合群/露情绪留空间/相对剥夺快速凝聚/团体迷思三破解 |
| ③重塑组织 | 组织变革怎么搞？ | 先搭班子再定战略/节点人物/心理授权三维/冲突不个人化/政治三分类划红线/共享心智地图/高阶理论自上而下 |
| ④最前沿 | 学科最前沿突破是什么？ | 启动效应环境先行/强互惠利他惩罚/基因控制变量/负向激励建设性批评/意义感透明化+重建阶梯 |

## 二、核心律速查（24律）

### ① 激发个体——别把人当只认钱的执行工具

| 编号 | 模型 | 什么时候用 / 看到什么信号 / 怎么用 |
|---|---|---|
| LY01 | 信息河流律 | MIT彭特兰给美国银行呼叫中心3000人戴可穿戴设备：绩效差异跟管理水平/团建/领导魅力都没关系，唯一相关变量是非正式聊天机会多不多。解法=加长食堂桌子+调倒班让更多人一起休息，年利润提高1500万美元。组织中除了物质能量流动，还有一条看不见的信息河流。用法：别迷信"加强团建/提高执行力"口号，观察10人团队谁和谁午饭坐一起、谁在群里最活跃、谁被边缘化——信息流向哪里绩效就流向哪里 |
| LY02 | 权变无绝对真理律 | 组织行为是权变的——A导致B，但必须加一句"在C条件下"。霍桑实验八年间做照明/福利/疲劳实验：从24根蜡烛加到76根生产率微乎其微；多给钱反而不增产（班组形成非正式小群体排挤干太快的人）。"走动式管理"对内控型人格反效果。用法：别信"加强管理就提升效率"普世口号；先判断员工是内控型（给结果别管过程）还是外控型（给流程别只给目标），管理动作因人而异 |
| LY04 | 情境强度塑人律 | 成年人性格像河流，宽度不变但方向会改。改变性格的不是时间长短，是情境强度。德国义务兵9个月不打仗只做基础训练，宜人性显著下降4年后仍在——关键是射击/刺杀科目情境强度极高。四维：明确性（口令细到一根手指）、一致性（要求方向无矛盾）、约束性（连方法都限定）、严重性（赏罚分明）。用法：别把成本全砸在招聘面试上，挪到培训——把岗位关键情境拆出来，在四维上加强；客服岗每个典型投诉场景写一句标准话术纳入考核 |
| LY05 | 情绪资源有限律 | 情绪不是用来平复的感受，是有限资源——会耗竭需要补充。发奖状加薪水越来越没用，因为工作场景里的成就感无法补充情绪资源，必须切换到家庭/生活场景才能加油。扎克伯格十几件一模一样的T恤=主动节省情绪资源。用法：派活不只看谁能力强，还要看谁的情绪资源还有余量；明星员工最容易崩，观察谁最近话少了、谁开始加班到很晚=情绪报警；保护救火队员别把油烧干 |
| LY06 | 主角合伙人动机律 | 传统动机理论（双因素/需求）共同前提=组织是主角员工是配角，用诱饵牵着走（唐僧取经徒弟都是被哄着的）。新生代从游戏和互联网长大，天生要当主角。解法：把自己当投资人，把员工当创业合伙人——一起定目标（OKR）、给资源做投后管理、让员工自己说出需要什么；携程"投名状"对赌（员工自己投钱，达标翻倍超2倍十倍）。用法：别拍脑袋下KPI，拉年轻人一起定季度目标——他自己说出来的数字才会拼命 |
| LY07 | 角色中心性律 | 工作生活冲突本质不是时间不够分，是角色打架。人同一时间只能专注一个角色，频繁切换极耗认知能量（斯坦福监狱实验：随机分配看守/犯人，普通大学生很快钻入角色刻板印象）。解法不是划时间边界（福特流水线老办法），是管理角色：无印良品"树干/枝叶分离"（上班只做核心树干任务，协作枝叶简化或带回家）、统一交流日、帮员工减家庭角色压力。用法：上午定"不打扰时段"全员做核心任务，下午统一处理沟通协作；写作业时手机放另一个房间让孩子只当"学生" |
| LY08 | 职业承诺律 | 组织承诺（员工忠于公司）过时了——企业平均寿命越来越短，终身雇佣制瓦解。新逻辑：员工忠于职业赛道不忠于公司，他既是组织雇员也是组织用户，企业必须把自己当商品经营。布兰森：先把员工培养成最优秀的人，再想办法留住他。茑屋书店三招（只给顶尖人才非全员普惠）：保证作品有突破、和最优秀的人共事、鼓励走出去看世界。用法：别指望工资+年终奖留核心运营，做一次"职业发展对话"——聊"你在冠生园这两年想变成什么样的人"，帮他把目标和公司业务对齐 |
| LY09 | 工作嵌入律 | 传统激励（钱/权/职业发展）都在工作圈里打转，但人还有社区和家庭两个圈层。组织可以跨出工作边界，帮员工搞定社区地位和家庭需求——成本极低效果极强。中国企业在非洲建厂：发奖金做思想工作都没用，解法是敲锣打鼓送奖状到村里、政府领导握手劳模父母；德国挖工程师：砸钱翻倍不行，搞定太太（柏林房子+孩子学校+家属部门）就行。用法：核心员工家里有什么难事主动问——孩子上学/老人看病帮把手，嵌入感比多给两千块强十倍 |
| LY10 | 彩虹年龄锚点律 | 人力成本连续10年增速超GDP，别只会裁员找"新能源"。萨柏彩虹理论：人一生扮演9种角色随年龄变化，学习欲望最高峰不在18岁而在45岁。EverYoung只招65岁以上员工做互联网——老人不缺钱缺学习机会，培训既是干活需要的也是他们上班的目的。45岁左右极其看重"持家者"角色。用法：别一概用工资激励；45岁员工帮他解决孩子上学/父母养老比涨工资管用；退休糕点老师傅可返聘（不在乎钱在乎价值感）；你自己45岁正处学习欲望峰值，你的状态就是家庭氛围 |

### ② 领导团队——领导力是互动关系不是个人特质

| 编号 | 模型 | 什么时候用 / 看到什么信号 / 怎么用 |
|---|---|---|
| LY11 | 领导力互动律 | 商业畅销书归因陷阱：宫本茂"撤走饭桌"团队毫无怨言跟着加班，成功学说是老板超凡魅力——李育辉反转：厉害的是员工，老板敢撤饭桌是因为之前已建立深厚默契信任。现实打脸：很多初创老板说产品差不多就得赶紧上线不然人就走了，你敢撤试试？真正的领导力不在老板一个人身上，在他和团队的互动关系里。用法：想临时改方向之前先问——团队跟我有这个默契吗？没有就提前沟通别直接拍板；别学老板"拍脑袋改方向"那一套 |
| LY12 | 三种新匹配律 | 传统"人-岗匹配"（招能力经验对口）在岗位越来越复合的时代失效。三种新打法：①人-人匹配（不描述岗位，照着团队里最牛的那个人招同类，两弹一星选聂荣臻=有理工学位让科研人员敢来）；②角色匹配（不招一张完整的脸，招鼻子眼睛眉毛——军工8人组=实干家×3+创新者×3+协调者×1+熟虑者×1踩刹车，走一个只补一个零件）；③潜力匹配（不为现在招为未来战略招，高绩效员工换岗后只有29%保持高绩效，高潜力人才93%未来出高绩效）。用法：10人团队盘点缺什么角色——是不是全是冲在前面的实干家，缺一个踩刹车的"熟虑者"？下次招人别写JD，照着最牛的人列特质招同类 |
| LY13 | 非正式合群律 | 传统团建两个硬伤：官方组织+非自愿，个体在认知上归类为"正式活动"反效果。合群真实路径：新人先和1-2个人配对→组成小型网络→再靠这个网络打入大群体。高校休息室实验：小（挤着坐4人）、半封闭（有门不锁）、不预约的休息室使用率全楼第一，一旦放进预约系统变正式场所使用率立马暴跌。用法：别搞全员正式团建；新人入职先让他自己找1个"自己人"（buddy但别强制配对）；微信群名改"名字+兴趣标签"（瑜伽/漫画/哪个足球队），新人自己找同类 |
| LY14 | 露情绪留空间律 | 现在员工越来越自恋（26年追踪1.6万大学生自恋评分显著上升），你端完美人设他们不买账。获取认同新方法：主动暴露缺陷让追随者觉得"老板有些地方搞不定得我来"——他们认同你其实是在认同自己。两条红线：①借情境暴露（松井忠三居酒屋酒过三巡"无意间"说出撑不住了），别随时随地示弱；②只暴露情绪（累/焦虑=增加参照权力魅力），绝不暴露能力（不会/搞不定=摧毁专家权力信任）。谷歌实验：领导露情绪痛苦组绩效最高，露能力无能组绩效最差。用法：开会主动说"这个新品方向我也在纠结大家怎么看"露情绪困惑，但绝不说"这个我不懂你看着办" |
| LY15 | 相对剥夺凝聚律 | 传统团建建凝聚力太慢，紧急临时组队时可用"相对剥夺"快速凝聚：领导在态度上狠一点（《兄弟连》索伯辱虐管理），大家觉得"我们都是被这个臭脾气压迫的人"从而抱团。四条红线：①剥夺要公平（至少一半人都被冷落过，否则少数人只想跑）；②只碰自尊心荣誉感，绝不能碰钱；③会后给足资源（员工把负面感受归到"领导风格"而不是怀疑公司）；④赢了一定要分果实。代价：这招对领导者本人有杀伤力，事后要保护。用法：大促攻坚前开会态度严一点，但会后夜宵后勤给足、赢了立刻分奖金；别在家庭里用这招 |
| LY16 | 团体迷思律 | 越团结的团队越容易决策失误——不是不团结是太团结，"内聚动力"过强。猪湾登陆（肯尼迪+四位部长+两位哈佛教授全是竞选老人）犯低级错误；得到全通卡团队兴奋到包酒店集中研发，明显漏洞没人提。三类症状：对自身高估（坚不可摧假象/正义性幻觉）、封闭保守（共同辩解/对手刻板印象）、寻求一致最隐蔽最致命（自我审查/从众即正确/信息保镖自动屏蔽不利信息）。三破解：指定一个唱反调的人、引入外部视角（外人一眼看到你循环论证的漏洞）、弱化强势者（领导和专家最后发言别先定调）。用法：下次大促方案讨论你最后一个发言，指定一人专门挑毛病；选科讨论时家长忍住别先表态，你先说话孩子就不敢说了 |

### ③ 重塑组织——变革必须自上而下

| 编号 | 模型 | 什么时候用 / 看到什么信号 / 怎么用 |
|---|---|---|
| LY17 | 先搭班子优先律 | 商业圈争论先定战略还是先搭班子，组织行为学立场：先搭班子再定战略。波音787血泪案例：67%组件给100多家海外供应商，边干边调人事——交付延期3年/锂电池起火被全球禁飞/损失6亿美元，根因是现有班子不适合打这场仗，边打边调远水解不了近渴。人事变动牵动整个领导力关系网，调整效果天然滞后。正确顺序：CEO先有构想→组高管团队→每人匹配队伍→优化结构→最后一起定战略。微软CEO用三年调人事结构，然后才和这些人讨论战略。用法：定明年GMV目标之前先盘10人班子——这10个人能打什么仗？别定一个超出班子能力的战略；选科先看孩子是什么料（班子）再定方向（战略） |
| LY18 | 节点人物律 | 去中心化不是没有领导，只是领导形式变了。拉平之后资源配置依据从"谁是部门经理"变成"谁是互动网络里的节点人物"。彭特兰实验：互动水平对绩效贡献率没有低于50%的。节点人物三件事：率先发起讨论但不发主宰性意见、推动想法跨小组分享外部情报、制定规则保证方向不偏。蜜蜂类比：侦查蜂先找巢址回来跳舞，超过临界值集体搬家。不用专业设备也能找：数邮件/发起讨论/主动开会制定规则次数。用法：盘点团队谁是那个总拉群讨论、跨部门牵线、分享外部信息的人——资源和机会优先给他，别只看谁绩效数字高；班级里总发起讨论的同学对氛围影响比班长大 |
| LY19 | 心理授权律 | 授权不是把事扔给下属就完了，关键是让他产生"心理授权"——三维度：目标内化（责任边界清楚吗？巴林银行李森一直搞不清自己是清算还是交易）、控制感（领导说"都交给你但一定要干成"你真有掌控感吗）、效能感（受过培训相信自己能干成吗）。巴林银行因李森亏5亿英镑倒闭：没给能力指导、交易+清算两个角色混一人自己查自己账、从没说过失败谁担责。两种走样都是目的错了：大撒把不管 vs 天天盯着盯死——授权真正目的是培养人不是把事办好，所以必须忍着看别人走弯路。塔塔汽车"创新能力温度计"：反馈你能力有没有提高，不反馈你做得对不对。用法：下次授权前先答三问——责任边界清楚吗？给辅导了吗？搞砸了谁担？答不上来就别授权 |
| LY20 | 冲突不个人化律 | 反常识：冲突多≠内耗大，冲突增多反而降低内耗。摩根大通"伦敦鲸"亏62亿美元，根因不是道德问题是CEO戴蒙"避免冲突"文化——两个部门吵架他就斥责，结果投资部隐瞒问题风控部睁一只眼闭一只眼。三种冲突：任务冲突（好事暴露问题）、程序冲突（好事暴露流程问题）、关系冲突（唯一恶性最隐蔽）。内耗不是因为冲突多，是冲突被个人化了——事的分歧变成人的矛盾。三方法：公开按规矩吵（桥水模式全公司围观辩论赛）、引入第三方裁判（让用户来评设计师vs工程师谁对）、人为制造冲突（不同部门定期聚一起吵两天）。用法：团队有分歧别当和事佬压下去——和事佬养出的是隐瞒；公开讨论按规矩吵，输了不怨人只怨没准备好；家里有分歧就事论事别翻旧账人身攻击 |
| LY21 | 政治三分类律 | 办公室政治根除不了——因为资源永远有限，饼够大没人抢。本质不是个人品德问题，是资源有限的问题，政治是一种技能不是专门搞破坏的动机。三类行为划红线：第一类故意违规（越级汇报/未经许可行动）=灰色可接受；第二类对上级指示做对自己有利的解释（惠普豪斯曲解老板"不想再见到"成"快点做"）=灰色可接受；第三类排除异己+实质利益交换（用绩效贿赂产品经理）=红线必须坚决制止。管理者前中后三段：事前预警（判断个人目标vs组织目标比例）、事中介入（CEO别置身事外，把自己变成最大权力砝码，斗争该叫停就叫停）、事后善后（就事论事解释决策理由别渲染矛盾）。用法：小团队有人为推方案耍点小手段（越级/曲解你的话）只要没拿公司利益做人情可以观察；发现搞小团体利益输送立刻处理 |
| LY22 | 共享心智地图律 | 传统知识管理（填表格→建电子知识库→大家随时补充）是面子工程：员工藏着掖着怕被取代、隐性知识没法文字化（销售看微表情判断客户）、知识变文字就成死规矩。正确做法：不共享知识本身，共享"知识地图"——目标不是让每个人背知识字典，是遇到问题时能准确找到对的人。手术团队实验三件事：一把手牵头轮流上台演讲式分享看家本领（仪式感强藏不住）、无任务时随机分组模拟+角色反串（医生当麻醉师）、真实手术后复盘重点讲"做了哪些妥协"和失败教训。三个企业三种法：海底捞口传心授不印手册、五菱知识集市经验做成海报贡献者站旁边等人提问、桥可信度积分。用法：别搞SOP手册让大家填——每周一次30分钟经验分享会，每人讲一个本周踩过的坑，谁是哪个领域的高手大家自然知道 |
| LY23 | 高阶理论自上而下律 | 反"自下而上"时髦：公司出大问题大概率是上面的问题——"问题出在前三排，根子还在主席台"。成功变革走阶梯式传导：CEO→高管团队→中层→基层，一步不能乱。微软复兴教科书级：盖茨2013年底赶走鲍尔默（销售出身强调岗位边界缺车库创业劲），2014年辞去董事长选纳德拉就放手不再指手画脚；纳德拉第一年拉高管去度假村只说理念，第三年转150名中层，之后才是基层。别迷信什么自下而上涌现——10人小团队没有涌现的土壤。用法：你是CEO方向错了下面再努力也白搭；先想清楚你要什么，和几个核心对齐理念，再推中层，最后才是基层；公司喊战略转型但CEO没换的基本是喊口号 |

### ④ 最前沿——环境/伦理/脑科学/意义感

| 编号 | 模型 | 什么时候用 / 看到什么信号 / 怎么用 |
|---|---|---|
| LY25 | 启动效应环境律 | 环境不是加成项是先决条件——环境直接启动你的认知模式，认知模式决定行为。画家出身的市长拉马没钱修下水道就给阿尔巴尼亚楼房外墙刷粉画涂鸦，刷了8年GDP增长4倍。长桌+领导位=三缄其口的会议，圆桌=畅所欲言；绿植装饰让效率升15%（不是氧气是环境启动积极情绪）；密闭小亭子里谁来都收黑钱，宽敞接待厅环境变了腐败自然减少。用法：别光想着加薪加福利，先看办公室桌子是方是圆、墙什么颜色、有没有绿植；把会议室桌子换圆桌、买两盆绿植、墙上换暖色调；给孩子收拾一个固定明亮整洁的学习角，坐到那里就启动"学习模式" |
| LY26 | 强互惠利他惩罚律 | 企业做了不道德的事，即使工资没变员工离职率飙升（Facebook泄密后短期不辞职员工从84%降到52%，七名高管离职）；企业社会责任做得越多，员工组织公民行为（无偿帮同事/服务团队）越多——不用额外出钱团队效能反而提高。强互惠本质是利他惩罚：宁可自己受损也要惩罚破坏公平的人，脑科学证据是看到坏人被惩罚时大脑愉悦区异常活跃。75%新员工选雇主看社会责任；公益投入最高降87%跳槽率+提20%团队效能。用法：别觉得钱能摆平一切——食品安全出问题给钱都留不住人；冠生园做云南本地助农公益（帮果农），员工自发参与劲头比发奖金管用；公司出道德丑闻后高管排队离职的基本救不回来 |
| LY27 | 基因控制变量律 | 别信"基因算命招聘"——基因预测复杂行为准确度不到3%。统计相关≠因果：500强CEO身高和绩效相关性最高，但不能说身高决定领导力——实验拆解发现身高影响的是沟通效能（下属微微仰视→瞳孔放大→注意力集中→沟通更精确）。基因正确打开方式：做研究的控制变量（终身不变是可靠基准）、给员工提供药物基因组学健康福利（比普通体检值钱）、保护员工基因隐私（保险公司已在收集基因信息准备差异化定价）。用法：别搞MBTI/基因算命招聘——看人就看实际干活的样子；把招聘时的性格测评环节砍了换成实际工作测试 |
| LY28 | 负向激励创造律 | 别再争该夸还是该骂——看你要培养什么人。脑科学发现：处理创新行为的脑区和处理消极情绪的脑区是重合的，负面情绪和创新高度相关。韦尔奇（GE传统制造）：员工不需要天天创新要缜密处理日常→激发左脑→正向激励；乔布斯（苹果不创新就死）：骂的是最有创造力的前20%天才→激发右脑→负向激励。伯克利实验：随意讨论/不批评头脑风暴各出2-3个新点子，鼓励争论+有理有据diss出7个以上。关键：不是一对一骂人，是在集体讨论会上"对事不对人"地建设性争论，分散痛苦，被批评后马上可能出好点子受表扬。用法：运营/客服岗多夸（日常执行类），内容/创意岗该骂就骂——选题会改成"这个方案哪里不行"的争论会，每个方案说出三个不行的理由 |
| LY29 | 意义感重塑律 | 年轻人觉得工作没意义、佛系，不是员工的错是社会变了。帕克尔主动性动机理论：员工要产生工作意义感+主动性需要两个条件——外部环境提供宽容的价值评价体系、外部有进步榜样/努力阶梯。过去20年两个变化动摇了这两个条件：职业超级繁荣（很多岗位社会价值没人知道，抢票软件的交互设计/流程管理价值外行看不见）、职业阶梯消失（去中心化公司没头衔看不到短期努力能升到哪）。解法两个方向：透明化（让社会看到每个岗位的价值，得到每周直播会/迪士尼片尾滚字幕加工种介绍）、重建阶梯（OKR个人目标要严肃对待，帮员工找短期目标和意义，只考核企业目标不考核个人目标OKR就白搞了）。用法：让团队每个人都知道自己的工作对冠生园这个百年云南品牌意味着什么，不是在打一份工；给一个清晰的成长阶梯（运营→主管→总监每步看得见）；和孩子聊他学的东西以后能干什么，别光说"考个好大学" |

## 三、组织诊断五步 SOP（跨项目复用）

遇到"这个团队怎么带/这个人怎么招/授权怎么不放走样/这家公司组织健康吗"类问题时按序走：

1. **先站组织逻辑（LY01+LY02+LY11）**：别站在自己（员工/老板）视角想问题，先看信息河流流向哪里（谁和谁非正式聊天）？管理动作是普世口号还是权变因人？领导力是老板个人魅力还是和团队的互动关系？→ 输出：组织真实状态判断，别被表象忽悠。
2. **盘个体（LY04+LY05+LY06+LY07+LY08+LY09+LY10）**：每个人情绪资源还有余量吗？动机是配角诱饵还是主角合伙人？角色在打架吗（一次只专注一个角色）？他忠于公司还是忠于职业赛道？需不需要跨边界帮他搞定家庭/社区？他处在哪个年龄段最在乎什么（持家者/学习者）？→ 输出：个体激励方案，别一概用工资。
3. **配团队（LY12+LY13+LY14+LY15+LY16）**：招人是照着最牛的人招同类，还是补角色缺口（实干家/创新者/协调者/熟虑者）？新人靠非正式小网络合群还是靠正式团建？领导该露情绪还是端完美人设？需不需要相对剥夺快速凝聚（临时组队）？有没有团体迷思症状（太团结/统一口径/自我审查）？→ 输出：团队配置+决策机制。
4. **塑组织（LY17+LY18+LY19+LY20+LY21+LY22+LY23）**：先搭班子还是先定战略？节点人物是谁资源该围着谁配？授权前答三问了吗（边界/辅导/风险谁担）？冲突被压制还是公开按规矩吵？政治行为第三类红线划了吗？知识是存地图还是存死文档？变革是CEO自上而下还是指望自下而上涌现？→ 输出：组织架构+变革路径。
5. **造前沿环境（LY25+LY26+LY28+LY29）**：环境启动效应做到了吗（圆桌/绿植/暖色调）？社会责任红线守住了吗（做坏事员工走）？创新岗有没有建设性争论？员工知道自己工作的社会价值和成长阶梯吗？→ 输出：环境+伦理+意义感收尾。

输出格式：结论先行（团队能打什么仗/组织健康红灯绿灯/核心动作）→ 每步证据 → 落点（冠生园10人团队/持仓公司诊断/孩子教育环境 行动项）。

## 五、边界

- 本包是**战术手册**，不做战略判断与财务分析（战略去 taoge-cognition-innovation-driver / taoge-cognition-hegang-driver；财务去 doubao-earnings-analysis）；不做产品定义与增长设计（去 taoge-cognition-product-growth-driver）。
- 学科立场：权变——A导致B必须加"在C条件下"，没有绝对真理；所有模型都是近10年实证研究结论，环境变了结论可能变。组织行为学是偏战术学科，别因战术勤奋掩盖战略懒惰（LY23终极忠告）。
- 模型置信度：LY01-LY29 均为 S级归档蒸馏（李育辉·组织行为学，2026-10-26）；本包选取其中跨项目复用率最高的24条为核心律，其余保留在 模型地图.md 备查。
- 更新规则：认知革命项目每新增组织/团队/个体相关模型，同步追加本包速查表与接线。
