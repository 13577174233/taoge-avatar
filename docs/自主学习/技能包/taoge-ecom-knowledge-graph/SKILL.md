# 知识神经网络图生成器

把「散落在多个文档、技能包、报告里的知识点」压成一张**放射式神经图**：内核是判断内核，内环是工作链，中环是知识域，域内是知识点，域间用语义化突触连线，并附两张可查表。产物是**零依赖单文件 HTML**（深色银河底 + SVG + 内联 JS），双击即看，可点击展开、悬停看语义。

## 一、先想清楚三层结构（出图前必做）

出图不是画关系网，是把项目的「判断逻辑」显性化。动笔前必须回答三件事：

1. **内核是什么**：这个项目靠什么做判断？写成一行公式，例如「一手事实 × 三套口径 × 可拍板结论」。内核是整个图的引力中心，所有域最终都服务于它。
2. **工作链是什么**：从原始素材到交付物，中间有几步不可跳过？通常 5-7 步（取数→对账→拆解→判断→归口→交付）。工作链是「时间轴」，知识域是「能力轴」，两者正交。
3. **知识域怎么切**：每个域必须是**可独立成章的知识边界**，不是部门名。判定标准：域内知识点能互相引用，域间靠少数几条语义明确的突触连接。经验值 8-12 个域、每域 4-6 个知识点、总量 40-60 个知识点、20-30 条突触。

域间连线必须带**语义类型**（口径链/经营链/证据链/节奏链/组织链/方法链），并在图下方表格里逐条写明「为什么连」。没有语义的连线等于没有连线。

## 二、准备数据（graph JSON）

按 [references/graph-schema.md](references/graph-schema.md) 写一份 JSON：`meta/stats/core/pipeline/quadrants/domains/models/links/carriers` 十个字段，每个知识点必须带 `d`（一句话定义）与 `src`（出处）。

出处纪律：知识点只能来自真实读过的材料（报告原文、技能包正文、档案卡、数据表）。读不到原始文件时，标注「以技能包蒸馏结论为准」，不得虚构页码或声称读过未读的文档。

## 三、出图

```bash
python3 scripts/build_graph.py <graph.json> [output.html]
```

不带第二个参数时，输出 `<graph 同名>.html`。脚本纯标准库，无第三方依赖。

改视觉尺度只改脚本顶部常量：`CX/CY` 画布中心、`VIEW` viewBox、`R_DOMAIN/R_PIPE/R_CORE/AE_R` 四个半径。**判定尺度是否够读的标准**：把 `svgW / viewBox宽` 当作缩放比，域节点文字 15 px × 缩放比 ≥ 8 px 才算可读；低于此值时放大半径与字号，或提高 `svg{min-width}` 让页面横向滚动（宁可滚动，不要缩到看不清）。

## 四、生成后必须自己验（三步，缺一步不算交付）

1. **JS 语法**：抽出 `<script>` 段落跑 `node --check`。语法错会让整张图静默空白（只有标题和统计卡），浏览器控制台报 `Uncaught SyntaxError`，而 `node --check` 能一行定位。
2. **渲染计数**：浏览器里读 `#domains g` / `#synapses path[data-link]` / `#models` 子元素数量，必须等于 JSON 里的域数、突触数，展开后等于该域知识点数。
3. **真实点击**：用坐标点击域节点（`click_xy` 用视口归一化 0-1000，坐标从 `getBoundingClientRect()` 换算），确认「展开→模型数增加、无关域淡化 5 个→再点收起归零」，并读 `console_messages()` 确认无错。只看渲染计数不点一次，等于没验。

## 五、已知坑（踩过就别再踩）

- **JS 对象字面量的引号错位**：`{"text-anchor":"middle",fill":"#fff"}` 被写成 `fill":"#fff"`，一个字符就让整张图不渲染。改完必须 `node --check`。
- **viewBox 过大**：内容半径写大、字号不跟，缩放到小窗口后节点只剩十几像素。尺度靠「半径+字号+min-width」三者一起调。
- **知识点环形均分重叠**：域内知识点按环均分，`AE_R` 不够时相邻文字互相压。按「相邻弧长 ≥ 文字宽度 × 1.6」估：字数 4-5 时 `AE_R` 取 150-180。
- **悬停 tooltip 被裁**：`#map` 设 `overflow-x:auto` 后，tooltip 若定位在图内会被横向裁掉，故 tooltip 用 `position:fixed` 贴光标。
- **四象限压到域节点**：象限框离域环留 ≥ 60 px 空隙，否则淡化态下会盖住域文字。

## 六、交付

产物落在用户的项目目录（不是 chats 日期目录），命名 `XXX知识神经网络图vX.Y.html`；同项目已有旧版时**保留旧版**不覆盖，用版本号区分，满足「可对比」。交付时用 `present_files` 给出 HTML，并在正文写清：内核是什么、几个域几层知识点、怎么看（先看内核→再看内环→点域展开→看两张表）。

## 失败模式与兜底

- 如果知识点来源互相矛盾 → 图上只留一条并标「口径待定」，不在图内做裁决。
- 如果节点超过可读上限 → 分层折叠：域内只展开代表节点，全量清单放文末。
- 如果没有机器可读的清单 → 先用正则抽取，抽不全的部分明确标「未上图」。
