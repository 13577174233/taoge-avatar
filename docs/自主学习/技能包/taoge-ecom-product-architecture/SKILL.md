# 电商产品架构规划（电商事业中心专用）

面向昆明冠生园电商事业中心的产品架构与产品线管理。核心价值：把产品从"一个个单品"提升为"结构化货盘+分阶段路线图"，支撑 2027 双战略产品与 SKU 精简目标。

## 判断模型接入（来自 taoge-jiahua-ecom-playbook）

货盘先定角色，再排 SKU。

- **M3 产品角色**：三层货盘每层标角色（引流/利润/形象/节庆专款）；角色独立考核，不共用一张 GMV 榜。
- **M5 用户资产**：新品评估加"复购与延展"一列，不只看首销与上新速度。
- **M7 让利治理**：促销款先算让利后毛利，再决定是否上架与备多少货。
- **M1 增长结构**：先看形状（节庆脉冲 vs 日常流水）再定新品目标；节令峰值抬起来的量不能当日销基线。

模型全文见 `../taoge-jiahua-ecom-playbook/references/ecom-thinking-models.md`。

## 产品架构框架（货盘三层，对接 2027 口径）

| 层 | 定位 | 2027 承接 | 价格带 | 毛利要求 |
|---|---|---|---|---|
| 引流款 | 低价自食/小克重尝鲜 | 小克重自食盘（超长蛋挞式打法：视觉×情绪×低门槛） | 60 元以下 | 不亏钱即允许走量 |
| 利润款 | 主推盈利单品 | 低糖云腿（300 万爆品第二增长点）、山珍云腿 | 60-150 元 | 毛利 >30% 才放量 |
| 形象款 | 高端溢价/礼赠 | 高端礼盒、B 端定制专供款（防比价） | 150-300 元+ | 礼盒净利率底线 6-8% |

**双战略产品分工**：山珍云腿=货架盈利盘（守京东/淘系搜索盘日销）；滇式健康点心=内容创新盘（抖音/小红书内容种草，跑通后导线下）。

**SKU 纪律（2027 权威口径）**：日常 100+→50+（Q1 启动 Q3 完成淘汰长尾）；中秋 90+；淘汰规则=动销×毛利×心智三维（连续 2 季动销<阈值且毛利<30% 即退）；上新 ≥12 款（低糖/短保 ≥6）、新品占比 ≥15%、TOP5 ≥60%、核心爆品复购 ≥20%。

**下市不是删链接**：进入下市评估的款先做四维评分（销量/毛利/复购心智/链接资产），再选留、改、并、退四类处置之一；单批次下市 ≤10 个 SKU 或 ≤15%，禁止一次全线清仓、禁止直接删除链接。判据、影响评估五项与六步执行顺序见 [references/delisting-decision.md](references/delisting-decision.md)。

## 价格带结构诊断（排新品之前先跑，最高优先级）

把在售 SKU 按**实卖件均价**（实收金额÷实卖件数，不用标价）分四档，每档只算三个数：SKU 数、金额占比、销量占比。

| 结构信号 | 判断 | 动作 |
|---|---|---|
| 单一档金额占比 >60% | 结构性依赖 | 先在该档内做规格/口味升级，不急着往外跳 |
| 某档 SKU 数与金额同时为 0 | 真空档 | 可用形象款占位，但必须同页给证伪条件 |
| 低档销量占比 >50% 而金额占比 <25% | 引流有效但不赚钱 | 靠组合装与规格升级提客单，不靠加价 |
| 单档 SKU 数占 60% 以上而金额不足 30% | 长尾堆积 | 进 SKU 精简清单，按角色而非销量一刀切 |

口径纪律：先确认数据表是「明细口径」还是「品类汇总口径」，两者覆盖盘不同（2026 年明细口径只覆盖总盘 47.8%）；合并表头、合计行、节令集中发货产线必须排除后再算。方法与本轮实证见 [references/price-band-diagnostic.md](references/price-band-diagnostic.md)。

## 毛利门槛测算链（立项前置，不可跳）

标价 → 到手价（标价 × 0.88）→ 平台扣点（5%）→ 履约（长保 4.5 元/单、礼盒 6.0 元/单、现烤 7.0 元/单）→ 单位成本上限 → 成本率上限 → 毛利门槛（引流 ≥25%、利润 ≥30%、形象/现烤 ≥35%）；礼盒另按净利率验算：到手价扣扣点、履约、产品成本、包装、推广费 5%、损耗 2% 后 ≥6%。

纪律：成本上限反算的毛利率与门槛存在 0.5 点级差异时，**不改数、不凑整**，标「以 3 月打样报价校准」；达不到门槛的款不进首批生产。测算表与示例见 [references/launch-gate-and-margin.md](references/launch-gate-and-margin.md)。

## 新品立项卡（要投首批钱的款才写）

固定字段：卡号 / 编号 / 名称 / 角色位 / 产品定义 / 价格定位 / 目标人群 / 核心场景 / 渠道打法 / RICE 四维 / 验证信号 / 证伪条件 / 首批投入。

- **RICE**：Reach×Impact×Confidence÷Effort（各 1-5，Effort 取倒数），满分 125；引流款与小批量测试款不折算评分，避免把「不投大钱」的款排出优先级。
- **验证信号**：30 天内可量化，≤3 条，每条带基线（例：非节令月日均 ≥40 箱，对照现烤 35.50 件下限）。
- **证伪条件**：达到即停，四类必查——检测不达标 / 30 天销量未达基线 / 毛利压不到门槛 / 退款或破损超限。

上市后建 30 天验证跟踪行（D7/D15/D30 三档，结论只能是 放量/维持/改/汰换），模板 `assets/30天验证跟踪表.xlsx`，填法与判据见 [references/launch-tracking-30d.md](references/launch-tracking-30d.md)；结论为「汰换」的直接进下市评估。

## 新品立项五维评分（承接 taoge-ecom-product-market-analysis）

对候选新品/架构新增项做证据型评估（评分 1-5 输出 进入/放弃/暂缓）：

1. 市场需求与规模（行业数据引用：机构—报告—页码）
2. 竞争格局与竞品对标（竞争简报见下）
3. 消费者需求与痛点（健康化/地域风味/情绪价值证据）
4. 定价与利润空间（毛利 >30% 门槛，按上方测算链算）
5. 供应链可行性（短保/冷冻/产能/合规——强制标糖 2027.3）

## 里程碑（H1 六节点，节令倒排）

1 月盘点定稿（SKU 下市清单、战略单品清单、立项书）→ **2 月标签与详情页合规改版（红线节点）** → 3 月打样与检测 → 4 月首批生产 → 5 月上市 → 6 月 30 天复盘。

合规硬约束：GB 28050-2025（预包装食品营养标签通则）与 GB 7718-2025 于 **2027-03-16** 实施，糖与饱和脂肪强制标示；检测报告未出，详情页不得宣称「低糖」；包装按 ≤3 层 / ≤3 公斤核查。

## 产品路线图（Now/Next/Later，月度+季度）

**Workflow**：读现状（月度销售分析的 TOP/滞销、分平台表现）→ 定操作（新增/调优先级/淘汰/迁移）→ 落图。

```
Now（本月-下月，资源已定）   Next（1-2 季度）            Later（半年+，验证后定）
低糖云腿饼02月上市          山珍扩容04月              现烤系列08月
荞麦03月                    小克重05月                松香饼09月
强制标糖合规改版02月底       蛋清饼06月                B端定制专供款
```

优先级：RICE 排序 + MoSCoW 定必须/应该有；评分=心智40%·销量30%·利润20%·口碑10%，优选"搜索量>曝光量"类目。

## 竞争简报（competitive-brief 本地化）

```
## 竞品简报：[竞品/品类]｜[日期]
### 货盘对标（SKU结构/价格带/爆品）
### 价盘监测（促销机制/到手价/折扣率——不打深折，官方立减15%机制让利）
### 内容与达人（主打卖点/种草话术/KOC结构）
### 渠道动作（平台布局/直播频次/专供款）
### 对我方产品架构的影响（补位机会/规避风险）
```

数据源：cqq-data（达人/商品/品牌查询）、taobao-product-data（竞品货盘）、电商平台后台、市场情报库（12-市场情报/）。空位判定与证伪条件见 [../taoge-ecom-product-market-analysis/references/competitor-gap-and-falsification.md](../taoge-ecom-product-market-analysis/references/competitor-gap-and-falsification.md)。

## 交付形态（论证件 + 执行表）

- **论证件**：报告（HTML/Word），承载判断、证据、竞品与类目推导；
- **执行表**：Excel 五表——00 说明（编号/密级/口径/留白）、01 新品总表（层别/角色/价格带/毛利门槛/节点/对应 OGSM/替代对象）、02 定价与毛利（到手价/扣点/履约/成本上限/成本率）、03 复购与合规、04 立项卡、05 里程碑排期；上市后接 30 天验证跟踪表（`assets/30天验证跟踪表.xlsx`），下市款接下市决策记录（`references/delisting-decision.md` 末节字段）；
- 用户只要「开发部门内容」时，执行表不复制竞品矩阵、类目分析、风险与不做清单；编号与报告原文一致，不重排不改号；
- 留白如实标（「待定」「原文未单列节点」「金额待打样报价锁定」），不填估算值充数。

## 与既有体系的衔接

- **情报**：taoge-ecom-market-intelligence 12项SOP技能2「货盘三层组合与选品打分」为同源框架，本技能管"架构与路线图"，情报技能管"证据与选品打分"；
- **销售**：taoge-ecom-monthly-sales 月度销售分析提供架构迭代的输入（爆款滞销/异动）；
- **新品**：taoge-ecom-product-market-analysis 管单点新品立项，本技能管产品线全局规划；
- **内容**：产品架构决定内容货盘叙事（低糖话术/云南食材叙事），对接 taoge-ecom-content-ops；
- **年度规划**：产品架构是 OGSM S 策略层产品策略的执行工具，对齐 taoge-ecom-annual-planning；
- **成稿质询**：报告落地前用 `../taoge-jiahua-ecom-playbook/references/adversarial-review.md` 做 P0-P3 对抗评审。

## 适用边界（2026-11-20 补）

- 适用：产品线组合、SKU 精简与下市、产品路线图、新品立项优先级、上市 30 天验证、价格带结构诊断。
- 不适用：单品详情页与卖点文案（走 `taoge-ecom-product-content`）、定价执行（走 `taoge-ecom-price-governance`）、新品的市场机会分析（走 `taoge-ecom-product-market-analysis`）。

## 失败模式与兜底

- 如果缺销量数据 → 用四维评分的主观项先排序，标注「待数据校验」。
- 如果下市引发链接权重担忧 → 走六步承接（清仓→承接→改链→观察），不直接删链接。
- 如果新品验证期数据不足 → 先按 D7 判断，不提前放量。
