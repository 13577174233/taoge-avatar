# 价格体系与渠道价格治理（电商事业中心专用）

毛利优先：2027 综合毛利率 +5 点、节令 +2 点。任何定价动作先过毛利底线，再谈销量。

## 口径纪律（先对齐再算数）

- 对外口径用**到手价**＝实付−券−补贴；毛利按**财务入账价**（扣退款与佣金后的净收入）计算。
- 成本三口径不可混用：内部结算价（工厂调拨）／实际成交价（消费者实付）／财务入账价（净收入）。
- 含税与不含税必须标注；同一页面不并列两种口径的数。

## 三段价格带（先定结构，再定 SKU）

| 段位 | 价格 | 任务 | 纪律 |
|---|---|---|---|
| 引流 | 32.9-36.9 | 拉新与试吃 | 不承担毛利任务，但不得低于成本线 |
| 主力 | 69.9-99 | 贡献约 70% GMV 与主要毛利 | 只做小幅让利，禁跨段打折 |
| 形象 | 168 封顶（298 已砍） | 立价格天花板 | 只涨不降，不参与任何促销机制 |

跨段打折等于自毁结构：引流款打到主力价，主力款就没有存在理由。

## 折扣授权矩阵（替代逐单特批）

按「渠道 × 客户 × SKU」三轴给上限，一张表定全年：

- 经销商综合折扣 **5 折天花板**；节令专供款单列，不并入综合折扣。
- 超额折扣走**特价审批**，并计入该客户**年度额度**；额度用尽即停，不再逐单开口子。
- 矩阵之外的成交价，一律先按窜货/价盘异常处理，而不是补审批。

模板与警戒线见 [references/price-governance-rules.md](references/price-governance-rules.md)。

## 让利底线（活动能不能上）

平台官方立减/满减（如立减 15% 起）叠加佣金与退货后，毛利率不得低于品类底线——礼盒净利率 6-8% 为警戒线。不达标时**改机制不改价**：改满赠、换规格、换货盘，不下调指导价。

## 佣金天花板

- 头部达人佣金 42% 直接击穿毛利，2027 目标压到 **20-25%**；净 ROI ≥1:2 才进池。
- 负毛利 SKU 禁止投达播；坑位费计入单品 ROI，不另开"推广费"账。
- 达播前必做三件事：调价、换品、压佣金；三件都没做就上，等于用毛利买 GMV。

## 控价与窜货

线上到手价（含券后）不得低于指导价下浮线；经销商专供款用独立条码与独立包装，跨区可扫码追溯；年框写明窜货罚则并与返利挂钩。

## 定价五步

1. 定成本口径（财务入账价）→ 2. 用脚本算毛利底线 → 3. 定价格带位置 → 4. 查授权矩阵 → 5. 落平台机制与活动备案。

## 脚本：反推最低成交价

```bash
python3 scripts/floor_price_calc.py --cost 12 --margin 0.35 --commission 0.20 \
  --fee 0.05 --return-rate 0.15 --shipping 4.5 --guide-price 69.9
```

输出综合留存率、最低可成交价（floor price）、对照指导价的最低可承受折扣；分母 ≤0 时明确报「不可达」并给出三条改法（降佣金／降退货率／改价差结构）。

## 适用边界（2026-11-20 补）

- 适用：三段价格带、渠道×客户×SKU 折扣授权、控价与窜货、活动让利底线、达人佣金天花板、毛利底线反推。
- 不适用：年度目标与预算（走 `taoge-ecom-annual-planning`）、产品架构与 SKU 取舍（走 `taoge-ecom-product-architecture`）、平台活动报名执行。
- 所有价格结论须写明含税/未税、到手价/标价口径。

## 失败模式与兜底

- 如果渠道价差无授权表 → 先出「现状价差表」，再定规则，不先承诺统一价。
- 如果成本不清导致毛利底线算不出 → 用倒推法给区间并显式写假设。
- 如果达人佣金超天花板 → 直接判「不做」，不给折中方案。
