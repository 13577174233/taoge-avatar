# 朋友圈文案创作

## 定位

朋友圈是熟人领地，不是广告位。文案像"一个 49 岁、读过书、卖过货、骑过车、喝过茶酒的人，今天想说的一句话"，不是营销物料。

## 人设三灯（取景原则）

写文案前先选光源，一种光源定一篇的基调：

- 阅读灯：谈书、谈认知、谈商业判断——引书不摆架子，落点在"我想通了"。
- 茶酒灯：谈事、谈人情、谈中年感悟——威士忌/白酒/普洱是道具，不是主题。
- 生活灯：骑行、追番、家人、日常——白描细节，不喊口号。

## 四类写法

### ① 个人生活分享

- 写具体到毛孔的细节：路况、气温、杯沿的香气、动漫里某一帧，不写"今天很开心"。
- 允许自嘲和笨拙，不允许精致表演。
- 结构：一个画面 → 一句感受，收在克制处。

### ② 人生感悟

- 克制、短、有留白。允许锋利，不允许说教。
- 落点是"我想通了/我认了/我变了"，不是"你们该学"。
- 允许一句金句收尾，但金句必须长在自己经历上。

### ③ 读书分享

- 一本书一句话：说清"这本书为什么触动我"，不剧透、不书单轰炸。
- 可带行业对照（财经/销售视角），但不摆知识架子。
- 结构：书名 → 一个观点 → 一个反差点（书里的/我自己经历的）。

### ④ 重要时刻激励

- 孩子关键节点、节庆、家庭时刻：有深意、有仪式感，可带诗性（如七言句）。
- 守住真实：祝福落点在具体的人和具体的事，不空喊。
- 例：中考/高考前夜，写"稳"不写"必胜"。

## 结构模板（四类通用）

钩子（一句具体的话或画面）→ 场景细节（1-2 句）→ 落点（感悟或祝福，一句收住）。

## 红线

- 不刷屏：一条只讲一件事，重要时刻才有长篇。
- 拒绝微商腔：家人们/亲/最后三天/限时抢购，一律不用。
- 不堆感叹号、不堆 emoji（用户不要求时不用 emoji）。
- 不暴露他人隐私（孩子学校、家庭住址、同事姓名）。
- 配图原生感优先：真实照片 > 精致海报。

## 去 AI 味

定稿前自检：删掉空话、万能金句、排比轰炸；如果一段话换个人也能发，重写。需要时配合 doubao-human-signal 校准。

## 认知革命接线（2026-10-30）

文案的情绪洞察与积极底色接线：

接线来源与能力定位：
- taoge-psych-wuzhihong：武志红心理模型（304模型），情绪真实度/关系动力/自我表达，帮文案挖到"真感受"而非表演
- taoge-psych-positive：赵昱鲲积极心理学模型（32模型），积极情绪/感恩/心流/品格优势，给感悟与祝福提供有厚度的正向落点

业务调用入口：
- 人生感悟类 → taoge-psych-wuzhihong 照见真实情绪（不自欺、不说教），taoge-psych-positive 收束到成长/感恩/优势的落点
- 读书分享类 → 两线交叉：武志红照见书中人物的关系模式，赵昱鲲落到"我想通了"的积极建构
- 重要时刻激励（孩子节点/节庆/纪念日）→ taoge-psych-positive 的祝福心理学（具体感恩+品格肯定），守住"稳"不喊"必胜"

## 平台机制与合规基线（2026-11 更新）

朋友圈是熟人关系场，不是算法分发场：一条内容能走多远，取决于有多少人愿意停一下、评一句。所以真实细节的权重远高于排版技巧。[经验]

**微信官方规则（硬红线）**：

- 禁止利诱分享：集赞、转发抽奖、分享解锁、邀请好友拆礼盒、分享增加抽奖机会，均属违规。
- 禁止胁迫煽动分享：如"不转不是…""转发保平安""请好心人转发"。
- 个人账号发布违规品营销信息，严重者永久封停；一般违规按阶梯处置（警告→限制功能→封停）。
- 官方已辟谣：好友数量多、长期固定地点登录、点赞频繁本身不会被封号，此类"新规"传言均不成立，不要据此自我设限。

出处：《微信个人账号使用规范》12.1；微信安全中心 2026-01 辟谣（光明网报道）。

**实操四则**：

1. 一条只讲一件事；只有重要时刻才写长。
2. 频率按需，不设日更指标，不为凑条数发。
3. 评论区是二次曝光位：不只用"谢谢"回，回一句具体的话（问细节、补一句后续）。
4. 配图 1-3 张，真实照片优先；要做海报时走 taoge-content-visual-prompt 的"素人抓拍"模板，不做商业海报感。

**版本**：v1.1（2026-11-08）新增平台机制与合规基线；原有四类写法、人设三灯、结构模板未改。

## 适用边界（2026-11-20 补）

- 只写朋友圈短文案（生活分享/感悟/读书/节点激励）。
- 不适用：小红书正文、公众号长文、发布与配图生成。

## 失败模式与兜底

- 如果素材不足 → 只写一句真话，不编细节。
- 如果读起来像广告 → 删卖点，改场景。
- 如果过度文艺 → 砍形容词，留动作与事实。
