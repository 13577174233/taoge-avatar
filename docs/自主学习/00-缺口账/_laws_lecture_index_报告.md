## 三、锚点问题诊断（本次查实）

| 项 | 事实 |
|---|---|
| 现象 | `anchor_locate_lecture.py` 连续多批输出「待定位 180／命中 0 (0.0%)」 |
| 此前猜测 | 锚点句与原文标点、全半角不一致导致匹配失败 |
| 实际根因 | 这 180 条全部是 **B 级条目的"概括式锚点"**（如 D244「现实世界中，套利有成本，有风险，收益不确定」），系撰写时对原文的提炼，原文并无此句，`rg -F` 字面检索必然 0 命中 |
| 影响面 | 仅 B 级 180 条；A 级锚点 1,166 条正常 |
| 已定纪律 | **新律「锚点句」字段必须逐字抄自原文（可直接 `rg -F` 命中）**；概括语移入"一句话"或"怎么用"，不得占锚点句位 |
| 处置 | 存量 180 条不强行回填，留作 B 级"意图句"；如需升级，只能回原文重抄。脚本无需改算法（算法本身正确） |
