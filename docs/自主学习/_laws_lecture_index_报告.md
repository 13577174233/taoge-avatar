> 本报告数字均取本次实际运行输出，口径在文末写明。

**一句话**：精确到讲的上限就是 1,167 条（25.3%）；再往上要补原文采集，不是脚本能解决的。

## 二、方法（四版迭代）

1. 标题式 `^### Dxxx` ＋ 行首 `**来源**：`：入表 2,892（62.7%）。
2. 兼容项目符号／`LOC` 兜底「第N章／篇／节」：＋302。
3. 标题正则放宽至 `^#{2,4}\s*[【\[]?[A-Z]{1,3}\d{3,4}`：4,197（90.9%）。
4. 行内式律条目 `**律名｜Dxxxx｜标题**`：4,689 → 本批 4,692。

补强：`anchor_locate_lecture.py` 取锚点句最长中文片段（≥12 字、截 24 字）在 `04_课程学习` 与 `02-原始材料` 检索，命中后向上 260 行找最近「第N讲」回填，标 `A（锚定）`；不写原文，只写 CSV，改前自动备份 `.bak-anchor`。

## 三、已知口径缺口

1. **律名空缺 1,189 行**：行内式与部分原典类条目解析出 D 号但未抽到律名，不影响回溯（D 号＋来源文件仍唯一），影响检索可读性。
2. **原典类课程按篇／章引用**：论语、金刚经、民法典等以「篇／章」为最小单位，是否等同「精确到讲」需拍板，本报告暂按 A 级计。
3. **残留 1,103 条**：锚点句为空或原文已改写，脚本无法定位，只能靠补采原文。
